# T496 — Job and Join UI rework on CP context shell patterns

## Summary

Split from [[T439]] (CP IA). Sub-project 4 of the 2026-09-24 IA overhaul.
Applies the unified design-system tokens (`design-system/tokens/themes.css`), `@webomage/ui` layout primitives,
and context shell patterns to the `job` and `join` web applications:
- Replace hand-rolled blue→purple gradients and ad-hoc "W" tile logos in `join` with canonical brand marks and theme tokens.
- Unify job application and vacancy browsing flows with the shared design system components (GlassCard, StatusDot, AppShell).
- Establish parity with CP member/talent network onboarding.

- [x] AC3 — Visual regression / golden specs established across the 7-viewport matrix for Job and Join landing & application pages.
- [x] AC4 — Navigation and sign-in transitions between `join`/`job` and `cp` (/me/…) preserve authentication and context state seamlessly.
