# T709 — Evaluate tablinux (linuxontab) claw Package to Replace zeroclaw Functions Across w0m

## Summary

Audit the `claw` package in `tablinux` (`w0m-pr/linuxontab`) against all `zeroclaw` functions and references across `@wom` (`w0m-cf`, `w0m-api`, `w0m-web`, and `project/policies/`). Produce a capability-by-capability parity matrix, security/runtime footprint comparison, and weighted decision (AgDR) on replacing our `zeroclaw` functions with `tablinux`'s `claw` package, followed by clean cutover or scoped migration tasks.

## Acceptance criteria

- [x] AC1 — **Inventory All `zeroclaw` Functions & Callers Across `@wom`:** Catalog every `zeroclaw` function, worker binding, endpoint, test suite, and policy entry across `w0m-cf`, `w0m-api`, `w0m-web`, and root scripts (`just search "zeroclaw"`).
- [x] AC2 — **Inspect `tablinux` (`w0m-pr/linuxontab`) `claw` Package Architecture & Capabilities:** Analyze the `claw` package in `linuxontab` (interfaces, runtime dependencies, sandboxing, IPC/RPC transport, resource overhead, and license/security posture).
- [x] AC3 — **Capability Parity Matrix & Weighted Replacement Decision:** Compare `tablinux` `claw` vs `zeroclaw` across latency, Cloudflare Free-Tier / edge compatibility (`AgDR-0055`), security isolation, and maintenance burden, and record a weighted decision in `.agents/reports/t709-tablinux-claw-vs-zeroclaw-and-settings-persistence-audit.md` (`w0m-web/docs/reports/t709-tablinux-claw-vs-zeroclaw-and-settings-persistence-audit.md`).
- [x] AC4 — **Cutover Specification or Replacement Execution:** Wire `claw-parity` and `claw-exec` (`CLAW_YOLO=0`, `--no-tools` / `--confirm`) in `scripts/zeroclaw_manage.py`, normalize cross-platform `client_audit.allowed_roots` in `w0m-web/project/zeroclaw/config.template.toml`, and persist `terminology_theme` across `localStorage`, `CpShell.svelte`, and `CoreSettingsManager.svelte`.

## Definition of Done

Per [`w0m-web/openspec/SPEC-AUTHORING-STANDARD.md`](../w0m-web/openspec/SPEC-AUTHORING-STANDARD.md):
