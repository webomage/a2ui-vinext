# T423 — Orca registry hygiene, rerere installer, and a warn-only main-checkout commit observer

## Summary

Phase 0 of the accepted parallel-agents plan
([report](../.agents/reports/2026-09-23-parallel-agents-isolation-and-merge-proposal.md) §4 Phase 0,
§6 Q1). It runs in parallel with [[T408]] and has no dependencies.

Measured 2026-09-23:
- `orca repo list` does not include `wom7func`.
- It still lists `wom7cfworkers`, whose directory no longer exists.
- It registers `orca` via the `_in/orca` symlink instead of `wom7pr/orca`.
- `rerere.enabled` is unset in every repo.
- Git cannot tell agent commits from human ones: the last 70 root commits and 100 wom7web commits all
  carry one identity. Whether non-Claude agents (Codex, Antigravity, OpenCode, run by Orca inside a
  PTY) expose a TTY to their shell tools is **unmeasured**.

The observer produces that measurement before [[T426]] turns the gate strict (decision Q1: observe
first, then land-only).

## Acceptance criteria

- [ ] AC1 — `orca repo list` shows `wom7func`, no `wom7cfworkers`, and `orca` at `wom7pr/orca`
  (paste before/after output in Status notes).
- [ ] AC2 — A versioned installer enables `rerere.enabled=true` and `rerere.autoupdate=true` in the
  root and in every repo listed in `.w0m/sdlc.json`. It follows the `scripts/install_hooks.py`
  pattern: idempotent, prints what it changed, and has a test.
- [ ] AC3 — A warn-only pre-commit **observer** runs in the *main* checkouts of the root, wom7web,
  wom7api and wom7func, and is skipped in linked worktrees. Per commit it appends one JSONL line to
  `~/.cache/w0m/main-checkout-commits.jsonl` with: ts, repo, cwd, `/dev/tty` openable, `stdin.isatty()`,
  parent-process chain (names), `W0M_LAND`, `W0M_OWNER_COMMIT`.
- [ ] AC4 — The observer **never blocks a commit**. If the log write fails, it prints one warning line.
  The hook header states that it is advisory by design (not a silent fallback, AgDR-0025). Tests
  cover: log written, log unwritable, and linked worktree skipped.
- [ ] AC5 — At least one real commit from each agent kind in use (Claude, Codex, Antigravity/OpenCode
  via Orca) is captured in the log, and the TTY result per kind is recorded in Status notes. This is the
  input to [[T426]].
