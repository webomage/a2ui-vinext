# T483 — Purge Hostinger MCP configurations, background processes, schemas, and estate residue

## Summary

Owner direction (2026-09-28): *"we do not need hostinger anymore anywhere, purge it from mcp, etc"*.
Hostinger was previously decommissioned from active stack use (Project 1945 paused; zero WP/hosting assets in estate), but residue remained across multiple layers:
1. Active background processes: 42 running node/npm MCP processes (`hostinger-*-mcp`).
2. MCP configurations: Declared in `~/.claude.json`, `~/.gemini/config/mcp_config.json`, and `~/.gemini/antigravity/mcp_config.json`.
3. Tool schemas: 21 schema directories across `~/.gemini/antigravity-cli/mcp/`, `~/.gemini/antigravity-ide/mcp/`, and `~/.gemini/antigravity/mcp/`.
4. Local credentials: `~/.config/hostinger-mcp/credentials.json`.
5. Estate SDLC declarations: 6 decommissioned entries in `.w0m/sdlc.json`.

This ticket executes the total purge of Hostinger across processes, configurations, tool schemas, credentials, and estate metadata, proving zero running processes and zero MCP declarations remain.
