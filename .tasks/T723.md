# T723 — Collapse Public `/services` and `/solutions` to 1-Click Fast Register + Direct Package Checkout and Keep Source/Target Infra Selector Strictly Post-Signup in `/o/[org]`

## Summary

Eliminates duplicate pre-signup infrastructure questionnaire friction on public `/services` and `/solutions` (`w0m-web/apps/web/src/components/services/ServiceActionOrderConfigurator.svelte`, `w0m-web/apps/web/src/components/pages/ServicesPage.astro`, `w0m-web/apps/web/src/components/pages/SolutionsPage.astro`, `w0m-web/apps/web/src/components/templates/sections/SolutionsGrid.astro`, `w0m-web/apps/web/src/components/templates/sections/ServicesDetailed.astro`). Removes the pre-signup Step-2 infrastructure selector form (`Source Infra`, `Target Infra`, `Involved Workloads`, `Cutover Timeline`, and `Scope Notes`) from public pages so every Service and Solution card routes straight into **1-Click Fast Register (Google / GitHub / LinkedIn OAuth SSO or Work Email Magic Link)** or **Direct Fixed-Price Stripe Checkout**, while keeping the detailed 3-step Source/Target Infrastructure & Workloads selector strictly inside the authenticated `/o/[org]` post-signup Onboarding Wizard (`w0m-web/apps/cp/src/components/client/ClientDashboard.svelte`).

## Acceptance criteria

- [x] AC1 — **Remove Pre-Signup Step-2 Infra Questionnaire from Public `/services` & `/solutions` (`w0m-web/apps/web/src/components/services/ServiceActionOrderConfigurator.svelte`, `w0m-web/apps/web/src/components/pages/ServicesPage.astro`, `w0m-web/apps/web/src/components/pages/SolutionsPage.astro`):** Collapsed `w0m-web/apps/web/src/components/services/ServiceActionOrderConfigurator.svelte` from a 3-step questionnaire into a compact 2-step **Choose Package/Service → 1-Click Fast Register & Direct Package Checkout** surface, removed `service-order-step-infra` (`service-order-source-infra`, `service-order-target-infra`, `service-order-workloads`, `service-order-timeline`, `service-order-scope-notes`, `service-order-infra-next-btn`, `service-order-skip-infra-btn`) from public pages, simplified each catalog card from 4 buttons to 2 crisp actions (`Checkout ($X)` + `Fast Register`), fixed the double-`$$` price label bug, and kept 1 optional domain/repo URL input alongside 1-click OAuth (`Google`, `GitHub`, `LinkedIn`) + Work Email Direct Checkout.
- [x] AC2 — **Streamline `/solutions` and `/services` Card Triggers Direct to Fast Register / Direct Checkout (`w0m-web/apps/web/src/components/templates/sections/SolutionsGrid.astro`, `w0m-web/apps/web/src/components/templates/sections/ServicesDetailed.astro`):** Updated `w0m-web/apps/web/src/components/templates/sections/SolutionsGrid.astro` and `w0m-web/apps/web/src/components/templates/sections/ServicesDetailed.astro` CTA labels and `wom:select-service-order` handlers so clicking any Solution or Service Track card selects the service/mode, seeds service defaults for the post-signup wizard, and scrolls directly to `#service-order-step-register` (`1-Click Fast Register & Direct Checkout`) with Turnstile mounted immediately.
- [x] AC3 — **Verify Post-Signup `/o/[org]` Infra Selector Exclusivity & Regression Suite (`w0m-web/apps/web/src/tests/service-action-order-configurator.test.ts`, `w0m-web/apps/cp/src/components/client/ClientDashboard.svelte`):** Updated `w0m-web/apps/web/src/tests/service-action-order-configurator.test.ts` to assert that public `w0m-web/apps/web/src/components/services/ServiceActionOrderConfigurator.svelte` contains zero pre-signup `service-order-step-infra` / `service-order-source-infra` / `service-order-target-infra` / `service-order-workloads` questionnaires while `w0m-web/apps/cp/src/components/client/ClientDashboard.svelte` (`cp-onboarding-service-wizard`) retains the full post-signup Source/Target Infra, Workloads, and Cutover Timeline configurator inside `/o/[org]`, passing Vitest, `svelte_typecheck_ratchet.py`, `just ds-conformance`, and `just ui-ticket-leak-check`.
