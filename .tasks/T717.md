# T717 — Complete Google Elephant-Goldfish Model (`egm-*`) Companion Vendoring (`agents/`, `resources/`, `docs/`) & Harden `audit_vendoring.ts` + `version.ts` Checks

## Summary

Reality audit of `google/elephant-goldfish-model` (`webomage/elephant-goldfish-model`) after [[T705]] revealed that `T705` vendored only the 7 `w0m-skills/skills/egm-*` directories without the 10 Goldfish reviewer persona files (`w0m-skills/skills/egm-review/agents/*.md`), 5 qualitative document standards (`w0m-skills/skills/egm-review/resources/document_standards/*.md` + `w0m-skills/skills/egm-review/resources/execution_instructions.md`), or harness setup docs (`w0m-skills/skills/egm-review/docs/{codex,claude,harnesses}.md`). Vendor all companion personas, document standards, and harness docs into the canonical `egm-*` units in `w0m-skills` while keeping every `SKILL.md` byte-identical to upstream (`origin: "imported"`), govern escaping repo-root pointers in `w0m-skills/docs/vendoring-decisions.json`, and harden `w0m-skills/scripts/audit_vendoring.ts` + `w0m-skills/version.ts` so `agents/` and `resources/` companion omissions fail at `pre-commit`.
