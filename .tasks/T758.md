# T758 — Balance homepage hero CTA spacing

## Summary

The homepage hero CTA band ("Start With Free Audit" / "Explore Blueprints") renders with
16px of padding above the buttons (`pt-4`) and 32px below (`pb-8`), because
`apps/web/src/components/pages/HomePage.astro` passes `class: "pt-4 pb-8"` to the `cta`
section (the T221-era class) while the services section beneath it contributes no top
padding of its own. Owner feedback (screenshot `verify_v2_web_home_desktop.png`,
2026-11-16): the gap above the CTA row looks too tight; it should equal the gap below.

Fix: change the CTA section class from `pt-4 pb-8` to `py-8` so vertical padding is
symmetric (32px above and below), keeping the T221 invariant (positive padding only —
never a negative margin that overlapped the hero). Single-file, single-class change;
no other page is affected (ServicesPage passes its own `py-2`).
