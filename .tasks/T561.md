# T561 — Build multi-platform Outreach & Clipping Vault schema, source_links integration, and outreach-clip-ingest Edge Function

## Summary

Create the provider-agnostic, owner-scoped **Outreach & Clipping Vault** in Postgres (`public.outreach_clips`, `public.outreach_threads`, `public.outreach_messages`) and the `outreach-clip-ingest` Supabase Edge Function per `AgDR-0033` and `AgDR-0029`, enabling members and org managers to ingest clipped jobs, profiles, proposals, contracts, and message threads from any freelancer or professional platform (Upwork, LinkedIn, Contra, Toptal, Freelancer.com, Fiverr Pro, Wellfound, X-Team, Indeed, and generic web pages) while keeping the `upwork.*` mirror schema strictly untouched (`T468`/`T533`).

## Acceptance criteria

- [x] AC1 — **Database Migration (`outreach_clips`, `outreach_threads`, `outreach_messages`).** Add idempotent migration creating `public.outreach_clips`, `public.outreach_threads`, and `public.outreach_messages` with platform/clip_type/status CHECK constraints, `content_hash` deduplication (`UNIQUE (profile_id, source_url, content_hash)`), optional `org_id` commercial linkage, and foreign keys to `public.contracts(id)` and `public.proposals(id)`.
- [x] AC2 — **Strict Owner & Org RLS + Column Grants (`authz_probe_suite.py`).** Enforce `profile_id = public.current_profile_id()` for member rows and `wom_is_org_member(org_id)` for org-linked rows, `REVOKE ALL` from `anon`, and add live red/green probes in `wom7web/project/scripts/authz_probe_suite.py` (`X39-outreach-vault-grants-and-rls`) proving `anon` and cross-member reads return 0 rows.
- [x] AC3 — **`source_links` & Evidence Passages Integration (`AgDR-0029`).** Link promoted clips and threads to `public.contracts`, `public.proposals`, and `public.projects` via `public.source_links`, and index vetted message/proposal snippets into `public.upwork_evidence_passages` (`source_kind: 'outreach_clip' | 'outreach_message'`) for `w0m-personnel` RAG retrieval via `public.wom_promote_outreach_clip`.
- [x] AC4 — **`outreach-clip-ingest` Edge Function & Deno Tests.** Implement `wom7api/supabase/functions/outreach-clip-ingest/{index.ts,handler.ts,handler.test.ts}` verifying the caller's JWT, stripping `<untrusted_participant_content>` and script/HTML injection tags recursively, upserting `outreach_clips` by `(profile_id, source_url, content_hash)`, auto-threading messages into `outreach_threads` + `outreach_messages`, and returning structured clip/thread IDs. Verified by `just deno-check` and `just deno-test`.
