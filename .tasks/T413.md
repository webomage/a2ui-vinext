# T413 — Surface build hints in build log analyzer and automate hint remediation

## Summary

Build diagnostics and typechecking (`astro check`, TypeScript) emit informative **hints** (such as `ts(6385)` deprecation notices and `ts(6133)` unused declarations) across monorepo web applications (`web`, `cp`, `join`, `job`, `demo`). Historically, these hints have been remediated manually in one-off sweeps (e.g. T115, T405) after accumulating silently.

This ticket raises the level of monitoring up to hints in the build log analyzer (`project/scripts/push_report.py`), enabling it to parse diagnostic hints across all source extensions (`.astro`, `.ts`, `.tsx`, `.svelte`, `.js`), categorize them in the Pre-Push Final Report, and provide automated remediation tooling (`just fix-hints` / `project/scripts/fix_hints.py`) to systematically resolve common patterns (such as migrating deprecated `src/lib/supabase.ts` clients to `staffAdminClient`/`userClient`) in the same manner as errors and warnings.

## Acceptance criteria

- [ ] AC1 — Extend `project/scripts/push_report.py` to parse build and typecheck hints: Match `.astro`, `.ts`, `.tsx`, `.svelte`, and `.js` diagnostic messages from `astro check` (including `ts(6133)`, `ts(6385)`, and summary `- X hints`), and categorize them into `astro-check` / `build-hints` in `push_report.py`.
- [ ] AC2 — Wire hint monitoring into pre-push and build reporting so that build hints for web applications are tracked and displayed with high visibility alongside warnings and ratchets in the Pre-Push Final Report.
- [ ] AC3 — Implement automated hint remediation script `project/scripts/fix_hints.py` and register `just fix-hints` recipe in `wom7web/justfile`: Provide automated codemod fixes for systematic deprecation hints (specifically rewriting legacy deprecated `import { supabase } from ...` to `staffAdminClient` / `userClient`) and unused declarations.
- [ ] AC4 — Remediate the existing 17 `ts(6385)` deprecation hints in `apps/cp` so `pnpm --filter cp exec astro check` reports 0 errors, 0 warnings, 0 hints.
- [ ] AC5 — Author unit tests in `project/scripts/tests/test_push_report.py` and `project/scripts/tests/test_fix_hints.py` covering hint parsing across diverse file extensions and verifying automated remediation idempotence.
- [ ] AC6 — Verify all quality gates pass cleanly (`just push-report-test`, `just typecheck`, `just test`, `just ticket-schema-check`).
