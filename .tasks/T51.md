# T51 — Implement Obsidian Vault ZIP import in Resource Library

## Summary

Add a user-friendly "Import from Obsidian" button inside the Control Panel Resource Library. The button will accept a `.zip` vault export containing markdown files, extract them client-side or server-side, chunk the contents by markdown heading elements, and batch-upload them through the existing `manage-document` Supabase Edge Function to populate the RAG vector search index.

## Acceptance criteria

- [x] AC1 — "Import from Obsidian" upload button integrated into the CP Resource Library interface.
- [x] AC2 — Upload handler extracts markdown text from files inside the uploaded `.zip`.
- [x] AC3 — Headers and sections parsed correctly into individual chunks.
- [x] AC4 — Chunks are batched and pushed successfully to `/functions/v1/manage-document`.
- [x] AC5 — Progress bar or status indicators show completion rate during batch upload.

## Status notes

✅ **2026-10-20 — Completed (AC1–AC5):**
- Implemented `extractMarkdownFromZip`, `parseObsidianMarkdownChunks`, `chunkObsidianVault`, and `uploadObsidianChunksBatch` in `wom7web/apps/cp/src/lib/obsidian-zip.ts` (supporting STORE and DEFLATE `.zip` archives, ignoring `.obsidian/`, `.trash/`, `__MACOSX/`, and splitting by ATX heading hierarchy while respecting code fences).
- Integrated "Import from Obsidian" `<Button>` (`@webomage/ui`) and real-time completion progress bar (`data-testid="obsidian-import-progress"`) into `wom7web/apps/cp/src/components/admin/ResourceLibrary.svelte`, improving `ds-conformance` metrics (`hex_occurrences` -3, `native_button_uses` -6).
