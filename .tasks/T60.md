# T60 — Implement GEO Metrics Tracker & llms.txt

## Summary

Build and deploy a Generative Engine Optimization (GEO) tracking pipeline to measure brand Share of Voice (SOV) and citation rates. Setup a daily cron trigger running prompt-test lists against search-enabled model pools (Perplexity Sonar API), saving metrics to Supabase, and compile a canonical `llms.txt` file at the web app root.

## Acceptance criteria

- [ ] AC1 — Create and serve a canonical `llms.txt` at the root of `webomage.com` mapping site collections.
- [ ] AC2 — Build a cron worker script `scripts/geo_tracker.ts` using the Perplexity Sonar API.
- [ ] AC3 — Setup a Supabase table `geo_metrics_history` and verify database logging of brand mentions, sentiment, and URLs.
- [ ] AC4 — Render tracking results in the Admin Control Panel dashboard.
