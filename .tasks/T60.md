# T60 — Implement GEO Metrics Tracker & llms.txt

## Summary

Build and deploy a Generative Engine Optimization (GEO) tracking pipeline to measure brand Share of Voice (SOV) and citation rates. Setup a daily cron trigger running prompt-test lists against search-enabled model pools (aligned with [[T36]] `AC2`: `cloudflare` primary + `google` search-grounded models, with Perplexity Sonar-compatible citation parsing), saving metrics to Supabase, and compile a canonical `llms.txt` file at the web app root.

## Acceptance criteria

- [x] AC1 — Create and serve a canonical `llms.txt` at the root of `webomage.com` mapping site collections (`wom7web/apps/web/public/llms.txt` and `llms-full.txt`).
- [x] AC2 — Build a cron worker script `wom7web/project/scripts/geo_tracker.ts` and core library `wom7web/packages/lib/src/seo/geo-tracker.ts` (+ unit tests `geo-tracker.test.ts`) running the canonical GEO prompt-test battery, computing Share of Voice (SOV %), sentiment, and cited URLs across allowed search-grounded providers (`cloudflare` + `google` per [[T36]] `AC2`).
- [x] AC3 — Setup a Supabase table `public.geo_metrics_history` (`wom7api/supabase/migrations/20261022180000_t60_geo_metrics_history.sql`) with RLS, admin/service_role policies, and verify database logging schema for brand mentions, SOV %, sentiment, and cited URLs.
- [x] AC4 — Render tracking results in the Admin Control Panel dashboard via `wom7web/apps/cp/src/components/admin/GeoMetricsDashboardCard.svelte` mounted on `wom7web/apps/cp/src/pages/admin/index.astro` using `@webomage/ui` primitives and CSS tokens.
