# T60 — Implement GEO Metrics Tracker & llms.txt

## Summary

Build and deploy a Generative Engine Optimization (GEO) tracking pipeline to measure brand Share of Voice (SOV) and citation rates. Setup a daily cron trigger running prompt-test lists against search-enabled model pools (Perplexity Sonar API), saving metrics to Supabase, and compile a canonical `llms.txt` file at the web app root.
