# T760 — Goal-aware Guided Q&A stack step

## Summary

The on-site Expert Consultation "**Guided Q&A**" funnel (`apps/web/src/components/ChatApp.svelte`)
asks Step 1 for a goal, then Step 2 for the current cloud/runtime stack — but Step 2 renders the
same fixed four options regardless of goal:

- `Cloudflare + Edge / Serverless`
- `AWS / GCP / Azure`
- `Self-Hosted / Hybrid`
- `Greenfield (Recommend Stack)` → `selectGuidedStack(..., infra: "none", deploy: "serverless")`

Two owner-reported problems (screenshot 2026-11-16):

1. **Contradiction:** for `Goal: Cloud Migration / Hardening` a "Greenfield" answer is
   self-contradictory — migration implies an existing estate; `goal: "Cloud Migration / Hardening"`
   paired with `infra: "none"` is lead-qualification noise, and the "(Recommended Stack)" hint
   steers the wrong way for that goal. It is also a hard puzzle for "Free Security + Lighthouse
   Audit" (pre-launch audits are the only greenfield case there).
   "Deploy Production Blueprint" and "Custom Web / AI Platform" are the natural greenfield goals.
2. **Copy bug:** the label reads "Recommend Stack" (verb); it should be "Recommended Stack"
   (adjective). The label feeds `guidedSurveyStack` verbatim into the intake summary and lead
   context.

Fix (minimal, single file): make Step 2 **goal-aware** — show `Greenfield (Recommended Stack)`
only for the two start-from-zero goals (`Deploy Production Blueprint`, `Custom Web / AI Platform`);
for `Cloud Migration / Hardening` replace it with an honest **"Not sure — assess my current
estate"** button mapping to the same `infra: "none", deploy: "serverless"` intake path (no
discovery probes attached); for `Free Security + Lighthouse Audit` use the same "Not sure" variant.
All labels spelled "Recommended".
