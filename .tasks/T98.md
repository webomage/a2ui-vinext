- [ ] AC1 — **Sales Navigator sourcing trial**: Conduct a structured sourcing run using LinkedIn Sales Navigator advanced search filters (roles, seniority, skills, geography) to identify candidate and business prospect cohorts strictly via manual navigation.
- [ ] AC2 — **Manual pipeline intake into LeadManager**: Ingest a curated batch of sourced leads into `LeadManager` on `apps/cp/src/pages/business/leads.astro`, testing field mapping (name, title, company, URL, notes) and verifying deduplication against existing records.
- [ ] AC3 — **Enrichment evaluation for profile_snapshots**: Assess and document whether data points from Sales Navigator profile unlocks and views provide actionable enrichment for `profile_snapshots` and candidate evaluation over standard public profile views.
- [ ] AC4 — **InMail response and funnel conversion metrics**: Log and measure response rates, communication quality, and screening conversion across a trial batch of InMail messages, establishing cost-per-response benchmarks.
- [ ] AC5 — **ToS boundary and anti-scraping guard verification**: Review and certify that `wom7ext` and backend automated tools remain completely isolated from authenticated LinkedIn Premium/Sales Navigator sessions to eliminate account ban and reputational risks.
- [ ] AC6 — **Paid seat Go/No-Go and API partnership assessment**: Produce a written evaluation report concluding with a clear Go/No-Go recommendation on a dedicated paid recruiter seat based on ROI metrics, along with an analysis of applying for the official LinkedIn Talent and Marketing Developer Partner API programs.
