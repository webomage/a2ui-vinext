# T782 — Achieve 100/100 mastered passive domain audit across webomage.com, me., and cp. and fix Linux daily audit NOT RUN checks

## Summary

Brings `webomage.com`, `me.webomage.com`, and `cp.webomage.com` to full 100/100 Grade A parity under `runPassiveDomainAudit()` and eliminates every `NOT RUN` / `SKIP` blind spot in the daily Linux audit (`scripts/w0m_audit.py`):

1. **RFC 7489 / RFC 7208 Subdomain DMARC & SPF Handling (`passive-audit.ts`):** Fixes false-negative `dns 0/25` failures on `me.webomage.com` and `cp.webomage.com` by adding `extractOrganizationalDomain()`, `_dmarc.<orgDomain>` inheritance lookup per RFC 7489 (evaluating `sp=` / `p=`), and non-mail subdomain MX + apex SPF checking per RFC 7208.
2. **Cloudflare DNSSEC, CAA & Null-SPF IaC (`w0m-api/cloudflare/`):** Declares `cloudflare_zone_dnssec` for `webomage.com`, `CAA` certificate-authority constraints, `sp=quarantine` on `_dmarc`, and explicit `"v=spf1 -all"` null-SPF TXT records for non-mail app subdomains (`me`, `cp`, `demo`) in Terraform IaC (validated with `terraform validate`, owner-applied via Touch ID-gated `just cf-apply`).
3. **Zero `NOT RUN` in Daily Audit & Native Linux Host Controls:** Fixes `graph_health.py` path resolution, `authz_probe_suite.py` flags/timeout (`--json --enforce`, `300s`), and `supabase_limits.py` flag (`--json`) + Linux `psql` discovery in `scripts/w0m_audit.py` and `w0m-api/scripts/supabase_limits.py`, and adds native Linux firewall/LUKS/LSM/systemd-user posture checks in `scripts/host_posture.py`.
