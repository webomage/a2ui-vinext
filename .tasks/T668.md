# T668 — Eliminate remaining Gauge/Infisical deploy tool chatter at the source and surface filtered audit lines in deploy_logged

## Summary

Following [[T666]] (which landed at `13:52:56`, after release `2026.11.07-1794074188` ran at `13:35:13`), three gaps remained in `just smoke-live` and `scripts/deploy_logged.py`:

1. **Gauge / Node / Infisical tool chatter still emitted at the source**:
   - `w0m-web/env/default/ts.properties` did not set `GAUGE_TS_PACKAGE_RUNNER = pnpm` or `NODE_NO_WARNINGS = 1`, so `gauge-ts` (`~/.gauge/plugins/ts/0.5.1/launcher-runner.cjs`) defaulted to `npx ts-node --esm` (invoking `npm`) and Node 22+ printed `(node:...) [DEP0180] DeprecationWarning: fs.Stats constructor is deprecated.` plus `(Use \`node --trace-deprecation ...\` to show where the warning was created)` on every `gauge run` (`smoke-live`, `goldens`, `e2e`, `e2e-local`).
   - Gauge printed `Updates are available. Run \`gauge update -c\` for more info.` because `check_updates` was enabled in Gauge config, and Infisical printed `A new release of infisical is available` during deploy steps.
2. **Duplicate Playwright console listeners & Chromium WebGL driver noise in `w0m-web/tests/`**:
   - `w0m-web/tests/support/hooks.ts` (`beforeScenario`) already attaches `state.page.on("console")` and `state.page.on("pageerror")`, yet `w0m-web/tests/steps/ai.steps.ts` (`implementationOpenUrl` and `openWithHash`) registered a second `state.page!.on("console")` and `state.page!.on("pageerror")` on every navigation step — duplicating every console message (`[Browser WARNING]: ...` and `[Browser Console]: ...`) 2x–4x per scenario, including headless Chromium's benign WebGL `GL_CLOSE_PATH_NV` (`GPU stall due to ReadPixels`) driver hint.
3. **Opaque `tool_chatter` and `other_trouble` in `deploy_logged.py` & `deploy-audit-latest.json`**:
   - `scripts/deploy_logged.py` recorded `build_warnings`, `advisory_failures`, and `browser_errors` arrays in `deploy-audit-latest.json`, but only recorded `tool_chatter_count` and `other_trouble_count` (omitting the `tool_chatter` and `other_trouble` line arrays), and printed `ℹ 4 tool deprecation/chatter line(s) filtered` in the terminal summary without listing what was filtered.

## Acceptance criteria

- [x] **AC1 — Eliminate Gauge, Node `DEP0180`, and Infisical tool chatter at the source (`w0m-web/env/default/ts.properties`, `w0m-web/env/default/default.properties`, `justfile`)**: Configure `GAUGE_TS_PACKAGE_RUNNER = pnpm` and `NODE_NO_WARNINGS = 1` in `w0m-web/env/default/ts.properties`, set `check_updates = false` in `w0m-web/env/default/default.properties` (and `~/.gauge/config/gauge.properties`), and export `INFISICAL_DISABLE_UPDATE_CHECK := "true"` in `justfile` so `just smoke-live` emits `0` `npm warn`, `0` `[DEP0180] DeprecationWarning`, `0` `--trace-deprecation`, and `0` `Updates are available` lines.
- [x] **AC2 — Deduplicate Playwright console listeners and suppress benign Chromium WebGL/WebGPU driver notices (`w0m-web/tests/support/hooks.ts`, `w0m-web/tests/steps/ai.steps.ts`)**: Remove duplicate `state.page!.on("console")` / `state.page!.on("pageerror")` listeners from `implementationOpenUrl` and `openWithHash` in `ai.steps.ts` and filter benign Chromium GPU driver hints (`GL Driver Message ... GL_CLOSE_PATH_NV`, `No available adapters.`) in `hooks.ts` while preserving all real browser console/page/HTTP errors.
- [x] **AC3 — Persist and display `tool_chatter` & `other_trouble` lines in `deploy_logged.py` (`scripts/deploy_logged.py`, `scripts/tests/test_deploy_logged.py`)**: Include `"other_trouble"` and `"tool_chatter"` line lists (`[:50]`) in `audit_record` inside `scripts/deploy_logged.py`, print each filtered `tool_chatter` line under the summary header in `scripts/deploy_logged.py`, and lock regression tests in `scripts/tests/test_deploy_logged.py`.
