# T630 — Codify Free-Tier-First resource rule (`AgDR-0055`: Cloudflare first, Supabase second) and gate free website audits behind Turnstile + Fingerprint order creation and zero-page-code domain ownership confirmation

## Summary

Two coupled architectural & security requirements from owner direction (`2026-11-03`):
1. **Free-Tier-First Architecture Rule (`AgDR-0055`)**: Our platform philosophy targets `$0/mo` free tiers with an explicit allocation hierarchy: **Cloudflare Free Tier FIRST** (`Workers`, `R2` `10 GB` + `$0` egress, `KV`, `Turnstile` `1M/mo`, `Workers AI` `10k Neurons/day`) and **Supabase Free Tier SECOND** (`500 MB` Postgres + GoTrue Auth + RLS reserved strictly for compact relational metadata, hashes, and append-only audit logs, never binary blobs or unverified scan writes).
2. **Deferred Website Audit Execution + Zero-Page-Code Domain Ownership Proof + Turnstile & Fingerprint Order Guard**:
   - Previously, `/audit` (`SecurityAuditWidget.svelte`), `POST /api/security-audit` (`action: "scan" | "register" | "order_service"`), `apps/cp/src/pages/o/[org]/projects/security-audit.astro`, and `GET/POST /api/client/security-audit` ran `runPassiveDomainAudit(url)` **immediately** without verifying domain ownership, allowing unverified visitors to trigger scans against third-party websites and consume free-tier Worker/Supabase budgets, while `audit.astro` did not load/pass Cloudflare Turnstile and order screens did not jointly enforce Turnstile + `@webomage/fingerprint`.
   - **Shipped behavior**: Submitting a free website audit or service order ONLY creates the pending order (`status: "pending_ownership_verification"`) guarded by **both Cloudflare Turnstile and `@webomage/fingerprint`**; after registration and Client Portal login, the user confirms website ownership via **either ONE OF** two zero-page-code methods — **DNS `TXT` record** (`_w0m-verify.<domain>`) **OR** **uploaded verification file** (`https://<domain>/.well-known/w0m-verify.txt`, never requiring HTML/page code changes) — BEFORE the free website audit executes and unlocks deliverables.
