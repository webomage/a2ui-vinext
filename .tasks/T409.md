# T409 — Comprehensive Rename/Refactor & Decommission Tooling Suite and wom7open -> wom7pr Tombstone Realignment

## Summary

Following the rename of `wom7open` to `wom7pr` ([[T377]]), an audit of the estate revealed significant tooling and verification gaps across rename, refactor, and decommission workflows:
1. **Silent Drift After Renames**: When `wom7open` was renamed to `wom7pr`, lingering references persisted across `.gitignore`, `_in/README.md`, `wom7pr/README.md` (which still bore the `# wom7open` header), and `w0m-prs/SKILL.md`. Furthermore, compiled build artifacts and native makefiles (`wom7pr/orca/out`, `orca_windows_registry.target.mk`) retained baked-in absolute path strings referencing `/Users/proto/Projects/@self/@wom/wom7open/...`.
2. **Decommission Gate Blind Spots**: `wom7open` was never entered into `wom7web/DECOMMISSIONED.md`. Because `project/scripts/decommission_check.py` (`just decommission-check`) only enforces tombstones explicitly listed in that file, the gate was structurally blind to lingering `wom7open` references.
3. **Absence of Unified Rename/Namespace Audit Tool**: While Serena LSP handles symbol-level refactoring in TypeScript/Python, it is completely blind to `.astro` files (210 files across `apps/web` and `apps/cp`), `.md` documentation, JSON/YAML configs, shell scripts, and `justfile` recipes. AST-grep similarly does not parse `.astro`, `.svelte`, `.vue`, or plain text configurations.

This ticket delivers:
1. **`rename_audit.py` (`just rename-audit <old> <new>`)**: A unified cross-surface audit tool verifying absence of old names across code, templates, configs, documentation, skills, symlinks, and build artifacts.
2. **Decommissioning Enhancement**: Add `wom7open` tombstone into `wom7web/DECOMMISSIONED.md` with explicit `path:` and `code:` assertions and required `except:` justification blocks (for backwards-compatibility in `w0m_prs.py` and historical docs).
3. **Estate Realignment**: Clean lingering `wom7open` occurrences across `.gitignore`, `_in/README.md`, `wom7pr/README.md`, and skills (`w0m-prs/SKILL.md`), and document instructions for flushing build caches.
