# T451 — /admin/vaults 500s: node:fs vault reading inside workerd

## Summary

`apps/cp/src/pages/admin/vaults.astro` calls `getLocalVaultNotes` (`lib/vault-reader.ts`), which does
`await import("node:fs/promises")` at request time. The CP runs on Cloudflare's workerd (dev and prod), where that
fails: every request to the page returns 500 `Cannot read properties of undefined (reading 'bind')`. Measured
2026-09-25, identical before and after T439 Plan B/C1 moved the page onto the new shell.

## Acceptance criteria

- [x] AC1 — Decide the source of vault notes for the admin page (storage bucket, a build-time index, or the
  Obsidian MCP) and read from it; no `node:fs` in a request path (`BUNDLED_VAULT_MARKDOWN` via Vite `import.meta.glob("../../../../projects/*/vault/**/*.md", { query: "?raw", import: "default", eager: true })` in `apps/cp/src/lib/vault-reader.ts`, plus pure zero-DOM `sanitizeVaultHtml` replacing `isomorphic-dompurify`/`jsdom` in `apps/cp/src/lib/vault-parser.ts`).
- [x] AC2 — `/admin/vaults` renders for a platform admin in dev and prod; a test covers the loader (`wom7web/project/scripts/tests/test_t451_vault_reader_workerd.py` + `apps/cp/src/lib/__tests__/vault.test.ts`; verified HTTP 200 on `https://cp.w0m.xyz/admin/vaults`).
