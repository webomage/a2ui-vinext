# T613 — Codify SDLC session wrap-up, zero-unused-parts & code-to-schema drift/audit governance (`T609`/`T611` lessons + `supabase_surface_drift_check`)

## Summary

Auditing session closeout and codebase-to-schema drift after `T609` and `T611` exposed three coupled governance gaps:
1. **`T609` lesson omission & archive disposition lines**: `T609` landed its code and in-repo architectural report (`.agents/reports/2026-11-02-hat-permissions-ui-visibility-and-agent-provider-ssot-T609.md` + `w0m-web/docs/reports/`), and `T611` landed its `LESSONS.md` rule, **but `T609` did not record its three earned transferable lessons in `LESSONS.md`**, nor did `T609` or `T611` record explicit `Lesson captured in LESSONS.md:` dispositions in `.tasks/T##.md`. In addition, `just lessons-harvest` surfaced recurring `w0m-web/justfile` path misses (`justfile` lives at root, `w0m-api/`, `w0m-cf/`, `w0m-ext/`).
2. **SDLC flow wrap-up gap between `verify`, human-gated `deploy`, and `archive`**: Because `w0m-sdlc-verify` routes to `w0m-sdlc-deploy` before `w0m-sdlc-archive`—while agents are prohibited from running human-gated `just deploy-all` / `just db-migrate` (`docs/DEPLOY-CONFIRM.md`)—sessions frequently stop after `verify` or flip `status: done` ad-hoc without executing full **`w0m-sdlc-archive` + Session Wrap-Up** (flipping ticket `done`, harvesting friction, landing `LESSONS.md`, mirroring all session/brain artifacts into `.agents/reports/`, refreshing `TECH-DEBT.md`/`TASKS.md`/`STATE.md`, running `just agent-tree-land`, fast-forwarding the live checkout, and pruning the pushed agent tree).
3. **Unwired / unused parts & silent code↔schema drift (`system_logs`, `organizations`, unwired `public_visibility`)**: `w0m-web` contained latent Supabase `.from(...)` calls to non-existent relations (`apps/cp/src/pages/api/admin/infra-usage.ts:173` querying `system_logs` instead of `admin_activity_logs`, and `packages/lib/src/public-profiles.ts:502` querying `organizations` instead of `orgs` / `public_company_profiles`) plus UI controls writing columns (`public_visibility`) missing from SQL migrations—and lacked a static gate verifying zero unused/unwired surfaces and audited change-log observability on mutable settings.
