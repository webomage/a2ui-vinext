## Status

- **2026-10-23 — Completed & Verified**:
  - **AC1 (Non-Zero Token/Neuron Accounting + Cloudflare GraphQL Analytics)**: Created `wom7api/supabase/functions/_shared/cf-cost-accounting.ts` (`computeCostAccounting`, `estimateTokens`, `queryCloudflareWorkersAiNeurons`) and wired it into `ai-router.ts` (`routeChat`, `routeChatStream`, `routeEmbed`) and `ai-utils.ts` (`logAIUsage`). Whenever Cloudflare Workers AI omits `usage` or returns `0` tokens (e.g. on SSE streams), `computeCostAccounting` deterministically estimates prompt/completion tokens (`ceil(chars / 4)`), computes exact model-specific neuron burn (`MODEL_NEURON_RATES`), and persists `neurons`, `estimated_cost_usd`, and `usage_estimated` into `public.ai_usage`. `queryCloudflareWorkersAiNeurons` queries Cloudflare GraphQL `workersAiAdaptiveGroups` and reconciles daily 10,000-neuron free-tier usage.
  - **AC2 (Per-Tier Daily Caps Enforced)**: Implemented `DAILY_TIER_CAPS` (`public`: 50k tokens / 5k neurons; `authenticated`: 250k tokens / 25k neurons; `internal`: 1M tokens / 100k neurons) and `checkUsageCap()`, enforced via `checkQuota` in `ai-utils.ts` and `chat-core.ts` before inference runs.
  - **AC3 (Admin CP Dashboard Card)**: Created `@webomage/ui`-conformant `wom7web/apps/cp/src/components/admin/AiCostAccountingCard.svelte` (`data-testid="ai-cost-accounting-card"`) displaying 24h tokens, estimated neurons, Cloudflare 10k free-tier utilization bar, per-tier cap progress bars, and per-model breakdown, mounted in `wom7web/apps/cp/src/pages/admin/ai-agents.astro`. Verified with `cf-cost-accounting.test.ts` (4/4 green) and `ds_conformance.py --enforce` (0 violations).
