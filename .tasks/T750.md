# T750 — Refine /services/ stage-card CTAs, semantic accessibility, and track/stage configurator context

## Summary

Replace the 28 identical bright-blue `Fast Register & Order Portal ->` footers on `/services/` track stage cards (`ServicesDetailed.astro`, 7 tracks x 4 stages) with intent-matched, visually hierarchical stage actions, real keyboard-accessible `<button type="button">` semantics, single-destination click routing (removing the competing `wom:chat-order-service` popup), and explicit selected track/stage context in `ServiceActionOrderConfigurator.svelte` Step 2 so non-DevOps tracks do not silently label Step 2 as "DevOps & Platform SRE".

## Acceptance Criteria

- [x] **AC1 — Intent-matched, hierarchical stage CTAs without 28x identical banner noise:** `w0m-web/apps/web/src/components/templates/sections/ServicesDetailed.astro` distinguishes stage 0 (`Engagements` / localized primary package stage -> stronger brand CTA such as `Configure Package & Audit`) from stages 1-3 (`Training`, `Certification`, `Employment` -> quieter secondary action labels matched to stage intent instead of 28 identical `Fast Register & Order Portal` bars), preserving equal-height card layout (`sm:auto-rows-fr items-stretch`, `h-full flex flex-col justify-between`, `mt-auto pt-3`).
- [x] **AC2 — Accessible single-destination routing & locale-safe stage detection:** Each stage card uses a semantic `<button type="button">` trigger (keyboard-focusable, accessible `aria-label` naming track + stage), derives `deliveryMode` by stage index (`0` -> `package`, `1..3` -> `by_request`) rather than English-only `.includes("engagement")`, and dispatches `wom:select-service-order` with `trackName`, `stageName`, and `stageRole` without simultaneously popping `wom:chat-order-service`.
- [x] **AC3 — Contextual track/stage display in configurator & unit tests green:** `ServiceActionOrderConfigurator.svelte` renders the selected track/stage context cleanly in Step 2 (and preserves it in `scopeNotes`) when triggered from a track stage card, and updated Vitest + Astro checks pass.
