# T597 — Orca cross-workspace tab drag-and-drop with confirmation dialog, session rebinding, and UI state sync

## Summary

Implement smooth cross-workspace tab mobility in [`webomage/orca`](https://github.com/webomage/orca) (`w0m-pr/orca`) so terminal and agent tabs can be dragged and dropped (or moved via context menu / shortcut) between the Floating Workspace (`FLOATING_TERMINAL_WORKTREE_ID = "global-floating-terminal"`) and normal project Worktree tab strips using an explicit 4-step transactional flow:

> **1. Start moving (drag-and-drop) → 2. Confirm in UI with session/worktree info → 3. Update session binding → 4. Update UI state**

Grounded in our code audit of `/Applications/Orca.app/Contents/Resources/app.asar.unpacked/out/`:
1. **Renderer DnD & Store Guards:** `FloatingTerminalPanel` (`FloatingTerminalPanel-DxHe-Yjx.js`) and worktree tab strips (`agent-tab-shortcut-launch-SXXoUDAE.js`) currently mount isolated `@dnd-kit` contexts and reject cross-worktree drops (`if (o.worktreeId !== t) return` and `dropUnifiedTab` in `store-DBDq0ZPi.js`: `if (t.worktreeId !== a.worktreeId) return e;`).
2. **Daemon & Agent Hook Scope (`orcad`):** When `orcad` spawns a shell, `worktree-activation` injects a static `ORCA_WORKTREE_ID` environment variable into the child shell, and `~/.orca/agent-hooks/antigravity-hook.sh` posts `worktreeId=${ORCA_WORKTREE_ID}` back to `orcad` (`127.0.0.1:49152/hook/antigravity`), where `orcad-migration-source-retention` checks `t.worktreeId !== o.scope.workspaceId`.
3. **Why the 4-Step Flow Solves It Cleanly:** Instead of silently mutating React state while leaving the underlying session/hook scope out of sync, dropping a tab onto a target workspace opens a confirmation modal with clear session/workspace telemetry, updates the session binding (`orcad` PTY scope + hook `paneKey -> worktreeId` mapping and/or clean `--conversation=<uuid>` session handoff), and then atomically updates the UI tab strip.

## Acceptance criteria

- [ ] **AC1 — Step 1 & 2: Cross-Workspace Drag-and-Drop Initiation & Confirmation Dialog with Session Info**:
  - Allow dragging a tab between `FloatingTerminalPanel` (`global-floating-terminal`) and any project Worktree tab strip (plus right-click context menu `Move Tab to Workspace…`).
  - On drop, trigger a pending move state and render a confirmation modal displaying: source workspace vs target workspace path/branch, detected agent session (`agentIdentity`, `conversation_id`, `working`/`idle` status), current process working directory, and the session transition mode (live PTY scope rebind vs clean `--conversation` re-attach in target worktree `cwd`).
- [ ] **AC2 — Step 3: Session & Hook Authority Update (`orcad` `pty.moveWorktree` + Dynamic Hook Resolution)**:
  - On user confirmation, execute the session update before committing the UI tab move:
    1. Call `pty.moveWorktree({ paneKeys, tabId, targetWorktreeId })` in `orcad` to update `o.scope.workspaceId = targetWorktreeId` and `last-status.json`.
    2. In `orcad`'s `/hook/*` ingestion router, resolve `worktreeId` dynamically from the authoritative `paneKey` / `tabId` registry when a tab has been moved, overriding the stale spawn-time `ORCA_WORKTREE_ID` environment variable inside the child process.
    3. Optionally (when selected in the confirmation dialog for an idle agent session) perform a clean session handoff (`cd <targetWorktreePath>` or respawn `agy --conversation=<uuid>` in the target worktree directory).
- [ ] **AC3 — Step 4: Atomic Renderer UI Update (`moveUnifiedTabToWorktree`)**:
  - Once Step 3 succeeds, atomically migrate the tab across `unifiedTabsByWorktree`, `tabsByWorktree`, `groupsByWorktree`, and `layoutByWorktree` in the Zustand store (`store`), preserving terminal scrollback and split panes, closing the floating panel if empty, and activating the moved tab in the destination workspace.
- [ ] **AC4 — CLI Parity (`orca terminal move`) & Vitest Suite in `w0m-pr/orca`**:
  - Add `orca terminal move <term-or-tab-id> --to-worktree <selector>` to the Orca CLI and add unit/component tests covering the cross-worktree drag-and-drop confirmation modal, `moveUnifiedTabToWorktree` store reducer, and `orcad` dynamic hook `worktreeId` resolution on `webomage/orca`.
