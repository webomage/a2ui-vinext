# T313 — Artemio managed delivery roles (PM, TPM, Dev) and host-managed CP portal import

*"it's managed project with Aleksei as PM, TPM and Dev for all 3 roles/hats in project

This ticket completes the operational import of Artemio (`artemioquierocomer.mx`) into the w0m Control Panel (CP) portal across all four operational features:
1. **Clients Portal:** Verified client tenancy, invoices, contracts, proposals, and milestones under Artemio's client identity (`eva@webomage.com` / `66b018cd-b7a3-48f2-aa5c-51c92856a4bb`).
2. **Project Manager (PM) Hat:** Delivery scope, milestones approval, roadmap, and client liaison.
3. **Technical Program Manager (TPM) Hat:** Technical coordination, cross-cutting architecture, repository oversight, and quality gates.
4. **Developer (Dev) Hat:** Code delivery, Astro platform, KV menu synchronization, and PDF menu compilation.

Artemio executes directly on the macOS host (`/Users/proto/Projects/_self/delivery/artemioquierocomer.mx`) and does **not** use Tart VM sandbox isolation (unlike Evercred).
