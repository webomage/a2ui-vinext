# T57 — Implement w0m Open Routing Layer

## Summary

Build and deploy the w0m Open Routing layer to dynamically allocate tasks between commoditized local SLMs (or Cloudflare Workers AI) and flagship frontier model APIs (Claude 3.5 Sonnet / Gemini 1.5 Pro). Establish complexity heuristics (intent-routing classification) and integrate Gemini context caching to lower API overhead.

## Acceptance criteria

- [ ] AC1 — Implement Intent Router logic in `wom7api` / `wom7cfworkers` classifying incoming prompts (Routine/Simple vs. Complex).
- [ ] AC2 — Route Routine queries to local SLM/CF-Workers-AI endpoints, and Complex queries to flagship models.
- [ ] AC3 — Integrate Gemini context caching for repeated input sequences.
- [ ] AC4 — Log token routing allocations to audit blended cost metrics.
