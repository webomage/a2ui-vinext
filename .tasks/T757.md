# T757 — Align Webomage color tokens, contrast, and design-system package with OpenDesign

## Summary

Eliminate cross-app visual color mismatches observed in `web`, `cp`, and `me` captures and align both runtime `@webomage/ui` tokens and `w0m-web/design-system/` with OpenDesign (`od-design-system-project/v1`, `craft/color.md`, `craft/anti-ai-slop.md`) while preserving all existing Webomage token-parity and conformance requirements.

## Acceptance Criteria

- [x] **AC1 — Unified dark-slate canvas & signature Sky/Emerald/Cobalt token harmony:**
  - Eliminate pure `#000000` WebGL canvas seams against `--slate-950` (`#020617`) headers in `apps/{web,cp}/src/components/three/WarpScene.ts` (and related active starfield backgrounds), soften harsh opaque header hairlines, and eliminate `bg-black/*` in shared auth panels (`AuthForm.astro`, `forgot-password.astro`).
  - Realign `[data-app="me"]` (`--brand-me`, `--brand-accent`) away from pastel `#818cf8`/`#a855f7` AI-slop indigo/purple onto crisp Sky + Emerald (`--sky-400` / `--emerald-400`) matching shared header/logo tokens, remove dimmed `#64748b` hero fade in `JobBoard.svelte`, and remove legacy `indigo-*`/`purple-*` washes across `apps/me`, `apps/web` auth pages, and `apps/cp` auth/account pages.
  - Give `[data-app="cp"]` white text (`--primary-foreground: var(--white)`) on a WCAG AA (`>= 4.6:1`) calibrated Cobalt primary fill paired with high-contrast sky links (`>= 7:1`), fix `ChatApp.svelte` `.chat-toggle-btn` foreground contrast (`var(--primary-foreground)`), and remove `--accent: var(--brand-color)` overrides in app global styles/layouts so shadcn `--accent` hover fills stay distinct from brand fills.
- [x] **AC2 — Calm auth surfaces & single primary CTA per viewport:**
  - Neutralize secondary OAuth buttons (`Google`, `LinkedIn`, `GitHub`) in `AuthForm.astro` onto dark-slate glass (`variant="outline"`) so `Sign In` stands as the sole primary CTA; replace the asymmetric corner blob and gradient-clipped heading across `login.astro` / `forgot-password.astro` / `reset-password.astro` with clean centered top ambient wash and crisp solid heading typography.
- [x] **AC3 — Upgrade `w0m-web/design-system/` to OpenDesign `od-design-system-project/v1` + import into `:7456`:**
  - Keep `design-system/tokens/*.css` in 100% parity with `packages/ui/src/tokens.css`, upgrade `w0m-web/design-system/manifest.json` (`schemaVersion: "od-design-system-project/v1"`), add OpenDesign-canonical `w0m-web/design-system/tokens.css` (`TOKEN_SCHEMA` A1+A2+B-slot slots), `USAGE.md`, `design-tokens.json`, `tailwind-v4.css`, and `components.manifest.json`.
  - Validate via OpenDesign manifest/package scripts (`check-design-system-manifests.ts` parity/extract logic) and register/import into running local OpenDesign (`http://127.0.0.1:7456`).
- [x] **AC4 — Before/after visual capture & regression verification:**
  - Pass `just ds-diff`, `just ds-bundle`, `just ds-conformance --enforce`, `just design-system-check`, `just ui-ticket-leak-check`, `astro check` across `web`, `me`, `cp`, Vitest regressions, and capture refreshed `verify_v2_*.png` Chromium screenshots across `web`, `me`, and `cp`.
