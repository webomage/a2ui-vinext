# T412 — Elevate Global Governance, Task Queue, and Policy Tooling to Root @wom Workspace

## Summary

As established in [[T411]], the w0m workspace root (`casualuser/w0m`) now hosts the canonical ticket store (`.tasks/`) and coordinates multi-agent worktrees. However, 90%+ of the estate's core operational infrastructure remains nested in `wom7web/project/scripts/`:

1. **Monorepo Inversion**: Estate-wide commands (`just tasks`, `just state-check`, `just prs`, `just w0m-audit`) executed at root or from other repos (`wom7api`, `wom7skills`) delegate through `@just --justfile wom7web/justfile`, forcing non-web agents to interact with the web monorepo and triggering web-specific pre-commit hooks (Astro checks, oxlint, frontend linters).
2. **Scattered Governance Config**: Central config `.w0m/sdlc.json` still resides in `wom7web/.w0m/sdlc.json`, rather than at `@wom/.w0m/`.
3. **Missing Top-Level Board**: The compiled `TASKS.md` is emitted to `wom7web/TASKS.md`, so a developer opening the `@wom` workspace finds no root-level `TASKS.md`.
4. **Policy & Script Fragmentation**: Policies (`stacks-policy.json`, `tools-policy.json`, `ports-policy.json`, `emoji-policy.json`) and 188 scripts live under `wom7web/project/` despite governing all 7 repositories.

This ticket delivers Phase 1 of the migration:
1. Establish `@wom/project/` with `scripts/`, `policies/`, and `templates/`.
2. Elevate `.w0m/sdlc.json` to `@wom/.w0m/sdlc.json` with a backward-compatible symlink in `wom7web/.w0m/`.
3. Configure `just tasks-render` to emit `TASKS.md` directly to `@wom/TASKS.md` (and maintain a symlink in `wom7web/TASKS.md`).
4. Relocate core queue & SDLC scripts (`tasks_query.py`, `tasks_render.py`, `ticket_audit.py`, `dod_check.py`, `state_doctor.py`, `sync_github.py`) to `@wom/scripts/` with path resolution that works seamlessly from root and subrepos, leaving lightweight forwarding shims in `wom7web/project/scripts/`.
5. Update root `justfile` to run these core recipes natively without delegating through `wom7web`.

## Acceptance criteria

- [x] AC1 — Establish `@wom/project/` structure (`scripts/`, `policies/`, `templates/`) and elevate `wom7web/project/policies/*.json` and `ticket.md` template to `@wom/project/`, maintaining symlinks in `wom7web/project/` for zero breakage.
- [x] AC2 — Elevate `wom7web/.w0m/sdlc.json` to canonical `@wom/.w0m/sdlc.json`, updating paths to resolve from the workspace root and leaving a backwards-compatible symlink in `wom7web/.w0m/`.
- [x] AC3 — Update `tasks_render.py` to compile `TASKS.md` directly at `@wom/TASKS.md` and establish a symlink at `wom7web/TASKS.md`.
- [x] AC4 — Relocate core queue and SDLC scripts (`tasks_query.py`, `tasks_render.py`, `ticket_audit.py`, `dod_check.py`, `state_doctor.py`, `sync_github.py`) to `@wom/scripts/`, with `find_workspace_root()` path resolution that operates identically from root, subrepos, and worktrees.
- [x] AC5 — Leave lightweight Python forwarding shims in `wom7web/project/scripts/` for relocated scripts so existing hooks and caller recipes continue functioning without disruption.
- [x] AC6 — Update root `justfile` to invoke relocated queue, state, and SDLC commands directly from root `scripts/` instead of delegating to `wom7web/justfile`.
- [x] AC7 — Verify all gate suites (`just preflight --fast`, `just state-check`, `just tasks-render-test`, `just ticket-audit T412`, `just dod-check --ticket T412`) pass cleanly from both `@wom` and `wom7web`.

## Definition of Done

This ticket is complete when all of the following are observably true:
The workspace root `@wom` contains `.w0m/sdlc.json`, `TASKS.md`, and `project/policies/` as canonical sources of truth; `just tasks`, `just tasks-render`, and `just state-check` execute natively at `@wom` using `@wom/scripts/` without indirection into `wom7web`; `wom7web` preserves 100% backward compatibility via symlinks and forwarding shims; and all pre-commit and pre-push quality gates pass cleanly across root and subrepos with zero `--no-verify`.
