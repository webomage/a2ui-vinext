# T405 — apps/join sat at its type-error ratchet baseline for six weeks — the cause was one missing tsconfig path

## Summary

> 🔬 **Read the correction below first.** This ticket was filed on the premise that join was
> *unmeasured*. That premise is **wrong**, and the wrong version is preserved here rather than
> quietly edited away, because the corrected shape is the more useful one.

The root `typecheck` script ran `astro check` for `web`, `cp`, `demo` and `job`. `apps/join` was
absent, so `just typecheck` / `just check` exited 0 while saying nothing about an app that serves
`join.webomage.com` from the `webomage-join` Worker.

**But join was not ungated.** It was *deliberately* excluded from the zero-gate under
[[T149]] / TECH-DEBT **D6** and held by `project/scripts/typecheck_ratchet.py` at a baseline of
**12 errors**, re-measured on every push. So join had a *weaker* gate, not *no* gate — and the 12
errors this ticket "discovered" were the 12 the ratchet had been carrying since **2026-08-10**.
The real defect was narrower and less dramatic: **a recorded debt sat at its baseline for six weeks
while its actual cause was a one-line tsconfig omission.**

Adding the missing filter surfaced **12 errors**, of which exactly one was a defect in join's own
logic. The other eleven traced to a single omission:

**join's `tsconfig.json` was the only app tsconfig without the `@webomage/lib/*` path mapping.**
`web`, `cp`, `demo` and `job` all carry `"@webomage/lib/*": ["../../packages/lib/src/*"]`. Without
it, TypeScript resolves through the package's `exports` (`"./*": "./src/*"`), which is a literal
rewrite with no extension or `/index` substitution — so every `@webomage/lib/auth`,
`/health`, `/supabase`, `/demo/fixtures` import failed as ts(2307) (9 errors). Two further
ts(7006) implicit-`any` errors on `createAuthMiddleware` callback params were downstream of that and
resolved themselves once the module typed. Vite does substitute extensions, which is why
`astro build` and the live Worker were never affected — a type-only gap, invisible precisely
because nothing was looking.

The one genuine defect: `let challenges = []` in `assessments/index.astro` evolved to `any`, leaving
`challenges.map((challenge) => …)` untyped against the `skill_challenges` rows it renders.

The gate also caught a **dangling import** — `dashboard.astro` imported
`../components/DashboardStats.svelte`, **a file that does not exist**. esbuild elides an unused
import before resolution, so the build never asked for it; `astro check` only reported it as an
unused-variable hint. Removed.

## What was deliberately NOT fixed

Two ts(6385) hints remain in `apps/join/src/pages/interview/[id].astro` — the deprecated
`@webomage/lib/supabase` singleton. Confirmed already tracked: `just authz-admin-client` lists that
exact file as a 🔴 middleware-only importer, and it is the subject of [[T327]]. The module's own
docstring is explicit — *"Migrate per-caller, WITH an auth check added (AC3). Do not bulk-replace."*
Silently swapping the client here would be the bulk-replace that comment forbids, so it stays,
visible, for T327. `astro check` exits non-zero on errors only, so this does not weaken the gate.

  is itself a push gate, so join *is* gated at zero today.
- **2026-09-20 — ✅ RESOLVED, owner chose the explicit empty state.** join deleted from
  `typecheck-baseline.json`; **TECH-DEBT D6 is paid** (5 of 5 apps gated at zero). 🔑 The point of
  the chosen option: retiring the ratchet did **not** unwire it. Emptiness alone is still exit 2 —
  a ratchet must never pass over nothing — and is accepted only alongside `retired` (a dated
  reason) and `graduated` (the apps released). The step then **verifies every graduate is still
  enumerated in the root `typecheck` script**, failing 1 if one is dropped. That seam — an app
  released by the ratchet, then quietly removed from the zero-gate — was the *only* way graduation
  could have left an app gated by nothing, and it is now the thing the step watches. Re-arm by
  putting an app back in `apps`; `retired` is then ignored.
  **5 red probes, each run and observed:** graduate dropped from `typecheck` → **1**; empty with no
  `retired` → **2**; `retired` with empty `graduated` → **2**; `typecheck` script unreadable → **2**
  (never silently "all gated"); re-armed with an app in `apps` → **0**, ratcheting normally.
  Side benefit: the step no longer shells out to `astro check`, reclaiming the ~26s per push D6
  recorded as its cost.
