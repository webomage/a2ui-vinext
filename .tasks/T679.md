# T679 — Onboard LinuxOnTab (`kilian-ai/linuxontab`) & Unified `@k7` Module System (`k7hub`)

## Context

The `@k7` family (`k7env`, `k7pwd`, `k7d`, `k7s`, `k7c`, `k7llm`, `k7spec`, `k7sol`, `k7tg`, `k7log`) requires:
1. A unified module/plugin host (`k7hub/k7hub`, binary `k7`) that unites all 9 `@k7` tools in one multi-tab TUI (`1`–`9` hotkeys + shared Infisical profile and secret bus) while keeping every individual crate 100% runnable as a standalone application (`k7 run <module>`).
2. Integration with [`kilian-ai/linuxontab`](https://github.com/kilian-ai/linuxontab) (`github.com/webomage/linuxontab` in `w0m-pr/linuxontab`) so `@k7` modules can run both inside **Orca** (as embedded browser `LinuxOnTab` WASM Linux tabs or terminal split panes) and standalone (`k7 linuxontab`, `k7 orca <module>`).
