# T418 — Eliminate Ticket Dual-SSOT and Fallback Resolvers: Retire wom7web/project/tickets

## Summary

Under **AgDR-0025** (Reject Silent Fallbacks, Backward-Compatibility Shims, and Shadow Symlinks in Estate Architecture), the w0m ecosystem enforces a strict single source of truth and atomic cutovers.

Currently, tickets are maintained in two places:
1. Canonical SSOT: `.tasks/T##.md` (417 tickets at workspace root `@wom`).
2. Legacy Mirror: `wom7web/project/tickets/T##.md` (413 tickets, missing 4 tickets).

This split-brain layout creates friction:
- Agents must create or sync duplicate files (e.g. `chore(T413): add project/tickets mirror for T413`).
- Scripts (`tasks_query.py`, `ticket_audit.py`, `sync_github.py`) contain defensive fallback search ladders (`if (ROOT / ".tasks").is_dir(): ... else: ROOT / "project" / "tickets"`).
- Tests and skills reference legacy paths (`cat /.../wom7web/project/tickets/${TICKET}.md`).

This ticket executes an atomic clean cutover:
1. Delete `wom7web/project/tickets/` completely (zero shadow symlinks).
2. Remove fallback ladders across `scripts/` and point 100% of tools directly to `.tasks/`.
3. Update documentation, skills, and tests to reference `.tasks/` as the sole canonical home.

## Acceptance criteria

- [x] AC1 — Completely remove `wom7web/project/tickets/` from disk and git tracking with zero shadow symlinks left behind.
- [x] AC2 — Update `scripts/tasks_query.py`, `scripts/ticket_audit.py`, and `scripts/sync_github.py` to resolve `.tasks/` directly and fail closed immediately if missing, eliminating all fallback ladders.
- [x] AC3 — Update `w0m-sdlc-*` and `w0m-ticket-audit` skills to cite `.tasks/T##.md` directly.
- [x] AC4 — Update `wom7web/CLAUDE.md`, `wom7web/AGENTS.md`, and `openspec/SPEC-AUTHORING-STANDARD.md` removing all references to `project/tickets/` as a live mirror.
- [x] AC5 — All ticket test suites (`just tasks-render-test`, `just ticket-dups-test`, `just ticket-audit`, `just sync-tickets-test`) pass 100% green without referencing `wom7web/project/tickets/`.
- [x] AC6 — `just ticket-paths` verifies zero broken ticket references across the estate.

## Definition of Done

T418 is done when:
1. `wom7web/project/tickets/` no longer exists on disk or in git.
2. `just tasks` and `just tasks-render` operate strictly on `.tasks/`.
3. `just ticket-audit T418` passes with all ACs confirmed and 0 contradictions.
4. All pre-commit hooks in `wom7web` and `@wom` pass organically (zero `--no-verify`).
