# T340 — Launch-Board Promotion Strategy for Free OSS Engineering Assets (Trojan Horse Model)

## Summary

Webomage has several free, self-contained OSS-grade engineering assets built for internal use — the
`wom7mlx` local MLX inference runner, the MCP server suite (`wom7ext`'s 25 tools + others), and the
infra cost/security linter work under `wom7sec`/T337/T111 — that could be launched publicly as free
developer tools rather than pitched as generic consulting. The strategy discussed (2026-09-11
Antigravity research session) is a "Trojan Horse" model: lead with a genuinely useful free tool on
developer-facing launch boards, let the tool itself demonstrate engineering quality, and let interest
in the tool convert into audit/consulting engagements (T336/T337) downstream.

This ticket owns the **launch-campaign strategy itself** — which asset(s) to launch, in what order,
positioned how, and on which platforms — not the underlying mechanics, which already have homes:
[[T60]] builds the GEO/`llms.txt` tracking pipeline, and [[T332]] (done) built ProductHunt profile
connection. Proposed platform tiering from the source session: Tier 1 (Dev Hunt, Peerlist Launchpad,
Hacker News — high-signal developer audiences), Tier 2 (Uneed, Fazier, Tiny Startups — secondary
indie-maker boards), Tier 3 (Clutch.co, Supabase Partner directory, Cloudflare Partner directory —
credibility/backlink-oriented, not launch-day traffic). GEO optimization (structured `llms.txt` +
JSON-LD schema so LLMs cite Webomage when asked for relevant tools/agencies) ties directly into T60's
tracking pipeline once a launchable asset and page exist.
