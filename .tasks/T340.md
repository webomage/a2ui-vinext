# T340 — Open-source & launch-board promotion strategy ("Trojan Horse" model)

## Context

Launch boards (`Product Hunt`, `Hacker News`, `BetaList`, `DevHunt`, `Fazier`, `Uneed`, `Reddit`) reject or ignore traditional service/agency pitches ("Hire Webomage"). However, they strongly reward **free, zero-friction open-source developer tools and interactive utilities**.

Webomage already has high-leverage technical assets in the estate (`@webomage/webmcp` from `T21`, `wom7sec` security probes from `T74`, `wom7mlx` local inference benchmarks from `T88`) that can be packaged and launched as standalone developer tools that funnel enterprise leads back to `webomage.com`.

## Scope

1. **Asset Readiness Audit (`AC1`):** Evaluate which w0m packages/tools (`@webomage/webmcp`, `wom7sec` security audit CLI/widget, `wom7mlx` benchmark suite) are ready to launch publicly as standalone "Trojan Horse" developer tools.
2. **Platform Sequencing Plan (`AC2`):** Define a tiered launch sequence:
   - Tier 1 (High engineering signal): `Show HN`, `r/LocalLLaMA`, `r/cloudflare`, `r/supabase`, `r/webdev`
   - Tier 2 (Dev launch boards): `DevHunt`, `Product Hunt`, `Uneed`, `Fazier`
   - Tier 3 (Directories & MCP registries): `BetaList`, `AlternativeTo`, `StackShare`, `mcp.so`, `glama.ai/mcp`, `smithery.ai`
3. **Launch Assets & Copy (`AC3`):** Draft launch copy, README positioning, and demo requirements framed strictly as "free engineering tool, not a sales pitch".
4. **AI Discovery Alignment (`AC4`):** Ensure `llms.txt` (`T55`) and public docs reference these open tools so LLM search engines (`Perplexity`, `ChatGPT`, `Claude`) cite Webomage as the creator.
