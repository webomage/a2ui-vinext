# T638 — Orca Desktop & Mobile: built-in `*top` & Docker TUI monitor launcher (staged for next overlay release) + HP host monitor tooling

## Summary

Running `htop`, `btop`, `lazydocker`, `ctop`, `docker stats`, `ncdu`, `duf`, GPU `*top`, and I/O monitors inside Orca previously required opening an empty terminal tab and typing each TUI command manually (especially tedious on Orca Mobile). In addition, per the operator's GitHub Actions build-quota rule, single-feature Orca overlay additions must be verified 100% locally (including full overlay branch stacking) and staged on `webomage/orca` without dispatching `w0m-overlay-release.yml` until the next batched release.
