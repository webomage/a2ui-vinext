# T557 — Mobile Orca (`casualuser/orca`): Add camera photo capture ('Take Photo') to attach captured photos directly into Native Chat and Terminal sessions

## Summary

Currently, Mobile Orca (`casualuser/orca` in `wom7pr/orca/mobile/`) only allows attaching images into Native Chat (`MobileNativeChatComposer.tsx`) or Terminal sessions from the **Photo Library** (`'library'`) or **Files** (`'files'`) via [`mobile/src/session/mobile-image-source-picker.ts`](https://github.com/casualuser/orca/blob/main/mobile/src/session/mobile-image-source-picker.ts).

Users on Mobile Orca need to **take a photo directly with the device camera** (`'camera'`) from the image source sheet and drop it straight into the active Native Chat composer (as a staged thumbnail uploaded to the host temp file and pasted into the chat session) or Terminal session.

## Acceptance criteria

- [x] AC1 — **Extend `mobile-image-source-picker.ts` with `'camera'` source & `CameraPermissionError`.** Add `'camera'` to `MobileImageSource` (`'camera' | 'library' | 'files'`), request camera permissions via `ImagePicker.requestCameraPermissionsAsync()`, launch the native camera via `ImagePicker.launchCameraAsync({ mediaTypes: ['images'], base64: false, quality: 1 })`, and convert the captured image into `{ base64, uri }`.
- [x] AC2 — **Add "Take photo" camera button to `MobileNativeChatComposer.tsx` & `MobileTerminalInputActions.tsx`.** Expose a `Camera` action button (`accessibilityLabel="Take photo"`) in `MobileNativeChatComposer.tsx` (`MobileNativeChatView.tsx`, `MobileNativeChatOverlay.tsx`) and `MobileTerminalInputActions.tsx` (`MobileSessionCommandDock.tsx`) wired to `images.attachImage('camera')` / `attachImage('camera')`.
- [x] AC3 — **Handle `CameraPermissionError` across Native Chat & Terminal image upload hooks.** Update `use-mobile-native-chat-image-upload.ts` and `use-mobile-image-attachment.ts` so `CameraPermissionError` displays a `'Camera permission denied'` toast, and declare `NSCameraUsageDescription` / `expo-image-picker` `cameraPermission` in `mobile/app.json`.
- [x] AC4 — **Unit tests in `mobile-image-source-picker.test.ts`, `MobileNativeChatComposer.test.ts`, & `use-mobile-native-chat-image-attachments.test.ts`.** Add unit tests covering `'camera'` permission grant, permission denial (`CameraPermissionError`), user cancellation, photo capture + base64 encoding, and the composer `Take photo` button.
