# T25 — Knowledge-graph engine research

## Summary

Evaluate a code/knowledge-graph engine for codebase understanding + tech-debt:
[`Understand-Anything`](https://github.com/Egonex-AI/Understand-Anything)
(TS/tree-sitter+LLM, JSON graph, multi-assistant) vs
[`graphify`](https://github.com/Graphify-Labs/graphify) (Python/tree-sitter+LLM, Leiden
communities, optional Neo4j/FalkorDB) vs extending our own Supabase **pgvector** RAG.

decide adopt-as-dev-tool (feeds T23/§5) vs build-on-our-stack. Deliver a recommendation.
