# T703 — Embed Advanced Services & Packages Configurator into Post-Registration & Post-Checkout Client Portal Onboarding Wizard with Checkout Trigger

## Summary

1. Embed the **Advanced Services, Packages & Infrastructure Selector Configurator** (`PUBLIC_SERVICE_ACTION_CATALOG`, `SERVICE_SOURCE_INFRA_OPTIONS`, `SERVICE_TARGET_INFRA_OPTIONS`, `SERVICE_WORKLOAD_SCOPE_OPTIONS`, `SERVICE_CUTOVER_TIMELINE_OPTIONS`) directly into the Client Portal **Post-Registration & Post-Checkout Onboarding Wizard** (`ClientDashboard.svelte` on `/o/[org]`, `data-testid="cp-onboarding-service-wizard"`).
2. Wire **Stripe Checkout** (`stripe-checkout`) and **1-Click OAuth / Magic Link Registration** (`ServiceActionOrderConfigurator.svelte`, `AuditPricing.svelte`, `BlueprintOrderFlow.svelte`, `order-form-state.ts`, and `apps/cp/src/pages/index.astro`) so completing or triggering package checkout acts as a direct trigger that opens the Client Portal Onboarding Wizard pre-loaded with the selected service package and infrastructure scope.
3. Persist non-website `order_works` deliverables (`infra`, `cross_cloud_migration`, `blueprint`, `repo`) and `service_scope` metadata into `orgs.service_usage.deliveries` (`apps/cp/src/pages/api/client/security-audit.ts`) so wizard configurations survive refreshes and immediately surface in the Client Portal.

## Acceptance criteria

- [x] AC1 — **Canonical Onboarding & Checkout Trigger URL Builders + Query Parser (`packages/lib/src/security/order-form-state.ts`):** Add `buildOnboardingWizardPortalUrl(context, cpOrigin, orgBasePath)` and `parseOnboardingWizardQuery(search)`, extend `FastOAuthOrderContext` with `checkoutTriggered?: boolean` and `onboardingWizard?: boolean`, include `onboarding=wizard` in `buildFastOAuthRegisterUrl`, and add `ORDER_FORM_STORAGE_KEYS.cpOnboardingWizard`.
- [x] AC2 — **Preserve Query Parameters Across CP Root Redirect (`apps/cp/src/pages/index.astro`):** Forward `Astro.url.search` when `/` redirects to `result.to` (`/o/<org>`) so OAuth `next` callbacks, magic links, and Stripe Checkout return URLs preserve `?onboarding=wizard&checkout=triggered&order=service&service=...&sourceInfra=...&targetInfra=...`.
- [x] AC3 — **Checkout as a Direct Trigger for the Onboarding Wizard on Public Order Flows (`ServiceActionOrderConfigurator.svelte`, `AuditPricing.svelte`, `BlueprintOrderFlow.svelte`):** Provide direct `"Checkout & Launch Wizard ($X)"` package trigger actions (`data-testid="fast-checkout-trigger-${slug}"`), wire Stripe Checkout `success_url` with `?onboarding=wizard&checkout=triggered&order=service&service=${slug}&mode=package`, and render a `"Checkout Confirmed — Launch Client Portal Onboarding Wizard"` banner (`data-testid="checkout-triggered-onboarding-banner"`) with deep-link CTA (`data-testid="open-cp-onboarding-wizard-link"`).
- [x] AC4 — **Interactive 3-Step Advanced Services & Packages Onboarding Wizard in Client Portal (`ClientDashboard.svelte` & `apps/cp/src/pages/api/client/security-audit.ts`):** Embed `data-testid="cp-onboarding-service-wizard"` into `/o/[org]` that auto-opens when triggered by Checkout (`?checkout=triggered|success`, `?order=success`, `?success=true`), Registration/OAuth (`?onboarding=wizard`, `?order=service|audit|blueprint`, `?service=...`), or `onboarding` (`hasNoData`), featuring Step 1 (`cp-wizard-step-package`: 6-service catalog + `package` vs `by_request` toggle + in-portal Stripe Checkout trigger `cp-wizard-checkout-trigger-btn`), Step 2 (`cp-wizard-step-infra`: multi-select source/target infra, workloads, cutover timeline, optional URL/repo, and notes), and Step 3 (`cp-wizard-step-verify`: submits to `POST /api/client/security-audit` `order_works` and persists `service_scope` + `latest_k7_report` into `orgs.service_usage.deliveries`).
- [x] AC5 — **Automated Unit & Integration Regression Tests:** Add comprehensive unit tests in `apps/web/src/tests/service-action-order-configurator.test.ts` verifying `buildOnboardingWizardPortalUrl`, `parseOnboardingWizardQuery`, CP `/` query forwarding, public checkout-triggered wizard flows, and the embedded `ClientDashboard.svelte` onboarding wizard.
