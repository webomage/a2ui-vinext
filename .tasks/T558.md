# T558 — TypeSafe System One & Jev Image Processing: fast initial classification, two-stage skill suggestion, and multimodal image/box pipeline for w0m & Orca

## Summary

Alongside Google Research's **Harness²** ([[T556]]) and **Mobile Orca Camera Capture** ([[T557]]), `w0m` and **Orca** use **TypeSafe's System One (`Jev`)** (`https://docs.typesafe.ai/introduction/coding-agents`, `https://docs.typesafe.ai/images`, `https://docs.typesafe.ai/primitives/box`) internally for **fast initial classification, confidence-gated routing, two-stage skill suggestion, and multimodal image/bounding-box processing**.

Unlike a generative chat/code LLM, a System One model evaluates a structured `state` (including base64 or multipart `assets` images) against typed questions (`noul`, `choice`, `score`, `box`) and returns calibrated probabilities and confidence in a single forward pass.

## Acceptance criteria

- [x] AC1 — **Jev Image Preparation Pipeline (`prepare_jev_image` in `wom7web/project/scripts/jev_system_one.py`).** Prepare any input photo (including Mobile Orca camera captures from [[T557]]) to satisfy all Jev image limits (`docs.typesafe.ai/images`): apply EXIF orientation in pixel space (`ImageOps.exif_transpose`) before stripping metadata, reject animated images unless `extract_first_frame=True`, downscale longest side to `<= 1568` px, upscale or pad any side `< 280` px so dimensions stay within `[280, 1568]` and area within `[78,400, 2,458,624]` px², and export baseline 8-bit JPEG (`progressive=False`) or PNG `<= 16 MiB`.
- [x] AC2 — **Strict Offline Request & Asset Reference Validator (`validate_jev_request`).** Enforce Jev's multimodal request contract before network dispatch: require `TypeSafe-Danger-Zone-Images: true` header whenever `assets` or `box` questions are present, require `jev-1.14.0` / `jev-preview` for `box` questions, verify every asset reference key (`<= 1,024` UTF-8 bytes) appears in string values of `state`, `instructions`, or `criteria` (never counting object keys), and verify expanded request size `<= 32 MiB`.
- [x] AC3 — **Jev `Box` Localization, Confidence Padding & 4-Edge Truncation Verification (`box_with_presence`, `BoundingBox`, `crop_image_to_box`, `build_box_edge_verification_questions`).** Pair every `box` question with a companion `noul` presence check, support confidence-gated edge padding (`PAD = 0.05` when `confidence < min_confidence`), crop images to normalized `[0, 1]` bounding boxes, and generate the 4-edge Noul truncation verification questions (`continues_left/top/right/bottom`).
- [x] AC4 — **Fast Initial Classification & Two-Stage Progressive Skill Suggestion (`SystemOneClient`, `suggest_skill_two_stage`, `test_jev_system_one.py`).** Provide a unified `SystemOneClient` (`jev`, `kev`, `laya`, `von`) with zero silent fallback (AgDR-0025; `SystemOneUnmeasurableError` for hooks per [[T242]]), implement TypeSafe's 2-stage progressive skill suggestion (`cookbooks/skill_suggestion`: Call 1 roster skim + 3 Noul gates; Call 2 top-3 shortlist with 700-char `SKILL.md` opening + fit Nouls emitting `<skill_relevance>`), and verify with 12 unit tests in `wom7web/project/scripts/tests/test_jev_system_one.py`.
- [x] AC5 — **Wire `just jev-image` & `just jev-system-one-test` CLI recipes.** Expose `just jev-image` (`prepare-image`, `providers`) and `just jev-system-one-test` in the root `justfile` and verify CLI execution.
