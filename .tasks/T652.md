# T652 — Fix `preflight --fast` failures and wire bounded `automation-health` staleness ceilings across estate hooks and `session-complete`

## Summary

Measured on `2026-11-05` (`aleksei@HP`), two coupled classes of silent drift degraded estate operations:

1. **`just preflight --fast` exited `1` (`3 finding(s)`), breaking `just preflight --fast && just state-brief` in agent sessions**:
   - `mcp`: `headroom-proxy` (`127.0.0.1:8787`) omitted `"required": false` in `.w0m/sdlc.json` even though its declaration explicitly notes it is a non-load-bearing macOS `launchd` proxy for `claude -p` (`0` systemd units on Linux), unlike `obsidian-w0m-web`.
   - `graph`: `~/.graphify/global-graph.json` reported `STALE` across all `7/7` repos (`w0m-web` `+39` commits, `w0m-api` `+18` commits) because `AgDR-0032` commits happen inside agent worktrees (`_GFY_GITDIR != _GFY_COMMONDIR`, where `post-commit` exits `0`) and fast-forward onto canonical root (`git merge --ff-only`, which fires no `post-commit`), while `_post-deploy-knowledge` in `justfile` exited `0` whenever `W0M_RELEASE_WORKTREE` was set (`100%` of `deploy-all` runs).
   - `repos`: `w0m-sec/.gitignore` lacked Python bytecode ignore rules (`__pycache__/`), `w0m-web/.gitignore` anchored `.obsidian/{plugins/,workspace.json,workspace-mobile.json}` to the repo root instead of `**/.obsidian/...` (leaving `projects/w0m/vault/.obsidian/{appearance,core-plugins,workspace}.json` untracked), and Obsidian Desktop strips the trailing newline on `projects/w0m/vault/.obsidian/app.json` whenever the vault is open.
2. **Silent fire-and-forget / `|| true` / unmonitored staleness traps (`AgDR-0025`)**:
   - `w0m-web/.husky/pre-push` launched `nohup python3 ../scripts/sync_github.py > .git/w0m-ticket-sync.log 2>&1 &` and `just graph-global --settle 8 || true` inside the wrong repo, hiding crashes inside `.git/w0m-ticket-sync.log` while `pending_mirror` drifted to `647/647` with `[INFO]` (`exit 0`).
   - `deploy-web` in `justfile` appended `|| true` to `snapshot-{settings,blueprints,knowledge}.mjs` (even though those scripts already handle DB-unreachable warnings internally and only exit non-zero on real script/module crashes).
   - `5` PostgreSQL scripts in `w0m-api/scripts/` (`db_backup.py`, `db_restore_verify.py`, `stage2_schema_check.py`, `t287_repos_check.py`, `t510_publication_check.py`) hardcoded macOS Homebrew `/opt/homebrew` + `/usr/local/opt` paths, failing with `exit 2` (`brew install postgresql@17`) on Linux where PostgreSQL 18 is installed under Linuxbrew (`/home/linuxbrew/.linuxbrew/opt/postgresql@18/bin`).

## Acceptance criteria

- [x] **AC1 — Restore clean `just preflight --fast` (`exit 0`) across `mcp`, `repos`, and `graph`**: Mark `headroom-proxy` `"required": false` in `.w0m/sdlc.json` (preserving `mcp_declared` / `mcp_exposure` / `catalog` parity); fix `w0m-sec/.gitignore` (`__pycache__/`, `*.py[cod]`, `.pytest_cache/`, `.ruff_cache/`, `.mypy_cache/`) and `w0m-web/.gitignore` (`**/.obsidian/plugins/`, `**/.obsidian/workspace*.json`, `**/.obsidian/appearance.json`, `**/.obsidian/core-plugins*.json`); and treat pure whitespace/EOF-newline churn on `.obsidian/*.json` in `preflight.py:check_repos()` as a non-failing note while still flagging substantive uncommitted edits.
- [x] **AC2 — Worktree-aware `graph_global.py --auto-rebuild-stale` + canonical post-land & post-deploy refresh**: Add `--auto-rebuild-stale` (`--stale-limit 10`, incremental `graphify.watch._rebuild_code` + `GIT_DIR` hook-env scrubbing) to `scripts/graph_global.py` so repos exceeding `graph_fresh.py`'s `STALE_COMMITS_FAIL` (`10`) are refreshed before merging into `~/.graphify/global-graph.json`; invoke it post-land on the canonical root in `scripts/session_complete.py`; and fix `_post-deploy-knowledge` in `justfile` to run against the canonical estate root instead of skipping under `W0M_RELEASE_WORKTREE` or swallowing failures with `|| true`.
- [x] **AC3 — Remove swallowed `nohup` / `|| true` hook & deploy snapshot traps (`AgDR-0025`)**: Remove the stranded `nohup ../scripts/sync_github.py > .git/w0m-ticket-sync.log 2>&1 &` and `|| true` graph call from `w0m-web/.husky/pre-push` (gating `graph-global` to canonical checkouts with `GIT_DIR` unset), and strip `|| true` from the 3 `snapshot-*.mjs` invocations in `justfile` (`deploy-web`).
- [x] **AC4 — Cross-platform Linuxbrew + Debian/Ubuntu PostgreSQL binary discovery in `w0m-api`**: Update `CANDIDATE_DIRS` / `BIN_CANDIDATES` across `w0m-api/scripts/{db_backup,db_restore_verify,stage2_schema_check,t287_repos_check,t510_publication_check}.py` to discover Linuxbrew (`/home/linuxbrew/.linuxbrew/opt/postgresql@{18,17}/bin`, `/home/linuxbrew/.linuxbrew/opt/postgresql/bin`, `/home/linuxbrew/.linuxbrew/bin`) and `/usr/lib/postgresql/{18,17}/bin`.
- [x] **AC5 — Bounded `automation-health` gate (`scripts/automation_health.py` + `scripts/tests/test_automation_health.py`)**: Implement `<0.5s` offline `just automation-health` (`prepush: true` in `w0m-web/project/test-suites.json`, wired into `session_wrapup.verification_gates` and `preflight` full sweep) enforcing `.w0m/sdlc.json -> automation_health` staleness ceilings (`max_pending_ticket_mirror`, `max_graph_union_commit_lag`), banning `nohup ... .git/*.log` fire-and-forget hooks and `deploy-*` `snapshot-*.mjs || true` swallows, with full unit + red-probe coverage (`just automation-health-test`).
