# T393 — Rename and refactor wom7cfworkers estate repository and subsystem to wom7func

## Summary

The `wom7cfworkers` repository hosts the estate's edge compute, async workflows, and serverless functions (e.g. crawler, AI inference, domain scanners, certificate ingestion, vectorizers, and email workflows). However, the moniker `cfworkers` couples the architectural identity of the functions estate repository directly to a single vendor implementation name (Cloudflare Workers).

Per owner directive: *"then let's rename/refactor wom7cfworkers to be now wom7func"*.

This ticket renames and refactors the subsystem across the entire w0m estate:
1. Renaming the directory to `wom7func/` and GitHub repository to `casualuser/wom7func`.
2. Modernizing package and deployment manifests (`package.json`, `wrangler.jsonc`, documentation) under the `wom7func` identity.
3. Updating estate governance and tool contracts: `.w0m/sdlc.json`, `project/stacks-policy.json`, `project/deps-policy.json`, `project/hygiene-policy.json`, `project/ignore-policy.json`, `test-suites.json`, and root workspace pointers.
4. Aligning recipes in `wom7api/justfile` and root `@wom/justfile` to ensure seamless command execution and automated gate parity.
