# T482 — SkillOpt integration: nightly self-evolution cycle (just sleep) and skill optimization for wom7skills

## Summary

Integrate Microsoft SkillOpt (arXiv:2605.23904, May/July 2026) into the w0m estate. SkillOpt treats natural-language skill documents (`SKILL.md`) as the trainable parameters of frozen LLM agents, optimizing them via trajectory rollouts, reflection, edit aggregation, and held-out validation gates.

This ticket delivers:
1. `just sleep` CLI harness wrapping `skillopt-sleep` for nightly offline agent evolution.
2. A multi-agent transcript harvester for Claude Code (`~/.claude/projects/`) and Google Antigravity (`transcript.jsonl`), with automatic secrets redaction via w0m's `secrets-check` patterns.
3. Automated friction mining that detects repeated pre-commit hook failures, typecheck errors, and user corrections, synthesizing draft rules into `LESSONS.md` and candidate wording patches for `.agents/skills/*/SKILL.md`.
4. Held-out validation gates enforcing `gate_no_regression: true` before staging proposals for human adoption (`just sleep adopt`).
5. Support for local execution via `wom7mlx` / Ollama (Apple Silicon) for 100% air-gapped, zero-cost, secret-safe offline runs.

## Acceptance criteria

- [x] AC1 — **Tooling & Dependency Setup**: Add `skillopt` to estate tooling dependencies via `uv`/`pyproject.toml`, and register `just sleep` recipe in `justfile` exposing subcommands (`status`, `dry-run`, `run`, `adopt`, `harvest`). Proved by `just sleep --help` executing cleanly.
- [x] AC2 — **Antigravity & Multi-Agent Transcript Harvester**: Implement a w0m transcript reader supporting both Claude Code (`~/.claude/projects/`) and Antigravity (`transcript.jsonl`) logs, with automatic secret redaction using w0m's `secrets-check` patterns before any transcript excerpts are passed to mining.
- [x] AC3 — **Friction Mining & Lesson Synthesis**: The miner extracts agent friction points (failing pre-commit gates, repetitive user corrections, compiler/typecheck errors) and generates candidate rules formatted per `LESSONS.md` conventions (Problem, Lesson =>, and The Tell) into staged `report.md`.
- [x] AC4 — **Held-Out Validation Gate (`gate_no_regression: true`)**: Skill patches are replayed against a held-out benchmark set of real w0m tasks (e.g. 5 tickets across SDLC lifecycle) and strictly blocked if any benchmark score regresses.
- [x] AC5 — **Staged Proposal & Human Adoption Flow**: Proposed skill modifications land in `.agents/reports/sleep/` with before/after diffs; `just sleep adopt --skill <name>` copies accepted patches into `.agents/skills/<name>/SKILL.md` and runs `just skill reconcile` into `wom7skills` with pre-commit gates passing.
- [x] AC6 — **Local MLX Backend Support (`wom7mlx`)**: Provide configuration to route reflection and replay calls through a local OpenAI-compatible endpoint (`http://127.0.0.1:8000/v1` via MLX or Ollama) for 100% air-gapped, zero-cost, secret-safe execution.
