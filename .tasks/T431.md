# T431 — Top-level deploy helpers: one gated `just deploy-function <name…>` replaces 25 per-function recipes

## Summary

Owner direction (2026-09-23): `deploy`, `deploy-all` and per-function deploys are **top-level
helpers** in the estate root `justfile`. `deploy` and `deploy-all` were already canonical there
(wom7api delegates, from [[T421]]). Per-function deploys existed only as **25 hand-written
`deploy-<x>` recipes in `wom7api/justfile`**, each the same line with a different name:
- 2 could never run: `deploy-submit-service-request` and `deploy-client-register` confirmed steps
  missing from `confirm-policy.json`, so the gate fails closed on them;
- 1 targeted a function with no source (`deploy-log` → `log-event`);
- 4 passed `--no-verify-jwt`, and for 2 of those (`linkedin-ingest`, `github-repos`) that contradicted
  the declared posture in `supabase/config.toml` (`verify_jwt = true`, decided under T198/T199 AC3 on
  2026-08-11). Every bulk deploy since then has applied `true`; that is what is live
  (`supabase functions list`, 2026-09-23).

Trigger: the 2026-09-23 `deploy-all` hit three Supabase `500 internal error`s on `get-bot-status`,
`hume-token` and `linkedin-share`. There was no top-level way to redeploy just those three without
re-running the whole chain. None of the three had code changes since their 2026-09-20 deploy, so the
live versions already match the repo.

## Acceptance criteria

- [x] AC1 — Root `deploy-function +names: (_confirm "deploy-function")` runs
  `scripts/deploy_function.py`. Every name is validated against `wom7api/supabase/functions/`
  before anything deploys: unknown names get close-match suggestions, duplicates and empty input fail,
  and one bad name blocks the batch. The recipe issues ONE `supabase functions deploy <names…>`
  under `infisical run --projectId=…` (see [[T429]]). JWT posture comes from `config.toml`. It does
  not restamp DEPLOY_VERSION, because a partial redeploy is not a release.
- [x] AC2 — `just deploy-function-list` (read-only, ungated) prints the 58 deployable names.
- [x] AC3 — Clean cutover: all 25 per-function recipes deleted from `wom7api/justfile` and replaced
  by thin delegates (`deploy-function`, `deploy-function-list`). `confirm-policy.json` drops their 23
  step entries and gains `deploy-function`. `just confirm-test`: 30 passed.
- [x] AC4 — Probe `scripts/tests/test_deploy_function.py` (9 checks, validation and dry-run only,
  never deploys), including "no per-function deploy line survives in wom7api/justfile" and "the root
  recipe is confirm-gated" and "the root justfile exports `W0M_DB_MIGRATIONS`". Registered as
  blocking suite `deploy-function`.
