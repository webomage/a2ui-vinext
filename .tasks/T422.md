# T422 — Design System React Spec Elimination & Token SSOT Consolidation (Post-T420 Phase 2)

## Summary

Following the completion of [[T420]], the runtime design system wiring landed successfully:
- `@webomage/ui/tokens.css` is active across `apps/web` and `apps/cp` with 213 declarations.
- shadcn color utilities emit in production bundles, `--radius-md` resolves to 8px, and hardcoded inline fallbacks were eliminated (32 → 0).
- All React code (`.jsx`, `.dc.html`, templates) was deleted from `design-system/` (24 MB → 4.9 MB).

However, as analyzed in the post-T420 audit report (`_in/2026-09-23-recheck-design-system-post-t420-and-react-free-component-plan.md`), the surviving specification layer remains written in React terms:
1. **React-shaped Specs**: 21 of 26 surviving `.prompt.md` files still exhibit ` ```jsx ` code blocks and `className` attributes, and 17 `.d.ts` files still type props using `ReactNode` and `JSX.Element`. Svelte authors are still guided through a legacy React mental model.
2. **Blocked T92 Registry**: `TARGET-COMPONENT-REGISTRY-2026-09-10.md` §2 directs T92 to source the 7-component port from `.jsx` files that T420 deleted. T92 cannot start as written.
3. **Token Divergence**: `packages/ui/src/tokens.css` (203 names) and `design-system/tokens/*.css` (188 names) are hand-maintained independently, and `--tracking-widest` was dropped from the shipping package.

This ticket delivers **Phase 2 (Ticket A: P1 + P2 + P3)** of the React-free component pipeline:
- Purge all React syntax, JSX blocks, and React typings from `design-system/components/` in favor of native Svelte 5 / Astro contracts.
- Consolidate token definitions into a single authoritative SSOT, restore `--tracking-widest`, and establish a parity verification test.
- Re-point `TARGET-COMPONENT-REGISTRY-2026-09-10.md` to live, resolving files so [[T92]] is completely unblocked.

## Acceptance criteria

- [ ] AC1 — **Eliminate React / JSX from Component Prompts**: Rewrite all 21 surviving `design-system/components/**/*.prompt.md` files to provide native Svelte 5 / Astro markup examples imported from `@webomage/ui`, with zero occurrences of ` ```jsx `, `className`, or React imports.
- [ ] AC2 — **Eliminate React Types from Component Declarations**: Replace `ReactNode`, `JSX.Element`, and React imports in all 17 `design-system/components/**/*.d.ts` files with native TypeScript contracts matching Svelte 5 `$props()` interfaces.
- [ ] AC3 — **Consolidate Token SSOT & Restore Missing Tokens**: Establish a single authoritative source of truth between `design-system/tokens/*.css` and `packages/ui/src/tokens.css`. Restore the missing `--tracking-widest` token to `packages/ui/src/tokens.css`.
- [ ] AC4 — **Implement Token Parity & Drift Gate**: Establish automated test verification ensuring token definitions between the spec layer and shipping `@webomage/ui` package match 100% with zero divergence.
- [ ] AC5 — **Re-point T92 Target Component Registry**: Update `TARGET-COMPONENT-REGISTRY-2026-09-10.md` §2 so that the 7 target components (`BlueprintCard`, `ComplexityBadge`, `SegmentBadge`, `TechIcon`, `GlassCard`, `StatusDot`, `QuickViewModal`) reference valid live `.prompt.md`, `.d.ts`, and live `.astro` implementations, with 100% paths resolving on disk.
- [ ] AC6 — **Automated Regression Proof**: Implement automated regression verification proving zero React artifacts (` ```jsx `, `className`, `ReactNode`, `JSX.`) in `design-system/components/`, zero broken references in the component registry, and passing token parity.

## Definition of Done

Per `openspec/SPEC-AUTHORING-STANDARD.md`:
1. `grep -rnE '(```jsx|className|ReactNode|JSX\.)' wom7web/design-system/components` returns 0 hits.
2. Every path in `wom7web/design-system/TARGET-COMPONENT-REGISTRY-2026-09-10.md` resolves on disk.
3. `just ds-react-free-test` passes 100% green.
4. Pre-commit and pre-push quality gates pass without `--no-verify`.
