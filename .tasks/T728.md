# T728 — Harden Client JSON Parsing via Shared `readJsonSafe`, Eliminate Missing `<img>` Dimensions (CLS), and Replace `transition-all` Hotspots

## Summary

Hardens client-side HTTP error handling across `apps/web`, `apps/me`, and `apps/cp` via a shared `readJsonSafe` helper in `@webomage/lib` so non-JSON `403`/`502`/`504` responses never surface raw `SyntaxError: Unexpected token ... is not valid JSON` banners, adds explicit `width` and `height` attributes (`+ loading="lazy" decoding="async"`) on `<img>` elements missing intrinsic dimensions across `web`, `me`, and `cp` to prevent Cumulative Layout Shift (`CLS`), and replaces layout-thrashing `transition-all` classes in top UI hotspots with compositor-friendly transitions.

## Acceptance criteria

- [x] AC1 — **Publish Shared `readJsonSafe` Helper & Wire Client Fetch Callers (`w0m-web/packages/lib/src/http/json-safe.ts`, `w0m-web/packages/lib/src/http/__tests__/json-safe.test.ts`):** Published `readJsonSafe<T>(res)` in `@webomage/lib` (`5/5` Vitest unit tests passed) and wired 10 client fetch surfaces across `apps/web`, `apps/me`, and `apps/cp`.
- [x] AC2 — **Eliminate Missing `<img>` Intrinsic Dimensions & `transition-all` Hotspots (`w0m-web/apps/web/src/`, `w0m-web/apps/me/src/`, `w0m-web/apps/cp/src/`):** Added explicit `width`, `height`, and `decoding="async"` on all remaining real `<img>` tags across `web`, `me`, and `cp` (`0` missing) and replaced `72` `transition-all` hotspot occurrences with explicit property transitions.
