# T242 — align the numbering by creating it, not by renaming anything

## Summary

Owner 2026-08-20, after establishing that **a personal account cannot be converted to an
organization** (tried; GitHub does not offer it): *"create w0m account … rewrite carefully our
ticketing numbers, sync tightly with GH, and reprocess everything with validation — that will help
also to master projects importing."*

### 🔑 This is the REVERSE of the renumbering [[T239]] AC6 rejected, and that is why it works

AC6 disqualified **renaming T-ids to match GitHub** because **1,004 commit messages** cite a T-id
and a rename makes them *silently wrong* rather than merely broken. This proposal holds **T-ids
fixed** and aligns a **fresh** repo's counter to them:

| | rename T-ids (rejected, AC6 option 4) | align a fresh repo (this ticket) |
|---|---|---|
| 1,004 commit messages | 🔴 silently wrong | ✅ untouched |
| 1,735 body cross-refs | mechanical churn | ✅ untouched |
| junk placeholder issues | **9** (to reach #246) | **0** — a new counter starts at 1 |
| master/projection direction | 🔴 inverted | ✅ preserved |

### 🔴 The contradiction that shapes the design — transfer and alignment are mutually exclusive

Transferring a **repository** *preserves* its issue numbers. That is normally the good news, and
here it is the opposite: **preserving the numbers preserves today's misalignment** (235 mapped
tickets span **21 offsets, −61 to +41**). Alignment therefore requires issues to be **created**, not
moved — which means a **new repo**, because numbering cannot be rewritten in place.

⇒ **The tracker becomes a NEW, CODE-FREE repo in the `w0m` org.** And that lands exactly on AC6's
own conclusion about stability: a code-free repo **never receives a pull request**, and the issue
counter is shared with PRs — so this is the *only* form of `T<n> == #<n>` that is permanently true
rather than defended. The current tracker (`casualuser/webomage.com`) is the **web application's**
repo, i.e. the likeliest PR source in the estate.
📌 **The code repos are a separate, unhurried decision.** Transfer preserves their numbers, so
nothing forces them to move with the tracker.
