## How it arrived, which is half the ticket

🔑 **It blocked a commit before anyone read it.** The file carried **17 emoji headings**, breaching
`emoji-check`'s `md_headings_estate` ratchet (476 → 493), and `git add -A` swept it into an unrelated
commit. Two separate defects, and both are the ticket's real subject:

1. **A gate scoped wider than the change.** `emoji-check` measures the **working tree**, not the
   staged set — so an **untracked** file nobody was committing blocked a commit. Unstaging did not
   help. ⚠️ This is [[T267]]'s shape exactly (a deploy in another repo blocking a commit here), and
   the escape hatch in both cases is `--no-verify`, which is **prohibited**. A gate that blocks on
   files outside your change is how that prohibition gets tested.
2. **No handoff protocol between agents on one machine.** A second agent wrote into this repo's
   `docs/reports/` with no signal of ownership, completeness, or intent. The `T235` hook
   (*"refuse to commit another agent's in-flight work"*) **passed** — it did not catch this.

⇒ The owner's *"master also archiving and handoff processes later"* is the durable half. The 21 GB
is a one-off; the two defects above will recur every time two agents share a filesystem.
