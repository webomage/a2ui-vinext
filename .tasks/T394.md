# T394 — Interactive filtering, multi-dimensional aggregation, and client-delivery readiness insights in STATUS-DASHBOARD

## Summary

`docs/STATUS-DASHBOARD.html` (generated by `project/scripts/gen_status_dashboard.py` from `TASKS.md`, `ROADMAP.md`, and embedded ticket JSON) is the executive and agent delivery dashboard for the w0m ecosystem.

Per owner directive:
1. *"let's make STATUS-DASHBOARD more interactive with filters and aggregated groupping by tags, domain or roadmap section clicking a tag/domain/roadmap from list to activate"*
2. *"look how we can enhance this DASHBOARD with insights regarding what should be done in first place for security, quality and stability in bringing to deliver client functions solid"*

Today the dashboard renders a static list of board tasks without client-side interactive slicing. Furthermore, it lacks a dedicated, structured advisory view analyzing which open tickets and quality interventions directly impact **security, quality, and stability** for client-facing capabilities (such as portal access, client contracts, Stripe commercial billing, tenancy scoping, and KYC).

This ticket implements:
1. Interactive pill/tag filters in `STATUS-DASHBOARD.html`: click any tag, domain (`area`), status, or roadmap section to filter and group tasks dynamically with live counts.
2. An authoritative "Client Delivery Readiness & Stabilization Insights" panel highlighting prioritized security, quality, and stability interventions required to solidify client functions.
3. Enhanced generator logic in `project/scripts/gen_status_dashboard.py` to calculate tag/domain aggregates and client readiness metrics during build and embed them cleanly.

## Acceptance criteria

- [x] AC1 — Design and implement interactive filter controls (clickable pills for Status, Domain/Area, Tags, and Roadmap Sections) in `docs/STATUS-DASHBOARD.html` that reactively filter the task board with active state toggling, search, and multi-dimensional aggregation counts.
- [x] AC2 — Create a dedicated "Client Delivery Readiness & Stabilization Insights" panel in `docs/STATUS-DASHBOARD.html` categorizing the top critical interventions across Security (auth/RLS/tenancy), Quality (test coverage/specs), and Stability (deploy/error handling) required to deliver client functions solid.
- [x] AC3 — Update `project/scripts/gen_status_dashboard.py` to extract metadata (tags, areas, epics, blockers) from embedded tickets and generate the structured data attributes and aggregation summaries for the interactive board.
