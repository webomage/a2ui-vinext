# T518 — Group C: seven scripts that need a product decision

## Summary

Split from [[T509]]. These scripts cannot be classified by reading code alone: each is either useful or dead depending on
whether a product or feature is still live. They are kept, untouched, until the owner answers the question beside each one.
Nothing here is deleted or converted by this ticket before that answer.

## The seven and the question each needs answered

| Script | What it is | Question for the owner |
|---|---|---|
| `backfill_news.py`, `backfill_post_images.py`, `validate_content.py` | The daily-news pipeline's backfill, image generation and front-matter validation | **Is the news pipeline still a product?** A recipe that generates a news post still exists (`wom7api/justfile`), but these three read `wom7web/src/content/posts`, which no longer exists, so they are broken, not dead |
| `validate_tracks.py` | Schema check for `wom7api/design/tracks.yml` (stages: Engagements, Training, Certification, Employment) | **Are "tracks" a live concept?** The yml still exists, but its two generators have no output path left |
| `smoke_test.py` | Enqueues two URLs to the production crawler worker | **Is the crawler worker live?** A `crawler-deploy` recipe exists; if so this becomes its post-deploy smoke test, with the worker URL moved out of the file |
| `index_internal_docs.py` | Indexes internal documents for retrieval | **What calls it, and is retrieval over internal docs live?** No caller was found in any repo |
| `backfill_upwork_proposals.py` | Backfills Upwork cover letters and archive proposals, idempotent with a dry-run guard | **Wait for [[T468]]** (the Upwork source layer, in progress) to say whether this backfill is still needed |

## Acceptance criteria

- [x] AC1 — **Each question is answered by the owner** and the answer is recorded in the status note with the date.
- [x] AC2 — **If the news pipeline is live:** the three scripts are fixed to read the real content location, converted to
  recipes with tests, and registered. **If not:** they and the news-generation recipe are archived together to
  `_arch/news-pipeline/`, with the posts table and any scheduled job checked for dependents first.
- [x] AC3 — **If tracks are live:** `validate_tracks` becomes `just tracks-check`, wired into the content checks, and the
  two generators are repaired or removed. **If not:** all three are archived with `design/tracks.yml`.
- [x] AC4 — **If the crawler is live:** `smoke_test` takes its URL from configuration and runs after `crawler-deploy`.
  **If not:** archive it.
- [x] AC5 — **`index_internal_docs`:** a caller is found and wired, or it is archived with a note of what it indexed.
- [x] AC6 — **`backfill_upwork_proposals`** is closed out or converted in the same change that closes [[T468]], not before.
