# T707 — Audit and Adopt casualuser/job-hunter-skill into w0m-skills & Estate Skill Manifests

## Summary

Perform a full security, prompt-injection, exfiltration, and provenance audit of `https://github.com/casualuser/job-hunter-skill` before adoption. Once verified clean (or remediated in a `webomage/job-hunter-skill` fork), vendor the skill into `w0m-skills/skills/`, record provenance in `w0m-skills/skills-registry.json` and `w0m-skills/NOTICE.md`, declare it in `.w0m/skills.json`, `w0m-web/.w0m/skills.json`, and `w0m-web/project/skills-survey.json`, and sync across the estate via `just skills-sync`.

## Acceptance criteria

- [ ] AC1 — **Zero-Exec Static & Security Audit of `casualuser/job-hunter-skill`:** Audit all `SKILL.md`, scripts, references, and hooks in `https://github.com/casualuser/job-hunter-skill` using `pnpm --dir w0m-skills run skill-audit` and `runReadOnlyRepoAndSkillUiAudit` to verify zero prompt injection, secret exfiltration, or unsafe shell execution.
- [ ] AC2 — **Canonical Fork & Vendoring into `w0m-skills`:** Fork/mirror to `github.com/webomage/job-hunter-skill` if needed, vendor the complete skill directory into `w0m-skills/skills/job-hunter-skill` (or canonical skill name), and record provenance + license in `w0m-skills/skills-registry.json` and `w0m-skills/NOTICE.md`.
- [ ] AC3 — **Estate Manifest Enrollment & `just skills-sync`:** Add the skill to `.w0m/skills.json`, `w0m-web/.w0m/skills.json`, and `w0m-web/project/skills-survey.json`, and verify `just skills-sync && just skills-sync --check` exits `0`.
- [ ] AC4 — **Audit & Adoption Report:** Publish the security audit findings and usage guide in `.agents/reports/` (mirrored to `w0m-web/docs/reports/`).

## Definition of Done

Per [`w0m-web/openspec/SPEC-AUTHORING-STANDARD.md`](../w0m-web/openspec/SPEC-AUTHORING-STANDARD.md):
- Acceptance criteria AC1–AC4 verified by `pnpm --dir w0m-skills run skill-audit`, `pnpm --dir w0m-skills run skill-test`, and `just skills-sync --check`.
