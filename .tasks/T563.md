# T563 — Build multi-platform Outreach & Communications Hub in job.webomage.com with AI drafting and follow-up pipeline

## Summary

Build the unified **Outreach & Communications Hub** in `job.webomage.com` (`wom7web/apps/job/src/pages/me/outreach.astro` and `/o/[org]/outreach.astro`) per `AgDR-0033`, giving members and org commercial leads a single workspace to triage browser-clipped jobs/profiles/threads (`outreach_clips`), manage multi-platform conversations (`outreach_threads` + `outreach_messages` + `upwork.*` rooms), track follow-up pipelines (`clipped` → `drafting` → `sent` → `replied` → `follow_up_due` → `converted_to_proposal` → `converted_to_contract`), and generate evidence-grounded outreach/proposal drafts via `w0m-personnel` (`profile_cv_facts` + `upwork_evidence_passages`).

## Acceptance criteria

- [x] AC1 — **Unified Outreach Inbox & Pipeline View (`/me/outreach`, `/o/[org]/outreach`, `OutreachHub.svelte`).** Render platform filter pills (`All`, `Upwork`, `LinkedIn`, `Contra`, `Toptal`, `Freelancer`, `Fiverr`, `Wellfound`, `X-Team`, `Indeed`, `Direct`, `Generic Web`), stage filter/Kanban (`clipped`, `drafting`, `sent`, `replied`, `follow_up_due`, `converted_to_proposal`, `converted_to_contract`, `archived`), search across threads/clips/messages, and follow-up due badges using `@webomage/ui` primitives (`Button`, `Input`, `Badge`, `Card`, `PageHeader`).
- [x] AC2 — **Clipped Pages Vault & Promotion Flow (`/me/outreach` Clips drawer/tab).** Inspect raw and Markdown-rendered `outreach_clips` captured by `wom7ext` (or manual URL/markdown paste), edit structured fields (counterparty, company, platform URL), and promote a clip in one click to an active `outreach_thread`, `proposals` row, or `contracts` link via `public.source_links`.
- [x] AC3 — **Evidence-Grounded AI Outreach & Reply Composer (`w0m-personnel` integration).** In any outreach thread or clipped job/profile, invoke `/api/outreach/draft` with the member's primary/selected CV variant (`profile_resumes`), curated `profile_cv_facts`, and matched `upwork_evidence_passages` to draft tailored cold outreach, screening answers, or thread replies with one-click copy + open-source-URL to send in the target platform.
- [x] AC4 — **Unified Cross-Channel Thread Timeline (`/me/outreach`, `/api/outreach/{threads,messages}`).** Display inbound/outbound messages (`outreach_messages`) alongside linked `upwork` room messages, linked proposals, and linked contracts, with ability to log manual replies or append newly clipped messages from `wom7ext`. Verified by component and route unit tests (`outreach-hub.test.ts`).
