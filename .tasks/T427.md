# T427 — Remove cross-repo escaping symlinks across w0m repos (replace with direct `@wom` root resolution)

## Context

In `T412` and `T414`, `.tasks/`, `.w0m/`, and `project/` were elevated to the `@wom` workspace root, and compatibility symlinks were temporarily created inside `wom7web/`, `wom7api/`, and `wom7func/` so existing relative paths wouldn't break immediately.

However, cross-repository symlinks (`../...` or `../../...`) that escape a git repository's root boundary are a **fragile anti-pattern** (see `AgDR-0025`):
1. **Broken in isolated git worktrees:** When an agent creates a worktree (`git worktree add /tmp/wt-branch`) for `wom7web` or `wom7api` outside the standard parent directory layout, every `../` symlink becomes a dangling link (`ENOENT`). (Partially mitigated at the estate level by `AgDR-0032` `just agent-tree`, which clones all 8 repos in layout, but individual repo checkouts still break on escaping symlinks.)
2. **Double-counting in search & indexers:** Tools that follow symlinks or scan multiple repos index the same files twice or fail on circular/escaping links.
3. **Confusing ownership:** It obscures whether a file belongs to `@wom`, `wom7web`, or `wom7api`.

### Current Escaping Symlinks Inventory (Resolved 2026-10-22)

1. **`wom7api` (4 -> 0 tracked escaping symlinks):**
   - Removed `.agent -> ../wom7web/.agent` (retired singular `.agent`; `wom7api/.agents` is a real tracked directory with 55 files and `wom7api/.agents/rules/w0m.md` carries the Antigravity contract)
   - Removed `.codex -> ../wom7web/.codex` (dangling link; target did not exist)
   - Removed `.gemini -> ../wom7web/.gemini` (dangling link; target did not exist)
   - Removed `.kilocode -> ../wom7web/.kilocode` (dangling link; target did not exist)
2. **`wom7func` (1 -> 0 tracked escaping symlinks):**
   - Replaced `justfile -> ../wom7api/justfile` with a self-contained `wom7func/justfile` exporting `W0M_ROOT` and providing `dev`, `test`/`cf-test`, `typecheck`/`cf-typecheck`, `cf-typegen`, `check`, and `deploy` (delegating to `@wom/justfile deploy-workers`).
3. **`wom7web` (16 -> 8 tracked symlinks; 8 zero-caller escaping symlinks removed, remaining 8 + 76 script symlinks governed by `[[T509]]`):**
   - Removed 8 escaping symlinks in `wom7web/project/`: `doc-format-policy.json`, `hygiene-policy.schema.json`, `ide-policy.schema.json` (updated `test_ide_trace.py:112` to read `ROOT / "project" / "policies" / "ide-policy.schema.json"`), `mcp-health-policy.json`, `skills-policy.schema.json`, `stacks-policy.schema.json`, `templates/decision.md`, `templates/ticket.md`.
   - Remaining `wom7web` symlinks (`justfile`, `TASKS.md`, `.w0m/sdlc.json`, and 5 active policy symlinks + 76 script symlinks in `wom7web/project/scripts/`) are explicitly scoped to `[[T509]]` (`U1`/`U2`, `AC9`/`AC10`), which performs the staged 6-commit script ownership cutover and updates `tasks_render.py` and `test_confirm_step.py`.
