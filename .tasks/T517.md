# T517 — Group B: fold nine scripts into existing tools

## Summary

Split from [[T509]]. These nine scripts do something worth keeping, but each overlaps a tool that already exists or repeats a
pattern three times. Converting each into its own recipe would add surface, not value. The right move is to move the
useful part into the existing home and then archive the leftover. Weighted 2026-09-30 by reading each file.

## The nine

| Script | V | R | Ready | Folds into | Why |
|---|---|---|---|---|---|
| `verify_t440_live.py` | 2 | 2 | 3 | one shared live-verify helper | Signs in as a member and checks counts and RLS through the real API; [[T440]] is done |
| `verify_t443_founder_units.py` | 2 | 2 | 3 | the same helper | Same pattern; [[T443]] is done |
| `verify_t444_site_settings.py` | 2 | 2 | 3 | the same helper | Same pattern; [[T444]] is done |
| `t352_fallback_hat_probe.py` | 3 | 3 | 3 | `project/scripts/authz_probe_suite.py` | Every mutating check is already `BEGIN ... ROLLBACK`, the suite's own shape; [[T352]] is done |
| `verify_siri_shortcuts_contract.py` | 2 | 2 | 3 | `zeroclaw health` ([[T516]]) | Checks the host's ZeroClaw and Shortcuts config; [[T367]] is done |
| `verify_cf_ai.py` | 3 | 3 | 2 | `just health` | A Cloudflare AI connectivity check, but it tests a retired model (`llama-2-7b`); point it at the current alias |
| `fetch-upwork.js` | 3 | 2 | 2 | `just upwork-poller-status` | Lists the `contracts` storage folder and `upwork_poller_state`; useful for [[T468]] |
| `test_obsidian_mcp.py` | 3 | 3 | 2 | the MCP-bridge test suite | Smoke test of the Obsidian MCP bridge with a hardcoded absolute path; preflight showed that server down, so a real test has value |
| `security_audit.py` | 2 | 2 | 2 | the gitleaks pre-commit hook | Runs a staged-file gitleaks scan, which the hook already does |

## Acceptance criteria

- [ ] AC1 — **One live-verify helper replaces three probes.** It signs in as a named member and asserts counts and RLS
  through the real API, so a ticket's live verification is data (a list of checks), not a new script. The three `verify_t44x`
  scripts are re-expressed as check lists and give the same results against the live state they were written for.
- [ ] AC2 — **`t352` checks live in `authz_probe_suite`** and the suite's check count rises by the number moved, with the old
  script removed in the same commit.
- [ ] AC3 — **`zeroclaw health` includes the Siri and Shortcuts contract checks** from `verify_siri_shortcuts_contract`.
- [ ] AC4 — **The Cloudflare AI probe uses the current model alias** (`w0m-llm-personnel`) and is part of `just health`; the
  retired model name is gone from the repo.
- [ ] AC5 — **`just upwork-poller-status`** prints poller state and the storage listing with no hardcoded contract path.
- [ ] AC6 — **The Obsidian MCP bridge test uses repo-relative paths,** asserts a real response (not only that the process
  starts), is registered in `test-suites.json`, and fails with a clear message when the bridge cannot start.
- [ ] AC7 — **`security_audit.py` is removed** after confirming the gitleaks hook covers its checks (staged scan,
  missing-binary message); anything it did that the hook does not is listed first.
- [ ] AC8 — **Nothing is deleted before its replacement is proven.** Each folded script is archived to
  `_arch/<descriptive-name>/` (the estate's soft-delete bin), not removed, and the archive records which check replaced it.
