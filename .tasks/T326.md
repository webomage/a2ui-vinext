# T326 — Authenticate outbound mail, and codify the 3-channel sender architecture

## What is true right now

- **SPF — authored in Terraform (`AC1`, `AC5`).** Added `cloudflare_record.webomage_root_spf_txt` (`"v=spf1 include:_spf.google.com include:amazonses.com ~all"`) on `webomage.com`, authorizing both Google Workspace SMTP (`_spf.google.com`) and Resend (`amazonses.com`).
- **DMARC — authored in Terraform (`AC2`, `AC5`).** Added `cloudflare_record.webomage_dmarc_txt` (`"v=DMARC1; p=none; rua=mailto:dmarc@webomage.com; pct=100"`) on `_dmarc.webomage.com`.
- **3-Channel Sender Architecture (`AC3`, `AC4`, `AC6`, [[AgDR-0040]]):**
  1. **Supabase Auth (`supabase.auth.*`)** — Self-service OTP login, password reset, email verification.
  2. **Transactional & Platform Messages via Google Workspace SMTP (`sendTransactionalSmtpMail`, `SMTP_USER@webomage.com`)** — `client-register` (B2B client portal magic link), `admin-invite-candidate` (1:1 technical interview invite), and internal admin alerts in `contact-submit` & `apply-submit` (`CONTACT_NOTIFY_EMAIL`).
  3. **Notifications & User Messages via Resend Free Tier (`sendNotificationResendMail`, `no-reply@webomage.com`, DKIM-signed by `resend._domainkey.webomage.com`)** — Visitor auto-reply in `contact-submit`, applicant auto-reply in `apply-submit`, and subscriber broadcasts in `weekly-digest`.

## Acceptance criteria

- [x] AC1 — An SPF record exists on `webomage.com` authorising every sender actually in use (`v=spf1 include:_spf.google.com include:amazonses.com ~all` in `wom7api/cloudflare/records.tf`).

- [x] AC3 — Decision [[AgDR-0040]] (`docs/decisions/AgDR-0040-transactional-mail-sender-consolidation.md` & `wom7web/docs/backend/transactional-mail-sender-decision.md`) records the 3-channel outbound mail architecture: Supabase Auth for auth ceremonies, Google Workspace SMTP (`sendTransactionalSmtpMail`) for 1:1 platform/transactional messages & internal admin alerts (`client-register`, `admin-invite-candidate`, `contact-submit` admin alert, `apply-submit` admin alert), and Resend Free Tier (`sendNotificationResendMail`, DKIM-signed via `resend._domainkey`) for automated user notifications & broadcasts (`contact-submit` visitor receipt, `apply-submit` applicant receipt, `weekly-digest`).
