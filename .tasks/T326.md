# T326 — Authenticate outbound mail, and send through the signed sender

## Summary

Measured 2026-09-07 with `dig` against 8.8.8.8:

- **SPF — authored in Terraform (`AC1`, `AC5`).** Added `cloudflare_record.webomage_root_spf_txt` (`"v=spf1 include:_spf.google.com include:amazonses.com ~all"`) on `webomage.com`.
- **DMARC — authored in Terraform (`AC2`, `AC5`).** Added `cloudflare_record.webomage_dmarc_txt` (`"v=DMARC1; p=none; rua=mailto:dmarc@webomage.com; pct=100"`) on `_dmarc.webomage.com`.
- **DKIM — present (`resend._domainkey.webomage.com`) and now used by all 5 transactional edge functions (`AC3`, `AC4`, `AC6`).** Consolidated `client-register`, `contact-submit`, `admin-invite-candidate`, `weekly-digest`, and `apply-submit` onto `wom7api/supabase/functions/_shared/transactional-mail.ts` (`RESEND_API_KEY` + `RESEND_FROM_EMAIL` primary).

## Acceptance criteria

- [x] AC1 — An SPF record exists on `webomage.com` authorising every sender actually in use (`v=spf1 include:_spf.google.com include:amazonses.com ~all` in `wom7api/cloudflare/records.tf`, verified by `mail_auth_check.py`).
- [x] AC2 — A DMARC record exists at `_dmarc.webomage.com` with a reporting address (`v=DMARC1; p=none; rua=mailto:dmarc@webomage.com; pct=100` in `wom7api/cloudflare/records.tf`, policy recorded in [[AgDR-0040]]).
- [x] AC3 — Decision recorded on the sender split in [[AgDR-0040]] (`docs/decisions/AgDR-0040-transactional-mail-sender-consolidation.md`), explicitly naming `client-register` and consolidating transactional mail onto the DKIM-signed Resend sender.
- [x] AC4 — Applied to all five transactional mail callers (`client-register`, `contact-submit`, `admin-invite-candidate`, `weekly-digest`, `apply-submit`) via `wom7api/supabase/functions/_shared/transactional-mail.ts` with zero partial migration.
- [x] AC5 — Every DNS record added (`webomage_root_spf_txt`, `webomage_dmarc_txt`) is authored in the Cloudflare Terraform stack (`wom7api/cloudflare/records.tf`, [[T125]]).
- [x] AC6 — Verified by `wom7web/project/scripts/mail_auth_check.py` (+ `test_mail_auth_check.py`) that `client-register` and all 4 sibling functions dispatch via DKIM-signed Resend (`resend._domainkey.webomage.com`) and `--live-dns` probes `spf` / `dkim` / `dmarc` TXT records.
