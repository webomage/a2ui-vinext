# T79 — Demo showcase app (demo.webomage.com) + cross-app walkthroughs

## Summary

A front door for the live demo. New standalone `apps/demo` (Astro→CF Worker,
`demo.webomage.com`, `custom_domain`, public) with an **explanatory two-path landing** —
Client vs Candidate — that sends each visitor into the right live app with **one click**
(no password, no link-passing) via the blessed `generateLink → token_hash → /api/auth/callback`
handoff, landing signed-in as the T41 demo persona (`demo-client`→cp `/client/portal`,
`demo-candidate`→join `/dashboard`). Plus a reusable **walkthrough engine** in `@webomage/ui`
(spotlight overlay + floating step card via `@floating-ui/dom`, `data-tour` targeting,
`?tour=` trigger, `localStorage` seen-state) with an authored tour for **all four apps**
(web/cp/join/job). The demo handoff deep-links `?tour=…` so prospects are guided on arrival;
the same engine doubles as first-run onboarding (pairs with T41 demo-data empty states).

Builds on [[T41]] (demo personas/seed-demo) and [[T48]] (`handleCallback` `token_hash` branch).
No new auth model, no new personas, no password login for demo.
