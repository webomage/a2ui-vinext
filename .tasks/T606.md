# T606 — Expose unified 5-target service ordering (Website, Repo, Infra, Cross-Cloud Migration, Blueprint) and @k7* smart infra audit engine across main website and Client Portal

## Summary

Split from [[T604]] to enforce single-responsibility ticket hygiene:
- Build the `@k7*` automated smart infrastructure audit & cross-cloud migration assessment engine (`runK7InfraAndMigrationAudit` in `w0m-web/packages/lib/src/security/advanced-audit.ts`) powered by the `@k7` ecosystem (`@k7c`, `@k7tg`, `@k7s`, `@k7d`, `@k7env`, `@k7spec`).
- Expose unified 5-target service ordering (`website`, `repo`, `infra`, `cross_cloud_migration`, `blueprint`) on the main website (`Header.astro`, `OrderServiceSection.svelte`, `HomeServices.astro`, `ServicesDetailed.astro`, `SecurityAuditWidget.svelte`) and in the Client Portal (`ClientDashboard.svelte`).
- Connect all main-website ordering flows directly to registration (`client-register`) or the AI Agent service-ordering workflow (`ChatApp.svelte` via `wom:chat-order-service`).

## Acceptance criteria

- [x] **AC1 — `@k7*` smart infra audit & cross-cloud migration engine (`@webomage/lib/security/advanced-audit.ts`)**: Implement `runK7InfraAndMigrationAudit` and `K7_ECOSYSTEM_MODULES` (`@k7c`, `@k7tg`, `@k7s`, `@k7d`, `@k7env`, `@k7spec`) supporting source/target cloud paths (`aws`, `gcp`, `azure`, `vercel`, `heroku`, `digitalocean`, `self-hosted` -> `cloudflare` / `supabase` / `hybrid-edge`) with automated readiness scores, savings estimates, and migration phases.
- [x] **AC2 — Main website (`apps/web`) 5-target ordering visibility & AI Agent conversion funnel**: Surface `Free Security Audit` (`/audit`) and `Order Service` (`#order-service`) in `Header.astro`, embed `OrderServiceSection.svelte` and `SecurityAuditWidget.svelte` on `HomeServices.astro` and `ServicesDetailed.astro`, and wire `wom:chat-order-service` in `ChatApp.svelte`.
- [x] **AC3 — Client Portal (`apps/cp`) 5-target ordering & `@k7*` deliverable provisioning (`client-register`, `ClientDashboard.svelte`)**: Provision `latest_k7_report` into `orgs.service_usage` during `client-register` and expose the 5-target service order drawer and `@k7*` report cards in `ClientDashboard.svelte`.
