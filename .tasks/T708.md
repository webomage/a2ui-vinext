# T708 — k7 WASM Git Navigation Browser in TUI with GitHub, GitLab & New LLM Git Flavours Support

## Summary

Build and integrate a WASM-compatible Git Navigation Browser inside the `k7` Rust TUI ecosystem (`k7hub` commit `8acca23` + `w0m-web` CP/TabLinux console) with first-class provider adapters for **GitHub**, **GitLab**, and **new LLM Git flavours** (Hugging Face Hub repositories/datasets/spaces, Forgejo/Gitea/Codeberg, Agent-Git / GitButler virtual branches, and LLM prompt/skill/checkpoint git trees).

## Acceptance criteria

- [x] AC1 — **Multi-Provider Git Remote & Provider Abstraction (`GitHub`, `GitLab`, `LLM Git Flavours`):** Implemented `GitProviderAdapter` + `parse_git_coordinate` in `k7hub/src/git_browser.rs` (mirrored in `w0m-web/packages/lib/src/security/k7-git-browser.ts`) supporting `GitHub` (REST v3 / GraphQL v4), `GitLab` (API v4 subgroups & MRs), `HuggingFaceHub` (`models`, `datasets`, `spaces`), `ForgejoGitea` (`codeberg.org` / API v1), and `LlmAgentCheckpoint` (`agent/*`, `gitbutler/*`, `orca/*` lanes).
- [x] AC2 — **Interactive TUI Git Navigation Browser (`ratatui` + WASM target):** Shipped 4-pane `ratatui` navigator (`Tree & Blobs`, `Commit Graph`, `Branches, PRs & Agent Lanes`, `Diff & LLM Inspector`) via `k7 git` and `[v]` inside `k7hub`, with syntax-highlighted diff/code preview and zero-exec binary `.safetensors`, `.gguf` v3, `SKILL.md`, and Hugging Face Model Card header inspection.
- [x] AC3 — **WASM Compilation & Browser/Portal Embed Readiness (`wasm32-unknown-unknown`):** Gated OS/TTY dependencies behind `cfg(not(target_arch = "wasm32"))`, typed blob byte lengths as `u64` for 32-bit WASM safety, exposed `render_git_browser_frame_snapshot` (`TestBackend`), compiled `k7hub.wasm` cleanly (`cargo build --lib --target wasm32-unknown-unknown`), and mounted the interactive `k7 WASM Git TUI` tab in `CrewToolkitAndTabLinuxConsole.svelte` + `w0m-web/docs/K7-FAMILY.md`.
- [x] AC4 — **Automated Unit & Provider Fixture Tests:** Verified `7 passed` Rust unit tests in `k7hub`, `wasm32-unknown-unknown` compilation, and `3 passed` Vitest tests in `w0m-web/apps/web/src/tests/k7-git-browser.test.ts`.
