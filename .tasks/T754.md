# T754 — Fix P0 BaseLayout sticky footer clipping, --muted contrast collision, AuthForm/CP monospace regression, Me anonymous UX, and remove right-side Codemap

## Summary

Resolve the P0 visual, contrast, auth typography, and layout defects uncovered in the OpenDesign + Chromium UI/UX audit (`.agents/reports/2026-11-16-uiux-audit-opendesign-report.md`), and remove the collapsed right-side floating `Codemap` page navigation rail requested by the owner.

## Acceptance Criteria

- [x] **AC1 — Remove right-side collapsed page navigation (`Codemap`):** Remove `Codemap` wiring from `PageTemplate.astro`, `TeamPage.astro`, `ProcessPage.astro`, `sectionRegistry.ts`, and `pageTemplate.ts`, and delete the collapsed right-side `Codemap` component from both `apps/web` and `apps/cp`.
- [x] **AC2 — Non-clipping footer flow inside `.content-scroll-area`:** Move `<slot name="footer" />` inside `.content-scroll-area` (after `.layout-inner-container`) in `packages/ui/src/lib/components/ui/BaseLayout.astro`, remove the `-mt-16` / gradient-mask overlay clipping in `apps/web/src/components/Footer.astro` and `apps/cp/src/components/Footer.astro`, and adopt `100dvh` safely so hero CTAs, `/audit/` forms, and `/login` OAuth buttons stay unobstructed at `1440x900` and `375x812` while keeping `layout-matrix.mjs` `.content-scroll-area` checks green.
- [x] **AC3 — Fix `--muted` contrast collision & `[data-app]` token parameterization:** Remove the legacy `--muted` / `--text-muted` override conflict in `apps/me/src/layouts/{ContextLayout,Layout}.astro` so `FeatureVotingBoard.svelte` renders dark surfaces instead of `#9ca3af` pills under light text; complete `[data-app="cp"]` `--brand-rgb` and parameterized shadow/focus-ring custom properties in `packages/ui/src/tokens.css`.
- [x] **AC4 — Fix `AuthForm.astro` & `apps/cp` public auth typography/gradient leaks:** Restore `Inter` body/heading typography on `apps/cp` public `/login` & `/forgot-password`, parameterize `AuthForm.astro` focus rings, links, and generic placeholder via `[data-app]` CSS variables (removing hardcoded `purple-*` and `<InputComponent type="hidden">`), and align `forgot-password.astro` submit button with `[data-app="cp"]`.
- [x] **AC5 — Fix `apps/me` anonymous UX & `cp /me` overview cards:** Constrain `JobBoard.svelte` paywall overlay inside `.w0m-main` (zero `375px` left-edge clipping), replace duplicate Sign-In / restricted-DB noise and raw `/u/<slug>` copy for anonymous `apps/me` visitors, add `EmptyState` + `auto-rows-fr` + `<h2>` hierarchy + `--brand-me` accents to `apps/me/src/pages/assessments/index.astro`, and upgrade `apps/cp/src/pages/me/index.astro` bare links into structured glass cards.
