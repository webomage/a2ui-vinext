# T428 — DECISION: move session handoffs from STATE.md into ticket Status notes and generate PICK UP HERE

## Summary

**Decided 2026-09-24 — adopt, extended to crash-safety** (AC1). From
[report](../.agents/reports/2026-09-23-parallel-agents-isolation-and-merge-proposal.md) §6.1 Q2.

After [[T425]], `STATE.md`'s generated blocks are regenerated by `just land`. The remaining hot spot is
the **hand-written** `⭐ PICK UP HERE — LATEST` section (`STATE.md` ~113-154). Every session rewrites it,
so two parallel sessions collide there, and T425's additions-only register rule will stop such lands.

Proposal:
- each session writes its handoff into its own ticket's `## Status notes` (disjoint per ticket);
- "PICK UP HERE" becomes a generated section built from the most recent notes;
- this changes the `w0m-state-save` and `w0m-state-load` skills (canonical in wom7skills).

## Acceptance criteria

- [x] AC1 — Owner decision recorded here (adopt / reject / modify). **Adopt, modified** (2026-09-24):
  *"sessions in .agents/reports sometimes written before tickets are created … if quota suddenly finished
  … that session remains incomplete — but sure thing we should have one source of truth."* The ticket is
  the one source of work state and is written AS the work happens, so the design must also cover a
  session that dies mid-way, not only two sessions that collide. No new ticket: this one carries it.
- [ ] AC2 — If adopted: `state_doctor.py` generates PICK UP HERE from ticket Status notes; the skills are
  updated atomically (wom7skills → stamp → relock → sync); `STATE.md`'s hand-written area shrinks to
  gotchas + how-to.
- [ ] AC3 — If adopted: two parallel sessions each save a handoff and both land via `just land root`
  with no conflict.
- [x] AC4 — Crash-safe read, unblocked by T425: `just state-brief` (`state_doctor.py --brief`, 0.2s) prints
  every `in-progress` ticket with its newest dated status note and age (a ticket with none is listed as
  such), then the current ⭐ PICK UP HERE block, labelled recorded-not-measured; fails on a missing file
  or no pickup block. Claude runs it at SessionStart; root `AGENTS.md` tells every other agent to (they
  have no hook here). Proven by `just state-doctor-test` (8 brief probes).
- [x] AC5 — Ticket-first reports: `just reports-ticket-check` fails on an `.agents/reports/` file that
  cites no EXISTING ticket in its filename or header; blocking suite `reports-ticket`, 6 red probes.
- [x] AC6 — Checkpoint rule: the `w0m` hub skill tells agents to append a dated status note and commit
  at each gate, not at the end; `w0m-state-load` starts from `just state-brief` and its STATE.md /
  archive paths are corrected to the estate root (they still said `wom7web/`). Canonical in wom7skills,
  stamped, synced, relocked in wom7web and the root.
