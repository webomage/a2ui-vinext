# T399 — Cut over Cloudflare infrastructure from wom7cfworkers to wom7func and decommission legacy worker

## Summary

Following the rename of repository `wom7cfworkers` to `wom7func` (T393), an audit of live Cloudflare infrastructure and estate configurations revealed that the Cloudflare operational layer remained tied to the legacy `wom7cfworkers` worker:
1. **Cloudflare Crons Hijacked:** `wom7cfworkers` remained deployed holding all 5 account cron schedules, leaving `wom7func` with 0 active schedules.
2. **Worker Secrets Gap:** `wom7cfworkers` held 19 secret bindings while `wom7func` lacked database, platform, and AI secrets.
3. **Infisical Configuration Drift:** `WORKERS_WEBHOOK_URL` in Infisical (`beta`) still pointed to `https://wom7cfworkers.webomage.workers.dev`, causing Supabase Edge Functions and web apps to route to the old worker.
4. **Runtime Hardcodings:** `wom7func/src/index.ts` returned `service: "wom7cfworkers"`, while CP HealthDashboard, sources registry, and audit scripts queried the old URL.

This ticket executes the complete operational cutover to `wom7func` and decommissions `wom7cfworkers`.

## Acceptance Criteria

- [x] AC1 — Sync Cloudflare worker secrets from Infisical to `wom7func` and update `WORKERS_WEBHOOK_URL` in Infisical `beta` to `https://wom7func.webomage.workers.dev`.
- [x] AC2 — Clear cron schedules from `wom7cfworkers` on Cloudflare, and deploy `wom7func` claiming all 5 cron schedules (`0 14 * * SUN`, `0 */6 * * *`, `0 8 * * *`, `*/15 * * * *`, `*/30 * * * *`). Verify schedules via Cloudflare API.
- [x] AC3 — Patch runtime endpoints: update `wom7func/src/index.ts` `/health` payload to return `service: "wom7func"`, update `apps/cp/src/components/admin/HealthDashboard.svelte`, `packages/lib/src/system-registry/sources.ts`, and `project/scripts/w0m_audit.py` to query `wom7func`.
- [x] AC4 — Update governance references: remove stale `wom7cfworkers` entries in `scripts/no_nested_repos.py`, `scripts/install_excludes.py`, and update `wom7func` repo metadata (`LICENSE`, `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `AGENTS.md`).
- [x] AC5 — Decommission legacy worker `wom7cfworkers` on Cloudflare and verify all estate quality gates pass cleanly without `--no-verify`.

## Definition of Done

- Cloudflare crons, secrets, and traffic fully active on `wom7func`.
- Legacy `wom7cfworkers` script decommissioned from Cloudflare.
- OpenSpec change spec validated and verified.
- Pre-push gates and unit tests pass cleanly.
