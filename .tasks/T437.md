# T437 — WebTorrent Desktop without Rosetta: webomage fork shipping native Apple Silicon builds, upstream arm64 PR, Rust (librqbit) WebTorrent path

## Summary

On macOS 27, WebTorrent Desktop reports that it needs Rosetta, and it will stop working when Rosetta support ends
(macOS 28). The installed v0.24.0 is `Mach-O x86_64`. That is still the latest upstream release, published
2020-08-29, although `webtorrent/webtorrent-desktop` master is maintained (Electron 27.3.11, dependency bumps
through 2026-09-19). Owner ask 2026-09-24: a side promo/hype task.

**Measured 2026-09-24 in a scratch clone:**
- The only blocker is `bin/package.js`: `darwin: { arch: 'x64' }` ("Build x64 binary only").
- Every native module ships a darwin-arm64 N-API prebuild: `utp-native` (`darwin-arm64`), `bufferutil` and
  `utf-8-validate` (`darwin-x64+arm64`), `fsevents`. `fs-xattr` and `macos-alias` are build-time only (dmg).
- Changing the arch to `arm64` produced `WebTorrent.app/Contents/MacOS/WebTorrent: Mach-O 64-bit executable arm64`.
- Traps: the build needs Node 18/20 (per `engines`). Under Node 24/26, `extract-zip` quits silently, the
  Electron postinstall unpacks only its licence files, and packaging exits 0 with no output. `bin/package.js`
  also runs `rimraf node_modules && npm ci` every time.
- Upstream history: [#2190](https://github.com/webtorrent/webtorrent-desktop/pull/2190) (universal, 2022,
  closed unmerged); [#2509](https://github.com/webtorrent/webtorrent-desktop/pull/2509) (arm64, closed stale
  2026-08-12); [#2529](https://github.com/webtorrent/webtorrent-desktop/pull/2529) (`--arch` option, +4/-2, open).

**Rust / WASM:** don't start from scratch. [`ikatson/rqbit`](https://github.com/ikatson/rqbit) is a maintained
Rust BitTorrent library (`librqbit`) with a Tauri desktop app that already ships
`rqbit-desktop_9.0.1_universal.dmg`. It lacks WebRTC/WebTorrent peers:
[rqbit#71](https://github.com/ikatson/rqbit/issues/71) is open. That transport is the highest-value
contribution. A Tauri client and a Rust→WASM browser core follow only if it lands.
