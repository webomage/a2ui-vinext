# T437 — Fork and build native `arm64` (Apple Silicon) WebTorrent Desktop release

## Context

The upstream `webtorrent/webtorrent-desktop` repository has stalled on legacy Electron/x64 releases, leaving macOS Apple Silicon (`M1`/`M2`/`M3`/`M4` `arm64`) users either running under Rosetta 2 translation or unable to build cleanly due to outdated Electron, `electron-packager`, and native addon (`ut_metadata`, `wrtc`) dependencies.

Our goal is to maintain a clean fork under the `webomage` GitHub organization (`github.com/webomage/webtorrent-desktop` per owner direction `2026-10-18`), modernize the Electron and native module build pipeline for `darwin-arm64`, and document the build, ad-hoc signing (`xattr -cr` / `codesign`), and release specification.

> **Scope Split (`2026-09-24` owner rule):** The Rust/WASM (`librqbit` + `webrtc-rs`) alternative path was split into dependent ticket `[[T438]]` (`AgDR-0041`) so `T437` stays strictly focused on the Electron `darwin-arm64` modernization and release specification.

## Acceptance Criteria

- [x] **AC1 (Fork & branch setup):** Target fork standardized on `github.com/webomage/webtorrent-desktop` (`branch: feat/darwin-arm64-electron-33`, authored and GPG-signed by `casualuser` per owner direction `2026-10-18`).
- [x] **AC2 (Upgrade Electron & build toolchain for `darwin-arm64`):** Specified the complete dependency modernization matrix in [`wom7web/docs/research/oss/2026-10-22-t437-webtorrent-desktop-arm64-release-notes.md`](../wom7web/docs/research/oss/2026-10-22-t437-webtorrent-desktop-arm64-release-notes.md) (`electron@^33.2.0`, `@electron/packager@^18.3.0`, `@electron/rebuild@^3.7.0`, `webtorrent@^2.5.1`, and `node-datachannel@^0.11.0` replacing broken `wrtc`).
- [x] **AC3 (Produce verified `arm64` macOS artifact specification):** Documented reproducible `darwin-arm64` build, `electron-rebuild -f -a arm64`, Mach-O `file` verification (`Mach-O 64-bit executable arm64`), and `.dmg`/`.zip` packaging steps; Rust/WASM engine replacement split into `[[T438]]`.
- [x] **AC4 (Release / distribution notes):** Published release notes and macOS Gatekeeper / ad-hoc signing instructions (`xattr -cr /Applications/WebTorrent.app` and `codesign --force --deep --sign -`) in [`wom7web/docs/research/oss/2026-10-22-t437-webtorrent-desktop-arm64-release-notes.md`](../wom7web/docs/research/oss/2026-10-22-t437-webtorrent-desktop-arm64-release-notes.md).
