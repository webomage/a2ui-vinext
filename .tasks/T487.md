# T487 — Visual goldens: regenerate on the local stack or pin the render environment

## Summary

Split from [[T478]] and [[T439]] (owner, 2026-09-29: close T478 at "environment fixed, failures triaged"; leftover scope becomes
its own ticket; T439 AC7/AC10 wired `specs/visual/cp_visual.spec` for the 4 CP contexts and removed the captured-404 `dashboard` golden). T478 run 4 (150 specs, local stack, guard on): 291/442 scenarios passed, 151 failed, 34 min.

## Measured (T478 run 4)

35 golden scenarios in 3 specs (`web/goldens`, `visual/web_visual`, `visual/join_visual`) fail with ~66k-112k mismatched
pixels per page; `job/goldens` and `join/goldens` fail with "No golden for desktop-<name>" (absent baselines).
`web/goldens` alone spends 140 s on 30 mismatches. Goldens captured on live or another machine will differ from a
local render by fonts, data and GPU, so the comparison measures the environment, not the page.

- [x] AC1 — **Decide the golden source of truth:** rendered on the local stack with seeded data (regenerated by one
  recipe), or on a pinned render environment; recorded as an AgDR.
  - **Evidence:** Recorded in [[AgDR-0053]] (`docs/decisions/AgDR-0053-visual-golden-local-stack-source-of-truth-and-diff-gate.md`, indexed in `docs/DECISIONS.md` via `just decisions`). The local stack (`astro dev` + local Supabase + `just test-team-local` seeded data, never live `https://webomage.com`) is the canonical source of truth for visual goldens, regenerated via `just goldens-regen`. Updated `w0m-web/scripts/update_goldens.mjs` so `BASE_URL` defaults to `http://127.0.0.1:4321` rather than `https://webomage.com`.
- [x] AC2 — **Baselines exist for every page** (`job`, `join`, and `cp_visual.spec`'s 4 CP contexts `cp_profile` / `cp_business` / `cp_client_org` / `cp_system` via `just test-team-local`) and a missing baseline still fails
  closed, as today.
  - **Evidence:** Created `scripts/regen_goldens.py --check` (`just goldens-check`) and `scripts/tests/test_regen_goldens.py` (`just goldens-check-test`). Fixed quoted `<path>`/`<name>` table parameters in `specs/job/goldens.spec` and `specs/join/goldens.spec`, aligned `JOB()` port (`:4322`) and `implementationRemoteCPOnPage` (`CP()`), retired the obsolete captured-404 `dashboard` scenario in `specs/visual/join_visual.spec`, exposed the `gamification` schema in local PostgREST (`just test-team-local`), and generated all missing baselines (`en-desktop-job_home.png`, `en-desktop-job_list.png`, `en-desktop-join_home.png`, `en-desktop-join_dashboard.png`, `en-desktop-join_assessments.png`, `en-desktop-join_interview.png`, `en-desktop-cp_client_org.png`, `en-mobile-cp_client_org.png`).
