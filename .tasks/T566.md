# T566 — Catch @astrojs/* adapter ESM export mismatch, engines.node drift, and lockfile build failures at preflight and pre-push

## Why

deploy-all release 2026.10.22-1792700696 failed in deploy-web (astro build) with [MISSING_EXPORT] beginContentEntryCollection is not exported by astro@7.3.3 from @astrojs/cloudflare@14.2.1. Neither pre-push nor preflight caught it because astro check only runs TypeScript/Volar diagnostics over src/, deps-check only checks cross-repo package.json specifiers rather than @astrojs/* -> astro/* ESM named-export linkage, and preflight only checked node binary existence rather than engines.node compatibility.

## Scope

- **In:** Upgrade `@astrojs/cloudflare` (`^14.3.4`), `@astrojs/markdown-remark` (`^7.3.0`), and `wrangler` lockstep (`^4.151.0`); add static ESM export linkage (`@astrojs/*` -> `astro/*`), peer dependency (`astro`, `wrangler`), and `engines.node` verification to `deps_sync.py` and `preflight.py`; add conditional `astro build` smoke gate to `wom7web/.husky/pre-push`; unit and red-probe tests in `test_deps_sync.py`.
- **Out:** Full multi-app production build on every code-only push (gated on manifest/lockfile changes in `pre-push`, while static ESM export + peer linkage runs on every push and `preflight`).

## Acceptance Criteria

- [x] **AC1:** wom7web/package.json and apps/{web,cp,demo,job,join}/package.json upgrade @astrojs/cloudflare to ^14.3.4 (and @astrojs/markdown-remark to ^7.3.0), resolving [MISSING_EXPORT] beginContentEntryCollection so astro build succeeds across all 5 apps.
- [x] **AC2:** wom7web/project/scripts/deps_sync.py verifies ESM named-export linkage from installed @astrojs/* packages against astro/* entrypoint exports and verifies host node -v against installed package engines.node constraints.
- [x] **AC3:** wom7web/project/scripts/preflight.py checks host Node version against workspace engines.node requirements and surfaces @astrojs/* export linkage failures during preflight.
- [x] **AC4:** wom7web/.husky/pre-push runs adapter ESM linkage verification (via deps-check) and executes a build smoke check when package.json or pnpm-lock.yaml changes in the push range.
- [x] **AC5:** Unit and red-probe tests in wom7web/project/scripts/tests/test_deps_sync.py prove that a simulated missing export (e.g. beginContentEntryCollection) or unsupported engines.node version fails deps_sync.py with exit code 1.

## Definition of Done

All 5 `wom7web` apps (`web`, `cp`, `demo`, `job`, `join`) build cleanly via `astro build` under `astro@7.3.3` + `@astrojs/cloudflare@14.3.4` + `wrangler@4.152.0`, `deps_sync.py` and `preflight.py` enforce `@astrojs/*` ↔ `astro` ESM named-export linkage, peer dependencies, and `engines.node`, `wom7web/.husky/pre-push` gates lockfile/manifest changes with an `astro build` smoke check, and `python3 -m unittest project/scripts/tests/test_deps_sync.py` passes (`Ran 7 tests — OK`).
