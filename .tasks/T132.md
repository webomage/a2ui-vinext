# T132 — `w0m-pixel-clone`: lightweight pixel-perfect parse & copy

## Summary

Owner ask (2026-07-25): find the skills that do **lightweight, pixel-perfect parsing and copying**
(take a visual source — a live URL, a screenshot, or a design — and faithfully reproduce its UI in
code, and/or extract/clone a page's structure and styling), survey all related skills, and **build a
combined, enhanced w0m skill** on top of them.

The research below found **no installed or upstream skill covers the whole pipeline for w0m's stack**:
existing options either build *into* Figma, target React/Next or SwiftUI, or capture-but-don't-emit.
The proposal is a single **orchestrator** skill — `w0m-pixel-clone` — that reuses the capture/verify
tools w0m already has (Playwright via `webapp-testing`, the browser preview + Chrome MCP, and
`playwright-best-practices`' visual-regression reference) and adds the two missing pieces: **computed-
style → `@webomage/ui` token extraction** and a **Svelte/Astro emitter with a closed visual-diff
refinement loop**. "Lightweight" = DOM + `getComputedStyle` + screenshot-diff with the tooling already
in-session — no hosted scraping service, no image-generation model.

This is the "new capability" complement to [[T127]] (skills governance) and [[T128]] (library docs).
Any new skill lands **under management** (T127): fully-qualified provenance in `.w0m/skills.json`,
canonical source in `wom7skills/skills/`, `w0m` orchestrator registration, run through the
`w0m-sdlc-*` gates.

## Acceptance criteria

- [x] **AC1 — Capture (multi-source, lightweight).** The skill accepts {live URL, screenshot image,
      Figma URL}. Live/running-app inputs snapshot via `webapp-testing`/Chrome-MCP: full-page
      screenshot + a11y tree + per-node `getComputedStyle`. No hosted scraping service; vision only as
      the fallback for screenshot-only inputs.
- [x] **AC2 — Auditable structure parse.** DOM/a11y tree normalized into a reviewable per-section
      outline (header/hero/cards/footer) written to `docs/research/<hostname>/` (the
      `julianromli@clone-website` spec-first method) — human-checkable before any code is generated.
- [x] **AC3 — Token extraction into `@webomage/ui`.** Colors/spacing/typography/radii/shadows harvested
      from computed styles and **mapped onto `@webomage/ui` CSS variables/tokens**, honoring the
      header/UI-spec hex-in-`rgba()` golden rule (emit `--brand-rgb` triplets, not raw hex).
- [x] **AC4 — Svelte/Astro emitter.** Generates Svelte components + Astro pages using `@webomage/ui`
      primitives where they match, raw markup only where they don't. (Figma motion → hand off to
      `figma-implement-motion`.)
- [x] **AC5 — Closed visual-diff fidelity gate.** Render the emitted output (preview), screenshot it,
      diff against the source capture (playwright visual-regression), iterate on token/layout deltas
      until under a set pixel/SSIM threshold. The pass/fail metric is explicit.
- [x] **AC6 — Under management + governed (T127).** Canonical in `wom7skills/skills/`, declared in
      `.w0m/skills.json` with fully-qualified provenance, registered in `w0m/SKILL.md`, `just skill
      check` green. If any upstream skill is vendored/adapted, it is pinned by content diff (never by
      name) and its license/stack-fit recorded.
- [x] **AC7 — Legal/ToS guardrail.** Cloning third-party sites warns on copyrighted-UI reproduction /
      enforces an allowlist, given the "clone any website" framing.

## Open questions — Settled with Weighted Decisions

1. **Scope of "clone":** → **Settled: DS-aligned visual reproduction using `@webomage/ui` primitives (`Button`, `Card`, `Badge`, `Input`, `Select`, `PageHeader`) and CSS custom property tokens.** *(Cost: Low · Risk: Low — avoids shipping unmaintainable scraped DOM soup and passes `ds-conformance` · Unblocks: Direct adoption in `apps/cp` and `apps/web`.)*
2. **Primary input:** → **Settled: Multi-source with live URL / DOM+CSS dump as the deterministic primary path (`375x812`, `768x1024`, `1440x900`) and reference screenshots as visual-diff ground truth.** *(Cost: Low · Risk: Low · Unblocks: Offline testability + live browser capture.)*
3. **Firecrawl:** → **Settled: Fully local (zero hosted Firecrawl dependency).** *(Cost: Zero API spend · Risk: Zero external key requirement · Unblocks: Portable offline execution in CI and client workspaces.)*
4. **Fidelity metric:** → **Settled: Pixel mismatch ratio `<= 0.02` (`2.0%`) across all 3 breakpoints (`375`, `768`, `1440`) with `channelTolerance = 8` and up to `N = 3` refinement passes (`compareVisualFidelity`).** *(Cost: Low · Risk: Low · Unblocks: Deterministic numeric gate in `pixel_clone.mjs`.)*
5. **Reuse vs build:** → **Settled: Authored fresh as `w0m-native` (`w0m-skills/skills/w0m-pixel-clone/`) combining the spec-first `docs/research/<hostname>/outline.md` pattern with `@webomage/ui` token extraction and Svelte 5 runes emission.** *(Cost: Medium · Risk: Low — zero React/Tailwind mismatch · Unblocks: Full stack alignment.)*
6. **Token source of truth:** → **Settled: Runtime `@webomage/ui` CSS custom properties (`--brand`, `--brand-rgb`, `--bg`, `--bg-rgb`, `--surface`, `--text`, `--text-rgb`, `--radius-*`, `--space-*`) enforcing the RGB-triplet rule inside `rgba(...)`.** *(Cost: Low · Risk: Zero invalid `rgba(#hex, a)` rules · Unblocks: Immediate compatibility with `@webomage/ui`.)*
