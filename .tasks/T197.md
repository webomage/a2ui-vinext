# T197 — the warnings a successful deploy prints, and nobody triages

## Summary

The 2026-08-10 deploy (`2026.08.10-1786387039`) succeeded: all 6 surfaces live, all `/api/health`
green on commit `e59babcc`. It also printed **20+ build warnings**, and nothing in the pipeline
reads them. Triaged here, because "the deploy went green" is not the same as "the deploy was
clean" — and one of these is a live 404.

## 📍 Findings, measured against production

### 🔴 A. `/noise.png` — a live 404 on a rendered element

`apps/cp/src/components/admin/CharacterSheet.svelte:133` rendered
`<div class="absolute inset-0 bg-[url('/noise.png')] …">`. The file existed in **no app's
`public/`**. Resolved (`AC1`).

### 🟠 B. Twelve `/assets/info{1-4}-web.webp` 404s — latent, and a trap

`join`, `job` and `demo` each reached across into `apps/web/src/styles/global.css`. Resolved (`AC2`):
promoted shared reset/scroll/utility CSS to `@webomage/ui/base.css` (`packages/ui/src/base.css`)
and eliminated `@import "../../../web/src/styles/global.css"` and the `@webomage/styles` cross-app
alias from `join`, `job`, and `demo`.

### 🟠 C. Hume `ReadStream` — browser bundle hazard resolved

```
[vite] hume/…/expressionMeasurement/streaming/StreamSocket.mjs (46:35):
       "ReadStream" is not exported by "__vite-browser-external"
```

Resolved (`AC3`): replaced the Node-coupled `hume` SDK barrel import in
`apps/join/src/components/interviews/InterviewSession.svelte` with a browser-native EVI WebSocket
client (`@webomage/lib/interviews/hume-evi-browser`) and wired a browser-safe `fs` stub
(`@webomage/lib/interviews/fs-browser-shim`) in `apps/join/astro.config.mjs`.

## Acceptance criteria

- [x] **AC1 — ship or remove `/noise.png`.** Removed the unserved `/noise.png` layer from `CharacterSheet.svelte`.
- [x] **AC2 — kill the cross-app stylesheet import.** Moved the shared base layer into `@webomage/ui/base.css` (`wom7web/packages/ui/src/base.css`) and updated `join`, `job`, and `demo` (`src/styles/global.css` + `astro.config.mjs`) so no app reaches into `apps/web/src`.
- [x] **AC3 — decide the Hume question by exercising it.** Replaced the full `hume` barrel import in `InterviewSession.svelte` with `@webomage/lib/interviews/hume-evi-browser` (`HumeClient` over browser `WebSocket`) + `fs-browser-shim.ts` in `apps/join/astro.config.mjs`, eliminating the `StreamSocket.mjs` `fs.ReadStream` browser bundle hazard.
- [x] **AC4 — a build-warning budget.** Created `wom7web/project/scripts/build_warning_ratchet.py` + `wom7web/project/build-warnings-baseline.json` (+ unit tests in `test_build_warning_ratchet.py`) in advisory mode with recorded promotion trigger (`D3`/`T103`).
- [x] **AC5 — asset references are checked at build.** Created `wom7web/project/scripts/css_asset_check.py` (+ unit tests in `test_css_asset_check.py`) scanning `url()` / `bg-[url()]` and cross-app stylesheet imports across all 5 apps; proven red on `/noise.png` and `/assets/info1-web.webp` in unit tests and passing green on the live monorepo tree.
