# T314 — Demote aleksei@webomage.com to non-admin member and enable delivery roles (PM, TPM, Dev) testing in CP

## Summary

Owner requirement 2026-09-04:
*"ok, let's do one thing - let's remove from aleksei@webomage.com admin's permissions to let me test everything as PM, TPM, Dev first hands"*

Currently, `aleksei@webomage.com` holds both `member` and `admin` roles in `public.user_roles` (`8d16aff5-d996-4759-80b0-39b60e3c0920`). This causes `is_admin()` and `context.locals.role` to evaluate to admin, bypassing normal member restrictions and project hat boundaries.

This ticket:
1. Revokes `admin` from `public.user_roles` for `aleksei@webomage.com` (`8d16aff5-d996-4759-80b0-39b60e3c0920`), leaving `member` as their sole platform role, while retaining superuser admin on `casualuser@gmail.com` (`5691add5-48f9-4ac5-ab54-7ca5757e44da`).
2. Resets `public.user_active_role` for `aleksei@webomage.com` to `member` (or null), ensuring JWT minting cleanly assigns `wom_roles = ['member']` and `wom_active_role = 'member'`.
3. Adds `/business/projects` (and `/cp/business/projects`) to `MEMBER_ROUTES` in `apps/cp/src/lib/member-routes.ts`, allowing members holding project delivery hats (PM, TPM, Dev) to view their projects and use `MyProjectHats` in the Control Panel.
4. Mounts the project hat switcher / delivery role HUD on `/profile.astro` for direct access from the member home dashboard.
5. Verifies end-to-end that `aleksei@webomage.com` can wear PM, TPM, Dev hats on Artemio without admin superuser privileges.

- **Toolchain & Preflight:** `just sdlc-doctor` verified (`✅ SDLC toolchain conformant — 2 interfaces across 5 repo(s)`).

- **Grounded Web/CP Reality:**
  - `apps/cp/src/lib/member-routes.ts`: `MEMBER_ROUTES` does not contain `/business/projects`, causing non-admins to bounce to `/profile`. Adding `/business/projects` allows members with delivery roles to access their project delivery dashboard.
  - `apps/cp/src/pages/profile.astro`: contains RPG character sheet and account info, but lacks `MyProjectHats` panel. Mounting `MyProjectHats` provides instant hat switching for non-admins upon sign-in.
- **Routing:** Proceeding to `w0m-sdlc-spec`.
