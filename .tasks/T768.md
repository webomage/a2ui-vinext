# T768 — Real apple-touch-icon and favicon set for apps/web

## Summary

Owner bookmarked the site on iPhone (`Add to Home Screen`): iOS rendered the
fallback letter tile on a black background instead of the brand mark.

Measured 2026-11-17 in `apps/web`:

- `src/components/BaseHead.astro:16` references ONLY `rel="icon"` with
  `/assets/logo.svg` (SVG). iOS does not use SVG for home-screen icons, so the
  use of `apple-touch-icon` never happens and the letter tile appears.
- `public/assets/apple-touch-icon-180.png` exists but is a junk placeholder
  (93 bytes, 180x122, `mode: 1` single-bit bitmap) and is referenced nowhere.
  `public/assets/favicon-16.png` / `favicon-32.png` are 71-byte stubs.
- The real brand raster `public/assets/logo.png` (846x720 RGBA, transparent)
  exists; the DS app background token is `packages/ui/src/tokens.css:35`
  `--slate-950: #020617`.

iOS home-screen icons must be opaque square PNGs (180x180 nominal);
transparency renders black.

## Fix

Generate a proper opaque icon set from the existing brand mark
(`logo.png` composited on `#020617`), commit the PNGs as assets, reference
them from `BaseHead.astro` (`apple-touch-icon` 180, `icon` 16/32/180,
192/512), and add a source-reading vitest asserting the links exist
(prevention against silent loss again).
