# T474 — Unstructured CV and resume document vault in CP Resume Studio

## Summary

Owner direction (2026-09-27):
> "we have to have an option here to have old unstructured copies of CV/resume .pdf/etc
> [screenshot of /me/profile/resume with Member Resume & CV Studio]
> and also import here all my (Aleksei's) resumes, CVs and related"

Currently, `/me/profile/resume` (`ResumeStudio.svelte`) focuses purely on synthesizing dynamic variants from `profile_experience` structured facts across 6 visual themes. While it synthesizes new variants, it lacks:
1. An integrated view/tab to browse, download, and manage raw, unstructured legacy copies of resumes and CVs (.pdf, .md, .docx).
2. Direct document upload capabilities inside Resume Studio (previously only exposed on `/me/profile`).
3. An imported collection of Aleksei's canonical master, standard, full, Upwork, and legacy CV files.

Objective:
1. Add an **"Unstructured Copies & Documents"** tab/panel to `ResumeStudio.svelte` on `/me/profile/resume`.
2. Display all linked documents from `profile_resumes` with metadata, download/view links, and direct upload capability.
3. Import Aleksei's canonical resume documents (`resume_master.pdf`, `resume_master.md`, `aleksei-tcelishchev-cv-standard.pdf`, `aleksei-tcelishchev-cv-full.pdf`, `aleksei-tcelishchev-cv-upwork.pdf`, `AT resume.pdf`, `Aleksei_CV_2026.pdf`, `Aleksei_CV_2025.pdf`) into `profile_resumes` for Aleksei's profile.

## Acceptance criteria

- [x] AC1 — **ResumeStudio Document Tab**: Add a 4th tab (`Raw Documents & Past Copies`) to `ResumeStudio.svelte` on `/me/profile/resume`, listing all stored files in `profile_resumes` with file name, type, size, upload date, and primary status.
- [x] AC2 — **Document Actions & Direct Upload**: Provide direct file download/viewing for each document and an inline drop-zone/file picker to upload new unstructured `.pdf`, `.md`, or `.docx` copies directly from Resume Studio.
- [x] AC3 — **Aleksei's Canonical CV Import**: Author an idempotent seed/import script and database migration linking Aleksei's existing PDF and Markdown resume variants (`resume_master`, `aleksei-tcelishchev-cv-standard`, `aleksei-tcelishchev-cv-full`, `aleksei-tcelishchev-cv-upwork`, `AT resume`, `Aleksei_CV_2026`, `Aleksei_CV_2025`) to Aleksei's personal profile in `profile_resumes`.
- [x] AC4 — **Verification & Tests**: Add automated tests verifying document listing, upload handler, and rendering in `ResumeStudio.svelte` and verify that `/me/profile/resume` displays the imported unstructured CV copies cleanly.
