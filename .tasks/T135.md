# T135 — Repo-hygiene gates: stack-matched checks, required human files, license audit, Infisical corpus enforcement

## Summary

**Four owner asks from 2026-07-25 collapsed into one ticket, because they are one build.** Each needs
the identical plumbing — a `just` recipe + a `commands` role in `project/stacks-policy.json` + a
pre-commit hook + a `just sdlc-doctor` check — across the same set of repos. Filing them separately
would mean four passes over the same files and four rounds of the same review.

The four strands (grounding for each is recorded in `STATE.md`; **do not re-derive it**):

| Strand | Ask | STATE |
|---|---|---|
| A | per-repo SDLC gate parity — the gaps the owner approved | §0n |
| B | required human-facing files (`README.md` et al.), enforced | §0p |
| C | dependency **and vendored-content** license audit | §0u |
| D | enforce that skills/tools take secrets from Infisical | §0m |

**Strand D is deliberately narrow, and this is the main right-sizing.** [[T119]] **AC2b is genuinely
done** — verified 2026-07-25: `wom7web/.env` is gone, `set dotenv-load := true` is removed, no
`apps/*/.dev.vars` remain, and no recipe calls `infisical export`. Debt row **D18 was deleted** as part
of filing this ticket, because it asserted all of that was still true. So D does **not** revisit
file-based secrets. The actual gap: `just sdlc-doctor` verifies the *interfaces are present*, never
that a skill or tool **uses** them — and only **2 of 27** canonical skills mention `infisical` at all.

**The single hardest requirement is AC7.** This project has shipped a vacuous gate three separate
times — T127's empty manifest printing `0 managed skill(s) match the lockfile ✓`, T130's `enforce_raw`,
and the `wom7md` hook that did not exist until 2026-07-25. A file-exists check for `README.md` would
pass `wom7skills`' 16-line stub. Every gate here must be **proven red** against a real violation before
it is trusted, and must **start green** on the current tree so it walls off no pre-existing debt.
