# T52 — Enable compromised password checks in Supabase Auth

## Summary

Configure Supabase Auth to enable automated verification of passwords against compromised databases (e.g., HaveIBeenPwned API) during registration and password updates. This is a dashboard-level toggle that hardens security by preventing users from setting weak or leaked passwords.

## Acceptance criteria

- [ ] AC1 — Enable "Check for leaked passwords" under Supabase Dashboard -> Authentication -> Security.
- [ ] AC2 — Verify that attempting to register or update password with a known compromised password (e.g., "password123") is gracefully blocked with an appropriate security error.
- [ ] AC3 — Document this configuration in the security manual or audit trails.
