## Summary

Audit and verify the end-to-end authorization floor for client-facing capabilities (client CP, onboarding, guest portals, and API routes). Ensures active-hat enforcement, tenant isolation, and prevents unauthenticated data leakage across all client functions.

## Acceptance Criteria

- [ ] AC1 — Audit all client-facing Edge Functions and API endpoints to verify strict session and tenant isolation.
