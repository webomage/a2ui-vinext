# T562 — Extend wom7ext browser extension with Universal Page & Selection Clipper and multi-platform freelancer/outreach specs

## Summary

Upgrade `wom7ext` (`wom7ext/extension`) with a **Universal Page & Selection Clipper** (`content/clipper.ts`) and declarative platform specs (`wom7ext/extension/specs/*.json`) across all major freelancer and professional networks (Upwork, LinkedIn, Contra, Toptal, Freelancer.com, Fiverr Pro, Wellfound, X-Team, Indeed) so members can clip job posts, client profiles, proposals, contracts, and message threads directly from their authenticated browser tab into the `job.webomage.com` Outreach & Communications Vault (`POST /functions/v1/outreach-clip-ingest`).

## Acceptance criteria

- [x] AC1 — **Universal DOM-to-Markdown Page & Selection Clipper (`wom7ext/extension/src/content/clipper.ts`).** Extract clean Markdown (`markdown_body`), `source_url`, `title`, OpenGraph/JSON-LD metadata, and user-highlighted text selections from any active browser tab, stripping scripts/styles/trackers and computing a deterministic SHA-256 `content_hash`.
- [x] AC2 — **Declarative Platform Specs (`wom7ext/extension/specs/*.json`).** Add and validate declarative extraction specs for `upwork.messages.json` (Room title, counterparty, messages, linked proposal/contract URL), `linkedin.messages.json`, `linkedin.jobs.json`, `contra.jobs.json`, `contra.messages.json`, `toptal.jobs.json`, `freelancer.jobs.json`, `fiverr.messages.json`, `wellfound.jobs.json`, and `indeed.jobs.json`.
- [x] AC3 — **Extension Popup & Context-Menu Clipping Actions (`popup.ts`, `background.ts`).** Add `Clip Page to Vault`, `Clip Selection`, `Clip Message Thread`, and `Clip Job + Draft Outreach` actions in the `wom7ext` popup and right-click context menu, with platform auto-detection badge, tag/thread selector, and deep-link to open the ingested clip in `https://job.webomage.com/me/outreach`.
- [x] AC4 — **Automated Spec & Clipper Unit Tests.** Add unit tests in `wom7ext/extension/scripts/clipper.test.ts` verifying DOM-to-Markdown extraction, selection clipping, and every platform spec against representative HTML fixtures (`just typecheck`, `just lint`, and `deno test` green).

## Definition of Done

Per [`openspec/SPEC-AUTHORING-STANDARD.md`](openspec/SPEC-AUTHORING-STANDARD.md):
- Extension builds cleanly (`node build.js`) and unit tests pass across all declarative specs and the universal clipper fallback.
- Quality gates clean (`just test`, `just lint`, `just typecheck`, `just debt-check`).
- Committed referencing ticket ID; `TASKS.md` row + ticket + GH issue in sync.
