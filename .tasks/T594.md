# T594 — Per-Project UI Screens & Workflows User Guides with Visual SVG Diagrams Across All 5 Vaults

## Summary

Each of the 5 project Obsidian vaults (`w0m` / `eg-w0m`, `1945` / `eg-1945`, `artemio` / `eg-artemio-quiero-comer`, `servicios777` / `eg-servicios777`, `personaje0` / `eg-personaje0`) currently contains `notes/mobile-sync-user-guide.md` for R2 WebDAV sync, but lacks a dedicated **UI Screens & Workflows User Guide (`notes/ui-user-guide.md`)** with visual screen mockup diagrams (`assets/ui-screens.svg`) and end-to-end workflow diagrams (`assets/ui-workflows.svg`) documenting how users, clients, and administrators operate the UI of that specific project.

Additionally:
1. `knowledge_hub.allowed_prefixes` in `project/policies/clients-policy.json` did not include `"assets/"`, preventing visual SVG/image attachments inside `vault/assets/` from syncing to Cloudflare R2 (`r2://wom-engagement-vaults/engagements/<engagement>/assets/`) or passing gateway path validation.
2. `renderObsidianMarkdown` in `w0m-web/apps/cp/src/lib/vault-parser.ts` did not rewrite Obsidian image embeds (`![[assets/...]]`) or relative vault `assets/...` image links to static/gateway URLs (`/assets/vaults/<vaultSlug>/...`) when rendering notes inside `<KnowledgeHub>`.

## Acceptance Criteria

- [x] **AC1 — Allow `assets/` in `clients-policy.json`, `vault-r2-gateway.ts`, and `vault-parser.ts` image rendering**:
  - Add `"assets/"` to `knowledge_hub.allowed_prefixes` for all 5 vaults (`w0m`, `1945`, `artemio`, `servicios777`, `personaje0`) in `project/policies/clients-policy.json`.
  - Support `.svg`, `.png`, `.jpg`/`.jpeg`, `.webp` content types in `vault-r2-gateway.ts` (`contentTypeForPath`).
  - Enhance `renderObsidianMarkdown` in `vault-parser.ts` so Obsidian image embeds (`![[assets/foo.svg]]` / `![[assets/foo.svg|Alt]]`) and relative markdown images (`![Alt](assets/foo.svg)` / `![Alt](../assets/foo.svg)`) resolve to `/assets/vaults/<vaultSlug>/foo.svg` in `<KnowledgeHub>` while working natively as `assets/foo.svg` inside Obsidian Desktop & Mobile.
- [x] **AC2 — Visual SVG Screen Mockups & Workflow Diagrams for All 5 Projects (`assets/ui-screens.svg`, `assets/ui-workflows.svg`, `assets/obsidian-mobile-r2-webdav.svg`)**:
  - Author project-specific `assets/ui-screens.svg` (annotated multi-screen UI layout & navigation map) and `assets/ui-workflows.svg` (step-by-step user & admin operational workflows) plus `assets/obsidian-mobile-r2-webdav.svg` inside `w0m-web/projects/<slug>/vault/assets/` for all 5 projects (`w0m`, `1945`, `artemio`, `servicios777`, `personaje0`), and mirror them to `w0m-web/apps/cp/public/assets/vaults/<slug>/`.
- [x] **AC3 — Comprehensive `notes/ui-user-guide.md` & Inline Diagrams in `notes/mobile-sync-user-guide.md`, `index.md`, and `mocs/deliverables.md` for All 5 Vaults**:
  - Create `notes/ui-user-guide.md` in each of the 5 vaults grounded in the actual screens, routes, components, and workflows of that project (`w0m` 5-app ecosystem & `w0m-ext`; `1945` Social Club lounge menu, e-commerce cart & admin panels; `artemio` bilingual menu, Telegram ordering & 12-module restaurant admin + PDF print compiler; `servicios777` Mexican services marketplace & client portal; `personaje0` AI digital persona passport, DSL script studio & Apple Silicon Wan 2.2 / voice synthesis pipeline).
  - Embed the visual SVG diagrams inline in `notes/ui-user-guide.md`, `notes/mobile-sync-user-guide.md`, and `index.md`, and populate `mocs/deliverables.md` across all 5 vaults.
- [x] **AC4 — Sync All 5 Vaults (Notes + SVG Assets) to Live Cloudflare R2 & Supabase (`public.vault_notes`) and Verify with Unit Tests**:
  - Add Supabase migration seeding `notes/ui-user-guide.md` and updated `index.md`, `mocs/deliverables.md`, and `notes/mobile-sync-user-guide.md` into `public.vault_notes` for all 5 vaults, and apply to live `public.vault_notes`.
  - Push all 5 vaults (including `assets/*.svg`) to `r2://wom-engagement-vaults/engagements/<engagement>/` via `scripts/vault_push_r2.py --verify`.
  - Add unit tests in `vault-parser.test.ts` and `vault-r2-gateway.test.ts` covering `assets/` path validation, SVG content-type headers, and Obsidian image embed / relative asset rewriting.
