# T623 — Compact top-left Enterprise/RPG mode icon switcher with `Alt+M` & 4-tap gestures, mobile header logo filter corruption fix, and Personal Information verification check-mark rounds

## Summary

Owner live UI review on `cp.webomage.com/me/profile` and mobile viewports (2026-11-03) identified four targeted UI/UX refinements across `@webomage/ui` and `apps/cp` / `apps/web`:
1. **Bulky Sidebar `Vocabulary Mode` Card**: `SidebarHatSwitcher.svelte` rendered a full-width two-button `Vocabulary Mode` (`Enterprise` / `RPG Guild`) box beneath `ContextSwitcher` while the top-left of the sidebar rail (`AppShell.svelte` `.rail-top`) sat empty opposite the collapse button. Shrinking Enterprise/RPG switching to a compact icon button at the top-left of the side panel that swaps its icon between Enterprise (`web`) and RPG (`mage`) frees sidebar vertical space and keeps mode state visible at a glance.
2. **Keyboard (`Alt+M`) & Mobile (`4 taps`) Mode Shortcut**: Pressing `Alt+M` on desktop or performing 4 rapid taps on mobile/touch (outside interactive buttons/inputs/links) should toggle Enterprise (`web`) ↔ RPG (`mage`) mode identically to clicking the top-left icon button.
3. **Corrupted Mobile Header Logo Filter Effect**: `apps/cp/src/components/{Header,Footer}.astro` and `apps/web/src/components/{Header,Footer}.astro` applied `blur-[0.5px] opacity-90 drop-shadow-[0_0_8px_rgba(255,255,255,0.4)]` directly onto `<img src="/assets/logo.svg">` (`viewBox="0 0 746 746"`, `stroke-width="12"`). At `h-10` (`40px` on mobile), `stroke-width="12"` scales down 18.65× to `0.64px` sub-pixel strokes; mobile GPU compositors rasterize `<img src="*.svg">` into a `40×40` bitmap tile before running chained `blur(0.5px)` + `8px` white `drop-shadow` inside a `backdrop-blur-md` header, smearing the thin multi-color strokes into a washed-out white halo artifact.
4. **Verbose `: unverified` Text in `PersonalInformation.svelte` Summary Strip**: On `/me/profile`, the collapsed `Personal information` summary strip (`Phone: unverified`, `Address: unverified`, `Identity: unverified`) should replace `: unverified` / status text with compact **gray** (empty/unverified), **yellow** (entered/pending verification), and **green** (KYC verified) check-marks inside filled round icons (`[●✓] Phone`, `[●✓] Address`, `[●✓] Identity`).
