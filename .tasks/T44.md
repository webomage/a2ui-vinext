# T44 — Research: Compute Economics & SLM Profitability

## Summary

Research the cost models, hardware optimization (MLX/vLLM), and amortization kinetics of deploying Small Language Models (SLMs) on private hardware vs. relying on frontier model APIs (Claude 3.5 Sonnet / GPT-4o) in high-volume agentic loops, providing a pricing model to ensure the w0m Open Routing layer operates at sustainable margins.

## Acceptance criteria

- [x] AC1 — Investigate frontier vs. SLM API price divergence and "agentic loop multipliers".
- [x] AC2 — Estimate on-premises hardware costs (Mac Studio M2/M4 Ultra vs. PCIe GPUs) and compute daily/monthly amortization metrics.
- [x] AC3 — Design a token routing matrix allocating routine tasks to SLMs and edge logic to frontier models.
- [x] AC4 — Document w0m routing target margins and pricing formulas.
