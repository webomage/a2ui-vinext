# T321 — Disambiguate wom7cfworkers dev port from Headroom proxy (8787 -> 8788) and restore Headroom health

## Summary

The Cloudflare Workers service (`wom7cfworkers`) dev server defaults to port 8787 when running `wrangler dev`. This collides directly with the local Headroom proxy daemon which is statically configured and declared on `127.0.0.1:8787` (`PORT = 8787` in `project/scripts/headroom_bootstrap.py`, `~/.claude/settings.json`, and `just headroom-task`). When `wom7cfworkers` dev runs on 8787, Headroom cannot bind or answers with workers JSON, resulting in `daemon: deployment 'default' INSTALLED BUT NOT HEALTHY`, `proxy: ready=False`, and `proxy /stats unreachable`. In addition, `stop-dev` in `wom7web/justfile` issues `lsof -ti:8787 -sTCP:LISTEN | xargs kill -9`, directly killing the Headroom daemon process when stopping dev servers.
This ticket moves `wom7cfworkers` local dev port to `8788`, updates client fallback RPC / test references, aligns `stop-dev` in `justfile`, terminates the stray `workerd` process currently squatting on 8787, and restores the Headroom daemon to a clean, healthy state (verified via `just headroom-status`).

## Acceptance criteria

- [x] AC1 — Configure `wom7cfworkers` `wrangler.jsonc` (and `package.json` scripts) to use port `8788` for `wrangler dev`.
- [x] AC2 — Update `stop-dev` in `wom7web/justfile` so it targets port `8788` for worker dev and leaves port `8787` untouched, preventing inadvertent Headroom termination.
- [x] AC3 — Update fallback URLs in `wom7web/apps/web/src/lib/rpc.ts`, `wom7web/apps/cp/src/lib/rpc.ts`, and `wom7web/tests/steps/ats.steps.ts` from port 8787 to 8788.
- [x] AC4 — Terminate the stray `workerd` process currently listening on port 8787 and ensure port 8787 is exclusively freed for Headroom.
- [x] AC5 — Restore and restart the Headroom daemon (`headroom install restart` / `just headroom-bootstrap`) so `http://127.0.0.1:8787/health` reports `ready=True` and `/stats` is reachable.
- [x] AC6 — `just headroom-status` (via `headroom_bootstrap.py`) passes with 0 failures and confirms daemon healthy and proxy reachable.

## Definition of Done

Port 8787 is reserved exclusively for the local Headroom proxy daemon and verified healthy (0 failures via `just headroom-status`), while `wom7cfworkers` `wrangler dev` is configured to run on port 8788 without port conflict; `stop-dev` terminates port 8788 rather than 8787, client fallback RPCs point to 8788, and quality/ticket checks pass.
