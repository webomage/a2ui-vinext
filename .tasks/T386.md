# T386 — Unify git hooks architecture under single just runner contract and eliminate husky vs pre-commit shadowing

## Summary

Git hooks across the w0m estate are split across two disconnected frameworks (`husky` and `pre-commit`), resulting in shadowed hooks, tool execution contract violations, and staged-vs-full-tree gate divergence.

Specifically:
1. In `wom7web`, `core.hooksPath` points to `.husky/_`. This causes `.pre-commit-config.yaml`'s `commit-msg` hook installed in `.git/hooks/commit-msg` to be dead and completely ignored, while `.husky/commit-msg` runs.
2. 10 of 11 local hooks in `.pre-commit-config.yaml` bypass `just` recipes and call linters/formatters raw (`semgrep`, `oxlint`, `oxfmt`), violating the T130 contract that all stack commands must route through declared `just` recipes in `project/stacks-policy.json`.
3. Pre-commit operates exclusively on staged files, whereas `.husky/pre-push` runs full-tree checks via `just` recipes, creating surprise failures where a commit passes pre-commit cleanly but is subsequently blocked by pre-push.

This ticket unifies git hooks under a coherent runner contract, ensures all hooks invoke `just` recipes, eliminates shadowed hooks, and aligns staged vs full-tree gate expectations.

## Acceptance criteria

- [x] AC1 — **Single Hook Runner Contract**: Standardize hook dispatch architecture across `wom7web`, `wom7api`, and child repos so no hook framework shadows or silences another (`wom7web/.husky/pre-commit` → `pre-commit run`, `wom7web/.husky/commit-msg` → `exec just commit-msg-check "$1"`, all 8 repos' `.pre-commit-config.yaml` unified).
- [x] AC2 — **Route Hooks Through declared just Recipes**: Replace raw binary invocations (`semgrep`, `oxlint`, `oxfmt`, `prettier`, `deploy-in-flight`, `skills-drift`, `guard-test-admin`, `lexicon-lint`, `status-dashboard`, `cp-feature-index`, `ds-conformance`, `ds-adherence`, `decisions-index`) in `wom7web/.pre-commit-config.yaml` with corresponding recipes declared in `wom7api/justfile` and `project/policies/stacks-policy.json` (`lint-staged`, `fmt-staged`, `fmt-astro-staged`, `semgrep-staged`).
- [x] AC3 — **Eliminate Dead Shadowed Hooks**: Resolve the duplicate `commit-msg` definition between `.husky/commit-msg` and `.pre-commit-config.yaml` across all 8 repos, ensuring conventional commit + `T##` verification has one canonical SSOT (`scripts/conventional_commit.py` / `just commit-msg-check`).
- [x] AC4 — **Align Staged and Pre-Push Verification Scopes**: Provide staged-check fast paths (`just lint-staged`, `just fmt-staged`, `just fmt-astro-staged`, `just semgrep-staged`, `just ds-conformance --enforce`, `just ds-adherence`) and retire inline `bash -c 'grep -qE ...'` duplicates across `wom7api`, `wom7func`, `wom7ext`, `wom7sec`, `wom7skills`, and `wom7mlx/wom7mlx`.
- [x] AC5 — **Verify Hook Health**: Confirm `just hooks-check`, `just discovery --enforce`, `just suites-drift`, and `just t129-t386-hooks-test` pass 100% green.
- [x] AC6 — **Tech Debt Update**: On archive, move rows `D52` and `D67` to `## Closed-Debt Ledger` in `TECH-DEBT.md` and verify `just debt-check --enforce` passes.
