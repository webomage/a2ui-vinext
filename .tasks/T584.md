# T584 — Mobile Terminal & Deploy Gate: Asterisk Password Masking (`***`) & Show/Hide Toggle

## Context
When running `just deploy` / `just deploy-all` from the Orca mobile terminal on iOS (`[confirm] sudo password for aleksei:`), two UX/security gaps appeared:
1. **Orca Mobile `Live input` (`w0m-pr/orca`)**: In direct (`Live input`) and buffered command modes, `MobileSessionCommandDock` displayed `liveInputCapture` / draft text in plain text (`oiu`) above the keyboard while typing passwords.
2. **Linux System Auth (`scripts/confirm_step.py`)**: `_confirm_presence_linux` invoked `sudo -k -p "   [confirm] sudo password for %u: " sudo -v` directly without echoing `*` feedback per character on the terminal line.

## Acceptance Criteria
- [x] **AC1 (`scripts/confirm_step.py` — Terminal Asterisk Feedback)**: Added `_read_masked_password()` in `scripts/confirm_step.py` reading from `/dev/tty` (or TTY `stdin`) in `termios` `cbreak`/no-`ECHO` mode, echoing `*` per character typed, handling Backspace (`\x7f`/`\x08` -> `\b \b`), Ctrl+U (`\x15` line clear), Ctrl+W (`\x17` word erase), and Ctrl+C (`\x03`), and validating against `sudo -k -S -p "" sudo -v`.
- [x] **AC2 (`w0m-pr/orca` — Mobile Input Asterisk Masking & Inline Show/Hide Button)**: Added `mobile/src/terminal/terminal-password-prompt.ts`, `mobile/src/terminal/use-terminal-password-prompt-state.ts`, and `mobile/src/session/MobileTerminalPasswordMaskOverlay.tsx` (`Eye`/`EyeOff` inline Show/Hide toggle button + `*` asterisk overlay) wired into `MobileSessionCommandDock.tsx` (both `Live input` and buffered `commandField`), `use-mobile-session-terminal-runtime.ts`, and `mobile-session-route-helpers.ts` (`61a1e8ad8e` on `webomage/orca` branch `feat/mobile-live-input-password-mask`).
- [x] **AC3 (Tests & Verification)**: Added PTY/unit tests in `scripts/tests/test_confirm_step_masked_password.py` (`5/5` passed), verified `scripts/tests/test_confirm_step.py` (`91/91` passed), and verified `w0m-pr/orca` Vitest suites (`terminal-password-prompt.test.ts` + `MobileTerminalPasswordMaskOverlay.test.tsx`, `8/8` passed) plus `oxlint` (`0 warnings, 0 errors`) and `max-lines` ratchet.
