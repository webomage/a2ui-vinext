# T454 — MFA for non-admin accounts

## Summary

Split from [[T100]] by owner decision 2026-09-25 (*"let's split 2fa/mfa for admin and non-admins"*). T100 keeps
admin MFA: the aal2 gate on admin context, now keyed on the held admin role (AC8). This ticket covers everyone else.

**Measured 2026-09-25:**
- MFA is enforced only in admin context (`isAdminMfaContext`, `packages/lib/src/auth/mfa-policy.ts`). A member or
  client who enrols TOTP on `/profile` is never challenged. Enrolment therefore adds no protection for them.
- The challenge page and verify endpoint exist only in `apps/cp` (`pages/mfa/challenge.astro`,
  `api/auth/mfa/challenge-verify.ts`). `web` and `join` sign in through `AuthForm.astro` and have neither.
- Live: 0 enrolled factors on any account.

**Decided:** the factor is per profile. TOTP now, and Touch ID / WebAuthn when [[T100]] AC9 lands (one relying party
per domain). Sequenced behind [[T453]], which puts every app on one middleware and route-policy model. Without
it this would be a fourth per-app copy of the challenge wiring.

## Acceptance criteria

- [x] AC1 — **Policy:** a session whose user has a verified factor (`nextLevel === "aal2"`) is held at `aal1` on
  protected routes in every app until challenged, whatever their role; users with no factor are not forced to enrol
  (opt-in for non-admins). Red probes in `mfa-policy.spec.ts`.
- [x] AC2 — **One challenge endpoint and page in the shared lib**, used by cp, web and join (no per-app copy),
  `challengeAndVerify()` server-side, aal2 cookies set.
- [x] AC3 — **`AuthForm.astro` inline challenge step** after password / magic-link sign-in when a factor exists:
  `autocomplete="one-time-code"`, error feedback, recovery guidance.
- [x] AC4 — **E2E:** an enrolled member cannot reach a protected route until the challenge passes (Gauge, non-real
  test account, [[T31]]).

## Definition of Done

T454 is done when a member or client with an enrolled factor is challenged at sign-in in every app through one
shared endpoint and UI, a user without a factor is unaffected, and an E2E test proves the block. Quality gates clean;
deploy run by the owner.
