# T464 — Orca Obsidian-Flavored Markdown (OFM) engine

## Summary

Enhance Orca IDE (`wom7pr/orca`, `stablyai/orca`) to natively resolve and render Obsidian-Flavored Markdown (OFM) without requiring external servers or containerized desktop workarounds. Orca already contains the initial scaffolding for Obsidian-style `[[docLink]]` navigation (`src/renderer/src/components/editor/markdown-doc-links.ts`), but it currently fails on real-world Obsidian vaults due to three gaps: (1) exact-name-only lookup in `resolveMarkdownDocLink` preventing `[[AgDR-0027]]` from resolving to `AgDR-0027-platform-companies-persons-and-operator-gate.md`, (2) strict exclusion of dot-directories and symlinks in `listMarkdownDocuments` (`src/main/ipc/markdown-documents.ts`) omitting `.tasks/` and workspace symlinks, and (3) lack of Obsidian callout rendering (`> [!NOTE]`, `> [!WARNING]`). This change fixes all three and validates resolution against the w0m workspace.

## Acceptance criteria

- [x] AC1 — `listMarkdownDocuments` in Orca's main process scans whitelisted dot-directories (`.tasks/`) and traverses safe in-workspace directory symlinks.
- [x] AC2 — `createMarkdownDocumentIndex` indexes document slug prefixes and frontmatter metadata (`id`, `aliases`) alongside exact names.
- [x] AC3 — `resolveMarkdownDocLink` matches bare ID references (`[[AgDR-0027]]`) to slugged files (`AgDR-0027-*.md`) and frontmatter aliases with deterministic disambiguation.
- [x] AC4 — `useMarkdownPreviewComponents` renders Obsidian/GitHub callouts (`> [!NOTE]`, `> [!TIP]`, `> [!WARNING]`, `> [!IMPORTANT]`, `> [!CAUTION]`) with themed icons and callout containers.
- [x] AC5 — Unit and integration tests added in `src/renderer/src/components/editor/markdown-doc-links.test.ts` and `src/main/ipc/markdown-documents.test.ts` passing organically.
- [x] AC6 — Quality gates in `wom7pr/orca` pass cleanly (`pnpm run typecheck`, `pnpm run audit:code-quality:native`, `pnpm test`).
- [x] AC7 — Upstream branch `feat/obsidian-ofm-engine` prepared and pushed to `casualuser/orca`.
