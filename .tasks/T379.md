# T379 — Extend, fulfill, and backfill ROADMAP.md and GitHub Projects visual timeline dates

## Summary

Owner directive, 2026-09-18:
> *"I think we should extend and fullfill and backfill roadmap and also where in GH we use epics names ??"*
Followed by confirmation to execute **both** Track A (GitHub Projects timeline setup and date backfill) and Track B (ROADMAP.md extension and ticket epic backfill).

### Background & Gaps
1. **GitHub Projects Roadmap View is Blank**: On GitHub Project #2 (`w0m Delivery` under `webomage`), View 3 (`Roadmap`) displays all items in an "Unscheduled items" drawer with `+` buttons and zero Gantt timeline bars. This occurs because Project #2 has zero custom `Date` fields configured (`Start date`, `Target date` do not exist).
2. **Missing Ticket Epics in Open Queue**: 9 open tickets (T322, T323, T326, T327, T328, T329, T330, T344, T347) and several completed tickets (T341, T342, T350, T352) currently carry an empty `epic: ""` frontmatter value, causing them to show up without epic grouping on the board and in audit tools.
3. **ROADMAP.md Out of Sync with Recent Architecture**: `wom7web/ROADMAP.md` ends at §34 (added 2026-09-12). Major strategic initiatives developed in T370–T378 require formal section anchors:
   - **§35: Apple Virtualization & MicroVM Sandboxes** (Tart, Apple virtualization framework, guest agents, isolated execution sandboxes; T373).
   - **§36: Generative Video & Media Subprojects** (`wom7clips` SMB short-form video generation and `wom7ava` consented-identity virtual avatars; T322, T323).
   - **§37: Open Source Forks & PR Federation** (`wom7pr` repository namespace, continuous fork synchronization, upstream PR triage, and CP developer tooling; T345, T369, T377, T378).

### Deliverables
1. **Extend `ROADMAP.md`**: Author §35, §36, and §37 with clear summaries, exit criteria, effort, and ticket mappings.
2. **Backfill Ticket Frontmatter**: Assign canonical epics to all open and unassigned tickets so `epic_completeness.py` reports 0 open tickets without an epic.
3. **Synchronize Epic Vocabulary**: Run `sync_epic_vocabulary.py --sync` to update `project/tickets-schema.jsonc` and verify `--check`.
4. **Provision GitHub Project #2 Date Fields**: Create `Start date` and `Target date` DATE fields on Project #2 using `gh project field-create`.
5. **Backfill Timeline Dates to GitHub**: Extend `populate_project_fields.py` to calculate and push start and target dates for tickets so the GitHub Project Roadmap layout renders visual timeline bars.
