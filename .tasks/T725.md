# T725 — Restore Cross-App `/api/board` and `/api/vault/r2` Route Parity in `apps/me`, Fix `FeatureVotingBoard` Error Split-State, and Add Standing `me-api-parity` Gate

## Summary

Fixes the live HTTP `403 Forbidden` banner on `https://me.webomage.com/me/oss` (and the twin missing route families `/api/vault/r2/*` and `/api/auth/impersonate-handoff` on `me.webomage.com`) caused by `apps/me` mounting `@cp/*` Svelte islands without re-exporting their backing endpoints or declaring them in `w0m-web/apps/me/src/lib/route-policy.ts`. Also fixes the split-state UI bug in `w0m-web/apps/cp/src/components/oss/FeatureVotingBoard.svelte` where a failed repository load changed `selectedRepo` in the header while keeping stale issue cards from the previous repository rendered below, and adds a standing Vitest gate (`w0m-web/apps/me/src/tests/me-api-parity.test.ts`) so `apps/me` can never drift from its transitive `@cp/*` `/api/*` dependencies again.

## Acceptance criteria

- [x] AC1 — **Re-export Missing `/api/board/*`, `/board/*`, `/api/vault/r2/*`, and `/api/auth/impersonate-handoff` Endpoints in `apps/me` (`w0m-web/apps/me/src/lib/route-policy.ts`):** Added route re-exports under `w0m-web/apps/me/src/pages/api/board/[owner]/[repo].ts`, `w0m-web/apps/me/src/pages/api/board/[owner]/[repo]/badge.svg.ts`, `w0m-web/apps/me/src/pages/board/index.astro`, `w0m-web/apps/me/src/pages/board/[owner]/[repo].astro`, `w0m-web/apps/me/src/pages/api/vault/r2/[engagement]/index.ts`, `w0m-web/apps/me/src/pages/api/vault/r2/[engagement]/[...path].ts`, and `w0m-web/apps/me/src/pages/api/auth/impersonate-handoff.ts`, and declared explicit `isBoardApi` / `isVaultR2Gateway` (`subject: "public"`) rules in `w0m-web/apps/me/src/lib/route-policy.ts`.
- [x] AC2 — **Eliminate Split-State Stale Cards on Failed Repo Switch (`w0m-web/apps/cp/src/components/oss/FeatureVotingBoard.svelte`):** Updated `loadBoard()` and `handleVote()` in `w0m-web/apps/cp/src/components/oss/FeatureVotingBoard.svelte` to use `readJsonSafe` and clear `board` + `activeSpecCard` whenever `board.repo !== cleanRepo` on fetch failure.
- [x] AC3 — **Enforce Transitive Cross-App API Parity via Automated Vitest Gate (`w0m-web/apps/me/src/tests/me-api-parity.test.ts`):** Added `w0m-web/apps/me/src/tests/me-api-parity.test.ts` walking `w0m-web/apps/me/src` and transitive `@cp/*` imports; verified `2/2` Vitest checks pass.
