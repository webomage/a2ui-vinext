# T579 — CP UI/API Parity & Multi-Role E2E Harness

## Goal

Close the actionable UI↔API parity gaps and multi-role E2E harness gaps surfaced in [`.agents/reports/2026-10-28-t579-ui-ux-api-parity-and-e2e-roles-audit.md`](../.agents/reports/2026-10-28-t579-ui-ux-api-parity-and-e2e-roles-audit.md):
1. **Un-reserve `/admin/claims`**: `/admin/claims` already has `pages/admin/claims.astro`, `BrandClaimsManager.svelte`, and `/api/admin/claims.ts` implemented, but was still marked `reserved: true` in `apps/cp/src/lib/context/nav.ts`.
2. **Wire headless CP APIs & unmounted admin components**:
   - `InvoiceManager.svelte`: route `reconcileSpeiInvoice()` through `POST /api/admin/invoices/reconcile-spei` instead of direct client-side table mutation.
   - `DualManagerGovernanceCard.svelte`: wire interactive T61 Dual-Manager gate verification against `POST /api/project/release-approval` (`milestone_release` / `release_tag`).
   - `pages/admin/vaults.astro`: mount `VaultSyncPanel.svelte` calling `POST /api/sync/vault` and `POST /api/admin/broadcast-extension` using `@webomage/ui` primitives.
   - `pages/admin/tasks.astro`: mount `HatchetActivity.svelte` on `/admin/tasks` so live workflow activity (`domain_scan_results`) is visible above the Cloudflare console and `HatchetActivity.svelte` is no longer an orphaned admin component.
   - `ATSKanban.svelte`: wire an external ATS sync button calling `functions/v1/ats-api` using `@webomage/ui` `Button`.
3. **Multi-role E2E step definitions & self-contained `just roles-verify` / `just e2e-roles-local` targets**:
   - Implement the 5 missing Gauge `@Step` methods in `w0m-web/tests/steps/personas.steps.ts` for `specs/web/multi_role_hats_and_guild.spec` so `gauge validate specs/personas/class_reach.spec specs/web/multi_role_hats_and_guild.spec` passes with 0 validation errors.
   - Add `just roles-verify` (running all multi-role RBAC/Postgres/Nav/Vitest suites) and `just e2e-roles-local` (self-contained 7-persona local browser E2E runner for `specs/personas/class_reach.spec` and `specs/web/multi_role_hats_and_guild.spec`).
