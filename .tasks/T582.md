# T582 — iOS Mobile Browser Support for w0m-ext (Orion iOS .xpi/.zip Package, Safari WebExtension Target & 1-Tap iOS Universal Auto-Fill Bookmarklet)

## Context

On iOS, Chrome/Brave/Firefox cannot install browser extensions due to Apple WebKit restrictions, leaving mobile job applications and profile form-filling without `w0m-ext` unless delivered through:
1. **Option 1 — Orion Browser on iOS (`.xpi` & `.zip` Direct File Install)**: Orion Browser (by Kagi) on iOS natively loads Chrome and Firefox MV3 WebExtensions directly from `.xpi` or `.zip` packages without Xcode or App Store review, and renders `action.default_popup` (`ui/popup.html`) in a mobile bottom sheet.
2. **Option 2 — Native iOS Safari WebExtension (`BROWSER_TARGET=safari`)**: Safari on iOS 15+ supports MV3 WebExtensions when `manifest.safari.json` omits desktop-only/blocking permissions (`contextMenus`, `webRequest`), declares `background.non_persistent: true`, and is wrapped via `xcrun safari-web-extension-converter --ios-only`.
3. **Option 3 — Universal iOS 1-Tap Auto-Fill Bookmarklet (`javascript:...`)**: Works inside **any** iOS mobile browser (Safari, Chrome iOS, Brave iOS, Orion iOS) by injecting a self-contained field-matcher that populates headlines, summaries, skills, links, rates, and screening Q&A fields from the user's synthesized `PlatformProfileStudio` profile.
