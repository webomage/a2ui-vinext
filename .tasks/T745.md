# T745 — k7 WASM job-hunter multi-channel search with include/exclude source filter and vector/graph rubric

## Summary

Unify and automate multi-channel remote job and contract search across `w0m-cf`, `@k7` (`k7hub`), `w0m-web` (`w0m-cp`), and the estate CLI so operators can search **all included** or **include/exclude specific sources** (e.g., `--include all --exclude upwork`), score every listing with the deterministic `0–100` 5-axis rubric (`Stack /35`, `Ownership /20`, `Commercials /20`, `Timezone/Remote /15`, `Signal /10`), and link every match to the Hybrid BM25 + Vector KB and `cv-profile-seed.json` Knowledge Graph provenance.
