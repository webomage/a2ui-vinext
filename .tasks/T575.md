# T575 — Telegram & Meta Threads Hiring Post Search (Option A: Cloudflare-Native + Keyword Search UI + Member Credentials)

## Goal

Enable automated and on-demand keyword search for hiring posts across **Telegram (`TG`)** and **Meta Threads**, running 100% natively on Cloudflare (`w0m-api` Workflows, `w0m-cf` Cron, and `w0m-web` Astro SSR endpoints) without requiring a self-hosted Rust/Python daemon (`ZeroClaw`), while using the signed-in **member's Telegram & Threads connections/credentials** when login/token authentication is required, and providing an interactive **Keyword Search UI** + `w0m-ext` browser clipper fallback for private/authenticated tabs.

## Acceptance Criteria

- [x] **AC1 — Database Schema & Edge Function Source Constraints (`w0m-api`)**:
  - Migration `20261026120000_t575_telegram_threads_job_search.sql` widens `public.aggregated_jobs_source_check`, `public.outreach_clips_platform_check`, `public.outreach_threads_platform_check`, and `public.source_links_provider_check` to admit `'telegram'` and `'threads'`.
  - Updates `public.wom_upsert_aggregated_job_from_clip(uuid)` and `public.trg_fn_outreach_clip_to_aggregated_jobs()` so `'telegram'` and `'threads'` `job_post` clips automatically upsert into `public.aggregated_jobs`.
  - Seeds `job_source_enabled:telegram` (`true`) and `job_source_enabled:threads` (`false` until token present) in `public.admin_secrets`.
  - Widens `VALID_SOURCES` in `w0m-api/supabase/functions/jobs-list/index.ts` and `PLATFORMS` in `w0m-api/supabase/functions/outreach-clip-ingest/handler.ts`.
- [x] **AC2 — Provider Registry, Member Service Handles & `@webomage/lib` Connectors (`@wom`, `w0m-web`)**:
  - Declares `threads` in `project/policies/services-policy.json` (`oauth_providers`) and `telegram` + `threads` in `job_board_sources`.
  - Adds `threadsAdapter` (`https://threads.net/oauth/authorize`, `https://graph.threads.net/oauth/access_token`, `https://graph.threads.net/v1.0/me`) to `@webomage/lib/connectors/adapters.ts` and `threads` handle to `@webomage/lib/auth/service-handles.ts`.
  - Extends `@webomage/lib/connectors/telegram-job-source.ts` with `?q=<keyword>` filtering and multi-channel `searchTelegramHiringPosts`.
  - Adds `@webomage/lib/connectors/threads-job-source.ts` (`searchThreadsHiringPosts` via `GET https://graph.threads.net/v1.0/keyword_search`) with hiring-post scoring, USD compensation extraction, and explicit `auth_required` signal when member/platform login token is needed.
- [x] **AC3 — Cloudflare Cron & Workflow Job Sources (`w0m-api`, `w0m-cf`)**:
  - Adds `w0m-api/src/utils/job-sources/telegram.ts` (`fetchTelegramJobs`) and `w0m-api/src/utils/job-sources/threads.ts` (`fetchThreadsJobs`) and wires both into `w0m-api/src/workflows/job-aggregator.ts` and `w0m-api/src/lib/job-boards.ts`.
  - Adds `scrapeTelegram` and `scrapeThreads` to `w0m-cf/src/lib/job-boards.ts`.
- [x] **AC4 — On-Demand Social Hiring Keyword Search API, Member Credentials & Interactive UI (`w0m-web`)**:
  - Creates `POST / GET /api/jobs/social-search` (`apps/cp` + re-exported in `apps/job`) that resolves the signed-in member's Telegram handle/custom channels and AES-256-GCM encrypted Threads access token from `public.connections` (with fallback to `admin_secrets` `THREADS_ACCESS_TOKEN`), supports saving member TG/Threads credentials inline, searches Telegram channels + Threads by keyword, and optionally saves matched posts to `public.outreach_clips` and `public.aggregated_jobs`.
  - Creates `SocialHiringSearch.svelte` using `@webomage/ui` primitives (`Button`, `Input`, `Badge`, `Card`) with keyword search bar, channel selector, platform toggles, member TG/Threads login/credential configuration drawer, and one-click save to Outreach Vault / Job Board.
  - Integrates `SocialHiringSearch.svelte` into `JobBoard.svelte` (`apps/job`), `OutreachHub.svelte` (`apps/cp` & `apps/job`), and `/me/connectors` (`apps/job`), and adds `threads` handle mapping to `ConnectedIdentities.svelte`.
  - Updates `packages/lib/src/team-card.ts` (`mapTeamMember`) and `packages/lib/src/team-card.spec.ts` so every active team member with `has_public_resume: true`, `profile_slug`, or `cv_url` renders prominent bottom CTA links (`Expert Profile` `/u/<slug>`, `Detailed CV` `cv_url`, `Download Resume (PDF)` `cv-pdf?member=<id>`) on the public Team card alongside the header PDF link, and mounts `PublicSettings.svelte` directly on `apps/job/src/pages/me/resume.astro` (moved to `apps/me/src/pages/me/resume.astro` in [[T646]]) so members can toggle **Public resume** and **Show LinkedIn on team card** inside Resume Studio.
- [x] **AC5 — Browser Extension Clipper Support (`w0m-ext`)**:
  - Updates `w0m-ext/extension/src/content/clipper.ts` (`detectPlatformAndClipType` and `ClipPlatform`) and `w0m-ext/extension/src/ui/popup.ts` so `t.me` / `web.telegram.org` and `threads.net` / `threads.com` tabs are recognized as `"telegram"` and `"threads"` (`job_post` / `selection`) for clipping authenticated/private channels and posts.
  - Unit tests pass across `@webomage/lib`, `w0m-api`, and `w0m-ext`.
