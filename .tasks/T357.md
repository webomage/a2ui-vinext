# T357 — Ingest external project work reports into w0m project progress tracking

## Summary

In multi-project and client delivery engagements (such as `artemioquierocomer.mx`, `bridgeroad`, and `evercred`), autonomous agents and engineers produce rich delivery and session reports documenting shipped tickets, live Cloudflare/Vercel versions, verification metrics, and durable architecture lessons. Currently, these reports are dropped into `@wom/_in/` or client Obsidian vaults as unindexed markdown files, requiring manual review to incorporate lessons and track actual progress.

This ticket builds an automated ingestion pipeline in `w0m`:
1. Parses inbound markdown work/delivery reports from `_in/` or client vaults.
2. Validates metadata (source project, tickets completed, deployment versions, verification gates).
3. Links the work directly to `public.projects` and project progress records in the w0m Control Panel.
4. Automatically extracts and proposes new earned lessons for inclusion in `wom7web/LESSONS.md`.
5. Automatically archives processed reports to `_arch/` with provenance.

## Acceptance criteria

- [ ] AC1 — Schema & Parser Specification: Define an ingestion schema (source project slug, ticket IDs, deployment versions, quality gate results, artifacts, and earned lessons) capable of parsing standard w0m delivery reports (e.g. `YYYY-MM-DD-*-delivery-report.md`).
- [ ] AC2 — Ingestion CLI Recipe: Author `just project-report-ingest <path>` in `wom7web` that validates report structure, resolves project identity against `project/clients-policy.json` and `public.projects`, and dry-run validates payloads.
- [ ] AC3 — Project Progress Sync: Ingested reports update project milestone/progress records (`public.project_milestones` or client progress matrix in `_msg/Progress/`) with version stamps and completed ticket references.
- [ ] AC4 — Automated Lesson Extraction: Pipeline parses the "Durable Architecture Rules Added" / lessons section of incoming reports and generates formatted candidate rules for `wom7web/LESSONS.md`.
- [ ] AC5 — Automated Archival: Once successfully ingested and recorded, the report is automatically moved from `_in/` to `_arch/` under a project-dated directory (`_arch/<project>_reports_<date>/`).
- [ ] AC6 — Regression Suite: Unit and integration tests in `project/scripts/tests/test_report_ingest.py` proving clean ingestion of sample reports (e.g. Artemio T216-T222) and fail-closed error handling on malformed reports.
