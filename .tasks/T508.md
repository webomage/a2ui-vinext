## What `sandboxed` means (plain language, owner asked 2026-09-30)

- A **sandbox** is a play pen: a tool inside it can only touch what you hand it, so it cannot wander off or break anything.
- `sandboxed: true` is the label for "this tool is kept in the pen". `sandboxed: false` is "this tool runs in the open, as you, on your computer".
- The catalogue does not enforce the pen. It checks that the **label matches reality**. A skill that ships runnable code gets the default `true`
  unless a written decision says otherwise, and it then looks for call sites that run that code directly on the host. If it finds one, the label
  and the facts disagree, and it says so.
- `mmd-validate` is a spell-checker for diagrams: it reads a `.mmd` or Markdown file and answers "valid" or "broken". Its code was read on
  2026-09-30 and has no network call, no child process and no file write. It runs on the host from a pre-commit hook, so the honest label is
  `false` with a reason, and a pen would only break the hook. Changing the label changes nothing about how it runs; it only makes the record true.
- Why the label matters: a wrong `true` is a false claim of confinement that nobody checked, which is the failure this catalogue was built to catch.
  The decision for `mmd-validate` moved to [[T521]].
