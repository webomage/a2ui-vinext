# T686 — Cloudflare Computer (`@cloudflare/computer`) hybrid isolate-first DO SQLite workspace & 3-backend runtime integration

## Summary

Cloudflare announced [`@cloudflare/computer`](https://blog.cloudflare.com/cloudflare-computer/) (`https://github.com/cloudflare/computer`, `@cloudflare/computer@0.10.0`), an open-source agent runtime that provides every agent with a persistent virtual filesystem (`@cloudflare/dofs`, up to ~10 GB backed by Durable Object SQLite storage) and dynamically orchestrates `workspace.runtime.exec(source, { backend })` across three execution backends so **containers are required for `<10%` of agent work**:
1. **`worker-shell` (Isolate via `just-bash` + Dynamic Worker):** Zero-cold-start shell execution with direct Workers RPC access to `Workspace` (`core`, `jq`, `yq`, `xan`, `curl`, `file`, `python`, `sqlite`, `js-exec`, `html-to-markdown`, plus `@wom`'s `just-1.59.0-w0m.1` WASM runner).
2. **`codemode` (Isolate ECMAScript Module via Dynamic Worker):** Production-stable isolate execution with `node:fs/promises`, `codemode:git`, `codemode:artifacts`, `codemode:assets`, `codemode:tools`, and `codemode:browser`.
3. **`container` (FUSE-mounted Cloudflare Container via `computerd` + `capnweb` RPC):** On-demand full Linux userland mounted over FUSE strictly for `<10%` of workloads requiring native Linux binaries (`semgrep`, `trivy`, `gitleaks`, `checkov`, `cargo`, `pandoc`).

This directly advances **`AgDR-0055` (Free-Tier-First Resource Rule)** by keeping `>90%` of agent file, Git, JSON/YAML/CSV, Markdown, and JS/TS code-mode operations inside horizontally scalable Cloudflare Isolates.
