# T722 — Fix Astro v6 `locals.runtime.env` SSR Crashes (`blueprints/order` & CP), Classify Recovered Deploy Retries, and Ship Full-Scope Admin Member & Client Impersonation

## Summary

Resolves three coupled production reliability, observability, and access-administration gaps surfaced after `release 2026.11.11-1794417310`:
1. **`https://webomage.com/blueprints/order` & `https://me.webomage.com/me/todos` Astro v6/v7 `Middleware Error: Astro.locals.runtime.env has been removed in Astro v6`:** Five worker-bundled files (`apps/web/src/pages/blueprints/order.astro`, `apps/cp/src/lib/todos-server.ts`, `apps/cp/src/pages/api/insights/index.ts`, `apps/cp/src/pages/api/insights/promote.ts`, and `packages/lib/src/auth/handlers.ts`) still touched `locals.runtime.env` (which throws an uncaught getter error in `@astrojs/cloudflare` v13+ / Astro 7) or bare `process.env`, bypassing `worker_env_gate.py` and `live-smoke.spec` (and causing `TodoWorkspace.svelte` on `me.webomage.com/me/todos` to throw `Unexpected token 'M', "Middleware"... is not valid JSON`), plus three API routes (`claims.ts`, `mcp.ts`, `vault/tokens.ts`) still read legacy pre-unification `locals` property names.
2. **Deploy-Log `other_trouble` Rise on Self-Healed Edge Function Retries (`scripts/deploy_logged.py`):** `scripts/deploy_functions.py` automatically detected 2 transient Supabase API `500`s (`submit-service-request`, `telegram-webhook`), retried them (`retry 1/3`), and verified `all 64 function(s) updated on live`, yet `scripts/deploy_logged.py` lumped those 4 lines into unrecovered `other_trouble` (`0 -> 4`) with no distinction between recovered retries and real unrecovered errors.
3. **Full-Scope Admin Impersonation of Any Member or Client (`cp`, `me`, `/admin/clients`, `/admin/users`):** `impersonate.ts` previously queried only `profiles.eq("auth_user_id", targetUserId)` (404ing on auth-only/client accounts), wrote `profiles.id` instead of `auth.users.id` into `sb-sudo-token` and `impersonation_audit.target_id`, trapped admins on `cp.w0m.xyz -> /404` when impersonating non-admins, left `impersonation_audit.ended_at` `NULL` in `stop-impersonate.ts`, left `assertNotImpersonating(locals)` unwired, and lacked one-click Client Org impersonation in `ClientManager.svelte` and `cp` vs `me` portal targeting in `LiveUserSessionsDashboard.svelte`.

## Acceptance criteria

- [x] AC1 — **Eliminate All `Astro.locals.runtime.env` & Bare `process.env` Reads + Harden `worker_env_gate.py` & `live-smoke.spec`:** Migrated `apps/web/src/pages/blueprints/order.astro`, `apps/cp/src/lib/todos-server.ts`, `apps/cp/src/pages/api/insights/index.ts`, `apps/cp/src/pages/api/insights/promote.ts`, and `packages/lib/src/auth/handlers.ts` to `import { env } from "cloudflare:workers"` (`AgDR-0023`), hardened `apps/cp/src/components/todos/TodoWorkspace.svelte` (`readJsonSafe`), fixed stale `locals` property names in `apps/cp/src/pages/api/admin/claims.ts`, `apps/cp/src/pages/api/mcp.ts`, and `apps/cp/src/pages/api/vault/tokens.ts`, upgraded `w0m-web/project/scripts/worker_env_gate.py` + `w0m-web/project/scripts/tests/test_worker_env_gate.py` (`0` violations; `17/17` tests pass), and added `/blueprints/order` + `Middleware Error:` guard to `w0m-web/specs/web/live-smoke.spec` & `w0m-web/tests/steps/ui.steps.ts`.
- [x] AC2 — **Classify Recovered Edge Function Deploy Retries vs Unrecovered Errors in `scripts/deploy_logged.py`:** Upgraded `audit_transcript()` and `compute_audit_deltas()` in `scripts/deploy_logged.py` to classify transient Supabase CLI `500` + retry lines into `recovered_retries` (`recovered_retries_count`) ONLY when `✅ all N function(s) updated on live.` is proven in the same transcript (keeping partial/failed deploys in `other_trouble`), added `--audit-check` + `just deploy-audit`, and verified `33/33` probes in `scripts/tests/test_deploy_logged.py` (`just deploy-logged-test`).
- [x] AC3 — **Full-Scope Admin Impersonation Backend, Cross-Domain Handoff, Audit Closure & Write-Guards:** Added `apps/cp/src/lib/impersonation-shared.ts` and `apps/cp/src/pages/api/auth/impersonate-handoff.ts`, upgraded `apps/cp/src/pages/api/admin/impersonate.ts` (`GET` unified member+client directory + `POST` supporting `targetUserId`, `targetProfileId`, `targetClientOrgId`, `targetEmail`, `targetPortal: "cp" | "me"`, and silent zero-email client preview provisioning on canonical `orgs` + `engagements` + `hats`), stamped canonical `auth.users.id` + `auditId` in `sb-sudo-token` and `impersonation_audit`, upgraded `apps/cp/src/pages/api/auth/stop-impersonate.ts` to stamp `impersonation_audit.ended_at` + revoke local session + restore stashed admin cookies, and wired `assertNotImpersonating(locals)` across `apps/cp/src/pages/api/me/identities.ts`, `apps/cp/src/pages/api/me/mfa.ts`, `apps/cp/src/pages/api/me/tokens.ts`, and `apps/cp/src/pages/api/client/billing-portal.ts`.
