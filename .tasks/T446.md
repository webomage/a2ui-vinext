# T446 — Estate file hygiene: every tracked file has a home, an owner and a reason, enforced

## Summary

The owner reviewed the repos visually on 2026-09-25 and found forgotten and badly organised files. Nothing in the
estate says where a kind of file belongs, so nothing can fail when one lands in the wrong place. The existing gates
each check one kind of file: `doc-format-check` (documents are Markdown), `emoji-check`, `suites-drift` (recipes)
and `discovery` (stack tools). None of them checks location or staleness.

Measured 2026-09-25: **0 untracked files in all 8 repos.** So the problem is in *tracked* files, and a
`git status` check would pass while the mess stays. Ignored entries: wom7web 1,696, root 88, wom7api 46, wom7ext 37
(mostly build output; each ignore pattern needs a reason too).

## Acceptance criteria

- [ ] AC1 — **Inventory.** A script lists every tracked file in all 8 repos with its directory class (source, test,
  spec, doc, report, config, asset, generated, vendored, scratch). Output goes to `docs/reports/` as Markdown. Files
  it cannot classify are listed by repo with counts, and this is the measured baseline.
- [ ] AC2 — **Layout policy.** `project/layout-policy.json` declares, per repo, which paths hold which class, plus
  the stale rules (e.g. a dated report older than N days with no ticket citing it). Each rule has a reason, like
  the doc-format and emoji policies.
- [ ] AC3 — **Triage the baseline.** Every unclassified or misplaced file is moved, deleted (after looking at it),
  adopted into a ticket, or waived with a reason. Nothing is deleted on a pattern match alone.
- [ ] AC4 — **Gate.** `just layout-check` fails on a new file outside its declared home. `just layout-check-test` has
  red probes: a misplaced file, an unclassified file, a stale dated report, a waiver with no reason. The check
  ratchets downward and runs in pre-push for every repo.
- [ ] AC5 — **Ignore patterns justified.** Every `.gitignore` pattern in the estate belongs to a declared class
  (build output, dependency cache, secret, local tool state). A pattern with no class is a finding.

## Definition of Done

- Quality gates clean (`just test`, `just lint`, `just typecheck`); new suites declared in
  `project/test-suites.json`.
- Committed referencing T446; TASKS.md row + ticket + GH issue in sync.
