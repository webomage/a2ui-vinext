# T653 — Consolidate `webomage.com` dynamic redirects within Cloudflare Free Tier 10-rule cap and add offline ruleset quota gate

## Summary

During the `T646` / `T648` production rollout (`just cf-apply` on `2026-11-05`), `5/6` Cloudflare changes applied cleanly (`retire_cf_worker_domains.py` detached `join.webomage.com` and `job.webomage.com`, destroyed `cloudflare_pages_domain.{join_webomage,job_webomage}`, created `cloudflare_record.{join,job}_redirect_edge`, and updated `cloudflare_ruleset.w0m_redirect` on `w0m.xyz`), while `cloudflare_ruleset.http_request_dynamic_redirect` on `webomage.com` (`Free Website` plan) failed server-side with:

`exceeded the maximum number of rules in the phase http_request_dynamic_redirect: 14 out of 10 (50001)`

Because Cloudflare enforces the `10`-rule Free-Tier phase quota server-side during `PUT /zones/{id}/rulesets/{id}` rather than during `terraform plan`, and `$CLOUDFLARE_API_TOKEN` is zone-scoped (`403` on account-level `/accounts/{id}/rules/lists` Bulk Redirects), `w0m-api/cloudflare/redirects.tf` must keep each zone's `http_request_dynamic_redirect` ruleset within `<= 10` rules (`AgDR-0055`), backed by an offline quota & Free-Tier expression check so `> 10` rules or Business-only regex operators never slip past pre-push / `session-complete` again.

## Acceptance criteria

- [x] **AC1 — Consolidate `cloudflare_ruleset.http_request_dynamic_redirect` from `14` to `9` rules (`<= 10` Free-Tier cap, `AgDR-0055`)**: Merged `www.webomage.com` + `beta.webomage.com` (`var.beta_redirect_enabled`) into one `https://webomage.com` rule, preserved single-hop edge rules for `job.webomage.com` `/o/* -> cp.webomage.com` and `job.webomage.com` `/ -> me.webomage.com/jobs`, and merged remaining `job.webomage.com`, `join.webomage.com` (with `/dashboard` and `/interview/:id` canonicalized pre-auth by `apps/me` `redirectStep`), and `webomage.com` (`/u/*`, `/wishlist/*`) into one `concat("https://me.webomage.com", http.request.uri.path)` rule (`9/10` total rules using only Free-Tier operators).
- [x] **AC2 — Offline Cloudflare Free-Tier Single Redirect quota & expression gate in `scripts/automation_health.py`**: Added `max_cf_single_redirect_rules_per_zone: 10` to `.w0m/sdlc.json -> automation_health` and implemented balanced-brace HCL ruleset auditing (`cf-free-tier-redirect-quota`) in `scripts/automation_health.py` failing closed on vacuous parsing, `> 10` `rules` blocks in any `http_request_dynamic_redirect` ruleset (verified RED against unmodified `14`-rule `redirects.tf` before fixing), or Business-only regex operators (`regex_replace(`, ` matches `), with `8/8` unit + RED-probe tests passing in `scripts/tests/test_automation_health.py`.
