## Summary

**Dev-tooling that silently doesn't run** — surfaced while upgrading deps 2026-07-20. (a) `pnpm lint` had been failing for a long time (13,413 problems on ESLint 9) and is in **no hook**; the config has since been fixed (`0096f567`, 13,635 → **9**), leaving 9 genuine pre-existing code issues in scripts (5 unused vars — several are destructured DB calls where only `error` is used, so the fix is `const { error } = …` not deletion; 3 useless regex escapes in `migrate_svelte.mjs`; 1 unused catch binding in `scripts/upheld-eval.mjs`). Fix those, then **wire `pnpm lint` into pre-commit** so it can't rot again. (b) `pnpm test` is broken: jsdom 29 requires `undici` internal handler *wrap-handler.js*, which the `undici: ">=7.28.0"` security override resolves away from — the runner aborts before collecting, and the suite is only 2 smoke specs. (c) `astro check` passes on **web** (the only gated app) but `join` = 12 errors and `job` = **104**, because their tsconfigs have no include/exclude boundary and reach into `../cp/src/**` and repo-root files.
