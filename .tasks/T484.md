# T484 — Fix contract promotion to CV and integrate personal resume library and CV script functions into CP Resume Studio

## Summary

Owner report & directive (2026-09-28):
1. Confirmed whether `/me/profile/work` is sourced from Upwork only (verified: 95/95 active profile contracts are from Upwork).
2. Reported failure on "Add to CV" button: `Failed to promote contract to CV` (HTTP 500).
   Root cause: `apps/cp/src/pages/api/profile/contracts/promote.ts` issues PostgREST `.upsert()` with `onConflict: "profile_id,source,source_id"`. In PostgreSQL, `idx_profile_experience_profile_source_source_id` was created with `WHERE (source_id IS NOT NULL)` (partial index). Postgres rejects `ON CONFLICT` when targeting a partial index without matching predicate, resulting in error `42P10`.
3. Requested: *"I want all my resumes and personal resume/cv scripts functions were available and tested in Resume studio"*.

This ticket:
1. Fixes `POST /api/profile/contracts/promote` to handle existing records cleanly and updates PostgreSQL constraint to allow standard upserts.
2. Ingests/seeds all of Aleksei's canonical resume/CV documents (12+ variants including `Private_Master`, `Public`, `Neo4j_Data_Engineer`, `Standard`, `Full`, etc.) into `public.profile_resumes`.
3. Integrates personal CV script capabilities (`cv_claims`, `cv_public` sanitization, role & tech synthesis, template gallery) into Resume Studio (`/me/profile/resume`).
4. Adds automated unit, component, and verification tests.

## Acceptance criteria

- [x] AC1 — Fix `POST /api/profile/contracts/promote`: replace unmatchable partial index upsert with resilient record check / update / insert, and add non-partial unique constraint on `(profile_id, source, source_id)`.
- [x] AC2 — Ingest & seed all canonical resume variants (both Markdown and PDF) into `public.profile_resumes` and ensure they appear in Resume Studio's Document Vault.
- [x] AC3 — Wire "Promoted Work History" and "Extracted Facts" seamlessly into Resume Studio's facts base and role/tech synthesis engine.
- [x] AC4 — Add privacy mode toggle (Full / Masked / Public) to Resume Studio aligned with `cv_public.py` conventions.
- [x] AC5 — Provide test coverage: Vitest tests for `promote.ts`, component tests for `ResumeStudio.svelte`, and verification that "Add to CV" promotes contracts without error.
