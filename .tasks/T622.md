# T622 — Essential stdout-filtering, shell-inspection, and multi-harness CLIs (`rg`, `fd`, `yq`, `bat`, `sqlite3`, `tree`, `ruff`, `curl`, `gpg`, `htmlq`, `mlr`, `sd`, `fzf`, `shellcheck`, `pdftotext`, `code-review-graph`) are misclassified in `out_of_scope` or ungoverned while `tool_usage_probe` misses YAML hook `entry:` commands

## Summary

Auditing why missing `rg`, `yq`, and related stdout/stream filters escaped `just preflight` and `just tools-check` on Linux (`aleksei@HP`) exposed four toolchain-governance gaps across `project/policies/tools-policy.json`, `scripts/tool_usage_probe.py`, and `scripts/tools_check.py`:
1. **Multi-harness search & stdout-filtering CLIs wrongly parked in `out_of_scope`**: `T164` excluded `rg`, `fd`, `yq`, `bat`, `sqlite3`, and `tree` into `out_of_scope` because static `justfile`/script probes did not see interactive agent pipelines (`| rg`, `| yq`, `fd`, `bat -r`, `sqlite3`, `tree -L 2`) and assumed every agent harness bundles its own `ripgrep`/globber. Antigravity CLI (`agy`) on Linux uses shell `run_command` and ships neither `rg` nor `fd`, while `yq`, `bat`, and `fd` were completely missing from the workstation and `/usr/bin/jq` sat on stale Ubuntu `1.6` instead of Homebrew `1.8.2`.
2. **YAML `entry:` / `bash -c` parser blind spot in `scripts/tool_usage_probe.py` (`ruff` false `0`)**: `SHELL_PREFIX` (`line 100`) scanned `.yml`/`.yaml` files without matching YAML `entry:` or `bash -c`, causing `tool_usage_probe.py` to report `ruff uses=0` and leave `ruff` in `out_of_scope` (*"not wired into any recipe or hook"*) while `w0m-sec/.pre-commit-config.yaml` actively runs `entry: ruff check` (`language: system`) on every commit.
3. **Essential workflow & structured stdout-filtering CLIs absent from `tools-policy.json` & `tool_usage_probe.py`**:
   - Core workflow CLIs: `curl` (`14` estate HTTP probe invocations + `3` skills), `gpg` (`gnupg` — required by `AGENTS.md` for `-S` GPG-signed fork commits), `pdftotext` (`poppler` — invoked twice in `w0m-web/project/scripts/cv_public.py`), and `code-review-graph` (`3` invocations in `justfile:513,524,533`).
   - Structured stdout/stream filters & shell analyzers: `htmlq` (CSS-selector HTML stdout filter), `mlr` (`miller` — CSV/TSV/JSON/JSONL stdout query/filter), `sd` (cross-OS regex stream replacement avoiding BSD vs GNU `sed -i` traps), `fzf` (`--filter` non-interactive stdout ranker), and `shellcheck` (shell/hook static analyzer).
4. **Below-floor system binaries shadowing missing Linuxbrew installs on `aleksei@HP`**: `/usr/bin/git` (`2.34.1 < min 2.39.0`) failed `tools_check.py`, and `/usr/bin/jq` (`1.6 != known_good 1.8.2`) drifted because neither formula was installed in Linuxbrew yet.
