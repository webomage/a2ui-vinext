# T467 — Blueprint-driven project creation: tech chips sets, commercial archetypes, and automated derivation of hats, skills, and MCP bundles

## Summary

In w0m's commercial delivery model, creating a project in CP must not be a bare name/description form. Instead, project creation bridges commercial offerings to autonomous execution. When creating a project, the creator selects a commercial archetype or architectural blueprint template (`externally_managed`, `bug_bounty`, `test_plan`, `consultation`, `fast_extended_audit`). The template configures a Tech Chips set (e.g. `flutter:mobile`, `astro:ssr`, `supabase:postgres`), which deterministically derives the engagement hat collection ([[T461]] / [[AgDR-0028]]), the agent skills manifest (`.w0m/skills.json`), and the sandboxed MCP servers bundle.

## Acceptance criteria

- [ ] AC1 — Commercial Archetypes & Tech Chips Matrix: Define the formal schema and catalogue for the 5 commercial archetypes (`externally_managed`, `bug_bounty`, `test_plan`, `consultation`, `fast_extended_audit`) with their default tech chips sets in `wom7web/src/data/project-archetypes.json` and TypeScript typings.
- [ ] AC2 — Template Derivation Engine: Implement helper `deriveProjectConfiguration(archetypeId, techChips)` that returns the associated hat collection template, required agent skills list, and MCP servers bundle.
- [ ] AC3 — CP Project Creation Wizard: Update `ProjectManager.svelte` to support the 4-step blueprint creation flow: Archetype selection, Tech Chips profiler, Derivation preview (hats/skills/MCP), and Instantiation.
- [ ] AC4 — API Endpoint & Storage: Update `/api/project` creation endpoint to accept `archetype_id`, `tech_chips`, `skills`, and `mcp_servers` in project metadata and initialize the project record.
- [ ] AC5 — Automated Verification Suite: Provide automated unit and regression tests verifying archetype validation, chip-to-configuration derivation, and CP creation payload parsing (`just project-archetypes-test`).
- [ ] AC6 — Spec & Governance Alignment: OpenSpec change `2026-09-27-blueprint-project-creation-matrix` documented, validated, and registered in `test-suites.json`.

## Definition of Done

T467 is done when a project created in CP can be instantiated from any of the 5 commercial archetypes or architectural blueprints, automatically generating its tech chips set, hat collection, skills manifest, and MCP server configuration, validated by automated test suites.
