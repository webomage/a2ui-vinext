# T188 — type-check the Python that implements every gate

## Summary

**145 tracked Python files have no type checker and no linter, and they are the files that
implement the estate's gates.** `wom7web/project/scripts/` alone is 62 of them — `hooks_check.py`,
`discovery.py`, `state_doctor.py`, `graph_health.py`, `repo_hygiene.py`, `w0m_audit.py`,
`preflight.py`. Every other stack's checks are enforced *by* this code, and nothing enforces it.

🔑 **The annotations already exist — 59 of 62 scripts use them.** So this is not "add typing to
untyped code"; it is *"a contract is written down and nothing verifies it"*. A wrong annotation is
currently invisible, which is the weakest possible state: it reads as rigour and provides none.

⚠️ **Not a greenfield claim — say what Python DOES have**, or this ticket overstates its own case:
`semgrep` covers `.py` at pre-commit (`files: \.(js|jsx|ts|tsx|py|json)$`) and `sg-scan` carries one
Python ratchet (`python-subprocess-shell-true`, from [[T166]]). ⇒ Python has **SAST**. It has **no
type check and no lint**. This ticket is only the first of those.

## 🔴 Why no existing gate can reach this — it is structural, not overlooked

**132 of the 145 Python files live in stacks declared `runtime: node`.**

| stack | runtime | `.py` files |
|---|---|---|
| `web` (wom7web), `worker` (wom7api), `ext` (wom7ext) | **node** | **132** |
| `mlx` (wom7mlx) | rust | 10 |
| `sec` (wom7sec) | **python** | **3** — and [[T135]] measured this repo at *zero source files*, so a gate there passes vacuously |

[[T135]] AC2 established the right rule — *checks must match the stack* — and retired `ruff` from
`wom7skills` (TypeScript) and `wom7mlx` (Rust) as **wrong-stack linters**: *"a vacuous gate that
reads as coverage on the matrix while checking nothing in the repo's actual language."*

⇒ **That rule cannot fire here, because the estate's tooling language is not a stack.** The only
`runtime: python` entry is the one repo with no Python worth checking. This is [[D37]]'s shape —
*a check that appears to have looked* — one level up: `discovery` and `hooks-check` are structurally
incapable of reporting the gap, so their green says nothing about it.

⚠️ **This does NOT reverse the ruff decision.** T135 retired ruff where the stack was not Python and
states explicitly that *"it is Python, so `ruff` is correct there"*. Applying a Python tool to Python
is the decision, not a reversal of it.
