## Summary

**Design System — unify shared components into `@webomage/ui`** (T42 phase 3, the bulk). Promote the 7 DS-specced brand/domain components (BlueprintCard, SegmentBadge, ComplexityBadge, TechIcon, GlassCard, StatusDot, QuickViewModal) into `@webomage/ui` as **Svelte** (JSX specs → Svelte port); dedup the byte-identical `Footer.astro` + `apps/cp/src/components/ui/Card.astro` and the forked `Header.astro`/`ChatApp.svelte`/badges; migrate all four apps off per-app forks; run `design-system/_ref/migration/codemod.mjs` to kill the ~175 `#0a84ff` + macOS-system hex in CP; wire the per-app `[data-app]` theme mechanism. Pairs with T87 (identity surface) — the same dedup pass retires `RoleSwitcher.svelte`.

## Acceptance criteria

- [ ] AC1 — Port and promote 7 brand/domain components into `@webomage/ui`: Implement and export `BlueprintCard`, `SegmentBadge`, `ComplexityBadge`, `TechIcon`, `GlassCard`, `StatusDot`, and `QuickViewModal` in `@webomage/ui` as Svelte components conforming to `design-system/` specs.
- [ ] AC2 — De-duplicate identical and forked shared components: Consolidate byte-identical `Footer.astro` and `apps/cp/src/components/ui/Card.astro` as well as forked components (`Header.astro`, `ChatApp.svelte`, badges) into `@webomage/ui`, replacing per-app copies in `apps/web` and `apps/cp`.
- [ ] AC3 — Retire duplicate `RoleSwitcher.svelte`: Remove `RoleSwitcher.svelte` from `apps/cp`, standardizing all hat and role switching onto the unified identity surface (`AuthWidget.svelte` / sidebar hat switcher).
- [ ] AC4 — Execute `#0a84ff` brand token codemod on CP: Run `design-system/_ref/migration/codemod.mjs` across `apps/cp/src` to convert hardcoded `#0a84ff` and `#007aff` references to design-system CSS tokens (`--brand-color`, `--brand-hover`).
- [ ] AC5 — Wire per-app `[data-app]` theme attribute: Ensure `[data-app]` (`web`, `cp`, `join`, `job`) is configured on `<html>` in root layouts across all four applications to bind theme tokens consistently.
- [ ] AC6 — Verification of unified components in all four apps: Verify in a real browser session that all four applications compile, typecheck, and render without regression using `@webomage/ui` components and unified tokens.

## Definition of Done

T92 is done when: `@webomage/ui` exports Svelte ports of all 7 brand/domain components
(BlueprintCard, SegmentBadge, ComplexityBadge, TechIcon, GlassCard, StatusDot,
QuickViewModal), the byte-identical `Footer.astro`/`Card.astro` pair and the forked
`Header.astro`/`ChatApp.svelte`/badges exist in exactly one place each, `RoleSwitcher.svelte`
is deleted from `apps/cp`, the `#0a84ff`/`#007aff` codemod has run against `apps/cp/src`
leaving zero hardcoded brand hex, `[data-app]` is set on `<html>` in all four apps' root
layouts, and all four typecheck and render without regression in a real browser session.
