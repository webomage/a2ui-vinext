# T548 — STATE.md links point into whichever agent tree generated it

## Summary

`just state-save` writes every ticket link in the `STATE.md` ranked table as an absolute path under the generating tree's root. Measured 2026-10-06: the `STATE.md` committed on `beta` has 20 links of the form `/Users/proto/.w0m/work/agy/w0m/.tasks/T468.md` and none under the live root; regenerated from another agent tree the same links become `/Users/proto/.w0m/work/<that tree>/w0m/.tasks/...`. A tree is removed after it lands (AgDR-0032), so the links in a committed `STATE.md` are dead as soon as the generating tree goes. `TASKS.md` has no such links (0 tree links, 0 live links on `beta`), so the defect is `STATE.md`'s alone.

The `w0m-tasks` skill asks for the ABSOLUTE ticket path "exactly as the tool prints it" because a relative path from the `@wom` umbrella resolves to nothing; an absolute path under a tree that no longer exists does the same.

## Acceptance criteria

- [ ] AC1 — **Decide the link form**, with the reason recorded: absolute under the LIVE root (`/Users/proto/Projects/@self/@wom/.tasks/T468.md`, what the owner opens), or `wom7web/`-style paths relative to the umbrella as the skill's own fallback allows. Not the generating tree.
- [ ] AC2 — **Fix the generator, test first.** A test generates the block from a path that is not the live root (an agent-tree-shaped temp path) and asserts no `.w0m/work/` appears in any link; a mutation that reintroduces `ROOT` as the link base is caught. `state-check` stays consistent across trees (it must not start failing a push from a tree other than the one that last generated).
- [ ] AC3 — **Regenerate once** in a complete tree and commit; the 20 existing links resolve.
