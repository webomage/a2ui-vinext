# T345 — w0m-prs: GitHub PR discovery, health monitoring, and audit reporting tool

## Summary

Owner ask, 2026-09-12: *"let's announce this script as w0m dev tool in w0m eco"*.

During active PR alignment and upstream contributions across `wom7open` (`stablyai/orca#16597` and `openai/tart-guest-agent#62`) and author portfolio discovery for `@casualuser` (42 public PRs across 21 repositories), an ad-hoc set of Python/gh scripts and cron pollers proved critical for discovering PR states, detecting merge conflicts, monitoring review decisions, and generating publication-quality markdown reports with Mermaid graphs.

Today, there is no canonical w0m developer tool for querying, tracking, or auditing external and internal GitHub pull requests. Tracking PRs currently requires one-off shell invocations or manual browser inspection. Furthermore, as the w0m estate expands upstream collaborations in `wom7open`, maintaining active health, conflict detection, review queues, and CI pass rates across repos demands a standardized, scriptable tool integrated directly into the `justfile` and agent skills system.

This ticket formalizes and packages the capability into `w0m-prs`: a canonical w0m dev tool and agent skill.

## Acceptance criteria

- [x] AC1 — Canonical CLI script `w0m_prs.py` created under `wom7web/project/scripts/` with subcommands: `search`, `audit`, `watch`, and `report`.
- [x] AC2 — Multi-mode ingestion: queries PRs by `--author <username>`, `--repo <owner/repo>`, or preset `--preset wom7open` (defaulting to the estate's open-source dependencies in `wom7open/orca` and `wom7open/tart-guest-agent`).
- [x] AC3 — Deep health and mergeability audit: extracts merge status (`MERGEABLE`, `CONFLICTING`), review decisions (`REVIEW_REQUIRED`, `CHANGES_REQUESTED`, `APPROVED`), review thread counts, unaddressed bot findings, and stale inactivity flags.
- [x] AC4 — Autonomous watch loop: configurable background polling (`--interval <mins>`, `--duration <mins>`, `--notify`) reporting delta events (review submission, merge status change, CI pass/fail) without busy-waiting.
- [x] AC5 — Structured report generator with validated Mermaid visualizations: outputs comprehensive markdown portfolio reports containing `flowchart TD` lifecycle topology, `xychart-beta` volume bars, and `flowchart LR` timeline phases, fully conforming to headless `mmd-validate` gates.
- [x] AC6 — `justfile` and `wom7skills` integration: exposes root and web recipes (`just prs [search|audit|watch|report]`), `just prs-test` test runner, and registers the `w0m-prs` skill in `wom7skills/skills/` for agent pairing.
