# T219 — wom7ext ↔ ZeroClaw realignment

> **Owner ask, 2026-08-15.** *"It looks like we should realign w0m ext to ZeroClaw integration for
> real"* and *"research if with ZeroClaw we can drop mcp-b."*

## Summary — the research reverses both halves of the question

Measured 2026-08-15 against the running system, not inferred.

**① "Can ZeroClaw replace mcp-b?" — No. ZeroClaw has no MCP surface at all.**
`zeroclaw --help` exposes `agent · gateway · **acp** · daemon · cron · integrations · skills` — and
**no `mcp` command anywhere**, including under `gateway` (whose own help says *"HTTP/WebSocket
gateway that accepts incoming webhook events and WebSocket connections"* — its own protocol, not
MCP). It speaks **ACP** (Agent Client Protocol, JSON-RPC 2.0 over stdio), which is a *different
protocol*, not an MCP transport. It therefore cannot host the extension's MCP tool surface.

**② "Can we drop mcp-b?" — Already done in code; only vestigial deps remain.**
`@mcp-b/extension-tools` and `@mcp-b/global` are declared in `extension/package.json` and
**imported nowhere** (grep across all `.ts`/`.js` outside `node_modules`/`dist`: zero import sites).
`mcpService.ts` builds on the **official** `@modelcontextprotocol/sdk` — `McpServer` from
`server/mcp.js`, `WebSocketClientTransport` from `client/websocket.js`. So the answer is not "we
could drop it" but "**we already did, and forgot to remove the dependencies**."

**③ The bridge host repo is missing.** `EXTENSION_UPDATES.md` records the `:8008` bridge as
`@mcp-b/websocket-bridge` *"in `wom7mcp`"* — and **there is no `wom7mcp` directory in the
workspace**. Neither `:8008` nor the ZeroClaw gateway (`:42617`) was responding when measured.

**④ The ZeroClaw migration already happened — and is honest about being incomplete.**
`agentBridge.ts` was migrated off OpenClaw **2026-08-10**, with the differences *verified against a
running gateway*: port `42617` not `3773`; no `POST /chat` (WebSocket upgrade on `/ws/chat`);
`/api/sessions` not `/sessions`; every `/api` route authenticated; a single `w0m` alias where
OpenClaw had four. **What is unbuilt is PAIRING** (tracked by [[T153]]/[[T154]]): without a bearer
token `zeroclaw_agent_ask` *"reports the gap instead of guessing a WebSocket envelope that was never
verified against a paired gateway."* ⇒ **"Realign for real" = finish pairing**, not re-point a bridge
that is already pointed correctly.

**The two ports do opposite jobs and are not substitutes:**

| | `ws:8008` (mcp-b bridge) | `127.0.0.1:42617` (ZeroClaw) |
|---|---|---|
| Direction | agents → **wom7ext's tools** | wom7ext → **ask an agent** |
| Extension's role | MCP **server** | gateway **client** |
| Protocol | MCP over WebSocket | ZeroClaw's own HTTP/WS (+ACP) |
