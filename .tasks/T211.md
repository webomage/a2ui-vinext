# T211 — Package wom7skills as Universal Claude Plugin & Cross-Client Validation Suite

## Summary

Owner requirement, 2026-08-14: *"make our wom7skills to be packaged as Claude Plugin and then tested in all mentioned apps (Claude App, Claude Code, Antigravity, OpenCode)"*.

Currently, `wom7skills` is managed as a standalone skill repository with partial plugin manifests. To achieve true cross-client universality, `wom7skills` must be packaged with full compliance for the official Claude Plugin specification, exportable for Claude Desktop/App (via MCP/WebMCP bridges), natively consumable by Claude Code CLI, governed within Antigravity (AGY) plugin architecture, and loadable by OpenCode agents.

---

## Problem Statement & Ecosystem Gaps

1. **Fragmented Client Loading Models**:
   - **Claude App (Desktop/Web)**: Cannot read local `.agents/skills/` directly without an MCP tool server or project knowledge.
   - **Claude Code (CLI)**: Reads `.claude/skills/` symlinks.
   - **Antigravity (AGY)**: Reads plugin definitions from `~/.gemini/config/plugins/wom7skills-plugin/` and `.agents/skills/`.
   - **OpenCode**: Reads from `.opencode/` or workspace instruction registries.
2. **Missing Canonical Plugin Packaging**:
   - `wom7skills` needs standard plugin metadata (`.claude-plugin/plugin.json`, `manifest.json`), typed skill schemas, and automated installation scripts for every client runtime.
3. **Absence of Unified Cross-Client Integration Test Matrix**:
   - No automated test suite currently verifies that all 33+ skills parse, load, and execute identically across all 4 host environments.

---

## Requirements & Acceptance Criteria (ACs)

- [ ] **AC1 (Claude Plugin Packaging & Schema Standard)**:
  Package `wom7skills` with standard Claude plugin packaging (`.claude-plugin/plugin.json`, MCP server entrypoints, tools declarations, and skill registries conforming to Anthropic & MCP standards).
- [ ] **AC2 (Claude App / Desktop MCP Bridge)**:
  Provide a standardized MCP server connector (`wom7skills-mcp`) allowing Claude Desktop and Claude Web App (via WebMCP/Claude Projects) to dynamically list, search, and invoke w0m SDLC and persona skills.
- [ ] **AC3 (Claude Code CLI Direct Integration)**:
  Ensure zero-config installation for Claude Code via `pnpm plugin:install` or `.claude/skills/` automated two-layer symlinking without manual intervention.
- [ ] **AC4 (Antigravity IDE Plugin Registry Parity)**:
  Validate and automate sync between `wom7skills` and Antigravity plugin location (`~/.gemini/config/plugins/wom7skills-plugin/skills/`) with zero drift (`just skill-check`).
- [ ] **AC5 (OpenCode Compatibility Layer)**:
  Provide configuration and loaders for OpenCode environments (`.opencode/skills/` or prompt-injected tool descriptors).
- [ ] **AC6 (Cross-Client Automated Verification Test Suite)**:
  Build automated integration tests that mock/probe skill discovery and tool execution across all 4 targets:
  - Claude App (MCP JSON-RPC discovery)
  - Claude Code (`.claude/skills` discovery & parsing)
  - Antigravity (AGY plugin loader & schema check)
  - OpenCode (agent runner & prompt context generation)
- [ ] **AC7 (Documentation & Quickstart Guide)**:
  Publish `docs/tooling/CLAUDE-PLUGIN-GUIDE.md` detailing single-command install, update, and verification procedures for developers using any of the 4 clients.
