# T529 — Org model S8: retire public.clients and client_users

## Summary

Split from [[T458]] AC7 (step S8 in T458 design / [[AgDR-0027]] / [[AgDR-0028]]).
Retire legacy `public.clients` and `public.client_users` tables. Replace them with:
1. Company details record keyed by `org_id` in `orgs` / `org_profiles`;
2. `client_users` membership replaced by `client` hats on engagements;
3. 7 foreign keys currently referencing `clients(id)` migrated cleanly to `orgs(id)` (`contracts`, `invoices`, `leads`, `projects`, `project_vaults`, `synced_vacancies`, `client_milestones`);
4. Update Edge Functions (`client-api`, `client-register`, `stripe-portal`) and CP routes.

## Acceptance criteria

- [x] AC1 — Migrate 7 foreign keys (`contracts.client_id`, `invoices.client_id`, `leads.client_id`, `projects.client_id`, `project_vaults.client_id`, `synced_vacancies.client_id`, `client_milestones.contract_id -> contracts`) from `clients(id)` to `orgs(id)`.
- [x] AC2 — Replace `client_users` memberships with client-side hats on engagements (`<contractor>.<engagement>.<client>`).
- [x] AC3 — Move company-specific CRM/metadata fields from `clients` to `orgs` or an `org_profiles` extension table.
- [x] AC4 — Update Edge Functions (`client-api`, `client-register`, `stripe-portal`) to query `orgs` and engagement client hats rather than `clients` and `client_users`.
- [x] AC5 — Deprecate and drop `public.clients` and `public.client_users` tables via migration with verify recipe `just clients-retirement-verify`.
- [x] AC6 — Update all RLS policies referencing `client_users` or `clients` to fail closed against the new engagement/org model.
