# T732 — Pass Explicit `--type=shared` on Infisical CLI Secret Delete & Restore Operations (`env_prune_dead.py` & `rotate_leaked_secrets.py`)

## Summary

Fixes the asymmetric Infisical CLI `0.44.x` flag default where `infisical secrets set` defaults `--type` to `"shared"` while `infisical secrets delete` defaults `--type` to `"personal"` (`404 Not Found` on workspace-shared secrets). Updates `scripts/env_prune_dead.py` (batch `infisical secrets delete ... --type=shared --silent` + `--type=shared` on `--restore-backup`) and `w0m-api/scripts/rotate_leaked_secrets.py` (`--type=shared` on `--prune-dead` and `--rotate-tier`).

Split from: [[T731]]

## Acceptance criteria

- [x] AC1 — **Explicit `--type=shared` & Batched Delete in `scripts/env_prune_dead.py`:** Pass `--type=shared` and `--silent` to batched `infisical secrets delete` and `infisical secrets set` in `scripts/env_prune_dead.py`, verified by `scripts/tests/test_env_prune_dead.py`.
- [x] AC2 — **Explicit `--type=shared` in `w0m-api/scripts/rotate_leaked_secrets.py`:** Pass `--type=shared` and `--silent` in `prune_dead_leaked_secrets` and `rotate_tier_in_infisical`, verified by `w0m-api/scripts/tests/test_rotate_leaked_secrets.py`.
- [x] AC3 — **Record Infisical `set` vs `delete` `--type` Asymmetry Rule in `LESSONS.md`:** Document the `infisical secrets delete` `--type=personal` default trap in `@wom/LESSONS.md` and pass `lessons_check.py`.
