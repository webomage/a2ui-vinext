# T389 — Modernize ticket template: adopt kebab-case epic slugs, declare managed x_* keys, and align DoD

## Summary

Owner directive: *"it looks like we have to alter tickets template and start using it"*.

The ticket template `project/templates/ticket.md` defines the schema of record for all tickets in the w0m ecosystem (read by `project/scripts/ticket_schema_check.py` via `template_keys()` and `optional_keys()`). It currently exhibits three major deficiencies:
1. **Outdated Epic references**: It still cites the retired verbose `# e.g. "ROADMAP §13.6 — ..."` and `- **Epic:** [[ROADMAP]] §—` format instead of canonical kebab-case epic slugs (e.g. `platform-health-tooling`) established in T380.
2. **Missing `# OPTIONAL` declarations for managed `x_*` frontmatter keys**: 388 tickets carry computed/synced keys (`x_ac_done`, `x_ac_total`, `x_ac_pct`, `x_hot_score`, `x_blocked_by`, `x_synced`) injected by tooling (`tasks_query.py`, `tickets_frontmatter_sync.py`, `sync_github.py`). Because `project/templates/ticket.md` does not declare them with `# OPTIONAL <key>:`, `ticket_schema_check.py` reports 2,328 warnings of template drift.
3. **Outdated Definition of Done pattern**: The template's generic boilerplate DoD cites unconditioned clauses (D38) rather than domain-verifiable acceptance criteria.

This ticket modernizes `project/templates/ticket.md`, documents canonical epic slugs and managed keys, updates the Definition of Done boilerplate to be verifiable, and verifies that `just ticket-schema-check` drops 2,328 template drift warnings.

## Acceptance criteria

- [x] AC1 — **Kebab-Case Epic Slugs in Template**: Update `epic:` frontmatter comment and `## Links` section in `project/templates/ticket.md` to specify canonical kebab-case epic slugs from `project/tickets-schema.jsonc` (e.g. `"platform-health-tooling"`).
- [x] AC2 — **Declare Managed `x_*` Frontmatter Keys**: Add `# OPTIONAL x_ac_done:`, `# OPTIONAL x_ac_total:`, `# OPTIONAL x_ac_pct:`, `# OPTIONAL x_hot_score:`, `# OPTIONAL x_blocked_by:`, and `# OPTIONAL x_synced:` to `project/templates/ticket.md` frontmatter with clear documentation of which tool populates them.
- [x] AC3 — **Modernize Definition of Done in Template**: Revise `## Definition of Done` in `project/templates/ticket.md` to provide a clear, domain-specific, verifiable template structure per `SPEC-AUTHORING-STANDARD.md`.
- [x] AC4 — **Verify Ticket Schema Gate**: Run `python3 project/scripts/ticket_schema_check.py` (and `just ticket-schema-check`) and confirm that all 2,328 warnings regarding missing `x_*` template keys are eliminated.
- [x] AC5 — **Validate Ticket Authoring Flow**: Verify that new tickets created from the template pass `ticket_schema_check.py` with zero template drift errors or warnings.
