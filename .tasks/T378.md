# T378 — w0m User Control Panel: Developer Forks and Upstream PRs Management Tool

## Summary

Owner directive, 2026-09-18: *"and also we have to have these feature in w0m user cp as a tool for developers"*, following PRs/forks registry management CLI helpers.

The w0m estate maintains external open-source forks and PRs under `wom7pr/` (`omlx`, `headroom`, `orca`, `tart`, `tart-guest-agent`, `claude-obsidian`). While terminal users have `just forks` and `just prs-open`, developers and managers utilizing the w0m Control Panel (`apps/cp`) require a dedicated visual Developer Tool interface to:
1. View real-time synchronization health across all managed forks (upstream lag, unpushed commits, dirty worktree files).
2. Trigger remote fetches and fast-forward updates directly from the UI or copy one-click CLI pickup commands.
3. Inspect detailed fork diffs, commit logs ahead/behind upstream, and branch configurations.
4. Browse open upstream PRs across preset repositories.
