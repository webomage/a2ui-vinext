# T500 — `w0m-` prefix for every agent; one name per thing

## Summary

Owner (2026-09-30): "let's make our agents w0m- prefixed", after asking whether `agent-architect` and `w0m-architect` are the same. They are not. Measured 2026-09-30 on the live registry, each role has THREE things sharing one stem:

| Role | Edge function (URL) | Persona (`ai_personas.name`) | Model alias (`ai_models.id`) |
|---|---|---|---|
| architect | `agent-architect` | `agent-architect` (model column = `w0m-architect`) | `w0m-architect` -> cloudflare llama-3.3-70b-instruct-fp8-fast, fallback llama-4-scout |
| consultant | `agent-consultant` | `agent-consultant` (model = `w0m-consultant`) | `w0m-consultant` -> mistral-small-3.1-24b, fallback llama-3.1-8b |
| admin | `chat-internal` (persona resolved in `chat-core.ts:324`) | `agent-admin` (model = `w0m-admin`) | `w0m-admin` -> llama-3.3-70b |

Renaming the personas to `w0m-<role>` alone would make the persona name equal the alias name in two tables: exactly the confusion the owner just hit. So the scheme is: **agents (personas and their functions) = `w0m-<role>`; model aliases = `w0m-llm-<role>`; `w0m-embed` (embedding) stays.**
