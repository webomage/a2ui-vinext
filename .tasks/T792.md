# T792 — Universal independent Mermaid diagram component for @webomage/ui across all portals

## Why

Mermaid diagrams in Knowledge Hub and across portals render as raw markdown/code blocks because client-side Mermaid rendering is not hooked up. Need a universal, independent @webomage/ui Mermaid component that dynamically renders diagrams with honest error degradation and zoom/controls across CP, web, and client portals.

## Scope

- **In:**
  - Universal Svelte 5 component (`MermaidViewer` / `Mermaid`) in `@webomage/ui` with dynamic `import("mermaid")` (zero SSR penalty, zero bundle bloat on non-diagram pages).
  - Universal DOM action (`mermaidHydrate`) and container scanner (`hydrateMermaidInContainer`) with `MutationObserver` for seamless hydration of dynamic markdown/vault figures.
  - Fail-closed honest error degradation (AgDR-0025, T284 AC4) displaying friendly error callouts and raw source when diagrams are malformed.
  - Interactive toolbar with zoom in/out, reset, copy code, download SVG, and toggle raw code drawer.
  - Wiring `mermaidHydrate` into `KnowledgeHub.svelte` so all roadmap, architecture, and vault diagrams render as interactive SVGs.
  - Full Vitest unit test suite covering diagram type detection, valid flowchart rendering, honest degradation, and DOM hydration.
- **Out:**
  - Modifying backend vault parsing rules or altering Markdown generator AST contracts.

## Acceptance Criteria

- [x] **AC1:** Shared Mermaid component in @webomage/ui: Create a universal Svelte 5 component (e.g. MermaidDiagram / MermaidViewer) in packages/ui with dynamic import of mermaid, dark-first styling, zoom/pan controls, and copy/expand.
- [x] **AC2:** Container hydration & action helper: Support standalone code props as well as automatic container hydration for pre-rendered Obsidian/Markdown figures (figure.mermaid-diagram pre.mermaid).
- [x] **AC3:** Knowledge Hub integration: Wire the universal component/action into KnowledgeHub.svelte in apps/cp so vault roadmap and architecture diagrams render as interactive SVGs.
- [x] **AC4:** Multi-portal verification: Verify rendering across CP knowledge hub and ensure clean fallback/honest degradation when Mermaid syntax is malformed.
- [x] **AC5:** Test suite & bundle efficiency: Ensure dynamic import prevents SSR breakage and bundle bloat, with unit tests covering valid rendering and syntax degradation.
