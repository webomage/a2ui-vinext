# T715 — Client Portal (`apps/cp`) Onboarding Wizard & Project Settings: Selectable SDD Spec Dialect (`GitHub Spec Kit`, `OpenGSD`, `OpenSpec`, `Webomage SDLC`)

## Summary

Expose a **Spec-Driven Development (SDD) Methodology & Dialect Selector** inside the Client Portal Onboarding Service Wizard (`T703`) and Project Settings (`apps/cp`) so clients can select **`GitHub Spec Kit (.specify/)`**, **`OpenGSD Phase Loop (.planning/)`**, **`OpenSpec Delta (openspec/)`**, or **`Webomage Full SDLC`**, persist the preference in `orgs.service_usage.onboarding_service_wizard` and project metadata, and render normalized spec/phase progress in the Client Portal dashboard.

Split from: [[T712]]

## Acceptance criteria

- [x] AC1 — **SDD Dialect Catalog & Recommendation Engine (`packages/lib/src/security/order-form-state.ts`):** Added `CLIENT_SDD_DIALECT_CATALOG` (`openspec`, `github-speckit`, `open-gsd`, `w0m-openspec`), `recommendClientSpecDialect`, `normalizeClientSddDialect`, `getClientSddDialectMeta`, and `computeNormalizedSpecProgress`, wired end-to-end through onboarding wizard query/order state helpers.
- [x] AC2 — **Onboarding Service Wizard & Project Settings UI (`apps/cp`):** Added SDD dialect selectors in `ClientDashboard.svelte` (`cp-wizard-sdd-dialect-selector`, `cp-project-settings-sdd-dialect`), `ProjectManager.svelte` (`project-sdd-dialect-select`), and `apps/cp/src/pages/api/client/security-audit.ts` (`save_sdd_dialect` + `onboarding_service_wizard` persistence) using 100% `@webomage/ui` primitives (`0` ticket leaks, `ds-conformance` improved).
