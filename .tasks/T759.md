# T759 — Make the OpenDesign import of the Webomage design system render at full fidelity

## Summary

The 2026-11-16 local import of `w0m-web/design-system` into OpenDesign
(`w0m-pr/open-design`, local sidecar on 127.0.0.1:7456) produced a starved kit:
`user:webomage` shows Identity + a serif Typography specimen + "No logo yet", and NO
Palette section. Root causes, all measured on 2026-11-16:

1. **Palette missing** — `apps/daemon/src/design-systems/import.ts`
   (`renderDesignMd`) synthesizes the record's DESIGN.md with `Visual Tokens` as
   `var()` references (e.g. `` `--color-bg: var(--bg)` ``); zero hexes. The UI fills
   Palette from `parseDesignMd`'s `color`/`palette` section (table rows
   `| role | name | hex | usage |` / bullets `- **Name:** \`#hex\`` / frontmatter
   `colors:` map), falling back to the record's `swatches` — `[]`
   (`apps/web/src/runtime/design-md-parse.ts:123-201,401-402`;
   `apps/web/src/runtime/design-kit.ts:511-522`;
   `apps/daemon/src/design-systems/index.ts:362-447,4276`).
   The repo's own `design-tokens.json` (56 concrete hex tokens) is ignored by the scan.
2. **Logo "No logo yet"** — the import copies `assets/logo/logo.svg` into the bundle
   (`.od/design-systems/webomage/assets/`), but `parsedToKit` hardcodes
   `logoSrc: null` for non-brand kits (`design-kit.ts:577-578`), so the copied asset is
   never wired to the logo chain.
3. **Type specimens render serif** — the bundle has 9 woff2 files but no
   `fonts/manifest.json`; `useBrandFonts` only injects `@font-face` from a PROJECT
   `fonts/manifest.json` (`DesignKitView.tsx:154-231`), so DS-bundle fonts never load
   and specimens fall back to Times. (Serving itself is fine once the right URL is
   used: `/api/design-systems/:id/static?path=...` sets a real content-type.)

Fix in two halves: (a) estate-side — make the package import-ready (parse-friendly
color identity + package.json identity); (b) upstream fork (`nexu-io/open-design`)
— make the local importer emit hex-backed palette data + `fonts/manifest.json`, and
let non-brand kits resolve logo + `@font-face` from the bundle. PR prepared via
`scripts/w0m_prs.py` rules for `nexu-io/open-design` (`auto`, GPG-signed,
`pnpm guard` + `pnpm typecheck`).
