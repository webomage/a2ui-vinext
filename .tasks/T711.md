# T711 — AI Agent, MCP & Skill Security Audit Service & First-Party Public/Client Agent Certification

## Summary

 Spec and implement an end-to-end **AI Agent, Model Context Protocol (MCP) & `SKILL.md` Security Audit Service** grounded in Big Tech security skills and standards (**Linux Foundation AAIF `SKILL.md` & Anthropic MCP Security**, **Google Secure AI Framework (SAIF) & Elephant-Goldfish Model**, **Trail of Bits `mcp-context-protector`**, **OWASP Agentic Skills Top 10 `AST01–AST10`**, **Microsoft PyRIT**, and **MITRE ATLAS / NIST AI RMF**), and audit/certify all 6 of Webomage's **public and client-allowed agents** so 100% pass our own Agent Security Audit.

## Acceptance criteria

- [x] AC1 — **OpenSpec Specification & Big Tech Agent Security Taxonomy (`openspec/specs/agent-security-and-mcp-audit/spec.md`, `agent-security-audit.ts`):** Define the formal specification and `BIG_TECH_AGENT_SECURITY_FRAMEWORKS` catalog covering OWASP Agentic Skills Top 10 (`AST01`–`AST10`), Google SAIF / EGM, Anthropic MCP guardrails, Trail of Bits `mcp-context-protector`, Microsoft PyRIT, and MITRE ATLAS / NIST AI RMF.
- [x] AC2 — **Zero-Exec Agent, MCP & `SKILL.md` Security Audit Engine (`packages/lib/src/security/agent-security-audit.ts`):** Implement `runAgentSecurityAudit()` detecting prompt injection & stealth Unicode (`AST01/AST05`), over-privileged tools (`AST03`), missing human-in-the-loop confirmation on destructive/commercial actions (`AST04`), MCP tool-description ANSI/line-jump poisoning (`AST06`), unpinned MCP/skill supply chain (`AST07`), secret/env exfiltration (`AST08`), system-prompt leakage (`AST09`), and unbounded autonomous loops (`AST10`).
- [x] AC3 — **100% First-Party Public & Client-Allowed Agent Fleet Certification (`FIRST_PARTY_ALLOWED_AGENTS`, `auditAllFirstPartyAllowedAgents()`):** Audit and certify all 6 Webomage public and client-allowed agents (`w0m-public-concierge`, `w0m-cp-mistral-security-helper`, `w0m-cp-onboarding-advisor`, `w0m-me-personal-copilot`, `w0m-sec-readonly-auditor`, `w0m-egm-goldfish-reviewer`) with `100%` pass rate (`status: "certified_pass"`, `overallScore >= 96`, Grade `A`).
- [x] AC4 — **Public Ordering & Client Portal Agent Security Workbench (`order-form-state.ts`, `security-audit.ts`, `client-audit-persistence.ts`, `SecurityAuditReportViewer.svelte`):** Add `ai-agent-mcp-security-audit` to `PUBLIC_SERVICE_ACTION_CATALOG`, wire `action: "agent_security_audit"` in `/api/client/security-audit` with 3-layer KV + `orgs.service_usage` persistence, and render the First-Party Certified Agent Fleet + Interactive Agent/MCP Security Scanner in Client Portal.
- [x] AC5 — **Automated Unit & Fleet Certification Regression Tests (`crypto-and-agent-security-audit.test.ts`):** Verify that all 6 first-party public and client-allowed agents pass with 0 critical/high findings and that vulnerable agent/MCP manifests trigger deterministic `AST01`–`AST10` findings with remediation diffs.
