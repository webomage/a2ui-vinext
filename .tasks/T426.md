# T426 — Parallel-agents pilot (2 agent kinds via Orca), then enforce land-only main checkouts and make it the default

## Summary

Phase 3 of the accepted plan
([report](../.agents/reports/2026-09-23-parallel-agents-isolation-and-merge-proposal.md) §4 Phase 3,
decision Q1 stage 2).

Run two **different** agent kinds (e.g. Claude + Codex, both launched by Orca into their own
worktrees) on two real tickets for about a week. Land everything through `just land`. Then:
- switch the [[T423]] observer from warn to **enforce C**: a main checkout accepts a commit only from
  `just land` (`W0M_LAND`) or the owner (`W0M_OWNER_COMMIT=1`, recorded in the observer log, **not** a
  commit trailer);
- make the flow the default;
- retire the self-reported claim file.

## Acceptance criteria

- [ ] AC1 — Pilot run: at least 2 tickets, 2 agent kinds, all landed via `just land`. Record in Status
  notes:
  - conflicts per land;
  - time-to-land;
  - hook runs per worktree commit (must equal the main-checkout hook set);
  - worktrees left behind after landing;
  - discarded-generated-file notices (expected → 0 after [[T425]] AC9).
- [ ] AC2 — The observer log is analysed: which agent kinds committed in main checkouts, and with or
  without a TTY. The result is written here.
- [ ] AC3 — The observer is switched to **enforce C**, with tests covering: land commit allowed, owner
  override allowed and logged, agent commit refused with a message naming `just land`.
- [ ] AC4 — The `AGENTS.md` default workflow says: writing agents start via
  `orca worktree create … --agent <any>`, work lands via `just land`, and main checkouts are land-only.
- [~] AC5 — `_in/active-work.json`, `agent_claim.py`, `just claim`/`unclaim` and the
  `active-work-heads-up` hook are removed. "Who works on what" = `orca worktree ps` / `git worktree list`.
  [[T274]] AC6 is closed with a pointer here.
- [ ] AC6 — `wom7web/docs/flows/orca-parallel-agents.mmd` and `ORCA_INTEGRATION.md` are redrawn to the
  real model (no fictional "Orca Merge Strategy (Compare & Diff)"; fix the "agy"/"opencode" drift).
