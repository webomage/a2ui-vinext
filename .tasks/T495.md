# T495 — Brand and page claims, anti-squatting

## Summary

Split from [[T439]] (CP IA). Handles org/brand namespace reservations, slug collisions,
proof of domain/brand control, and administrative dispute handling.
- Reserved slugs list (system routes, trademarked brands, platform roots).
- Proof of control verification (DNS TXT record, verified domain email, or OAuth provider match).
- Dispute and claim workflow for verified organization owners.

## Acceptance criteria

- [ ] AC1 — Slug validation rejects reserved system keywords, top-level routes, and protected names.
- [ ] AC2 — Organization creation requires domain matching or proof-of-control challenge for claimable brand slugs.
- [ ] AC3 — Admin console provides claim review interface (`/admin/claims`) for reviewing disputes and reassigning slugs.
- [ ] AC4 — Migration and unit tests prove uniqueness constraints and conflict resolutions without data leakage.
