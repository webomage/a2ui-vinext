# T681 — Fix T675 `role_templates.min_unit_id` migration bug, enforce static + transactional pending-migration dry-run gates, and auto-resequence parallel worktree migrations on land

## Summary

Release `2026.11.08-1794149333` (`just deploy-all`) failed during `just db-migrate` (`/home/aleksei/Projects/!self/w0m/deploy-logs/run-2026.11.08-1794149333.log`) with:

```text
Applying migration 20261108063000_t675_project_role_templates_and_naming.sql...
ERROR: column "min_unit_id" of relation "role_templates" does not exist (SQLSTATE 42703)
```

Root causes across the migration lifecycle:
1. `20261108063000_t675_project_role_templates_and_naming.sql` inserted and updated `public.role_templates.min_unit_id` without first adding `min_unit_id uuid references public.units(id) on delete set null` to `public.role_templates` (which was created in `20260915120000_t359_role_templates.sql` without `min_unit_id`, unlike `public.project_roles`).
2. `w0m-web/project/scripts/supabase_surface_drift_check.py` built `table_columns` from `CREATE TABLE` and `ALTER TABLE ... ADD COLUMN` across all SQL migrations, but only validated TypeScript `.from(...)` mutations against `table_columns` and never checked SQL `INSERT INTO [public.]<table> (<cols...>)` column lists inside `w0m-api/supabase/migrations/*.sql` themselves.
3. `w0m-web/project/scripts/db_drift_check.py` listed `PENDING` migrations (`local - remote`) and exited `0` without verifying that pending migrations are ordered after the highest applied remote version or dry-running them inside a rolled-back PostgreSQL transaction (`BEGIN; SET LOCAL w0m.migration = 'on'; ... ROLLBACK;`) before `deploy-all`.
4. Parallel agent worktrees creating migrations independently can pick timestamps that collide with or fall behind migrations landed on `origin/beta` while the worktree was in flight.

## Acceptance criteria

- [x] **AC1 — Fix `20261108063000_t675_project_role_templates_and_naming.sql` and harden `20261108120000_w0m_platform_repos_and_task_tracker.sql` (`w0m-api/supabase/migrations/20261108063000_t675_project_role_templates_and_naming.sql`, `w0m-api/supabase/migrations/20261108120000_w0m_platform_repos_and_task_tracker.sql`):** Add `alter table public.role_templates add column if not exists min_unit_id uuid references public.units(id) on delete set null;` (plus partial index `role_templates_min_unit_id_idx`) before `DO $$ ... $$` in `20261108063000_t675_project_role_templates_and_naming.sql`, and omit hardcoded UUID `id` values on `INSERT INTO public.project_repos` in `20261108120000_w0m_platform_repos_and_task_tracker.sql` so upserts on `(project_id, provider, lower(owner), lower(name)) WHERE deleted_at IS NULL` cannot collide with existing primary keys.
- [x] **AC2 — Offline SQL Migration Column Drift Gate (`w0m-web/project/scripts/supabase_surface_drift_check.py`, `w0m-web/project/scripts/tests/test_supabase_surface_drift_check.py`):** Replay `CREATE TABLE`, `ALTER TABLE ... ADD COLUMN`, and `RENAME COLUMN` chronologically across `baseline/schema.sql` and `migrations/*.sql`, and fail closed if any migration's `INSERT INTO [public.]<table> (<cols...>)` references a column absent from `<table>` at that point in migration history.
- [x] **AC3 — Live Transactional Pending-Migration Dry-Run & Out-of-Order Gate (`w0m-web/project/scripts/db_drift_check.py`, `w0m-web/project/scripts/tests/test_migration_versions_unique.py`, `justfile`, `.w0m/sdlc.json`, `scripts/tests/test_deploy_chain_order.py`):** Verify no pending 14-digit migration version precedes an already-applied 14-digit remote migration version (`out_of_order_pending`), execute all pending migrations in order inside a single rolled-back PostgreSQL transaction (`BEGIN; SET LOCAL w0m.migration = 'on'; ... ROLLBACK;` with `psql -X -v ON_ERROR_STOP=1` and top-level `BEGIN;`/`COMMIT;` stripped), and wire `@just db-drift-check` into `_deploy-preflight` and `.w0m/sdlc.json -> session_wrapup.verification_gates`.
- [x] **AC4 — Automatic Parallel-Worktree Migration Re-Sequencing on Offload (`scripts/session_complete.py`, `scripts/tests/test_session_complete.py`):** Inside `session_complete.py`'s serialized `w0m-session-complete.lock` critical section (`maybe_resequence_colliding_migrations`), detect newly added SQL migrations in `w0m-api/supabase/migrations/` whose 14-digit version collides with or is `<= max(origin/beta versions)` and automatically `git mv` them to the next monotonic timestamp (`max + 1s`) while rewriting filename references across the worktree.
- [x] **AC5 — Regression Tests & Lessons (`LESSONS.md`, `.agents/reports/2026-11-08-t681-audit.md`):** Add unit tests in `test_supabase_surface_drift_check.py`, `test_migration_versions_unique.py`, `test_session_complete.py`, and `test_deploy_chain_order.py`, and record the transferable engineering rule in `LESSONS.md`.
