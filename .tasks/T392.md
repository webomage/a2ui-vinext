# T392 — Make AgDR an estate-wide decision-record standard, not wom7web-only

## Summary

🆕 filed 2026-09-18 per owner directive: *"AgDR should be a standard tech connected to
everything in w0m eco."* AgDR (Agent Decision Record — `project/templates/decision.md` →
`docs/decisions/AgDR-NNNN-*.md`, indexed by `docs/DECISIONS.md` / `just decisions`) exists
today, but **measured 2026-09-18, it is wom7web-only in both structure and mechanism**:
- `docs/DECISIONS.md`, `docs/decisions/`, and `project/templates/decision.md` exist only under
  `wom7web/` — none of the other 6 repos (`wom7api`, `wom7cfworkers`, `wom7ext`, `wom7sec`,
  `wom7skills`, `wom7mlx`) or the `@wom` root carry a copy or a pointer to it.
- `project/scripts/decisions_index.py`'s `ROOT = Path(__file__).resolve().parents[2]` resolves
  to `wom7web/` and every `SOURCES` glob walks only inside it — a decision recorded in another
  repo's own `AGENTS.md`, tickets, or docs (e.g. the worker script-name-collision fix, the
  wom7mlx Gemma-4 realignment, deploy-pipeline gotchas — all real decisions from this estate's
  own history) is invisible to the index, structurally, not by omission.
- Root `AGENTS.md` (`@wom`) and `wom7web/AGENTS.md` both already point at `docs/DECISIONS.md`
  as *the* decision record — but nothing states or enforces that the other repos should record
  decisions there too, or how an agent working in `wom7cfworkers` would even know the convention
  exists one repo over.

This is the same shape T192 already solved for connected-IDE rules: **satisfy the contract by
pointing, not by pasting** — a repo's `AGENTS.md` states the convention and the pointer must
resolve to a target that actually carries the rules, checked by a trace, not assumed by prose.

## Acceptance criteria

- [x] AC1 — Every non-`wom7web` repo's `AGENTS.md` (and the `@wom` root's) states AgDR as *the*
      estate-wide decision-record standard and points at `@wom/project/templates/decision.md`
      / `@wom/docs/decisions/` as the single authoring location — mirroring the pointer
      pattern T192 established (`.agent`/`.claude`/`.opencode` symlinks, "canonical conventions
      live in ../AGENTS.md" prose that must resolve).
- [x] AC2 — `scripts/decisions_index.py` widens its harvest beyond `wom7web`: either (a)
      the `SOURCES` globs and the in-place `MARKER` sweep walk all repos declared in
      `.w0m/sdlc.json → repos`, or (b) the index explicitly states it covers wom7web only and
      each other repo gets its own lightweight index pointing back at the shared AgDR series —
      pick one and make the code match the claim (today's code silently does neither).
- [x] AC3 — A repo other than wom7web can author a NEW AgDR without duplicating the template or
      inventing a second series — either write directly into `wom7web/docs/decisions/` regardless
      of which repo the decision concerns (single series, single source of truth, same pattern as
      the `ai_models` registry), or the multi-series alternative from AC2 is fully wired.
- [x] AC4 — A trace/gate proves the convention actually reached every repo, not just that prose
      claims it — same shape as `just ide-trace` (T192): reads each repo's `AGENTS.md`, confirms
      the AgDR pointer resolves, and fails if a repo has drifted (a hand-copied template, a dead
      link, or no mention at all).
- [x] AC5 — Backfill audit: survey each non-wom7web repo's own "decided but unstructured"
      moments already known from prior sessions (worker script-name collision, wom7mlx Gemma-4
      realignment, deploy-pipeline gotchas, gh-identity isolation) against [[AgDR-0002]]'s
      load-bearing criterion, and produce AgDR records for the ones that qualify — proving the
      widened mechanism works end-to-end on real, pre-existing decisions, not only in theory.
