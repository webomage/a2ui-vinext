# T323 — Bootstrap wom7ava — consented-identity virtual avatars for video conferencing

## Summary

New w0m subproject: lets a user appear on a video call wearing a visual "skin" — a synthetic or
consented-identity avatar — instead of their live camera feed, with matching voice. Sibling to
wom7clips ([[T322]]), both bootstrapped from architecture/research already done for personaje0
(`/Users/proto/Projects/_self/personaje0`), verified present in that codebase before this ticket
was written.

## Acceptance criteria

- [x] AC1 — `casualuser/wom7ava.git` exists as its own repo (not a subdirectory of an existing
      wom7* repo) with an initial commit: README (scope, what's reused from personaje0 and why,
      what's out of scope), config matching estate convention, `.gitignore`.
- [x] AC2 — Provider-abstraction interfaces ported from personaje0 (`IVoiceEngine`,
      `IVisualMotionEngine`, `ILLMEngine`) exist in wom7ava as typed interfaces/stubs, with a short
      doc note on what changed vs. the personaje0 source — noting the added real-time/low-latency
      constraint (`wom7ava/src/wom7ava/interfaces/provider_contracts.py`).
- [x] AC3 — `HardwareProfile` detector ported from personaje0 and runs successfully on this
      machine (`python3 wom7ava/src/wom7ava/runtime/hardware_detector.py` prints a detected profile).
- [x] AC4 — `PassportVault` identity-lock ported from personaje0 (`wom7ava/src/wom7ava/vault/passport_vault.py`)
      to store each avatar-skin identity, with an added **consent field**: every vault entry is tagged
      `synthetic` or `consented` (requiring a non-empty `ConsentRecord`), enforced at the vault layer.
- [x] AC5 — A visible AI-avatar disclosure requirement is documented as a hard design constraint
      for the eventual call UI (`disclosure_badge_required=True`, `disclosure_badge_label="AI Avatar · wom7ava"`,
      enforced in `passport_vault.py` and `provider_contracts.py` and documented in `wom7ava/docs/DESIGN-NOTES.md`).
- [x] AC6 — `wom7web/.w0m/sdlc.json` `repos` map includes an entry for wom7ava
      (`"ava": "wom7ava"`), so this repo is visible to the estate's existing SDLC gates.
- [x] AC7 — A short design note (`wom7ava/docs/DESIGN-NOTES.md`) records which personaje0 pieces are reused as-is (`PassportVault`,
      provider interfaces, `HardwareProfile`) vs. deferred (the actual consent-collection workflow,
      real-time call transport/UI) vs. explicitly not applicable (Omnichannel Publishing Queue and Phase-5 multi-tenant SaaS publishing model).
