# T279 — Maksim Kulikov as a Managed Multi-Project Client

## Summary

Owner direction 2026-08-25: Add **Maksim Kulikov** (`servicios777@webomage.com`) as a registered client account in the w0m ecosystem managing two distinct projects:
1. **`servicios777`** (`/Users/proto/Projects/_self/servicios777.mx`)
2. **`personaje0`** (`/Users/proto/Projects/_self/personaje0`)

Following the tenancy architecture proven in [[T266]], client onboarding requires wiring all four tenancy components:
- `public.clients` organization entry (`Maksim Kulikov` / `servicios777@webomage.com`)
- `auth.users` authentication principal
- `public.user_roles` with `role='client'` (rank 80 in [[T39]]'s RBAC hierarchy)
- `public.client_users` membership mapping `(client_id, user_id)`

Additionally, this ticket introduces the **multi-project client model**: binding multiple discrete project entities in `public.projects` to the same parent `client_id`, enabling unified CP portal visibility under a single client session.
