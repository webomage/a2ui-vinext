# T593 — Re-check Orca Mobile Dark/Light Mode Override PRs & Maintain Open `w0m-pr` Upstream PRs

## Summary

Track and re-check two upstream open-source workstreams across `w0m-pr/`:

1. **Orca Mobile Dark/Light Mode Override Independent of Paired Desktop Host (`stablyai/orca`)**:
   - Currently on `stablyai/orca:main`, mobile app chrome (`mobile/src/theme/mobile-theme.ts`, ~150 `StyleSheet.create` call sites, and `mobile/app/_layout.tsx` `<StatusBar style="light" />`) is hardcoded dark (`#111111`), while terminal appearance (`RuntimeMobileTerminalTheme`) is 100% driven by the connected desktop host (`src/renderer/src/runtime/sync-runtime-graph/mobile-terminal-theme.ts`), falling back to `DEFAULT_TERMINAL_THEME` (`#1a1b26`) when paired to a headless `orca serve` host (issue `#23139`).
   - Three active upstream PRs cover parts of this surface:
     - **PR `#19599`** (`kargnas:feat/mobile-phone-terminal-appearance` — *Open, checks passing*, fixes `#25499`): Adds 4-mode device-local terminal preference (`orca:terminalThemeMode`: `Automatic (phone)` / `Dark` / `Light` / `Match desktop`) in `mobile/src/storage/terminal-theme-preference.ts` and `mobile/src/terminal/use-mobile-terminal-theme.ts`, exposed via session `⋯ → Terminal appearance`. Uses `Ghostty Default Style Dark` (`#282c34`) and `Builtin Tango Light` (`#ffffff`). Does **not** change mobile app chrome, Native Chat, or Markdown/File readers, and is not exposed in `Settings → Terminal` (`mobile/app/terminal-settings.tsx`).
     - **PR `#10421`** (`bbingz:feat/mobile-terminal-theme-picker` — *Draft*, stacked with `#10419`): Moves the 30 built-in terminal themes to `src/shared/terminal-themes/` and adds a picker in `Settings → Terminal`, but keeps mobile locked to the dark slot.
     - **PR `#25278`** (`jsandai:feat/mobile-true-black` — *Open, checks passing*, fixes `#25277`): Swaps `colors` in `mobile-theme.ts` at startup via synchronous `expo-secure-store` read (`orca.appearance.trueBlack`) + WebView `window.__orcaTrueBlack` global without touching all ~150 `StyleSheet.create` files.
   - **Follow-up when re-checking**: Once `#19599` / `#25278` land or stall, check whether full mobile app chrome + Native Chat + Markdown/File reader Light/Dark/System override (issues `#9959`, `#22184`, `#20382`) and `Settings → Terminal` integration are still needed, ensuring local override omits host `minimumContrastRatio` so `resolveTerminalContrastFloor` enforces the 4.5 WCAG-AA floor on light backgrounds.

2. **Active Open Upstream PRs Audit & Maintenance (`just prs-open`)**:
   - Rebase conflicting `stablyai/orca` PRs (`#21157`, `#21148`, `#16597`), sign the unverified commit on `Blaizzy/mlx-vlm#2288`, address the `head_at_merge` sampling advisory on `Graphify-Labs/graphify#4727`, and track `openai/tart-guest-agent#62`, `jundot/omlx#3743`, and `bulwarkid/virtual-fido#48`.
