# T346 — Admin CP corporate verification and registry requester for client onboarding and compliance

## Summary

Owner directive, 2026-09-12: *"so we NEED w0m Admin CP for requesting selectively these services as P0 blocker"*.

During international client onboarding (such as Mexican corporate entities like `artemioquierocomer.mx` and prospective B2B clients), w0m Admin and Ops require an immediate, selective corporate verification surface inside the Admin CP. Rather than navigating disconnected external government websites by hand or having no automated audit trail, this ticket establishes an extensible verification panel and API service allowing administrators to selectively query authoritative business registries and fiscal identity APIs on demand.

The initial release targets Mexico's primary corporate and fiscal validation infrastructure:
1. **INEGI DENUE REST API:** Official establishment directory (>5M entities) returning legal name (*Razón Social*), commercial name, industry sector code, registered address, employee size stratum, and contact info.
2. **SAT RFC Validator & Art. 69/69-B Blacklist:** Validates Mexican RFC tax ID format and checks real-time standing against SAT's published blacklist of simulated-operation shell companies (EFOS).
3. **SAT Constancia de Situación Fiscal (CSF) QR Verification:** Resolves official tax certificate QR URLs to pull live legal name and tax regime directly from SAT.
4. **CompraNet / RUPC:** Checks federal government contractor status via `datos.gob.mx`.

The resulting verification record is normalized into a structured scorecard and can be linked directly to client records in `public.clients`.

## Acceptance criteria

- [x] AC1 — Create backend endpoint `/api/admin/corporate-verify` in `apps/cp` supporting selective provider dispatch (`inegi_denue`, `sat_rfc`, `sat_csf_qr`, `compranet`).
- [x] AC2 — Admin-only authorization gate: enforce `denyUnlessAdmin` / service role check, rejecting non-admin or anonymous callers with HTTP 403 Forbidden.
- [x] AC3 — SSRF protection: strict URL allowlist for QR verification requests (`^https://siat\.sat\.gob\.mx/app/qr/`), blocking RFC1918 private ranges, loopback, and cloud metadata endpoints.
- [x] AC4 — Interactive Admin CP UI Surface (`apps/cp/src/pages/business/verification.astro`):
  - Pluggable provider selector dropdown.
  - Search input (Company Name / RFC / QR URL).
  - Structured scorecard rendering Legal Name, RFC, Tax Regime, Address, Blacklist Status, and Verification Timestamp.
  - "Attach to Client" action associating the verified scorecard with `public.clients`.
- [x] AC5 — Deterministic offline test suite with mock HTTP responses for DENUE and SAT endpoints, proving zero network flakiness in CI.
