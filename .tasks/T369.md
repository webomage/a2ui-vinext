# T369 — w0m-prs: add fresh report table recipe for wom7open pull requests

## Summary

Owner ask, 2026-09-17: *"so let's have a just command to show fresh report table for PRs for repos in wom7open"*.

Following the addition of `jundot/omlx` and `Blaizzy/mlx-vlm` upstream contributions and existing tracking across `stablyai/orca`, `openai/tart-guest-agent`, and `bulwarkid/virtual-fido`, there is no single `just` command to print a fresh, live table summarizing active PRs in `wom7open` repos with their live mergeability, review decisions, and CI statuses.

This ticket adds the `table` subcommand to `w0m_prs.py`, expands the `wom7open` preset to include `jundot/omlx` and `Blaizzy/mlx-vlm`, exposes the `just prs-open` recipe across the estate justfiles, and updates the `w0m-prs` agent skill.
