# T578 — CP Mobile UI Responsiveness: Unclip Collapsed Sidebar Popovers & Mobile `/me/work` ProjectManager

## Goal

Fix two mobile usability regressions on `cp.webomage.com` (`/me` and `/me/work`):
1. **Collapsed sidebar menu clipping**: When the sidebar is collapsed to its `60px` rail on mobile (`< 1024px`) or desktop, tapping the bottom-left `AuthWidget` avatar (or `ContextSwitcher` / `SidebarHatSwitcher`) clips the floating menu horizontally at `60px` because `<aside>` in `AppShell.svelte` sets `overflow-y: auto; overflow-x: visible;` (which CSS Overflow Level 3 §3.2 computes as `overflow-x: auto`).
2. **Broken mobile layout on `/me/work` (`AdminTableToolbar` + `ProjectManager`)**:
   - `AdminTableToolbar.svelte` and `ProjectManager.svelte` render duplicate `List / Groups` toggles (`📋 List / 📁 Groups` and `≡ List / ⊞ Groups`).
   - `AdminTableToolbar.svelte` overflows horizontally outside its card container on mobile viewports (`~330px` content column beside the `60px` rail) and pins a tall sticky header over half the viewport while scrolling.
   - `ProjectManager.svelte` renders a 6-column desktop `<table>` on mobile that crushes project names into 1 word per line and clips `Description / Tags`, `Blueprint`, `Status`, and `Actions` off-screen.

## Acceptance Criteria

- [x] **AC1 — Unclip Sidebar Popovers & Mobile Overlay Drawer (`@webomage/ui` & `apps/cp`)**:
  - Change `<aside>` and `.side-body` in `AppShell.svelte` (and `.cp-side` in `CpShell.svelte`) to `overflow: visible;` and move vertical scrolling (`flex: 1; min-height: 0; overflow-y: auto; overflow-x: hidden;`) exclusively onto `<nav class="sn">` in `SideNav.svelte` so `AuthWidget`, `ContextSwitcher`, and `SidebarHatSwitcher` popovers float cleanly over `<main>` without horizontal clipping.
  - On viewports `< 768px`, when `collapsed === false` (expanded sidebar), render `<aside>` as a fixed overlay drawer (`position: fixed; inset: 0 auto 0 0; width: min(264px, 82vw); z-index: 50`) with a clickable backdrop scrim so expanding the sidebar on a phone overlays `<main>` instead of shrinking `<main>` to `126px`.
  - Ensure `AuthWidget.svelte` `.auth-dropdown` includes `z-50 max-h-[calc(100dvh-5rem)] overflow-y-auto` so the menu remains scrollable and fully visible on short mobile viewports.
- [x] **AC2 — Deduplicate `List / Groups` Toggle & Make `AdminTableToolbar.svelte` Mobile-Responsive**:
  - Pass `bind:viewMode` to `<AdminTableToolbar>` in `ProjectManager.svelte` and remove the duplicate `≡ List / ⊞ Groups` switcher from `{#snippet actions()}`.
  - Update `AdminTableToolbar.svelte` to use `relative sm:sticky`, responsive padding (`p-3 sm:py-3 sm:px-5`), and full-width wrapping mobile rows (`min-w-0`, `w-full sm:max-w-xs` search input, wrapping filters/actions) so no control protrudes outside the card border on mobile.
- [x] **AC3 — Responsive Mobile Project Cards & `/me/work` Container Layout (`ProjectManager.svelte`, `MyProjectHats.svelte`, `me/work.astro`)**:
  - Add a responsive mobile card layout (`flex flex-col md:table-row` on `<tr>`, `hidden md:table-header-group` on `<thead>`) for projects in both `list` and `groups` view modes in `ProjectManager.svelte` (keeping the 6-column `<table>` on `>= 768px`), displaying project selection, title, type badge, status badge, description/tags, repository links, blueprint, and `Roles` / `Edit` / `Archive` actions using `@webomage/ui` `Button` primitives and CSS custom properties.
  - Update `apps/cp/src/pages/me/work.astro` (`p-3 sm:p-5 overflow-hidden`) and `MyProjectHats.svelte` (`flex-1 sm:min-w-[200px]`) for mobile viewports.
- [x] **AC4 — Verification & Design System Conformance**:
  - Add/update tests in `@webomage/ui` and `apps/cp` covering the unclipped sidebar layout and responsive `AdminTableToolbar` / `ProjectManager` rendering.
  - Pass `just ds-conformance --enforce`, `pnpm --dir w0m-web --filter @webomage/ui test`, `pnpm --dir w0m-web --filter cp test`, and `just typecheck`.
