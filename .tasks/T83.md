## Summary

**Local image generation (wom7mlx)** — Gemma 4 is multimodal-in → text-out only; add a separate MLX image-gen model/endpoint (mlx-vlm `--image-model`/`--output-modality image`, or a diffusion model) for image OUTPUT.

## Acceptance criteria

- [ ] AC1 — **Image generation engine selection**: Select and validate an MLX-native image synthesis engine (such as `mflux`, FLUX via MLX, or MLX Stable Diffusion) optimized for Apple Silicon Metal unified memory.
- [ ] AC2 — **OpenAI-compatible /v1/images/generations endpoint**: Expose an HTTP endpoint complying with the standard `/v1/images/generations` schema, taking prompt and dimension arguments and returning base64/URL image output.
- [ ] AC3 — **Memory footprint and quantization limits**: Ensure weights (using 4-bit or 8-bit quantization) run safely within local unified memory limits on 32 GB Apple Silicon without causing out-of-memory kernel panics.
- [ ] AC4 — **Generation latency and output benchmarking**: Benchmark per-step inference latency and output fidelity across target asset types (diagrams, UI mockups, icons).
- [ ] AC5 — **Agent tooling integration in ai_tools.py**: Wire the endpoint into `wom7api/scripts/ai_tools.py` as an image generation helper for agent workflows when `USE_LOCAL_IMAGE_GEN=true`.
- [ ] AC6 — **P3 consolidation compliance**: Keep the service configuration optional under [[T184]] and ensure it introduces no blocking dependencies or failing checks to repository CI gates.

## Definition of Done

T83 is done when: an MLX-native image-synthesis engine runs locally on Apple Silicon
unified memory without OOM at a stated quantization, an OpenAI-compatible
`/v1/images/generations` endpoint accepts a prompt+dimensions and returns a usable
image, latency/fidelity are benchmarked against real asset types (diagrams, UI mockups,
icons) rather than assumed, `wom7api/scripts/ai_tools.py` can call it as an agent tool
gated by `USE_LOCAL_IMAGE_GEN`, and none of this introduces a blocking CI dependency —
per [[T184]]'s P3 consolidation, the service stays optional and skippable.
⚠️ Currently research/unstarted (per Status notes) — this describes the outcome, not a
claim that it exists yet.
