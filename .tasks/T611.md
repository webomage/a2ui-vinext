# T611 — Fix `apps/web` `@webomage/fingerprint` `deploy-web` Rolldown failure, add workspace-import linkage gate in `deps_sync.py`, and add `tools-install` bootstrap for missing governed CLI tools (`gauge`)

## Summary

Release `2026.11.02-1793646360` (`deploy-logs/run-2026.11.02-1793646360.log`) failed at `deploy-web` (`pnpm --filter web build`) with:
`[vite]: Rolldown failed to resolve import "@webomage/fingerprint" from ".../w0m-web/apps/web/src/components/security/SecurityAuditWidget.svelte"`.
`T604` (`cfee32ec`) added an import of `@webomage/fingerprint` inside a `.svelte` island without declaring `"@webomage/fingerprint": "workspace:*"` in `apps/web/package.json` (`astro check` skips `.svelte` files, and `deps_sync.py` did not check internal `@webomage/*` / `@wom/*` workspace imports against `package.json`).

In addition, `gauge` (`1.6.42`, `source: "brew"`) is declared in `project/policies/tools-policy.json` and monitored by `scripts/tools_check.py`, while `scripts/tools_upgrade.py` only upgrades already-installed formulas (`cur is not None`) and had no `--install-missing` (`just tools-install`) bootstrap path or `post_install` plugin runner (`gauge install` for `w0m-web/manifest.json` plugins `ts`, `html-report`, `json-report`).

## Acceptance criteria

- [x] **AC1 — Declare missing workspace dependencies & verify all 5 Worker app builds (`w0m-web`)**: Add `"@webomage/fingerprint": "workspace:*"` to `apps/web/package.json` (plus TypeScript `paths` in `apps/web/tsconfig.json`) and `"@webomage/webmcp": "workspace:*"` to `apps/cp/package.json`, update `w0m-web/pnpm-lock.yaml`, and verify `pnpm --filter web --filter cp --filter join --filter job --filter demo build` succeeds cleanly.
- [x] **AC2 — Workspace-package import linkage check in `scripts/deps_sync.py`**: Add `check_workspace_package_imports()` to `scripts/deps_sync.py` (wired into `evaluate_policy_detailed` / `deps-sync` pre-push gate) so any `.ts`, `.js`, `.mjs`, `.svelte`, or `.astro` import of an internal `@webomage/*` or `@wom/*` workspace package missing from that app/package's `package.json` fails closed before deploy, backed by unit + red-probe tests in `scripts/tests/test_deps_sync.py`.
- [x] **AC3 — Governed CLI `--install-missing` (`just tools-install`) & `post_install` plugin bootstrap (`scripts/tools_upgrade.py`, `tools-policy.json`)**: Add `--install-missing` (dry-run by default, `--apply` installs missing `source: "brew"` tools via `brew install`, runs optional `post_install` hooks such as `gauge install` in `w0m-web/`, runs `smoke`, and never touches `tools-policy.json`) + `just tools-install` recipe in `justfile`, backed by unit tests in `scripts/tests/test_tools_upgrade.py`.
- [x] **AC4 — Provision `gauge 1.6.42` + Gauge TS/report plugins on Linux workstation (`HP`)**: Run `just tools-install --only gauge --apply` so `gauge` (`1.6.42`), `ts`, `html-report`, and `json-report` plugins are installed and `gauge validate specs` passes with 0 errors.

## Definition of Done

- All 5 `w0m-web` Worker apps (`web`, `cp`, `join`, `job`, `demo`) build cleanly via `astro build`.
- `scripts/tests/test_deps_sync.py` and `scripts/tests/test_tools_upgrade.py` pass with red-probe coverage.
- `gauge --version` (`1.6.42`) and `gauge validate specs` pass on the Linux host.
- Landed via `just agent-tree-land` referencing `T611`.
