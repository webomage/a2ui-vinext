# T586 — PRs & OSS UI: 2-Paragraph Repo Activity Digest, GitHub Rising Projects Radar & Issue Feature Voting Board

## Context
Enhance our PRs & Open-Source UI (`/me/oss` `ParticipatingProjects.svelte`, `/admin/forks` `ForksManager.svelte`, and `/board/[owner]/[repo]` `FeatureVotingBoard.svelte`) and CLI (`scripts/w0m_prs.py`) to:
1. Compile and display a **1–2 paragraph recent updates digest** across tracked repositories (Paragraph 1: Upstream Velocity & Core Changes; Paragraph 2: Webomage Fork & PR Alignment), plus per-repository 1–2 paragraph recent activity summaries.
2. Trace and surface **top GitHub rising / trending projects** from verified live sources (GitHub Native Trending `github.com/trending`, GitHub Official Search API Breakout Velocity `created:>YYYY-MM-DD stars:>250 sort:stars`, Trendshift.io, and Star History trajectory links).
3. Provide a **GitHub Issue Feature Voting & Roadmap Board** (`/board`, `/board/[owner]/[repo]`, `/api/board/[owner]/[repo]`, `/api/board/[owner]/[repo]/badge.svg`, `FeatureVotingBoard.svelte`, `githubFeatureBoard.ts`) with 4-column roadmap classification (`Proposed`, `Planned`, `In Progress`, `Shipped`), reaction-weighted vote scoring, and GitHub account authentication enforcement on voting.
