# T115 — Review + triage astro-check TypeScript warnings

## Summary

`astro check` emits a large, growing pile of **non-fatal TypeScript warnings** that scroll past on
every `git push` (the pre-push hook runs `astro check` for `web` + `cp`). They don't fail the gate
(astro check only fails on *errors*), so they've accumulated unreviewed. Do a real pass: inventory
them across all apps, triage each category (genuine fix vs intentional-and-suppress), and get the
output clean enough that a future warning actually stands out instead of drowning in noise.

## Grounded inventory (2026-07-22, `web` app only — cp/join/job add more)

- **72× `ts(6133)`** — *"X is declared but its value is never read"* (unused vars/imports). Mostly
  mechanical removal; some may be intentional (e.g. `TechMiniIcon.astro:48` `onerror` inline handler).
- **13× `ts(6385)`** — *deprecated API*. In `src/lib/models/project.ts` + `tech.ts`: **Zod v4
  deprecated the string-format methods** (`.datetime()`/`.uuid()`/`.url()`/… on `ZodString`) in favor
  of top-level `z.iso.datetime()` / `z.uuid()` / `z.url()`. Worth migrating before a Zod major removes them.
