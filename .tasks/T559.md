# T559 — CP Upwork Full MCP/DB Sync & Advanced Messages/Proposals Explorer UI + Auth Redirect Loop Fix

## Summary

Resolves the `ERR_TOO_MANY_REDIRECTS` loop on `cp.webomage.com`, pushes the full Upwork dataset (`contracts`, `proposals` including 1,894 screening Q&As across 725 proposals and bid terms across 1,782 proposals, `rooms`, `messages`, and cross-entity links) into both `public.*` and `upwork.*` schemas, strips `<untrusted_participant_content>` tags recursively across sync/loader/UI layers, and ships advanced search, filtering, sorting, and cross-linking UI on `/me/upwork/messages` and `/me/upwork/proposals`.

## Acceptance criteria

- [x] AC1 — **CP Auth & MFA Redirect Loop Fix (`middleware.ts`, `challenge.astro`, `MfaChallenge.svelte`, `middleware.spec.ts`).** Preserve `Set-Cookie` headers across all early 302 redirects (`withCookies` helper so rotated Supabase refresh/access tokens are never dropped), skip `authedHomeRedirect` on `/login` when `?error=` or `?clear_session=` is present, exempt MFA challenge/enroll routes (`isMfaExemptRoute`) from non-member hat `roleHome` bounces, prefer `Astro.locals.accessToken` in `challenge.astro`, and clear server HttpOnly cookies via `POST /api/auth/signout` on MFA sign-out. Verified with 8 unit tests in `middleware.spec.ts`.
- [x] AC2 — **Full Upwork MCP Sync & DB Enrichment (`upwork_mcp_sync.py`, `upwork_loader.py`, `upwork_mirror_loader.py`).** Recursively strip `<untrusted_participant_content>` tags across nested dicts/lists (`job.jobName`, room topics, cover letters, screening Q&As), add `sync_proposals_and_links` (`--sync-proposals`) in `upwork_loader.py` and archive merging + batched `executemany` in `upwork_mirror_loader.py`, and push all 95 contracts, 1,784 proposals (with `questionsAnswers` on 725 proposals and `terms` on 1,782 proposals), 162 rooms (0 tainted topics), and 2,614 messages into both `public.*` and `upwork.*`, reconciling 22 missing room-proposal links, 68 `roomUuid` backfills, and 55 proposal-contract links.
- [x] AC3 — **Advanced `/me/upwork/messages` UI (`messages.astro`, `upwork-view.ts`).** Resolve `?room=` by either UUID (`platform_rooms.id`) or Upwork external ID (`room_...`), add room filter pills with live counts (All, Contracts, Proposals, Awaiting Reply, Agency, Freelancer), instant room search & sorting (Newest, Oldest, Topic, Client), global cross-room message body search (`?q=`), sleek dark scrollbars, rich room header with participant name and direct **View Proposal →** / **Linked Contract →** buttons, date dividers, and in-thread message search + direction filters (All / Received / Sent).
- [x] AC4 — **Advanced `/me/upwork/proposals` UI (`proposals.astro`, `upwork-view.ts`, `upwork-view.test.ts`).** Add summary KPI cards (Total Synced, Hired, Screening Q&A, With Messages, Matching Filter), feature filter pills (Has Screening Q&A, Has Messages, Has Contract), keyword search across titles/cover letters/screening Q&As, sort order toggle, Expand/Collapse All toggle, bid rate (`$rate/hr`) and duration badges, expandable **Screening Questions & Answers** cards, and working cross-links to `/me/upwork/messages?room=...` and `/me/profile/work`.
