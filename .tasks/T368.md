# T368 — Research Apple Silicon native microVM containerization (apple/container), compose orchestration, and GUI tooling

## Summary

Evaluates Apple's open-source **`apple/container`** microVM containerization framework as a high-velocity, lightweight alternative to full VM boot via Tart (`cirruslabs/tart` / `openai/tart`) for ephemeral Linux workloads on Apple Silicon. Investigates performance metrics (sub-second <500ms startup, dynamic memory bounding vs multi-gigabyte slices), multi-container orchestration compatibility via **`Container-Compose`** and **`Opossum`**, native macOS monitoring GUIs (**`Orchard`**, **`Contained`**, **`ContainerUI`**), and formalizes the w0m substrate boundary separating Tart (full macOS/Linux desktop sandboxes) from Apple Container (ephemeral Linux code runners).

## Acceptance criteria

- [ ] **AC1 — Apple `container` Core Architecture & MicroVM Benchmark**: Profile Apple's `container` runtime (`apple/container`) against Tart VM execution on a live Apple Silicon host (deferred: sandboxing/VM benchmarks cannot run on this host).
- [ ] **AC2 — Multi-Container Compose Orchestration (`Container-Compose` / `Opossum`)**: Static compatibility matrix documented in `.agents/reports/T180-T368-sandbox-substrate-architecture.md`; live `apple/container` compose execution deferred to Apple Silicon host.
- [ ] **AC3 — Native macOS Management GUIs (`Orchard`, `Contained`, `ContainerUI`)**: Static feature matrix documented in `.agents/reports/T180-T368-sandbox-substrate-architecture.md`; live macOS GUI evaluation deferred to Apple Silicon host.
- [x] **AC4 — w0m Substrate & Sandbox Integration Blueprint**: Formulated and codified the 3-tier routing boundary in `scripts/tart_sandbox.py --classify-workload` (`apple/container` vs `devpod-tart-linux` vs `tart-macos`) and `.agents/reports/T180-T368-sandbox-substrate-architecture.md`.
- [ ] **AC5 — Host Provisioning & `just` Automation Spike**: `scripts/tart_sandbox.py` implemented; live `brew install container` + host sandbox isolation verification deferred to Apple Silicon host.
