# T650 — Certify estate tree-set offline gates in `session-complete` and reuse verified SHA certificates in `deploy` / `deploy-all`

## Summary

Measured on `2026-11-05` (`release 2026.11.05-1793910586`), `just deploy-all` spent `~8.5 min` running `97` suite invocations (`2,105` checks) before building or shipping: `16` `prepush` suites ran twice (`_deploy-preflight` and again inside `just test`), `check-infisical` ran twice (`_deploy-all-chain` and `_deploy-gates`), `check-guardrails` re-scanned full-tree `gitleaks --all-files` after `secrets` already ran, and all `81` `offline/medium` suites ran from scratch after Touch ID confirmation—even though `session-complete` did not run `vitest` or `py-typecheck` before landing onto `origin/beta`.

Implement Option A (`AgDR-0057`): shift `check-guardrails` + `offline/medium` certification into `just session-complete` (and `just certify`) keyed by a content-addressed SHA-256 digest over all `10` estate repo `HEAD` commits + `w0m-web/project/test-suites.json`, and have `deploy` / `deploy-all` verify the clean tree-set certificate in `<0.2s` while keeping `state-check`, `check-warp`, `check-infisical`, `_assert-provisioned`, and `smoke-live` live on every deploy.

## Acceptance criteria

- [x] **AC1 — Architectural Decision Record (`AgDR-0057`) & `scripts/deploy_cert.py` tree-set certification engine**: Recorded `AgDR-0057` (`docs/decisions/AgDR-0057-tree-set-certified-deploy-gates.md`, indexed in `docs/DECISIONS.md`) and implemented `scripts/deploy_cert.py` (`certify`, `status`, `preflight`, `guardrails`, `test`) computing SHA-256 `tree_set_digest` across all `10` estate repo `HEAD` SHAs + `policy_digest` (`w0m-web/project/test-suites.json`), refusing dirty tracked files (`AgDR-0025`) and supporting `W0M_DEPLOY_CERT_RESET=1` / `--reset`.
- [x] **AC2 — Zero-duplication `--skip-prepush` & deploy chain integration (`justfile`, `push_cadence_check.py`)**: Added `--skip-prepush` to `scripts/run_suites.py` so uncached deploy runs never execute the `16` `prepush` suites twice; wired `_deploy-preflight`, `check-guardrails`, and `test` to consult `deploy_cert.py` inside deploy contexts (`W0M_DEPLOY_LOGGED=1` / `W0M_RELEASE_WORKTREE=1` / `W0M_USE_DEPLOY_CERT=1`) while keeping standalone `just test` and `just check-guardrails` uncached; removed duplicate `check-infisical` from `_deploy-all-chain`; and preserved 100% of `test_deploy_chain_order.py` (`7/7` passed).
- [x] **AC3 — Automatic pre-land & post-rebase certification in `scripts/session_complete.py`**: Wired `session_complete.py` to certify the committed agent tree before `agent_tree.py land` and re-verify/certify post-land before worktree removal (`9/9` `test_session_complete.py` passed).
- [x] **AC4 — Offline unit & red-probe suite (`scripts/tests/test_deploy_cert.py`) + registry & typing gates**: Verified `just certify-test` (`5/5` passed), `just deploy-drift-test` (`6/6` passed), `just suites-drift` (`362` declared, `0` undeclared/unresolved), `just py-typecheck`, `just py-typing-check --check`, and `just session-complete T650`.
