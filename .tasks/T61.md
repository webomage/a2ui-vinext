# T61 — Dual-Manager Project Governance Policy

## Summary

Enforce the dual-manager project management model (PM/Org Manager and DevOps/Tech Manager roles) across the w0m Control Panel workflow processes.

- [ ] AC2 — Implement approval requirements for client milestone releases requiring signatures from both assigned managers.
- [ ] AC3 — Add check-gates in CP releasing systems verifying that the DevOps lead has approved the target release tag version.
