# T61 — Dual-Manager Project Governance Policy

## Summary

Enforce the dual-manager project management model (PM/Org Manager and DevOps/Tech Manager roles) across the w0m Control Panel workflow processes.

## Acceptance criteria

- [x] AC1 — Update project dashboard views to display both the PM (`delivery.manager`) and Tech Lead (`tl`, into which `dev` and `devops` collapse until staffed) assigned to each project (`wom7web/packages/lib/src/governance/dual-manager.ts`, `DualManagerGovernanceCard.svelte` using `@webomage/ui` primitives, wired in `wom7web/apps/cp/src/pages/o/[org]/p/[project]/index.astro`).
- [x] AC2 — Implement approval requirements for client milestone releases requiring `milestone.approve` signatures from both assigned managers (`evaluateMilestoneReleaseApproval`, supporting distinct-member and single-operator dual-hat modes per `AgDR-0028` Decision 4).
- [x] AC3 — Add check-gates in CP releasing systems verifying that the `tl` (or `devops` when staffed) has approved the target release tag version (`verifyReleaseTagGate` + `/api/project/release-approval`, enforcing `deploy.approve` vs `deploy.execute` separation when `devops` is staffed).
