# T59 — Implement ATS Sourcing & Syncing via Kombo

## Summary

Integrate the Kombo Unified ATS API in our Supabase Edge Functions. Expose endpoints to sync job vacancies and candidate profiles, and set up secure webhook receivers verifying HMAC headers to handle real-time syncs from Greenhouse, Lever, Ashby, and others.

## Acceptance criteria

- [ ] AC1 — Install and configure the Kombo client in Supabase Edge Functions (`/sourcing` routes).
- [ ] AC2 — Implement job vacancy sync mapping the normalized Kombo schema to local `vacancies` tables.
- [ ] AC3 — Expose Webhook endpoint at `/sourcing/webhooks/kombo` and verify incoming HMAC headers using Webhook Secret.
- [ ] AC4 — Map custom tags and hiring stages correctly using Kombo's custom fields mapping structure.
