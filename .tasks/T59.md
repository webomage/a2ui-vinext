# T59 — Implement ATS Sourcing & Syncing via Kombo

## Summary

Integrate the Kombo Unified ATS API in our Supabase Edge Functions. Expose endpoints to sync job vacancies and candidate profiles, and set up secure webhook receivers verifying HMAC headers to handle real-time syncs from Greenhouse, Lever, Ashby, and others.

## Acceptance criteria

- [x] AC1 — Install and configure the Kombo client in Supabase Edge Functions (`/sourcing` routes).
- [x] AC2 — Implement job vacancy sync mapping the normalized Kombo schema to local `vacancies` tables.
- [x] AC3 — Expose Webhook endpoint at `/sourcing/webhooks/kombo` and verify incoming HMAC headers using Webhook Secret.
- [x] AC4 — Map custom tags and hiring stages correctly using Kombo's custom fields mapping structure.

## Status notes

✅ **2026-10-20 — Completed (AC1–AC4):**
- Implemented `KomboAtsClient` (`fetchJobs`, `fetchCandidates`), schema mappers (`mapKomboJobToVacancy`, `mapKomboCandidateToSubmissions`, `mapKomboStage`, `extractKomboCustomTags`), and constant-time HMAC-SHA256 webhook verification (`verifyKomboWebhookSignature`) in `wom7api/supabase/functions/sourcing/kombo.ts`.
- Wired `/sourcing` edge function (`wom7api/supabase/functions/sourcing/index.ts`) supporting `POST /sourcing/webhooks/kombo` and authenticated `sync_vacancies` / `sync_candidates` / `sync_all` actions, failing closed (`503 UNAVAILABLE`, `measurement_state: "unmeasurable"`) when `KOMBO_API_KEY`, `KOMBO_INTEGRATION_ID`, or `KOMBO_WEBHOOK_SECRET` is absent.
- Verified with `wom7api/supabase/functions/sourcing/kombo.test.ts` (5/5 Deno tests passing).
