# T719 — Benchmark Stack-Aligned Context & Code-Graph Tools (`PageIndex`, `lean-ctx`, `Vibe-Skills`, `tilth`, `agtx`) & Prototype AgDR Decision Evidence-Decay Check

## Summary

Evaluate the top stack-aligned (`MIT` / `Apache-2.0`) tools surfaced during the GitHub `topic:context-engineering` and `topic:spec-driven-development` landscape audit ([[T718]]) against `w0m`'s live context stack (`codegraph`, `graphify`, `corpus.sqlite`, `headroom`, `w0m-skills`, and `k7` TUI [[T708]]), and prototype a native AgDR evidence-decay check (`just decisions --stale`, inspired by `m0n0x41d/haft`'s concept without copying unlicensed code).

Split from: [[T718]]

## Acceptance criteria

- [ ] AC1 — **Cold-Path Document Retrieval & Context Gateway Benchmark (`VectifyAI/PageIndex` & `yvgude/lean-ctx`):** Measure latency, token reduction, and cold-start cost of `VectifyAI/PageIndex` (`MIT`, Python) and `yvgude/lean-ctx` (`Apache-2.0`, Rust) against `w0m_kb_vector.py` and `headroom` on `w0m-web/openspec/` + `docs/decisions/`.
- [ ] AC2 — **Dynamic Skill Routing & Zero-Index AST Diff Benchmark (`foryourhealth111-pixel/Vibe-Skills` & `jahala/tilth`):** Benchmark `Vibe-Skills` (`Apache-2.0`, Python) prompt-token savings across `w0m`'s 127-skill catalog and `jahala/tilth` (`MIT`, Rust `tree-sitter`) function-level diff speed against `codegraph` during `ultra` mode reviews.
- [ ] AC3 — **Rust TUI Multi-Agent Blackboard Reference Review (`fynnfluegge/agtx` -> [[T708]]):** Document reusable `ratatui` + git worktree blackboard patterns from `fynnfluegge/agtx` (`Apache-2.0`, Rust) for `k7` TUI integration in [[T708]].
- [ ] AC4 — **Native AgDR Decision Evidence-Decay Check (`just decisions --stale`):** Implement a first-party Python check over `docs/decisions/*.md` that flags AgDRs whose cited repo paths or gate scripts have moved or been deleted since acceptance, with unit test coverage and weighted adoption recommendations in `.agents/reports/`.

## Definition of Done

Per [`w0m-web/openspec/SPEC-AUTHORING-STANDARD.md`](../w0m-web/openspec/SPEC-AUTHORING-STANDARD.md):
- Acceptance criteria AC1–AC4 verified with reproducible benchmark tables, `package_legitimacy_check.py`, `dep-licenses-check`, and report mirrored to `.agents/reports/` and `w0m-web/docs/reports/`.
