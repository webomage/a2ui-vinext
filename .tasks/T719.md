## Summary

- [x] AC1 — **Cold-Path Document Retrieval & Context Gateway Benchmark (`VectifyAI/PageIndex` & `yvgude/lean-ctx`):** Benchmarked `w0m_kb_vector.py` (`853.2–940.8 ms` local SQLite BM25 + 128d across `1,947` docs / `19,085` chunks) against `docs/decisions/*.md` (`57` files) + `w0m-web/openspec/**/*.md` (`906` files, `~1.257M` tokens), `PageIndex`'s async LLM heading-tree summarizer, `T162` `headroom` A/B data (`0` tokens removed, `+57%` latency), and `yvgude/lean-ctx` (withdrawn `BENCHMARKS.md` + mixed `LICENSE.md`).
- [x] AC2 — **Dynamic Skill Routing & Zero-Index AST Diff Benchmark (`foryourhealth111-pixel/Vibe-Skills` & `jahala/tilth`):** Measured `w0m-web/.agents/skills` (`129` dirs, `~17,028` frontmatter tok) vs `.w0m/skills.json` (`42` dirs, `~4,787` tok, `-71.9%` static cache-safe prune) vs top-5 subset (`~660` tok), plus `just ask` cold latency (`35.34–39.73 s` via `graphify`) vs `rg` (`69.7 ms`) and `jahala/tilth` (`MIT`, Rust `tree-sitter`).
