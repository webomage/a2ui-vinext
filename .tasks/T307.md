# T307 — Own and govern the @k7 toolset family

## Summary

The `@k7` ecosystem (`/Users/proto/Projects/@self/@k7`) represents the estate's suite of Rust-based Terminal User Interfaces (TUIs) and CLI tools (`k7c`, `k7d`, `k7s`, `k7llm`, `k7sol`, `k7spec`, `k7tg`). While `@k7` projects adhere to base spec-driven principles (`.spec/`, `.state/`, `.stories/`), they exist outside w0m's formal SDLC contract, policy registries, and canonical skills distribution.

This ticket defines and executes the **w0m SDLC onboarding and conversion path for the `@k7` family**:
1. Declaring `@k7` in `clients-policy.json` as a managed workspace project.
2. Establishing the `.w0m/sdlc.json` contract and instruction surfaces (`CLAUDE.md` / `AGENTS.md`) across `@k7` repositories.
3. Integrating the newly scaffolded **`k7d`** as the first-class Tart Virtual Machine & Daemon Control Panel (TUI).
4. Synchronizing canonical w0m skills and standardizing `Justfile` quality gates (`preflight`, `check`, `test`, `fmt`).

## Acceptance criteria

- [x] **AC1 — Workspace Symlink**: `@k7` is symlinked into `@wom/k7` with `.git/info/exclude` hygiene so the estate worktree remains clean.
- [x] **AC2 — Tart TUI CP Scaffolding**: `k7d/k7d` is scaffolded as a spec-first Rust Ratatui control panel (`.spec/`, `.stories/`, `.brain/`, `.state/`, `Justfile`, `Cargo.toml`, `src/`) and proven against live `tart` CLI output.
- [x] **AC3 — Policy Declaration**: `@k7` is registered in `clients-policy.json` under workspace mode with its constituent repos declared.
- [x] **AC4 — SDLC Contract & Instruction Surface**: `@k7` root and member repos carry `.w0m/sdlc.json` configuration and `@AGENTS.md` / `CLAUDE.md` enforcing w0m SDLC gate compliance.
- [x] **AC5 — Skills Governance**: `@k7` is enrolled with `.w0m/skills.json` and synchronized with w0m canonical skills.
- [x] **AC6 — Quality Gates**: `just client-inventory` measures `@k7` cleanly with zero unhandled contract divergences.

## Definition of Done

`@k7` is fully registered as a governed project in `clients-policy.json`, its repositories declare their `.w0m/sdlc.json` contract, agent instruction surfaces enforce SDLC gates, `k7d` provides live Tart VM management, and `just client-inventory` passes verification.
