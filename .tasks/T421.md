# T421 — Elevate Deployment Machinery, Scripts, Recipes, and Logs to Workspace Root (Phase 4)

## Summary

In Phases 1, 2, and 3 of Estate Root Elevation ([[T411]], [[T412]], [[T414]], [[T419]]), central governance (`.w0m/sdlc.json`), policy definitions (`project/*-policy.json`), the unified task queue (`.tasks/`), and quality-gate scripts were elevated into workspace root (`@wom`).

However, the estate deployment machinery remained stranded in `wom7api`:
1. Core deployment recipes (`deploy`, `deploy-all`, `deploy-web`, `deploy-cp`, `deploy-join`, `deploy-job`, `deploy-demo`, `deploy-workers`, `deploy-functions`, `_deploy-chain`) are still declared in `wom7api/justfile` (which `wom7web/justfile` symlinks to), rather than being exposed at workspace root.
2. Helper scripts (`log_deploy.sh`, `dump_deploy_log.sh`, `check_cf_deployment.py`) reside in `wom7api/scripts/`.
3. Deployment execution logs are written to `wom7api/deploy-logs/` rather than the workspace root.
4. Calling `just deploy` or `just deploy-web` from the workspace root fails with `error: justfile does not contain recipe deploy`.

This ticket delivers Phase 4 of the workspace elevation: cleanly migrating deployment recipes, helper scripts, and deploy-log destinations to the workspace root (`@wom`), while updating 100% of callers with zero backward-compatibility shims or shadow symlinks (AgDR-0025).

## Acceptance criteria

- [ ] AC1 — Elevate Deployment Scripts to Workspace Root `@wom/scripts/`: Relocate `log_deploy.sh`, `dump_deploy_log.sh`, and `check_cf_deployment.py` from `wom7api/scripts/` to `@wom/scripts/` with 100% callers updated atomically (zero shims/symlinks per AgDR-0025).
- [ ] AC2 — Centralize Deployment Logs to Workspace Root `@wom/deploy-logs/`: Relocate active deploy logs directory from `wom7api/deploy-logs/` to `@wom/deploy-logs/` (and ensure `.gitignore` rules in `@wom` and `wom7api` correctly reflect the location and retention policies).
- [ ] AC3 — Elevate Core Deploy Recipes to Root `justfile`: Expose canonical deployment recipes (`deploy`, `deploy-all`, `deploy-web`, `deploy-cp`, `deploy-join`, `deploy-job`, `deploy-demo`, `deploy-workers`, `deploy-functions`, `_deploy-chain`, `_log-deploy`, `_confirm`) in root `@wom/justfile`, executing with root context and clean repo references (`wom7web`, `wom7api`, `wom7func`).
- [ ] AC4 — Update Deployment Confirmation Gate & Documentation: Ensure `_confirm` interactive TTY gate functions correctly from root `@wom`, and update `docs/DEPLOY-CONFIRM.md` and `.w0m/sdlc.json` consumer declarations to reference `@wom/justfile`.
- [ ] AC5 — Clean Cutover in `wom7api` and `wom7web`: Update or remove duplicate recipes in `wom7api/justfile` to forward to workspace root or rely directly on root orchestration without circular loops or orphan paths.
- [ ] AC6 — Automated Verification and Regression Proof: Implement `scripts/tests/test_deploy_elevation.py` (and `just deploy-elevation-test`) verifying script presence, justfile recipe declarations, log directory paths, and absence of broken references across all 7 estate repos.

## Definition of Done

Per `openspec/SPEC-AUTHORING-STANDARD.md`:
1. All deploy scripts (`log_deploy.sh`, `dump_deploy_log.sh`, `check_cf_deployment.py`) are located in `@wom/scripts/` and removed from `wom7api/scripts/`.
2. Deploy logs write to `@wom/deploy-logs/`.
3. Root `justfile` exposes all canonical deploy recipes with working `--dry-run` or validation checks.
4. Pre-commit and pre-push quality gates (`just ticket-schema-check`, `just hooks-check`, `just dod-check --ticket T421`) pass 100% green without `--no-verify`.
