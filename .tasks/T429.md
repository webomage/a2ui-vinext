# T429 — check-infisical names the real failure cause; root justfile passes an explicit Infisical project id

## Summary

On 2026-09-23 `just deploy-all` stopped at `check-infisical` with "Infisical session invalid/expired".
The session was valid: from `wom7api` the same probe injected 105 secrets.

- **Root cause:** [[T421]] moved the deploy recipes into `@wom/justfile`, which runs from `@wom`, and
  `@wom` has no `.infisical.json` project link. The link exists only, untracked, in `wom7api/` and
  `wom7web/`, both pointing at the same workspace.
- **Why the error was misleading:** the recipe ran `infisical run … -- true >/dev/null 2>&1` and
  reported every failure as "expired". It discarded the CLI's actual line: "Please either run infisical
  init … or pass in project id with --projectId flag".
- **Stopgap:** a hand-copied `@wom/.infisical.json`. It has been removed; the fix below replaces it.

## Acceptance criteria

- [x] AC1 — `check-infisical` distinguishes (a) no project link, (a') wrong project id, (b) not logged in
  / expired, and (c) other (first stderr line, ANSI-stripped, truncated). It prints the cause and the
  fix for each. Logic is in `scripts/check_infisical.py`. The root recipe and the `wom7api` recipe both
  call that script, so the logic lives in one place. It runs only `true` and never uses `infisical
  secrets`.
- [x] AC2 — The root justfile declares `infisical_project_id` once and passes
  `--projectId={{ infisical_project_id }}` at **all 22** `infisical run` call sites, including those
  that `cd` into sub-repos (same workspace). No root `.infisical.json` is needed.
- [x] AC3 — Probe `scripts/tests/test_check_infisical.py` (9 tests) runs against a fake CLI. It covers
  RED no-link, CLI-init message, wrong id, expired, other (first line only), success via a parent link,
  and missing CLI. It also checks the justfile, so a new `infisical run` without the id fails the test.
  Registered as blocking suite `check-infisical` (recipe `check-infisical-test`).
- [x] AC4 — Lesson recorded in `LESSONS.md` ("A check that swallows the CLI's error will name the wrong
  cause").
