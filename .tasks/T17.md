# T17 — Purge .env.bak from wom7web git history

## Summary


🟡 **P2 2026-08-13 — hygiene, NOT an active exposure, and the distinction is the whole triage.**
The credentials in `.env.bak` were **rotated** in the 2026-06/07 passes, so history holds **dead**
values. It still belongs done — *"untracking is not removal"* — but nothing live is protected by it.
🔴 **Handle with care when it IS done:** it needs `filter-repo` + force-push, and this estate has a
standing rule that **force-pushing a pre-rewrite local branch resurrects the purged objects**.
Purge `.env.bak` from wom7web git history (filter-repo + force-push). Untracking is not
removal.
