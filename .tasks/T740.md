# T740 — Fix AI Agent Helper click close race across funnels, unify /solutions selector, and compare claw/audit runtimes vs ZeroClaw

## Summary

1. **Root Cause 1 — AI Agent Helper Click Race (`ChatApp.svelte`):** Clicking `Ask AI Agent Helper →`, `Complete via AI Agent Helper →`, `Open in AI Agent Helper →`, `Guided Q&A Scoping →`, or `AI Guided Q&A Survey →` from any order form outside `.chat-widget-container` synchronously dispatches `wom:chat-open` / `wom:chat-order-service` / `wom:chat-guided-survey` setting `isOpen = true`, and then milliseconds/microseconds later in the same native DOM `click` bubble, `<svelte:window onclick={onOverlayClick} />` fires, sees `!target.closest(".chat-widget-container")`, and immediately resets `isOpen = false` before paint. In addition, `finishGuidedSurvey` reset `contact` instead of keeping pre-filled `quoteEmail` / `quoteName`.
2. **Root Cause 2 — Duplicated Selector on `/solutions/` (`SolutionsPage.astro`):** Rendering both `{ id: "solutions", type: "solutions" }` (`SolutionsGrid.astro`) and `{ id: "service-order-configurator", type: "service-order" }` (`ServiceActionOrderConfigurator.svelte`) stacked two competing selector grids for the same architecture solutions and packages, with sparse top cards leaving empty vertical voids above their CTAs.
3. **Comparison Benchmark (`zeroclaw` vs Linux `libclaw`, `cloudflare/security-audit-skill`, and `-claw` agent runtimes):** Documented grounded capability/security comparison against existing `ZeroClaw v0.8.3` (`T153`) in `.agents/reports/t740-ai-helper-and-solutions-funnel-unification.md`.
