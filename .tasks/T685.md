# T685 — Maintain `webomage/just` (`w0m-pr/just`) Overlay Fork with Critical Patch Stack, Local Binary Installation, TabLinux WASM Package, and Unified Upstream Release Sync

## Summary

Because `casey/just` bans AI-assisted Pull Requests (`casey/just#3227`), `@wom` maintains a first-class self-healing overlay fork (`github.com/webomage/just` in `w0m-pr/just`, tracking upstream `casey/just` releases on `beta` alongside `webomage/orca`, `webomage/moksha`, `webomage/headroom`, and `webomage/omlx`) that ships critical bug fixes and the highest-demand `just` features directly into `~/.local/bin/just`, packages our enhanced `just` runner (`just-1.59.0-w0m.1.tar.gz`) for `TabLinux` (`w0m-pr/linuxontab`), and automatically rebases/merges onto new upstream `casey/just` releases (`just just-sync`, `just just-apply`, `just just-wasm`, `just overlays-status`).

## Scope

- **In:**
  - Fork `casey/just` to `github.com/webomage/just` and clone into `w0m-pr/just` (`origin = git@github.com:webomage/just.git`, `upstream = https://github.com/casey/just.git`) anchored on upstream release `1.59.0`.
  - Implement, test, GPG-sign (`-S`), and push 4 modular patch branches plus assembled `beta` and `config/w0m-overlay-branches.json`:
    1. `fix/fmt-preserve-recipe-header-comment` (`casey/just#3773`): Preserve trailing `# comments` on recipe header lines (`b: a # comment`) when the recipe has a body across `just --fmt` and `just --dump`.
    2. `feat/multiline-doc-comments` (`casey/just#2684`): Capture consecutive `#` doc comment lines above a recipe; render them in `just --list`, `just --usage <recipe>`, and `just --show <recipe>`.
    3. `feat/list-fallback-recipes` (`casey/just#1500`): When `set fallback` is enabled (and parent `justfile`s exist up the directory tree), list parent fallback recipes in `just --list` under a `[fallback]` group section.
    4. `feat/wildcard-imports` (`casey/just#1885`): Support glob/wildcard patterns in `import` statements (`import 'just/*.just'`, `import? '.just/*.just'`) expanded in deterministic lexicographical order.
  - Compile the `webomage/just@beta` (`1.59.0`) binary and install it to `~/.local/bin/just` via `just just-apply`.
  - Build and register the `TabLinux` WASM package (`just-1.59.0-w0m.1.tar.gz`) in `w0m-pr/linuxontab` via `just just-wasm`.
  - Add `scripts/just_overlay_sync.py` (and `scripts/tests/test_just_overlay_sync.py`) plus `justfile` recipes (`just just-status`, `just just-sync`, `just just-apply`, `just just-wasm`, `just overlays-status`) and update `project/policies/tools-policy.json` (`just` entry) with `custom_fork: "webomage/just@beta"`.
- **Out:**
  - Opening automated PRs against `casey/just` (remains `automation_mode: "banned"` per `casey/just#3227`).
