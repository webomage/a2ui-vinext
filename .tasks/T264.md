# T264 — 1945's declaration is not a declaration

## Summary

Split out of [[T182]] AC3 on 2026-08-23, when the Artemio half of that ticket was closed and 1945
was the only thing holding it open. T182 is the **import path**; this is **one client's divergence**,
and keeping them in one ticket meant a finished import could not be recorded as finished.

Measured by `just client-inventory` on 2026-08-23, against the estate's 34-key contract:

| | 1945 | Artemio (for contrast) |
|---|---|---|
| keys declared | **16** | 21 |
| missing | **22** | 13 |
| undeclared extras | **4** | 0 |
| `$schema` | **NO** | yes |
| required profile keys (of 8) | **3 declared, 5 missing** | **8 declared, 0 missing** |
| branch · dirty | `beta` · **59 files** | `main` · 0 |

🔑 **The 22 missing keys are not one problem, they are two.** `just client-inventory` reports a
`[WARN]` that **every** client lacks the same **12** keys — `_comment_format`, `backups`, `board`,
`coverage_scan`, `current_plan`, `deploy_logs`, `iac`, `ide_surfaces`, `preflight`,
`skills_governance_scopes`, `supabase_limits`, `tasks_surface`. A gap shared by 4 of 4 clients is a
property of the **import path**, not of a client, and it belongs to [[T182]]. Subtract it and 1945's
own divergence is **10 keys**:

`$schema`, `canonical_repo`, `codegraph`, `grounding_gate`, `mcp`, `root`, `stacks`,
`state_surface`, `toolchain`, `vcs`

⚠️ **`board` entered that shared-12 list on 2026-08-23**, hours before this measurement — [[T242]]
added it to the estate contract. Growing the contract instantly makes every client non-conformant
without anyone touching a client. That is worth a gate of its own and is recorded here because this
ticket is where the number was first read.

**Of the 8 required `client` profile keys, 1945 is missing 5:** `$schema`, `stacks`,
`state_surface`, `toolchain`, `mcp`.

🔴 **`state_surface` is also [[T177]]'s finding**, reached from the other direction: T177 measured
1945 at **725,305 B** of agent-maintained markdown (`STATE.md` 471,382 · `LESSONS.md` 194,499 ·
`SESSIONS.md` 59,424) and named the *absent declaration* as the reason nothing can bound it. **This
ticket does not re-own that.** T177 owns the retention fix and its delivery mechanism; T264 owns the
declaration being wrong. They meet at exactly one key, and the split is deliberate: T177's AC2
requires the adoption step be *performed* against 1945, which will write `state_surface` — so this
ticket must not write it twice.

⚠️ **The 4 extras were recorded as 5 in T182 AC3.** Measured today: `branches`, `description`,
`runner`, `version`. Either one was retired since 2026-08-08 or the original count was wrong; the
ticket that inherits a number inherits the duty to re-measure it, so the count above is today's.

⚠️ **1945 has 59 dirty files and a parallel actor committing in it** ([[T182]] AC6). Any write here
needs coordination first, and read-only measurement is the default.

## Acceptance criteria

- [ ] AC1 — **Each of the 4 undeclared extras is mapped, kept-with-reason, or retired, after
      checking what reads it.** `branches`, `description`, `runner`, `version`. The check is a
      reader search, not a judgement of the name: [[T182]] AC2 established that a quoted-word scan
      attributes readers that do not exist, so each disposition carries a `file:line` or an
      explicit "no reader found, searched X".
- [ ] AC2 — **`$schema` is declared and RESOLVES.** 🔴 Not merely present: `client_profile_check.py`
      already measured that w0m's and Artemio's both point at a `./sdlc.schema.json` that does not
      exist, so both passed every presence check while never being validated. 1945's must resolve to
      `project/client-sdlc.schema.json` (or a copy), and the validator must be *run* once with its
      output recorded.
- [ ] AC3 — **The remaining 4 required keys are declared or carry a recorded exception**: `stacks`,
      `toolchain`, `mcp`, and `state_surface`. ⚠️ `state_surface` is written by [[T177]] AC2, not
      here — this AC is satisfied by T177 having done it, and fails if both tickets write it.
- [ ] AC4 — **`just client-check 1945` runs and its verdict is recorded**, pass or fail. A
      divergence resolved without the gate agreeing is a claim, not a result.
- [ ] AC5 — **The shared-12 gap is NOT closed here.** If work on 1945 incidentally fixes a key that
      all four clients lack, it is reported to [[T182]] rather than absorbed — otherwise the
      import-path defect loses its only evidence, which is that every client shows it.
- [ ] AC6 — **No write to `1945` without recorded owner approval**, per [[T182]] Phase 0 / AC6, and
      coordinated against the parallel actor given the 59 dirty files.
