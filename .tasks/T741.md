# T741 — Build and publish @webomage/a2ui-vinext (A2UI v1.0 renderer for Cloudflare Vinext / Vite RSC + Workers) and contribute to a2ui.org/ecosystem/renderers

## Summary

Build, open-source under Apache-2.0 (`github.com/webomage/a2ui-vinext`), and contribute **`@webomage/a2ui-vinext`** — the first **A2UI v1.0 Renderer & Edge Streaming Adapter tailored for Cloudflare Vinext** (`cloudflare/vinext`, running Next.js App/Pages Router and React Server Components on Vite and Cloudflare Workers `workerd`) — to the official ecosystem directory at **https://a2ui.org/ecosystem/renderers/** (`a2ui-project/a2ui` → `docs/site/src/content/docs/ecosystem/renderers.mdx`).

## Research Grounding (`w0m-sdlc-research`)

1. **Gap Verified in Upstream `a2ui-project/a2ui` (`docs/site/src/content/docs/ecosystem/renderers.mdx`, Apache-2.0):**
   - The directory currently lists **21 community renderers** (`easyops-cn/a2ui-sdk`, `lmee/A2UI-Android`, `sivamrudram-eng/a2ui-react-native`, `zhama/a2ui`, `jem-computer/A2UI-react`, `BBC6BAE9/a2ui-swift`, `shawnwang15/a2ui-vue`, `AGenUI`, `lynx-stack`, `BoteAI/a2ui`, `a2ui-ink`, `a2tea`, `a2term`, `yessGlory17/generative-mui`, `ChaliceForAuri/a2ui-svelte`, `Language-Lit/material3-expressive-a2ui`, `uny/a2ui-compose`, `a2ui-miniprogram`, `xpert-ai/a2ui-react`, `a2ui-3d-renderer`, `AINative-Studio/ai-kit-a2ui`), plus 3 server libraries (`prefab`, `a2ui-go`, `tmc/a2ui`) and 2 related projects (`vercel-labs/json-render`, `thesysdev/openui`).
   - There are **zero `vinext` / Cloudflare Workers RSC edge renderers** and **zero `v1.0` community React/Next.js renderers** listed today (existing React entries target `v0.8`/`v0.9.x` or unversioned client-only bundles).
2. **Upstream Submission & Listing Requirements (`renderers.mdx`, `CONTRIBUTING.md`, `.github/PULL_REQUEST_TEMPLATE.md`):**
   - Public Apache-2.0 or MIT repository (`github.com/webomage/a2ui-vinext`, GPG-signed commits `-S`).
   - Explicit protocol declaration (`v1.0`, `v0.9.1`, `A2UI Express` JSONL/SSE streaming).
   - Coverage of all 18 core Basic Catalog components (`Row`, `Column`, `Card`, `Text`, `Button`, `TextField`, `Select`, `CheckBox`, `Divider`, `Badge`, `Modal`, `Tabs`, `List`, `Icon`, `Image`, `Slider`, `DateTimeInput`, `Audio`/`Video`).
   - Clear installation instructions and minimal runnable starter (`create-vinext-app` example deployed on Cloudflare Workers `workerd`).
   - Signed Google Contributor License Agreement (`https://cla.developers.google.com/`), `./scripts/fix_format.sh`, and fork PR from `github.com/webomage/a2ui` (`w0m-pr/a2ui`) via `just pr-open` (`AgDR-0058`).
3. **Internal Ecosystem Alignment (`T136`, `AgDR-0042`, `T739`, `nextjs-on-cloudflare`):**
   - Aligns directly with `AgDR-0042` (`vinext` dual-track SSR delivery stack alongside Astro) and shares core catalog schemas and `@a2ui/web_core` contracts with `T739` (`@webomage/ui` + `w0m-ext`).

## Acceptance criteria

- [ ] AC1 — Author and validate an OpenSpec change proposal defining `@webomage/a2ui-vinext` architecture: `@a2ui/web_core` integration, React 19 RSC `"use client"` interactive surface boundary, Vite SSR/HMR plugin hooks, Cloudflare Workers `workerd` SSE / `A2UI Express` JSONL stream transformer, and server-side sensitive data binding prior to edge egress.
- [ ] AC2 — Implement all 18 A2UI v1.0 Basic Catalog components plus fail-closed Zod/JSON-Schema catalog validation in `@webomage/a2ui-vinext`, alongside a runnable `examples/vinext-cloudflare-worker` starter using `cloudflare/vinext` (`wrangler.jsonc`, Workers AI / Agents SDK stream endpoint, zero-cold-start SSR + streaming hydration).
- [ ] AC3 — Publish public repository `github.com/webomage/a2ui-vinext` (Apache-2.0, GPG-signed commits `-S`) with a live Cloudflare Workers demo endpoint, passing A2UI protocol conformance checks (`conformance/core/agent_to_renderer.yaml` and `conformance/agent/renderer_capabilities.yaml`).
- [ ] AC4 — Fork `a2ui-project/a2ui` to `github.com/webomage/a2ui` (`w0m-pr/a2ui`), confirm Google CLA coverage, add `@webomage/a2ui-vinext` to `docs/site/src/content/docs/ecosystem/renderers.mdx` (and optional `Agent libraries` row for the Workers edge streaming adapter), run `./scripts/fix_format.sh`, and submit the PR via `just pr-open` (`AgDR-0058`).
