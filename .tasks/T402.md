# T402 — Port governance: enumerate estate ports, resolve port 8788 conflict, and allocate dedicated client project range

## Summary

Owner directive, 2026-09-18: *"I think we already use port 8788 in our llms setup so it looks like it's time to enumerate all ports used by all local apps started and make ports managed and monitored; also it looks like it could be smart to dedicate to clients projects a port range to avoid intersections"*.

Currently, ports are allocated ad-hoc across 7 estate repositories and external services. Live inspection reveals:
1. `8787`: `headroom.cli proxy --port 8787` (Anthropic Cloud proxy)
2. `8788`: `headroom.cli proxy --port 8788 --anthropic-api-url http://127.0.0.1:8888` (Local oMLX proxy)
3. `8788` (Collision): `wom7func` configured `--port 8788` in `wrangler.jsonc` and `stop-dev` in `justfile` (inherited from [[T321]]), directly colliding with the local Headroom daemon.
4. `8888`: `omlx-server` local inference daemon
5. `4321`–`4325`: Astro estate web apps (`web`, `join`, `job`, `demo`, `cp`)
6. Client projects (Artemio, Evercred, etc.) have no reserved port range, risking random collisions when running dev servers concurrently.

This ticket codifies port governance in `project/ports-policy.json`, relocates `wom7func` dev to port `8790`, allocates dedicated client port range `4400`–`4499`, and introduces automated port collision detection via `just ports-check`.

## Acceptance Criteria

- [ ] AC1 — **Codify `project/ports-policy.json`**: Establish the canonical port registry declaring reserved ports for Estate Web Apps (`4321`–`4325`), Tooling (`8765`), Agent Proxies (`8787` cloud, `8788` local), Estate Functions (`8790` `wom7func`), Local Inference (`8888`, `1339`/`1340`), Local Supabase (`54321`–`54328`), and dedicated Client Projects Range (`4400`–`4499`).
- [ ] AC2 — **Relocate `wom7func` Dev Port to 8790**: Update `wom7func/wrangler.jsonc` (`"dev": { "port": 8790 }`), `package.json` scripts, `stop-dev` in `wom7web/justfile`, and fallback URLs in `wom7web/apps/web/src/lib/rpc.ts` / `wom7web/apps/cp/src/lib/rpc.ts` from 8788 to 8790.
- [ ] AC3 — **Author `project/scripts/ports_check.py` & Recipe**: Implement `ports_check.py` that parses `project/ports-policy.json`, audits live listening ports (`lsof -iTCP -sTCP:LISTEN -P -n`), detects illegal squatted ports and unallocated overlaps, and reports clean status. Add `just ports-check` to justfiles.
- [ ] AC4 — **Document Client Port Allocation Standard**: Document in `docs/ECOSYSTEM.md` and `@wom/AGENTS.md` the reserved client port policy (`4400`–`4499`), assigning specific base offsets for active client delivery projects.
- [ ] AC5 — **Automated Test Suite & Quality Gates**: Author `project/scripts/tests/test_ports_check.py` validating collision detection, range boundary enforcement, and clean registry parsing. Verify `just ports-check` and pre-commit/pre-push gates pass organically.
