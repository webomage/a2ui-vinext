# T193 — CODEMAP.md is 6 months stale and hand-maintained

## Summary

Owner report 2026-08-10: *"CODEMAP.md — 🔴 Outdated (Feb 2026). Misses apps/join, apps/job, and
@webomage/ui. Needs automated regeneration via codegraph."*

## 📍 Measured 2026-08-10

`docs/CODEMAP.md` — 10,294 B, header reads **`Generated: 2026-02-16`**.

🔴 **It is worse than "misses three things": it describes a single-app tree that no longer
exists.** Its directory diagram is rooted at `wom7web/src/pages/…`. The repo is now a workspace
of **5 apps** and **5 packages**:

| on disk | in CODEMAP.md |
|---|---|
| `apps/web`, `apps/cp`, `apps/demo`, `apps/job`, `apps/join` | 🔴 **none of them — zero matches for `apps/`** |
| `packages/ui` (`@webomage/ui`), `packages/lib`, `packages/logger`, `packages/crawler`, `packages/mcp-aws-fundamentals` | 🔴 **none — zero matches for `packages/`** |

Grepped for `apps/join`, `apps/job`, `@webomage/ui`, `packages/ui`, `apps/cp`, `apps/demo`:
**0 hits for every one**. So the owner's "misses three" is generous — the file is not a partial
map, it is a map of a previous repo.

⚠️ **Why this is a governance problem and not a stale-doc nit:** it is under `docs/`, it is
phrased as ground truth, and an agent that reads it to orient will look for `src/pages/` and
conclude the apps do not exist. Compare [[T192]] — an agent acted on `w0m skill check`'s wording
and deleted a client's live directory. A confidently wrong map is the same failure mode with a
longer fuse.

## Acceptance criteria

- [x] **AC1 — CODEMAP.md is GENERATED, not hand-written.** A `just` recipe regenerates it; the
      generator, not a person, is the thing that has to be kept current. ⚠️ Regenerating it once
      by hand satisfies nobody — it will be six months stale again by 2027-02.
- [x] **AC2 — the source is the code graph, not a filesystem walk.** `just ask` / codegraph
      already holds the symbol and dependency structure; a `find`-based generator re-invents a
      worse version of it. 🔴 Note the known blind spots before trusting it — codegraph is
      per-repo and **serena/ast-grep cannot parse `.astro` at all** (220 files, the entire
      page/layout layer), so state which tool produced which section rather than implying one
      pass saw everything.
- [x] **AC3 — a staleness gate.** Regenerate and diff; a CODEMAP that no longer matches the tree
      is a finding, the way `just discovery` reports registry↔code drift. Without this AC1 just
      moves the rot from the file to the recipe.
- [x] **AC4 — the red probe.** The gate must be *observed* failing against **today's** CODEMAP.md
      (which misses 10 of 10 workspace members). A drift gate that passes on the known-bad case
      is worthless — the estate's standing rule, and the reason [[T192]] AC3 exists.

## Definition of Done
