# T312 — Unified multi-agent skills governance — consistent, validated, and managed skills for Antigravity, Claude Code, and supported agents across w0m and client workspaces

## Summary

Owner requirement 2026-09-04: *"the requirement is to have consistent validated and managed set of skills in w0m or any other client workspace for supported agents"* and *"mention D32 as P0 task"*.

An audit of agent capabilities across **Google Antigravity (AGY)** and **Claude Code** documented in [`docs/reports/2026-09-04-agent-parity-skills-tools-and-d32-p0-report.md`](../../docs/reports/2026-09-04-agent-parity-skills-tools-and-d32-p0-report.md) revealed critical divergence in how skills and tools are discovered and managed:
1. **Skills Visibility Divergence:** Claude Code attached inside `wom7web/` loads 77 skills (33 native + 44 vendor skills) via `wom7web/.claude/skills` -> `wom7web/.agents/skills`. Antigravity attached at the workspace umbrella root `/Users/proto/Projects/@self/@wom` only discovers 33 native skills via the global plugin `~/.gemini/config/plugins/wom7skills-plugin`, because `@wom` has no `.agents/skills` directory.
2. **Client Workspace Blindspot:** The portable skills installer (`just skills-install-generic` in `wom7skills/scripts/install_generic.ts`) only installs into `<target>/.claude/skills/`. When Antigravity or any agent using the standard `.agents/skills` convention opens a client project, it finds zero skills.
3. **Decided Debt D32 Escalation:** Although [[T294]] established `@wom` as a git repository, the umbrella workspace root lacks `.agents/`, lacks `.claude/skills`, and agent tools remain fractured across `~/.claude.json`, `~/.gemini/config/mcp_config.json`, and `@wom/.mcp.json`. Specifically, Serena LSP is active in Claude Code but absent in Antigravity.
4. **Enforcement Gap:** Skills verification (`just skill check`, `just skills-sync --check`) verifies `wom7web` against its local lockfile, but no test asserts parity across all supported agent runtimes or validates that external client projects have consistent, active skills across multiple agents.

This ticket establishes unified multi-agent skills delivery, governance, and verification for both internal (`w0m`) and external client workspaces.

## Acceptance criteria

- [x] **AC1 — Workspace Root Parity (`w0m` Estate Root):** Link and configure `.agents` and `.claude/skills` at the estate umbrella root (`/Users/proto/Projects/@self/@wom`) so that Antigravity and Claude Code running from the root discover an identical, validated set of skills matching `wom7web`.
- [x] **AC2 — Multi-Agent Generic Skills Installer:** Upgrade `wom7skills/scripts/install_generic.ts` (`just skills-install-generic`) to install into canonical `.agents/skills` and maintain `.claude/skills` (as symlinks or dual paths), ensuring client projects provide skills to both Antigravity and Claude Code.
- [x] **AC3 — Client Workspace Test Probes:** Extend `wom7skills/tests/install_generic.test.ts` to assert that both `.agents/skills` and `.claude/skills` are correctly created, populated, and identical in content for portable skills.
- [x] **AC4 — Tooling & MCP Harness Parity:** Register Serena LSP in Antigravity (`~/.gemini/config/mcp_config.json` and `~/.gemini/antigravity/mcp_config.json`) matching `~/.claude.json`, ensuring AST-aware semantic navigation is available in both Antigravity and Claude Code.
- [x] **AC5 — Skills Sync & Check Multi-Agent Support:** Upgrade `wom7skills/skills.ts` (`just skills-sync`) and `w0m_skill.ts` (`just skill check`) to recognize and validate skills across both `.agents/skills` and `.claude/skills` across root and subrepos.
- [x] **AC6 — Quality Gate Assertion:** Run `just skill check`, `just skills-install-generic-test`, and `just ticket-schema-check`, verifying zero drift and 100% green passing state.

## Definition of Done

Per [`openspec/SPEC-AUTHORING-STANDARD.md`](openspec/SPEC-AUTHORING-STANDARD.md):
All supported agents (Antigravity and Claude Code) discover an identical, validated set of skills when operating at `@wom` root or inside subrepos; `skills-install-generic` installs portable skills into both `.agents/skills` and `.claude/skills` for client workspaces, proven by automated tests in `tests/install_generic.test.ts`; Serena LSP is registered in Antigravity's MCP configuration; and `just skill check` / `just skills-catalogue` pass cleanly.
