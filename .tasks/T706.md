# T706 — Orca Desktop & Mobile Mode: Fix "Take back all" Resizing Only Agent Session Instead of Terminals & Browser Tabs Not Auto-Resizing Without Refresh

## Summary

When mobile mode is enabled in **Orca Mobile** for a browser tab and the operator clicks **"Take back all"** on **Orca Desktop** (`MobileDriverOverlay.tsx` / `use-terminal-pane-mobile-actions.ts`):
1. Clicking **"Take back all"** (`restoreAllTerminalFits`) resizes the agent session PTY (`use-native-chat-mobile-hold-notice.ts` / `getMobileOwnedTerminalPtyIds()`) instead of properly restoring all desktop terminal panes AND reclaiming mobile-driven browser tabs (`reclaimBrowserForDesktop` / `browser-mobile-driver-state.ts`).
2. Reclaiming a mobile-driven browser tab (`reclaimBrowserForDesktop` -> `cancelScreencast` -> `clearDeviceMetricsOverride` in `w0m-pr/orca/src/main/browser/browser-screencast-device-metrics.ts`) calls `Emulation.clearDeviceMetricsOverride` after `applyDeviceMetricsOverride` had also overridden `Emulation.setVisibleSize({ width: viewportWidth, height: viewportHeight })` — without restoring `Emulation.setVisibleSize` to desktop guest bounds or triggering a live viewport re-sync in `browser-page-webview-guest-session.ts`. As a result, the desktop browser tab stays stuck at the mobile viewport size until the user manually refreshes the page.

File an upstream bug issue on `stablyai/orca`, fix both the `"Take back all"` terminal/browser reclaim scope and the live browser tab viewport auto-resize on desktop reclaim in `w0m-pr/orca`, verify locally, and open a GPG-signed upstream PR via `just pr-open`.

## Acceptance criteria

- [ ] AC1 — **Reproduce & File Upstream Issue on `stablyai/orca`:** Document exact reproduction steps (enable mobile mode in Orca Mobile on a browser tab -> click `"Take back all"` on Orca Desktop -> agent session resizes instead of terminal panes, and browser tab fails to auto-resize to desktop viewport until manual refresh) and file the upstream GitHub issue on `stablyai/orca`.
- [ ] AC2 — **Fix `"Take back all"` Desktop Reclaim for Terminal Panes & Mobile-Driven Browser Tabs (`w0m-pr/orca`):** Update `restoreAllTerminalFits` (`w0m-pr/orca/src/renderer/src/components/terminal-pane/use-terminal-pane-mobile-actions.ts` and `w0m-pr/orca/src/main/runtime/terminal/layout/terminal-desktop-reclaim.ts`) so `"Take back all"` restores desktop dimensions and refits all held terminal panes (not just the agent session PTY) AND reclaims all mobile-driven browser tabs (`reclaimBrowserForDesktop`).
- [ ] AC3 — **Fix Browser Tab Immediate Auto-Resize on Desktop Reclaim Without Refresh (`w0m-pr/orca`):** Update `clearDeviceMetricsOverride` (`w0m-pr/orca/src/main/browser/browser-screencast-device-metrics.ts`) and desktop browser guest viewport synchronization (`w0m-pr/orca/src/renderer/src/components/browser-pane/host-guest/browser-page-webview-guest-session.ts` / `browser-manager-viewport.ts`) so reclaiming a browser tab from mobile mode immediately restores `Emulation.setVisibleSize` and desktop viewport metrics without requiring a page reload.
- [ ] AC4 — **Automated Tests & Upstream PR Submission:** Add unit/integration tests covering `"Take back all"` across terminal panes + mobile-driven browser tabs and immediate browser viewport auto-resize on reclaim, apply locally (`just orca-apply`), and open a GPG-signed PR from `webomage/orca` to `stablyai/orca` via `just pr-open`.
