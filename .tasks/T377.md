# T377 — Refactor wom7open into wom7pr and build continuous fork synchronization verification tooling

## Summary

Owner directive, 2026-09-18: *"verify forks all the time up to date and also let's actually refactor/rename wom7open into wom7pr"*, followed by *"we also should have fetch/info/update/etc just helpers for PRs registry management"*.

The workspace maintains 6+ open-source forks (`jundot/omlx`, `casualuser/headroom`, `stablyai/orca`, `cirruslabs/tart`, `openai/tart-guest-agent`, `AgriciDaniel/claude-obsidian`).
This ticket executes:
1. Workspace directory refactor: `wom7open` -> `wom7pr`, updating excludes scripts, root `.git/info/exclude`, and recipe citations.
2. Fork synchronization verification: adds `forks` subcommand to `w0m_prs.py` and estate recipes (`just forks`, `just forks-check`) to continuously check branch alignment, ahead/behind counts against `upstream/main` and `origin`, and working tree cleanliness.
3. Compatibility aliasing: updates presets in `w0m_prs.py` so both `wom7pr` and legacy `wom7open` work seamlessly.
4. Helpers for fork/PR management: adds `fetch`, `info`, and `update`/`sync` subcommands and `just` recipes (`just forks-fetch`, `just forks-info`, `just forks-update`, `just forks-sync`).
5. Unit tests and skill synchronization.
