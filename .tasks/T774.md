# T774 — Fix Telegram & Meta Threads hiring search errors and support multi-currency, multi-timezone discovery with per-user saved defaults

## Summary

Fixes the production `Unexpected token 'M', "Middleware"... is not valid JSON` failure and credential-vault errors in `SocialHiringSearch.svelte` + `/api/jobs/social-search`, hardens API 500 responses in `createAuthMiddleware`, wires `CONNECTOR_TOKEN_KEY_VERSION` / `CONNECTOR_TOKEN_KEY_V1` into `sync-me-secrets` / `sync-cp-secrets` / `deploy-me`, and upgrades Telegram & Meta Threads discovery + UI filters to support multi-currency compensation (`USD/USDT/USDC`, `CAD`, `EUR`, `GBP`, `AUD`), multi-region timezones (`EST/Americas`, `Strict EST`, `EU/EMEA`, `APAC`, `Worldwide`), cross-stack expansion (`DevOps/SRE`, `Full-Stack`, `Backend`, `AI/ML`), and **per-user saved default search preferences** (`connections.profile_data.search_preferences`) while keeping the baseline search unopinionated.

## Acceptance criteria

- [x] AC1 — Eliminate `Middleware Error` plain-text JSON crash and credential persistence defects: `createAuthMiddleware` returns JSON `500` on `/api/*` errors; `crypto.ts` exposes explicit `CONNECTOR_TOKEN_KEY_V1` reads and `hasEncryptionKeyMaterial()`; `/api/jobs/social-search` wraps `GET`/`POST` in structured `try/catch`, omits fabricated encryption payloads when no Telegram token is provided, fails closed (`503` JSON) on Threads/TG token encryption if key material is absent, reads `public.connections` non-secret columns safely while decrypting member-scoped encrypted tokens server-side via canonical `adminClient()` (registered in `authz-admin-client-baseline.json`), batches `outreach_clips` vault saves into a single deduplicated upsert, and wires `CONNECTOR_TOKEN_KEY_VERSION` + `CONNECTOR_TOKEN_KEY_V1` into `sync-me-secrets`, `sync-cp-secrets`, and `deploy-me`.
- [x] AC2 — Upgrade `@webomage/lib/connectors/{telegram,threads}-job-source.ts`: decode numeric HTML entities (`&#036;` -> `$`), add live-verified cross-stack & Remote/USD Telegram channels (`remoteok`, `remote_jobs_feed`, `remotejobs`, `remoteit`, `cryptojobslist`, `web3hiring`, `devops_vacancies`, `sysadmin_jobs`, `cryptojobs`, replacing bare-link `cloud_devops_jobs`), filter Lyzem and course/stats noise, upgrade Threads public discovery to high-yield 1–2 word `serp_type=default` + `tags` queries (`hiring devops`, `devops remote`, `DevOps`, `hiring remote`), exclude job-seeker self-promotion posts (`Any engineering teams hiring...`), parse multi-currency compensation (`USD`/`USDT`/`USDC`/`CAD`/`EUR`/`GBP`/`AUD`, hourly/monthly/annual, trailing-`$` and `&#036;`, excluding `~$0k`), classify timezone regions (`americas_est`, `eu_emea`, `apac`, `ru_cis`, `worldwide_async`, `unspecified`), expand DevOps/SRE, Full-Stack, and Backend/AI synonyms neutrally, and cap external fetches within Cloudflare Workers subrequest limits.
- [x] AC3 — Enhance `SocialHiringSearch.svelte` and `/api/jobs/social-search` with per-user saved default preferences & multi-currency UI: use `readJsonSafe` for all fetches, keep default initial filters neutral (`Any` currency/timezone, `remoteOnly: false`), add `POST action: "save_preferences"` and `"reset_preferences"` persisting `defaultQuery`, `remoteOnly`, `currency`, `timezone`, and `channels` in `public.connections.profile_data.search_preferences` (plus `localStorage` fallback), preserve `search_preferences` during `save_credentials`, add optional starter presets (`DevOps / SRE (USD · EST)` and `Full-Stack (CAD · Americas)`), interactive Remote / Currency (`Any`/`USD`/`CAD`/`EUR`/`GBP`/`AUD`) / Timezone (`Any`/`EST`/`Strict EST`/`EU`/`APAC`/`Worldwide`) / `Save as My Default` buttons, filtered-count breakdown with 1-click reset, multi-currency salary badges, and clean copy with zero ticket identifiers.
- [x] AC4 — Full unit, route, security, DS, and live discovery verification: passing tests across `middleware.spec.ts`, `connector-framework.spec.ts`, `telegram-job-source.test.ts`, `threads-job-source.test.ts`, `apps/cp/src/tests/api/jobs/social-search.test.ts`, clean `oxlint` and sequential `apps/me` + `apps/cp` builds, `just authz-admin-client --enforce`, `just secret-flow-check --enforce`, `just ui-ticket-leak-check`, `just ds-conformance`, `just spec-policy-check`, `just spec-drift`, `just mmd-validate`, `reports_ticket_check.py`, `lessons_check.py`, and dual-profile live discovery verification (`DevOps + USD + EST` and `Full-Stack + CAD + EST/Americas`).
