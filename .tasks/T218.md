# T218 — Adopt the official Upwork MCP for interactive work

## Summary

`.w0m/sdlc.json → mcp.servers.upwork` already **declares** the official server
(`https://mcp.upwork.com/mcp`, `transport: remote`, `enabled: true`) — *"OAuth 2.1; job discovery,
proposal drafting, live contract/milestone tracking, talent search"*. It has never been
**authorized**: it appears in the session-start "requires authentication" list, so zero tools are
reachable. Declared ≠ configured ≠ connected — the distinction [[T154]] exists to keep honest.

### 🔴 The MCP does NOT replace `UPWORK_API_KEY` — they cover disjoint halves

| | Upwork MCP | `UPWORK_API_KEY`/`_SECRET` |
|---|---|---|
| Auth | OAuth 2.1, **per interactive session** | stored credentials |
| Can run unattended | ❌ no session to authenticate with | ✅ |
| Drives | job discovery, proposal drafting, contract/milestone tracking, talent search | `upwork-poller` (fired on a **cron** — `wom7cfworkers/src/index.ts:603`), `upwork-callback`, `_shared/upwork.ts`, `src/utils/upwork-client.ts` |

A Supabase edge function and a Cloudflare cron have **no session to OAuth with**, so the poller
keeps its key. Anyone proposing "move Upwork to MCP and drop the key" is proposing to break the
scheduled ingestion. The genuine win is the *interactive* half, where the MCP also sidesteps a
contract this estate has already paid for: Upwork's GraphQL needs `room.stories` with
`filter:StoryFilter` (pagination nested), and errors are swallowed into **silent empty syncs**.

### The account map (from `_shared/upwork.ts`, not inferred)

| Context | Credentials | Status |
|---|---|---|
| **freelancer** (`UPWORK_*`, unprefixed) | `UPWORK_API_KEY`/`_SECRET` | ✅ **HELD** |
| agency (`UPWORK_AGENCY_*`) | — | ⛔ never granted (owner, 2026-08-15) |
| client (`UPWORK_CLIENT_*`) | — | ⛔ never granted |

The four empty agency/client secrets were **deleted 2026-08-15** — verified behaviour-neutral: the
constructor already fell through on falsy empty strings, and the **token probe** (`context_missing_user`)
is the real guard, not the API key.

### Can wom7ext call it? — researched, and the answer is "wrong layer"

**wom7ext is already an MCP *server***, not a client: `mcpService.ts:176` connects over
`WebSocketClientTransport` to a **local** bridge (`ws://localhost:8008`, `@mcp-b/websocket-bridge`),
and `agentBridge.ts` documents the flow as `Claude → wom7ext → ws:8008 → gateway → agent`. Making it
*also* a remote-MCP client would need: `https://mcp.upwork.com/*` in `host_permissions` (absent),
the `identity` permission for `launchWebAuthFlow` (absent), a second **HTTP** MCP transport
alongside the WebSocket one, and **OAuth tokens stored in a client-distributed artifact**.

⚠️ **And it would duplicate auth the extension already has.** Its value on upwork.com is that it
holds the **user's own logged-in session** in the DOM (`https://www.upwork.com/*` host permission).
The MCP's value is structured server-side access. The composition that needs no new plumbing:
**one orchestrator connects to BOTH** — the extension for DOM-level actions in the user's session,
the Upwork MCP for structured data. Two clean roles, no token duplication.

## Acceptance criteria

- [ ] **AC1 — Authorize and prove reachable.** Complete the OAuth 2.1 flow (interactive session,
      `/mcp`) and record the **tool list actually returned**. A server that is `enabled: true` in
      config and unauthorized in practice is the exact "listed ≠ connected" failure [[T154]] names.
- [ ] **AC2 — Map tools to the work they replace or add.** For each returned tool, state whether it
      **replaces** an existing GraphQL call site, **adds** a capability, or **overlaps** the poller.
      Overlap is a decision, not a coincidence.
- [ ] **AC3 — The unattended path is explicitly unchanged.** `upwork-poller` and `upwork-callback`
      keep `UPWORK_API_KEY`; no work in this ticket removes it. Prove the poller still runs after
      any change.
- [ ] **AC4 — Decide wom7ext's role in writing.** Either "extension stays an MCP server; the
      orchestrator calls both" (the researched default) **or** a justified case for adding a remote
      HTTP client to the extension, naming the manifest permissions, the token-storage model and
      who reviews it.
- [ ] **AC5 — Record it where the estate looks.** `.w0m/sdlc.json` reflects the real state, and
      `just mcp-exposure` (T154) is re-run so declared-vs-connected stays measured.
