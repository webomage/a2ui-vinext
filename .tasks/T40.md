`deno check` was failing across the Supabase Edge Functions, so the api repo had no type gate on
its edge runtime at all. The original row scoped this as type safety ("resolve type errors across
Edge Functions"), sourced from `w0m_project_diagnosis_audit.md`.

🔑 **The finding that made this a P0 rather than a cleanup:** the type errors were not cosmetic —
**four functions were runtime-broken**, and one of them was crashing *every* request. Fixing the
types was the mechanism that surfaced live outages nobody had reported.

The systemic cause of the bulk of the errors was a `supabase-js` generic skew (`.update()`
resolving to `never`), resolved by typing the edge-function client and helper params `any` — a
deliberate widening, not a fix of the underlying generics.
