# T693 — TabLinux Easy Clipboard / Paste & Terminal UX

## Summary

Eliminate clipboard and command-paste friction in TabLinux (`next.linuxontab.com`) and the embedded CP Crew Toolkit console (`w0m-web/apps/cp/src/components/admin/CrewToolkitAndTabLinuxConsole.svelte`) by wiring a zero-permission DOM `paste` listener, `Ctrl+V` / `Ctrl+Shift+V` / `Shift+Insert` keyboard shortcuts, top-bar `Paste` + `Copy` controls, a multi-line fallback modal, and a cross-frame `postMessage` (`tablinux:paste`) bridge into `window.lot_stdin_bytes`.

## Acceptance criteria

- [x] AC1 — **Bidirectional Terminal Clipboard Bridge (`clipboard-bridge.js`, `pip-shell.html`):** Implemented `window.TabLinuxClipboard` in `clipboard-bridge.js`, wiring zero-permission DOM `paste` events, `Ctrl+V`/`Ctrl+Shift+V`/`Shift+Insert` keyboard shortcuts, `#lot-paste-btn` / `#lot-copy-btn` top-bar buttons, and the `#lot-paste-modal` multi-line fallback modal into `window.lot_stdin_bytes` across both TabLinux shell surfaces.
- [x] AC2 — **Cross-Frame `postMessage` Command Dispatch (`w0m-web/apps/cp/src/components/admin/CrewToolkitAndTabLinuxConsole.svelte`):** Added the interactive TabLinux command & clipboard bar (`data-testid="tablinux-clipboard-dispatch-bar"`, `data-testid="tablinux-paste-run-btn"`, `data-testid="tablinux-paste-only-btn"`) in `w0m-web/apps/cp/src/components/admin/CrewToolkitAndTabLinuxConsole.svelte` that dispatches `{ type: "tablinux:paste", text, appendNewline }` directly to the embedded TabLinux iframe (`data-testid="tablinux-iframe"`).
- [x] AC3 — **Cloudflare Asset Build & Automated Verification (`cloudflare-build.ts`, `cloudflare.test.ts`):** Updated `cloudflare-build.ts` to bundle `clipboard-bridge.js` into the Cloudflare Pages asset output and verified with `node --test cloudflare.test.ts` (`7/7` tests passing).

## Status notes

- **2026-11-09 (`agy:tablinux-mesh-phase2`)**: Implemented `clipboard-bridge.js`, wired into `pip-shell.html`, `cloudflare-build.ts`, and `w0m-web/apps/cp/src/components/admin/CrewToolkitAndTabLinuxConsole.svelte`. Verified with `node --test cloudflare.test.ts` (`7/7` passed).
- **Lessons learned**: Recorded in `LESSONS.md` — browser `navigator.clipboard.readText()` often fails or prompts inside cross-origin/COOP/COEP iframes; always pair `readText()` with a zero-permission `document.addEventListener("paste")` listener, a `postMessage` (`tablinux:paste`) bridge, and an in-surface fallback `<textarea>` modal.
