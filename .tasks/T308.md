# T308 — own the `~/Projects` estate inventory audit

## Summary

The Antigravity agent dropped `2026-09-03-projects-inventory-audit.md` into `_in/`: a 96-project,
163.69 GB scan of `~/Projects` with a 29.51 GB reclaimable-space breakdown and a "Governance
Status" table checking each project for `.w0m` contract / `CLAUDE.md`-`AGENTS.md` / `Justfile`
presence. Owner direction: *"let's own it"*.

**The governance table repeats T307's own class of mistake.** It checked each of `wom7api`,
`wom7cfworkers`, `wom7ext`, `wom7mlx`, `wom7sec`, `wom7skills` for its **own** `.w0m/sdlc.json` and
found none, flagging 6 of 7 canonical repos as ungoverned. Verified live (`ls`, not trust): only
`wom7web` has that file — because this estate governs the other six **centrally**, through
`wom7web/.w0m/sdlc.json → repos` (`{"web":"wom7web","api":"wom7api","cf":"wom7cfworkers",
"ext":"wom7ext","sec":"wom7sec","skills":"wom7skills","mlx":"wom7mlx/wom7mlx"}`). This is the exact
failure `AGENTS.md` already names — *"measure from the root the CONFIG declares, not the one you
assume"* — reproduced by a fresh audit. `k7tg` in the same table likely carries the identical false
positive: it is declared under `k7d`'s workspace `.w0m/sdlc.json` per [[T307]], not standalone.

This ticket owns following through on the audit rather than letting it sit as an unactioned drop:
reclaim the disk space that is genuinely safe to reclaim, correct the false finding before it
propagates, and give every other flagged project an explicit disposition instead of silence.

## Acceptance criteria

- [ ] AC1 — Reclaim safe, regenerable build-artifact space (`node_modules`, `dist`, `.astro`,
      `.next`, `target`, `.venv` caches) across the 7 canonically w0m-governed repos (`wom7web`,
      `wom7api`, `wom7cfworkers`, `wom7ext`, `wom7mlx/wom7mlx`, `wom7sec`, `wom7skills` — the
      audit measured roughly 15.8 GB combined there). Check for a running dev/build/model-serving
      process touching each path before deleting it, and confirm the repo rebuilds cleanly after
      (`pnpm install` / `cargo build` / venv recreate as applicable).
- [ ] AC2 — Correct the audit's Governance Status table: `wom7api`/`cf`/`ext`/`mlx`/`sec`/`skills`
      ARE governed, centrally, via `wom7web/.w0m/sdlc.json → repos` — not ungoverned. Record this
      in a followup note so the false finding isn't repeated in a future audit or acted on by
      another agent.
- [ ] AC3 — For non-w0m projects the audit flagged with a real (not centrally-governed-elsewhere)
      gap — `barterbackup`, `solar@rise`, `wedding`, `mallow`, `k7tg` lacking `.w0m`/`CLAUDE.md`/
      `AGENTS.md` — record an explicit disposition per project (govern under w0m / leave as
      personal scope / explicitly excluded with a reason). No blanket import. Do not touch any
      project carrying uncommitted dirty files (🔴 74 in `1945`, 56 in `barterbackup`, 14 in
      `solar@rise`, 11 in `k7tg`, per the audit's own table) without confirming those aren't
      in-progress work — a dirty tree is someone's unfinished session, not debris.
- [ ] AC4 — Leave `_arc` (30 archived projects, 41.68 GB, ~767 MB reclaimable — not worth the
      churn) and anything outside `@self/@wom`/`@self/@k7` untouched. In particular `Evercred` is
      **deliberately unmanaged** (owner decision, sandbox-substrate direction) — this ticket does
      not extend w0m governance or cleanup into another person's or another agent's scope.
- [ ] AC5 — Drop the AC2 correction (and AC1's actual-vs-claimed reclaim numbers) into `_in/` as a
      followup note, same channel the audit itself used, so whoever reads
      `2026-09-03-projects-inventory-audit.md` next sees the correction alongside it.

## Definition of Done

Safe disk space is reclaimed in the 7 canonical repos, each confirmed to still build/run after.
The audit's governance-status false positive is corrected and the correction is recorded where the
audit itself is readable. Every other project the audit's scope touches has an explicit, written
disposition — governed, left alone, or excluded with a stated reason — rather than being silently
ignored or unilaterally acted on.
