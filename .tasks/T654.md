# T654 — Orca Desktop & Mobile: throttle terminal/chat redraws & SIGWINCH bursts, enforce light/dark agent session themes, build 22-branch v1.4.251-w0m.2 overlay + CLI repair, and guard Obsidian vaults

## Summary

1. **Desktop Chat/Terminal Redraw & `SIGWINCH` Throttling**: Suspend hidden/chat-covered xterm WebGL rendering + gate background PTY delivery when `NativeChatPaneCover` covers a pane, enable cross-platform DEC `?2026` synchronized-output holding without stripping POSIX `?25h`, coalesce non-echo foreground PTY writes per `rAF` and skip redundant non-ConPTY DOM viewport double-refreshes under WebGL, pause hidden `useNativeChatPacedText` 60fps `rAF` loops, cold-park inactive `StructuredAgentSessionPaneOverlayLayer` tabs, tighten hot-retain caps (`maxHotPanes = 4`), gate `createReattachGridPush` `SIGWINCH` on actual dimension deltas, stop settled `foreground-grid-drift-probe` polling, float `SessionRestoredBanner` without layout row shifts, scope `RetainedPaneHost` fit events, and extend `pty-resize-repaint-hold` dynamically across active rewrite bursts.
2. **Mobile Tab Caching & Scroll Stability**: Retain a bounded LRU (`3`) of initialized `TerminalWebView` sessions across tab switches with `preserveScroll: true` instead of tearing down and re-initializing `512 KB` scrollback on every tab hide, unmount evicted WebViews past the LRU cap, debounce transient height-only `SIGWINCH` refits, avoid mid-`?2026` `flushNow()` during `readPromptBackload`, memoize `TerminalPaneView`, and `rAF`-coalesce `useZoomStableViewport` scroll syncs.
3. **Agent Session Light/Dark Theme Fidelity**: Fix agent sessions rendering with black backgrounds instead of following light/dark theme across Desktop `TerminalPane` / `StructuredAgentSessionPaneOverlayLayer`, Mobile `TerminalWebView` (`setTheme` + pre-hydration HTML), and PTY `OSC 10/11` + `CSI ? 996 n` / DEC `2031` TUI color-scheme queries.
4. **Overlay Reconciliation (`22/22` Active Branches, `0` Skipped) & Local Linux `orca` CLI Repair**: Reconcile all 22 active `webomage/orca` branches + 5 `overlay/*` adaptations onto `stablyai/orca@v1.4.251` (`0` skipped, all 6 Orca CI gates green), ship and install `v1.4.251-w0m.2` (`42164014594`), register all 20 upstream PR proposals in `scripts/w0m_prs.py`, and wire native AppImage CLI extraction + `# orca-serve-bare-orca-dispatcher` / `linux-orca-cli-shim` repair into `scripts/orca_overlay_update.py`.
5. **Intelligent Obsidian Vault Survivability**: Isolate live unstaged Obsidian vault edits and `.obsidian/*.json` plugin/UI drift from `deploy_cert.py` (`AgDR-0025` preserved for staged or non-vault changes) and `preflight.py`, and 3-way merge `.obsidian/*.json` + Markdown notes during `session_complete.py` canonical fast-forwards (`scripts/obsidian_vault_guard.py`).
