# T777 — Allow deleting workspace-owned design systems when team share transport is unconfigured

## Summary

Signed-in users in OpenDesign cannot delete their own workspace-owned design systems (`DELETE /api/design-systems/:id`) when the team resource share transport is unconfigured (default local `OD_WORKSPACE_CONTEXT_SOURCE` without Vela resource transport). `deleteDesignSystemForRequest` (`apps/daemon/src/routes/design-systems.ts`) calls `unshareTeamDesignSystemIfShared`, which calls `unshareIfCurrentlyShared` (`apps/daemon/src/collab/team-resource-share.ts`). When `createTeamResourceShareService` is unconfigured (`configured: false`), its `sharedResources(..., { authoritative: true })` stub unconditionally throws `authoritative Team resource listing is unavailable`, turning every delete into HTTP `503` (`TeamResourceAuthorityUnavailableError`) and showing `"Something went wrong. Please try again."` in the UI.

Short-circuit `unshareIfCurrentlyShared` when `service.configured === false` while preserving fail-closed `TeamResourceAuthorityUnavailableError` behavior whenever `service.configured !== false`, add unit + HTTP route regression tests, verify on Node v24.22.3 + live `:7456` daemon, register the upstream PR in `scripts/w0m_prs.py`, and close out cleanly.

## Acceptance criteria

- [x] AC1 — Upstream daemon fix (`team-resource-share.ts`): `unshareIfCurrentlyShared` accepts optional `configured?: boolean` on `service` and returns `false` when `service.configured === false`, while keeping `TeamResourceAuthorityUnavailableError` fail-closed when `service.configured !== false`.
- [x] AC2 — Upstream tests (`design-system-delete-unshares-team-share.test.ts`, `team-resource-share.test.ts`): verify HTTP `204` delete succeeds when `createTeamResourceShareService` has `configured === false` (`env: {}`), `unshareIfCurrentlyShared` returns `false` for `configured: false`, and live-hub failures with `configured: true` still throw `TeamResourceAuthorityUnavailableError`.
- [x] AC3 — Verification, integration & PR registration: Node v24.22.3 `@open-design/daemon typecheck`, `pnpm guard`, and targeted daemon Vitest suites pass with zero public-leak strings; `fix/design-system-delete-unconfigured-share` is GPG-signed & pushed to `webomage/open-design`, merged into `local/sdlc-integration`, restarted on `:46237`/`:7456`, and registered in `scripts/w0m_prs.py` (`AgDR-0058` owner gate respected).
