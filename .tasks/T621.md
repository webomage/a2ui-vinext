# T621 — Implement Orca mobile triple-tap Enter PR branch, Live Input terminal prompt backload, and mobile/desktop subagent flat/tree modes + Floating agents category

## Summary

Deliver three single-concern, GPG-signed UX enhancements across Orca Mobile and Orca Desktop on `webomage/orca`: (1) an upstream-ready PR branch (`feat/mobile-terminal-triple-tap-enter`) enabling triple-tap on the mobile terminal viewport to send `Enter` (`\r`) immediately in interactive TUI dialogs (such as Antigravity selection/comment prompts); (2) automatic active-prompt backloading and per-tab session retention in mobile Live Input (`fix/mobile-live-input-prompt-backload`); and (3) default-enabled subagent display alongside agents (`flat` default with `CornerDownRight` subagent indicator icon) or as a collapsible `tree` under the parent agent—paired with Antigravity subagent roster tracking and a collapsible **Floating** agents category on both mobile and desktop (`feat/subagent-display-and-floating-category`)—integrated onto `webomage/orca:beta` (`c5e23497666`).
