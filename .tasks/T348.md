# T348 — Project types taxonomy and @mob mobile apps onboarding

## Summary

Owner directive, 2026-09-12:
*"and new addon - we have to use types of projects:
indie - when one person have PM,TPM,Dev all assigned to one
startup 
audit/consulting
software development
infra arch and meintain

let's also create P2 to put mobiles apps we have next to w0m workspace as Indie projects for Aleksei
and also Aleksei here the client"*

This ticket delivers:
1. **Canonical 5-tier Project Types Taxonomy:**
   - `indie`: Solo-operator model where one person holds `pm`, `tpm`, and `dev` hats simultaneously.
   - `startup`: Multi-role agile venture team.
   - `consulting`: Advisory, audits, security reviews, and compliance.
   - `software_development`: Custom full-stack software development.
   - `infra_maintenance`: Infrastructure architecture, cloud DevOps, and ongoing maintenance.
2. **Admin CP Projects Surface Enhancement:**
   - Update `ProjectManager.svelte` to support project type selection, visual badges, and type filtering.
   - Provide an Indie automated hat assignment helper (assigns `pm`, `tpm`, and `dev` delivery roles to the designated builder in `project_roles` and `hats`).
3. **Onboarding @mob Mobile Apps Portfolio:**
   - Register mobile apps from `/Users/proto/Projects/@self/@mob` (`solar`, `mantrabox`, `birds-echo`) in `project/clients-policy.json`.
   - Set client to Aleksei (`aleksei@webomage.com` / casualuser) as the client/patron organization, while simultaneously acting as the Indie Operator holding PM/TPM/Dev delivery roles.

## Acceptance criteria
