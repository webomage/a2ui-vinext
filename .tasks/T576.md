# T576 — Telegram & Meta Threads Automatic Channel, Group & Community Discovery

## Goal

Upgrade Telegram (`TG`) and Meta Threads hiring post search so that every keyword search automatically discovers and scans **all matching Telegram channels and public groups** (via multi-stack seed ecosystem, Lyzem `channels`/`groups`/`messages` index discovery, and snowball `@handle` / `t.me/` link spidering from group/channel descriptions and forwards) as well as **all matching Meta Threads topic communities / groups and public posts** (via both the official Threads Graph API `keyword_search` and public `threads.net/search?serp_type=default|tags` SSR JSON discovery).

## Acceptance Criteria

- [x] **AC1 — Telegram Channel & Group Discovery Engine (`@webomage/lib/connectors/telegram-job-source.ts`)**:
  - Expands the curated Telegram hiring seed registry across channels (`*_jobs_feed`, `remocate`, `remoteit`, `devjobs`, `startupjobs`, `data_science_jobs`, `product_jobs`, `work_in_it`) and paired public groups (`devops_jobs`, `rust_jobs`, `python_jobs`, `golang_jobs`, `qa_jobs`, `javascript_jobs`, `nodejs_jobs`, `frontend_jobs`, `backend_jobs`).
  - Adds `discoverTelegramChannelsAndGroups(query)` querying Telegram index search (`f=channels`, `f=groups`, `f=messages`), inspecting `t.me/<handle>` group/channel metadata (`kind: "channel" | "group"`, subscriber/member counts, description), and spidering snowball `@handle` / `t.me/<handle>` links (automatically resolving group → paired broadcast feed links).
  - Returns both deduplicated hiring posts (`matches`) and `discoveredEntities` (`TelegramDiscoveredEntity[]` with `kind: "channel" | "group"`, `title`, `stats`, `linkedHandles`, `vacancyCount`, `discoveredVia`).
- [x] **AC2 — Meta Threads Topic Community / Group & Public SSR Discovery Engine (`@webomage/lib/connectors/threads-job-source.ts`)**:
  - Adds public SSR search & topic-tag community discovery (`https://www.threads.net/search?q=<query>&serp_type=default` and `serp_type=tags`) alongside the official Meta Threads Graph API (`https://graph.threads.net/v1.0/keyword_search`), so Threads hiring search and topic community discovery work out-of-the-box even without an OAuth token and combine both sources when a member/estate token is connected.
  - Extracts `discoveredCommunities` (`ThreadsDiscoveredCommunity[]` for Threads `tag_header` topic communities like `Remote Jobs`, `WFH Threads`, `HIRING NOW`, `Tech Threads`, `#hashtag` groups, and active hiring accounts).
- [x] **AC3 — Background Cron & Workflow Discovery (`w0m-api`, `w0m-cf`)**:
  - Updates `w0m-api/src/utils/job-sources/telegram.ts`, `w0m-api/src/utils/job-sources/threads.ts`, and `w0m-cf/src/lib/job-boards.ts` to use expanded channel/group discovery and Threads public SSR + Graph API discovery.
- [x] **AC4 — Social Search API & Interactive Discovery UI (`w0m-web`)**:
  - Updates `POST / GET /api/jobs/social-search` (`apps/cp` + `apps/job`) to return `discoveredTelegram` (channels + groups) and `discoveredThreadsCommunities` (topic communities + hiring profiles).
  - Updates `SocialHiringSearch.svelte` with auto-discovery toggle, a **Discovered Channels, Groups & Topic Communities** explorer showing `CHANNEL` vs `GROUP` vs `THREADS TOPIC` badges, member/subscriber stats, linked feeds, and one-click **Pin to My Channels/Groups** or **Filter by Community**.
  - Unit tests pass across `packages/lib` and `w0m-api`.
