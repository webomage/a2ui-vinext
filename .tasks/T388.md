# T388 — Add just recipes for code-review-graph visualizer server and graphify visual dashboards

## Summary

Owner directive, 2026-09-18:
> *"let's make for code-review-graph just helper for "Option A" and all commands for graphify also need just helpers"*

Following the evaluation of visual knowledge and code exploration tools, this ticket adds standard, ergonomic `just` recipes in `wom7api/justfile` (shared canonical justfile) and workspace root `@wom/justfile` forwarders to launch, serve, and open interactive visual dashboards for `code-review-graph` (CRG) and `graphify`:

1. **`code-review-graph` visualizer server**:
   - `just crg-serve [repo="wom7web"]`: Runs `code-review-graph visualize --repo <repo> --data-dir ~/.cache/code-review-graph/<repo> --serve` (spawns local HTTP server on `http://localhost:8765`).
   - `just crg-open [repo="wom7web"]`: Generates and opens the static D3 graph HTML in the browser.
2. **`graphify` visual dashboards and queries**:
   - `just graph-tree [repo="wom7web"]`: Generates D3 v7 collapsible tree HTML (`graphify tree`) and opens it in browser.
   - `just graph-callflow [repo="wom7web"]`: Exports Mermaid multi-section call-flow HTML (`graphify export callflow-html`) and opens it in browser.
   - `just graph-query query`: Runs semantic query over graph (`graphify query`).
   - `just graph-explain concept`: Explains concept subgraph (`graphify explain`).
3. **Workspace Root Forwarders**: `@wom/justfile` delegates all recipes to `wom7web/justfile`.
