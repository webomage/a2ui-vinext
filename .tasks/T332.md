# T332 — Allow connecting ProductHunt to user profiles

## Summary

Allow users and guild members to connect their ProductHunt account to their user profile in the Webomage Control Panel (`apps/cp`). This enables member identity verification for ProductHunt makers, launch tracking, and social proof, integrating directly with our marketing, directory submissions, and launch workflows.

## Acceptance criteria

- [x] AC1 — UI Integration: Add a ProductHunt connection input field with branding/icon inside `apps/cp/src/components/admin/ConnectedServices.svelte` under "External Service Mapping & Identities".
- [x] AC2 — Validation & Link Generation: Validate ProductHunt username syntax and render a direct link to `https://www.producthunt.com/@<username>` for quick profile verification.
- [x] AC3 — State Persistence: Ensure the ProductHunt username/mapping persists across page reloads via localStorage and user profile state.
- [x] AC4 — Profile Integration & Display: Surface connected ProductHunt status badge on member cards or public profile view when linked.
- [x] AC5 — E2E / Specification Coverage: Add Gauge/Playwright E2E scenario in `apps/cp/specs/web/admin_profile.spec` validating the ProductHunt field input, save, and persistence behavior.
