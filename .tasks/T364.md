# T364 — w0m automated services expansion: LATAM corporate & personal KYC (CR, PA, BR, CO, AR, CL, PE) and client subscription/trial access gating

## Summary

Expand w0m's automated capability layer across two tightly linked commercial pillars:
1. **LATAM Corporate & Personal Verification**: Generalize `@wom/kyc` beyond Mexico to Latin America, delivering official corporate (legal entity) and personal (individual) verification engines for **Costa Rica** (Cédula Jurídica / Identidad, Hacienda ATV, Registro Nacional), **Panama** (RUC with DV, DGI, Registro Público, Cédula Electoral), and major South American economies (**Brazil** CNPJ/CPF/Receita, **Colombia** NIT/CC/DIAN/RUES, **Argentina** CUIT/CUIL/ARCA, **Chile** RUT/RUN/SII, and **Peru** RUC/DNI/SUNAT).
2. **Client Subscription & Trial Access Tiers**: Establish durable service access tiers and quota gating in `public.clients` for w0m clients, governing access across both automated services:
   - **Automated Security Audit (3 Levels)**: Level 1 (Public URL lead magnet, standard/unlimited), Level 2 (Air-gapped Code SAST/SCA Sandbox, trial capped at 1 demo scan <=50k LOC vs uncapped paid), and Level 3 (Deep Cloud Infrastructure & FinOps Posture via `@k7` `terraformer`/`k7tg`/`terracost`, demo preview vs active cloud IAM connectors).
   - **Corporate & Personal Verification**: Trial quota capped (e.g. 3 lookups/month for evaluation) vs tiered production volume.

## Acceptance criteria

- [ ] AC1 — **Modular LATAM Architecture in `@wom/kyc`**: Refactor `@wom/kyc` into a multi-jurisdiction package structure (`central-america/costa-rica`, `central-america/panama`, `south-america/brazil`, `colombia`, `argentina`, `chile`, `peru`) with a unified country registry, standardized tax ID sanitization, and polymorphic verification dispatchers.
- [ ] AC2 — **Costa Rica (CR) Corporate & Personal Verification**: Implement validation, check digits, and normalization for Costa Rica:
  - Corporate: Cédula Jurídica (10 digits, structure `3-XXX-XXXXXX`), validation with Ministerio de Hacienda (ATV / Tributación Digital) and Registro Nacional de Costa Rica (Personas Jurídicas).
  - Personal: Cédula de Identidad (9 digits, structure `X-XXXX-XXXX`, province code 1-9) and foreign DIMEX format validation.
- [ ] AC3 — **Panama (PA) Corporate & Personal Verification**: Implement validation, check digits, and normalization for Panama:
  - Corporate: RUC (Registro Único de Contribuyente) with DV (Dígito Verificador via DGI - Dirección General de Ingresos) and Registro Público de Panamá (Ficha/Folio/Documento).
  - Personal: Cédula de Identidad Personal (format `N-XXX-XXXX`, `PE-`, `E-` via Tribunal Electoral).
- [ ] AC4 — **South America Core Jurisdictions (BR, CO, AR, CL, PE)**: Implement structural validator routines and registry interfaces:
  - Brazil: CNPJ (14 digits, Modulo 11 check digits) and CPF (11 digits, Modulo 11 check digits) with Receita Federal / CEIS status checks.
  - Colombia: NIT (Modulo 11 DV) via DIAN / RUES, and Cédula de Ciudadanía (CC).
  - Argentina: CUIT/CUIL (11 digits, Modulo 11 check digit) via ARCA (AFIP).
  - Chile: RUT/RUN (Modulo 11 check digit 0-9/K) via SII.
  - Peru: RUC (11 digits, Modulo 11 check digit) via SUNAT, and DNI (8 digits) via RENIEC.
- [ ] AC5 — **Client Subscription & Trial Schema Migration**: Via a durable Supabase migration in `wom7api`, extend `public.clients` with subscription, trial, and quota gating columns:
  - `subscription_tier text NOT NULL DEFAULT 'trial'` (`trial`, `starter`, `growth`, `enterprise`),
  - `subscription_status text NOT NULL DEFAULT 'active'` (`active`, `past_due`, `canceled`, `trialing`),
  - `trial_ends_at timestamptz`,
  - `service_quotas jsonb`,
  - `service_usage jsonb`.
- [ ] AC6 — **Automated Service Entitlement Gating Logic**: Implement server-side entitlement enforcement in `@webomage/lib/entitlements` (and API middleware):
  - Trial tier: Level 1 (Public URL audit) unrestricted; Level 2 (Air-gapped Code Sandbox) capped at 1 demo scan (<=50k LOC, preview findings); Level 3 (Cloud/FinOps) preview demo only; KYC lookups capped at monthly trial quota (e.g. 3 lookups/month).
  - Paid tiers (`starter`, `growth`, `enterprise`): Uncapped Level 2 code audits, Level 3 Cloud & FinOps posture runs with `@k7` topology & `terracost` analysis, and tiered LATAM KYC verification volume.
- [ ] AC7 — **Admin CP & Client Portal Integration**:
  - Update `apps/cp/src/pages/business/verification.astro` with a multi-country jurisdiction selector (MX, CR, PA, BR, CO, AR, CL, PE) adapting input masks and dispatching to `@wom/kyc`'s country-specific dispatchers.
  - Expose current subscription tier, trial status, and service usage gauges in the Client Portal (`apps/cp/src/pages/client/portal.astro`).
- [ ] AC8 — **Deterministic Offline Unit Test Suite & Gate Verification**:
  - Comprehensive Vitest unit tests in `packages/kyc/tests/` covering check-digit algorithms, regex patterns, and mocked registry adapters for all 8 countries.
  - Offline test suite proving entitlement gating rejects requests when trial quotas or subscription permissions are exceeded.
