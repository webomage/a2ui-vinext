# T778 — Fold Talent hub (/) into an overview hub, upgrade host CLI tools incl. supabase 3.2.0, and add Linux systemd user auto-checks

## Summary

Addresses three related gaps reported after `T774`/`T775`:

1. **Talent Hub Overview (`/` vs `/jobs`):** Previously `apps/me/src/pages/index.astro` (`Talent hub`, `/`) and `apps/me/src/pages/jobs/index.astro` (`Job board`, `/jobs`) both mounted `<JobBoard />`, making both sidebar links look identical. Folds `/` into a 4-card overview hub covering **Workspace & Resume Studio**, **Public Profile (`/u/<slug>`)**, **Skill Assessments**, and **Saved Searches** (`TalentHubSavedSearchCard.svelte` -> `/jobs?social=1`, auto-expanding live TG & Threads search inside `JobBoard.svelte`), plus a compact recent-roles strip, while `/jobs` remains the dedicated full job board.
2. **Host CLI Toolchain & Supabase v3.2.0 Upgrade:** Upgrades the 11 auto-eligible Homebrew tools (`just tools-weekly`: `ast-grep`, `fd`, `fzf`, `gh`, `infisical`, `osv-scanner`, `pdftotext`, `ruff`, `semgrep`, `uv`, `yq`) plus `supabase` (`2.121.0 -> 3.2.0`), verifies read-only live compatibility (`supabase migration list`, `just check-supabase`, `just db-drift-check`), and promotes verified `known_good` versions into `project/policies/tools-policy.json`.
3. **Linux `systemd --user` Scheduled Maintenance:** Adds native Linux `systemd --user` `.service` / `.timer` generation and status/install/remove support in `scripts/launchd_schedule.py` reading the existing `w0m-web/project/launchd/schedules.jsonc` SSOT, updates `scripts/tools_check.py` cadence/log hints on Linux, adds `tools-schedule-test` (`scripts/tests/test_launchd_schedule.py`), and activates all 5 user timers pointing strictly to canonical `/home/aleksei/Projects/!self/w0m`.
