# T572 — Chrome-style icons-only collapsed side panel rail for AppShell, SideNav, ContextSwitcher, SidebarHatSwitcher, and AuthWidget

## Summary

Previously, `AppShell` (`packages/ui/src/lib/components/layout/AppShell.svelte`) had no collapsed state on wide viewports (`>= 1024px`) and completely hid the sidebar off-screen (`grid-template-columns: 1fr`, `translateX(-100%)`, `inert`) below `1024px`, leaving only a `☰` button in the top header next to the breadcrumb. In addition, `SideNav` (`packages/ui/src/lib/components/layout/SideNav.svelte`) rendered a placeholder `6px` dot instead of vector icons.

Owner direction (2026-10-25, with screenshot of `cp.webomage.com/o/webomage` next to Chrome's vertical side panel):
*"also let's make our side panel to have icons only collased state like chrome does"*

## Acceptance criteria

- [x] **AC1 — `AppShell` Chrome-style icons-only collapsed vertical rail (`60px` vs `264px`) & top rail toggle**:
  - Replaced the hidden off-screen drawer with a persistent `60px` (`3.75rem`) icons-only collapsed vertical rail (`data-collapsed="true"`, `grid-template-columns: 60px 1fr`) that stays interactive at all widths, auto-collapses below `collapseBelow` (`1024px`) via CSS media query + `matchMedia`, persists manual expand/collapse preference in `localStorage` (`w0m-sidebar-collapsed`), and places the collapse/expand toggle button (`PanelLeftClose` / `PanelLeftOpen`) at the top of `<aside id="app-sidebar">`.
- [x] **AC2 — Semantic `@lucide/svelte` vector icons & icons-only rail mode in `SideNav`**:
  - Rendered crisp `@lucide/svelte` vector icons for every navigation item across `me`, `org`, `project`, and `admin` contexts in `SideNav.svelte` (honoring `NavItem.icon` and semantic path/label resolution, including Enterprise and RPG Guild modes), and in collapsed rail mode opened all sections with compact group dividers, centered `38px × 38px` icon buttons, active brand highlight, badge overlays, and native hover `title` (`"<Section> · <Item>"`) tooltips.
- [x] **AC3 — Compact rail mode & unclipped popovers for `ContextSwitcher`, `SidebarHatSwitcher`, `AuthWidget`, and `CpShell`**:
  - Forwarded `collapsed` state through `CpShell.svelte` to `ContextSwitcher`, `SidebarHatSwitcher`, `SideNav`, and `AuthWidget` (`placement="sidebar"`) so each switcher renders a centered `38px × 38px` avatar/icon button with tooltip in collapsed mode while keeping its dropdown popover unclipped (`min-width`, `left: 0`, `z-index: 40/50/60`).
- [x] **AC4 — Design-system specs, unit tests, `ds-conformance`, and `svelte-typecheck-ratchet` verification**:
  - Updated `design-system/components/layout/{AppShell,SideNav,ContextSwitcher}.{d.ts,prompt.md}` and unit tests (`AppShell.test.ts`, `SideNav.test.ts`, `ContextSwitcher.test.ts`, `review-fixes.test.ts`, `CpShell.test.ts` — 12 test files / 64 tests passed), and passed `just ds-conformance --enforce` and `just svelte-typecheck-ratchet`.
