# T588 — MCP & WebMCP Tools for GitHub Feature Voting Board & Repo Activity Digest (`@webomage/webmcp`)

## Summary

Expose the GitHub-Issues-as-SSOT Feature Voting Board and the OSS Repository Activity Digest + Rising Projects feed as first-class tools in `@webomage/webmcp` (`w0m_board_list_features`, `w0m_board_vote_feature`, `w0m_board_generate_spec`, `w0m_oss_repo_digest`), registered both in the universal `TOOL_MANIFEST` (served over Streamable HTTP `/api/mcp`) and progressively on `document.modelContext` / `navigator.modelContext` when `FeatureVotingBoard.svelte` mounts in a WebMCP-capable browser.
