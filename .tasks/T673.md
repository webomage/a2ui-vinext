# T673 — Backlog & phased integration roadmap for newly forked `casualuser` and `webomage` AI, memory, ontology, document, security, and harness tools

## Summary

Between `2026-10-16` and `2026-11-08`, 30+ high-leverage open-source repositories were forked under `github.com/casualuser/*` and `github.com/webomage/*` across 6 capability clusters:
1. **Latent Semantic Memory, Cache Engineering & Incremental Wiki (`snap-stanford/memorilla`, `thu-nics/AKV`, `nashsu/llm_wiki`)** — latent KV/semantic memory for long-context agents, agentic KV-cache engineering, and Karpathy-style persistent Markdown wiki compaction.
2. **System-1 Calibrated Typed-Decision Engines & Local Inference (`nokia-applied-research/AnyJev`, `NandhaKishorM/laya`, `mizorewww/laya-mlx`, `jaredpalmer/kev`, `nico-martin/open-jev`, `browser-use/jev-ultrafast`, `FlashML-org/FreeToken`)** — sub-50ms deterministic/calibrated typed-decision routing (`JEV` / `Laya`) on Apple Silicon (`w0m-mlx`) and Cloudflare Workers.
3. **Semantic Graph Ontologies & Code Intelligence (`NVIDIA/auto-ontology`, `fabio-rovai/open-ontologies`, `ModernRelay/omnigraph`, `potpie-ai/potpie`)** — deterministic natural-language-to-graph query generation and RDF/OWL ontology layers complementing `codegraph` (`1.4.1`) and `graphify` (`0.9.92`).
4. **Threat Modeling, Skill Security & Legal Review (`jmanico/grim-prompter`, `NVIDIA/SkillSpector`, `microsoft/SkillOpt`, `anthropics/claude-for-legal`, `DenisSergeevitch/ex-ussr-kinship-research`)** — evidence-traced threat modeling across 36 architectures & 29 methods for `/audit/`, static/dynamic skill security scanning (`w0m-skills`), and contract/NDA review packs for CP legal workflows.
5. **Document Ingestion, Scraping & Sandboxed Execution (`opendatalab/MinerU`, `firecrawl/firecrawl`, `perplexityai/SPACE`)** — high-precision PDF/Office-to-Markdown/JSON extraction for CV/Resume Studio & client vault ingestion (`MinerU`), plus sandboxed agent execution (`SPACE`).
6. **Agent Observability, SDLC Steering & Multi-Agent Harnesses (`openlit/openlit`, `awslabs/aidlc-workflows`, `Asymptote-Labs/agent-beacon`, `SWE-agent/mini-swe-agent`, `feder-cr/git-ai`, `google/ax`, `morluto/rea`, `makecindy/cindy`, `block/buzz`, `agulli/atlas-agents`)** — OpenTelemetry-native agent tracing (`OpenLIT`), adaptive AI-DLC steering rules, live terminal/session beacons, and git provenance.

Full inventory and weighted integration matrix are documented in [`.agents/reports/2026-11-08-casualuser-forked-tools-integration-backlog.md`](../.agents/reports/2026-11-08-casualuser-forked-tools-integration-backlog.md).

## Acceptance criteria

- [ ] AC1 — **Fork Governance & `webomage/<repo>` Canonical Mirroring (`scripts/w0m_prs.py`, `project/policies/tools-policy.json`):** Audit the 31 `casualuser/*` forks created between `2026-10-16` and `2026-11-08` and mirror/transfer active upstream contribution targets to `github.com/webomage/<repo>` per the estate fork invariant (`origin = git@github.com:webomage/<repo>.git`, exact upstream repo name).
- [ ] AC2 — **Track 1: Threat Modeling & Skill Security (`grim-prompter`, `NVIDIA/SkillSpector`, `microsoft/SkillOpt`):** Integrate `jmanico/grim-prompter`'s 36-architecture / 29-method evidence-traced threat modeling taxonomy into the CP Security Audit Workbench (`SecurityAuditReportViewer.svelte` / `w0m-sec`), and wire `NVIDIA/SkillSpector` into `just skills-sync` / `just check-security` to scan `.agents/skills/` for prompt-injection or tool-abuse vectors.
- [ ] AC3 — **Track 2: System-1 Typed Decision Routing & Latent Memory on `w0m-mlx` (`webomage/memorilla`, `webomage/laya-mlx`, `AnyJev`, `open-jev`, `FreeToken`, `AKV`):** Benchmark and expose a sub-50ms calibrated typed-decision endpoint (`/v1/decide` via `laya-mlx` / `open-jev`) and latent semantic memory adapter (`memorilla`) inside `w0m-mlx` for ticket triage, hat routing, and prompt-cache reuse.
- [ ] AC4 — **Track 3: Document Extraction & Persistent Vault Compaction (`MinerU`, `llm_wiki`, `claude-for-legal`):** Wire `MinerU`-compatible PDF/DOCX structured Markdown+JSON extraction into Resume Studio (`apps/me`) and Client Vault ingestion (`T634`), paired with `llm_wiki` incremental compaction and `claude-for-legal` NDA/MSA review checklists in `w0m-skills`.
- [ ] AC5 — **Track 4: Ontology-Grounded Graph Queries (`NVIDIA/auto-ontology`, `open-ontologies`, `omnigraph`, `potpie`):** Add deterministic ontology-to-graph query generation on top of `codegraph` + `graphify` (`just ask` / `just graph-query`) so natural-language architectural questions resolve via typed schema relationships before fallback keyword search.
- [ ] AC6 — **Track 5: OTEL Agent Observability & SDLC Harness Enhancements (`openlit`, `aidlc-workflows`, `agent-beacon`, `git-ai`):** Connect `OpenLIT` OTLP span attributes and `agent-beacon` status telemetry to `w0m-cf` / Orca agent worktrees (`just agent-tree`) and evaluate `aidlc-workflows` adaptive stage gates against `.w0m/sdlc.json`.
