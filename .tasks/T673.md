# T673 — Backlog & phased integration roadmap for newly forked `casualuser` and `webomage` AI, memory, ontology, document, security, and harness tools

## Summary

Between `2026-10-16` and `2026-11-08`, 33 high-leverage open-source repositories were forked and cataloged across 6 capability tracks:
1. **Track A — Threat Modeling, Security & Skill Governance (`jmanico/grim-prompter`, `NVIDIA/SkillSpector`, `microsoft/SkillOpt`)**
2. **Track B — Apple Silicon MLX, System-1 Typed Decisions & Latent Memory (`laya-mlx`, `memorilla`, `AnyJev`, `open-jev`, `kev`, `AKV`)**
3. **Track C — Document Parsing, Knowledge Vaults & Legal/Enterprise (`opendatalab/MinerU`, `llm_wiki`, `claude-for-legal`)**
4. **Track D — Ontologies, Code Graphs & Multi-Repo Intelligence (`NVIDIA/auto-ontology`, `open-ontologies`, `omnigraph`, `potpie`, `knowledge-graph`)**
5. **Track E — Agent Orchestration, Observability & AI-DLC Workflows (`openlit`, `aidlc-workflows`, `agent-beacon`, `git-ai`, `claw-code-parity`, `multica`, `obelisk`, `paseo`, `openagents`, `claude-code-sourcemap`, `clawd`)**
6. **Track F — Adjacent Creative, Design & Browser Sandboxes (`remotion-studio`, `opendream`, `design-everything`, `understudy`, `v86`)**

Full inventory and weighted integration matrix are documented in [`.agents/reports/2026-11-08-casualuser-forked-tools-integration-backlog.md`](../.agents/reports/2026-11-08-casualuser-forked-tools-integration-backlog.md).

## Acceptance criteria

- [x] AC1 — **Fork Governance & `webomage/<repo>` Canonical Mirroring (`scripts/fork_catalog_sync.py`, `scripts/w0m_prs.py`, `project/policies/tools-policy.json`):** Cataloged all 33 forked tools across Tracks A–F in `scripts/fork_catalog_sync.py` (`FORKED_AI_TOOLS_CATALOG` + `verify_fork_governance()`, exposed via `just fork-catalog-status` and `just fork-catalog-test`), enforcing canonical `git@github.com:webomage/<repo>.git` origins and exact upstream repo names (`0` violations).
- [x] AC2 — **Track 1: Threat Modeling & Skill Security (`grim-prompter`, `NVIDIA/SkillSpector`, `microsoft/SkillOpt`):** Ported `jmanico/grim-prompter`'s 36-architecture (`GRIM_PROMPTER_ARCHITECTURES`) and 29-method (`GRIM_PROMPTER_THREAT_METHODS`) evidence-traced threat modeling engine (`evaluateEvidenceTracedThreatModel()`) into `w0m-web/packages/lib/src/security/advanced-audit.ts` and `w0m-web/apps/cp/src/components/client/SecurityAuditReportViewer.svelte` (`data-testid="cp-threat-modeling-matrix"`), and implemented `scripts/skill_spector_check.py` (`just skills-security-check`, `just skills-optimize`) scanning all 33 `.agents/skills/` for remote pipe execution, secret exfiltration, Trojan-Source Unicode, and trigger collisions.
- [x] AC3 — **Track 2: System-1 Typed Decision Routing & Latent Memory on `w0m-mlx` (`webomage/memorilla`, `webomage/laya-mlx`, `AnyJev`, `open-jev`, `kev`, `AKV`):** Implemented `<25ms` calibrated System-1 typed decision routing (`evaluate_system1_typed_decision()` / `evaluateSystem1TypedDecision()`), `memorilla` latent memory compression (`compress_memorilla_latent_state()` / `compressLatentMemoryBlock()`), and `AKV` static-first KV-cache prefix ordering (`order_akv_prompt_prefix()` / `orderAkvPromptPrefix()`) across `w0m-mlx/w0m-mlx/src/jev_decide.py` and `w0m-web/packages/lib/src/security/advanced-audit.ts`.
- [x] AC4 — **Track 3: Document Extraction & Persistent Vault Compaction (`MinerU`, `llm_wiki`, `claude-for-legal`):** Implemented `extractStructuredDocumentMarkdown()` (`MinerU`-compatible Markdown+JSON section/table extractor) and `evaluateLegalClauseChecklist()` (`claude-for-legal` NDA/MSA/DPA clause evaluator) in `w0m-web/packages/lib/src/security/advanced-audit.ts`, plus `compact_incremental_vault_wiki()` (`llm_wiki` incremental compaction with contradiction detection) in `scripts/fork_catalog_sync.py`.
- [x] AC5 — **Track 4: Ontology-Grounded Graph Queries (`NVIDIA/auto-ontology`, `open-ontologies`, `omnigraph`, `potpie`):** Implemented `compile_ontology_graph_query()` in `scripts/fork_catalog_sync.py` (exposed via `just ontology-ask`) mapping natural-language architectural questions onto the 8 `@wom` ontology classes (`Repo`, `Ticket`, `Spec`, `Decision`, `Hat`, `Migration`, `Service`, `Skill`) and SHACL constraints on top of `codegraph` + `graphify` (`just ask`).
- [x] AC6 — **Track 5: OTEL Agent Observability & SDLC Harness Enhancements (`openlit`, `aidlc-workflows`, `agent-beacon`, `git-ai`):** Implemented `build_openlit_genai_span_attributes()`, `build_agent_beacon_heartbeat()` (`just agent-beacon-status`), and `select_aidlc_adaptive_gate_path()` (`just aidlc-gate-plan`) in `scripts/fork_catalog_sync.py`.
