# T756 — Consolidate duplicated web/cp components, burn down CP hex/control DS debt, extend ds-conformance, and publish OpenDesign Webomage DS package

## Summary

Execute architectural design-system cleanup from `.agents/reports/2026-11-16-uiux-audit-opendesign-report.md`: remove dead `apps/web` marketing duplicates living in `apps/cp`, migrate top `apps/cp` macOS-hex offenders toward canonical `@webomage/ui` tokens/primitives, extend `ds_conformance.py` reporting across `apps/web` & `apps/me`, and generate OpenDesign-compatible `DESIGN.md` / `components.html` / `manifest.json` artifacts in `w0m-web/design-system/`.

## Acceptance Criteria

- [x] **AC1 — Prune 21 dead duplicated marketing components in `apps/cp`:** Verify zero imports/routes reference the orphaned `apps/cp/src/components/` copies (`HomePage.astro`, `ServicesPage.astro`, `SolutionsPage.astro`, `CostEstimator.astro`, `CVPage.astro`, `ProjectsPage.astro`, etc.) and remove them cleanly without breaking `cp` `astro check` or `build`.
- [x] **AC2 — Burn down CP hardcoded hex literals & low-contrast labels:** Replace hardcoded `#2c2c2e`, `#1c1c1e`, `#32d74b`, `#ff453a`, `text-gray-500`/`text-gray-600`, `focus:outline-none`, and native controls in top offending CP files (`TemplateManager.svelte`, `RoleManager.svelte`, `TeamManager.svelte`, `DomainManager.svelte`, `TechnologyManager.svelte`) with canonical CSS tokens (`var(--surface-*)`, `var(--text-muted)`, `var(--border-default)`, `@webomage/ui` `Button`/`Input`/`Select`), and roll `ds-conformance --save` baseline downward.
- [x] **AC3 — Extend `ds_conformance.py` visibility to `apps/web` & `apps/me`:** Add non-regressing `apps/web` and `apps/me` summary metrics to `w0m-web/project/scripts/ds_conformance.py` (preserving existing CP ratchet contract).
- [x] **AC4 — Publish OpenDesign Webomage DS package (`w0m-web/design-system/`):** Add `DESIGN.md`, `components.html`, and OpenDesign-compatible `manifest.json` under `w0m-web/design-system/` validated by `just design-system-check`.
