# T737 — Wire just tech-explainer into Orca embedded browser & integrate 12-Tool Security Audit Arsenal across w0m-sec and @webomage/lib

## Summary

Wires `just tech-explainer` (`scripts/tech_explainer_check.py`) to open, focus, reload, or split [`docs/visuals/w0m-tech-landscape-explainer.html`](../docs/visuals/w0m-tech-landscape-explainer.html) directly inside Orca's embedded worktree browser (failing closed per `AgDR-0025` inside Orca sessions instead of falling back to `xdg-open`), and integrates the 12-Tool Security Audit Arsenal (`Strix`, `Cloudflare Security Audit`, `Trivy`, `Nuclei`, `TruffleHog`, `NVIDIA SkillSpector`, `Semgrep`, `OpenAI Codex Security`, `ClamAV`, `Claude Code Security Review`, `BLA (Blind LLM Agents)`, `Microsoft PyRIT`) across `w0m-sec/scripts/sandbox_audit_runner.py`, `w0m-web/packages/lib/src/security/advanced-audit.ts`, `docs/TECH-LANDSCAPE.md`, and `docs/visuals/w0m-tech-landscape-explainer.html`.

## Acceptance criteria

- [x] AC1 — `scripts/tech_explainer_check.py` resolves the Orca CLI binary via `scripts.agent_provider.resolve_orca_bin()` and implements `open_in_orca_browser(primary, *, split=None)` using `orca tab list --json`, `orca tab create --url <file_uri> [--split <dir>] --json`, `orca tab switch --page <browserPageId> --focus --json`, and `orca reload --page <browserPageId> --json` (handling both `result` and `data` JSON envelopes and `BrowserTabInfo` entries without a `type` field).
- [x] AC2 — `scripts/tech_explainer_check.py` supports `--mode {check,path,open,orca,split,system}` and `--split {right,left,down,up}`. Inside an Orca session (`ORCA_CLI_COMMAND` or `ORCA_TAB_ID` set) or when `--mode orca|split` is passed, failure of the Orca CLI returns non-zero (`1`) immediately (`AgDR-0025`, zero silent fallback to `xdg-open`), and `justfile` passes extra args to `just tech-explainer`.
- [x] AC3 — `w0m-sec/scripts/sandbox_audit_runner.py` and `w0m-web/packages/lib/src/security/advanced-audit.ts` export the canonical 12-tool security audit registry (`SECURITY_AUDIT_12_TOOL_MATRIX` / `evaluateSecurityAudit12ToolArsenal` / `evaluate_security_audit_12_tool_arsenal`) covering all 12 repositories (`strix`, `cloudflare-security-audit`, `trivy`, `nuclei`, `trufflehog`, `nvidia-skillspector`, `semgrep`, `openai-codex-security`, `clamav`, `claude-code-security-review`, `bla-blind-llm-agents`, `microsoft-pyrit`) mapped across Tiers 1–4, and execute offline quarantined rules for `trufflehog`, `clamav`, `nuclei`, and `pyrit`.
- [x] AC4 — `docs/TECH-LANDSCAPE.md` and `docs/visuals/w0m-tech-landscape-explainer.html` document the 12-Tool Security Audit Arsenal and Orca embedded browser explainer integration with zero internal `T##`/`AgDR-####`/`AC#` leaks in user-facing HTML copy (`just ui-ticket-leak-check`: 503 files, 0 leaks).
- [x] AC5 — Unit tests pass in `scripts/tests/test_tech_explainer_check.py` (10/10), `w0m-sec/tests/test_t337_sandbox_runner.py` (18/18 via `just w0m-sec-test`), and `w0m-web/packages/lib/src/security/advanced-audit.test.ts` (8/8 via Vitest) alongside `just kb-vector-test` (8+2+10 OK), `mypy --config-file mypy.ini scripts/tech_explainer_check.py` (0 issues), `python3 scripts/tech_explainer_check.py --mode check`, `just ui-ticket-leak-check`, and live `just tech-explainer` (`orca:...:created` and `:reused`).
