# T541 — Root deploy confirmation ambient consent leaks across runs: standalone db-migrate bypasses prompt within 45-min TTL

## Summary

When a developer runs `just deploy-all`, the root confirmation gate writes an ambient consent ticket to `$TMPDIR/w0m-confirm-consent.json` with a 45-minute TTL (`ttl_seconds: 2700`), covering all recipes in `roots["deploy-all"]` (including `db-migrate`). Because the consent file is never cleared or consumed upon the completion (or failure) of the `deploy-all` chain, executing `just db-migrate` standalone in the same terminal or another shell at the same git HEAD within 45 minutes matches Rule 2 (`read_consent()`) in `confirm_step.py`, bypassing the interactive prompt and Touch ID dialog entirely.

This directly violates the architectural invariant stated across `confirm_step.py` ("standalone `just db-migrate` prompts on its own (rule 4 in main())"), `confirm-policy.json` ("Standalone `just db-migrate` still prompts"), and `DEPLOY-CONFIRM.md` ("A standalone `just db-migrate` still asks on its own"). This ticket enforces single-use consumption of sensitive steps (such as `db-migrate`) from the active consent grant upon first pass, adds lifecycle cleanup (`--clear`) on chain completion or exit/abort, and adds red probes to prevent regression.

## Acceptance criteria

- [x] AC1 — `confirm_step.py` consumes one-shot sensitive steps upon authorization: when `db-migrate` passes via Rule 2 under an agreed root consent, `db-migrate` is atomically removed from `consent["covered"]` on disk so subsequent standalone calls must prompt.
- [x] AC2 — `confirm_step.py` supports `--clear` to unconditionally delete the active consent file.
- [x] AC3 — `deploy_logged.py` and `release.py` execute consent cleanup in a teardown `finally` block / signal trap when `deploy` or `deploy-all` finishes or aborts.
- [x] AC4 — `test_confirm_step.py` includes a red probe asserting that a second or standalone call to `db-migrate` is withheld even if an unexpired root consent file was created by `deploy-all`.
- [x] AC5 — All 64+ existing confirmation gate probes pass cleanly (`just confirm-test`).
