# T420 — Design System & Shipping Code Reconciliation: Token Export, Tailwind @theme Wiring, and Inert React Cleanup

## Summary

A comprehensive audit of the Webomage Design System vs. shipping code (`_in/2026-09-21-audit-design-system-vs-shipping-code-and-update-proposal.md`) revealed that `design-system/` is currently disconnected from shipping applications:
1. **Shadcn Color Utilities Emit Zero CSS**: In Tailwind v4, `@webomage/ui` primitives rely on classes like `text-muted-foreground`, `bg-primary`, `border-input`, `ring-ring`, and `text-destructive`. Because `apps/web` and `apps/cp` declare only 6 `--color-*` variables in `@theme`, these utilities are completely omitted from built CSS bundles (`dist/client/_astro/*.css`).
2. **Silent Button Radius Drift**: `--radius-md` resolves to Tailwind's default 6px (.375rem) in built output rather than the Design System's specified 8px, because `design-system/tokens/effects.css` is never imported.
3. **Hardcoded Fallback Drift**: 10 token names survive only as inline hardcoded fallbacks across 32 component locations (e.g. `var(--text-muted, #e5e7eb)`).
4. **Language Mismatch (Inert React Payload)**: `design-system/` contains ~681 KB of React `.jsx` files, bundles, and templates, while the product stack is strictly Astro + Svelte 5 with zero React runtime or imports.
5. **Dead Bloat & Sourcing**: Multiple generations of duplicate Claude Design exports reside in `design-system/uploads/` and hash-suffixed files (~12 MB).

This ticket delivers the Phase 1 & Phase 2 reconciliation: wires the canonical token layer into `@webomage/ui` and app `@theme` blocks, eliminates inline fallbacks, and retires the inert React payload in favor of Svelte 5 / Astro implementations.

## Acceptance criteria

- [x] AC1 — Declare full shadcn color contract in Tailwind v4 `@theme`: Add `--color-primary`, `--color-primary-foreground`, `--color-secondary`, `--color-muted`, `--color-muted-foreground`, `--color-accent`, `--color-card`, `--color-popover`, `--color-border`, `--color-input`, `--color-ring`, `--color-destructive` mapped to design system variables in `apps/web` and `apps/cp`, verifying with built CSS inspection that utilities generate valid styles.
- [x] AC2 — Pin canonical radius scale: Declare `--radius: 0.625rem` and `--radius-md: calc(var(--radius) - 2px)` (8px) in the active token layer so buttons and inputs resolve to design system specifications rather than Tailwind defaults.
- [x] AC3 — Declare fallback-only tokens canonically: Declare `--text-primary`, `--text-body`, `--text-muted`, `--text-secondary`, `--text-on-brand`, `--color-primary`, `--font-sans`, `--warning`, and `--warning-rgb` in the token layer, and strip hardcoded fallback literals across all 32 component sites.
- [x] AC4 — Package canonical token CSS in `@webomage/ui`: Export `tokens.css` from `@webomage/ui` and import it directly into `apps/*/src/styles/global.css`, making `design-system/tokens/` the living source of truth for all web applications.
- [x] AC5 — Retire inert React components and bundles: Delete legacy React `.jsx` files (`design-system/components/**/*.jsx`), bundles (`_ds_bundle.js`, `support.js`), and React templates (`templates/*.dc.html`, `ui_kits/web/`) from `design-system/`, establishing `packages/ui` as the single component runtime.
- [x] AC6 — Clean up duplicate nested exports: Remove `design-system/uploads/` and unreferenced hash-suffixed files while strictly preserving language-neutral assets, token files, prompt files, and `.d.ts` contracts.
- [x] AC7 — Establish `just ds-check` and end-to-end build verification: Add automated token and theme verification recipe `just ds-check` and verify that all four apps (`web`, `cp`, `join`, `job`) build, typecheck, and render with complete token coverage in `dist/`.

## Definition of Done

T420 is complete when:
1. `dist/client/_astro/*.css` in `apps/web` and `apps/cp` contains valid rules for all shadcn color utilities and 8px `--radius-md`.
2. All 32 inline hardcoded fallbacks are removed in favor of canonical tokens.
3. `@webomage/ui` exports `tokens.css` and all 4 applications consume it.
4. No React `.jsx` files or duplicate upload archives remain in `wom7web/design-system/`.
5. `just ds-check` and all estate pre-commit/pre-push quality gates pass 100% green without `--no-verify`.
