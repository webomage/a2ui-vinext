# T383 — Remove orphaned dead code modules and uncalled subroutines across the estate

## Summary

A multi-repo dead-code audit powered by `code-review-graph` (CRG) v2.3.9 identified several completely unreferenced source modules, dead stubs, and obsolete subroutines across `wom7func` (formerly `wom7cfworkers`), `wom7web`, and `wom7api`:

1. `wom7func/src/utils/upwork-markdown.ts`: 100 lines of orphaned Markdown generators (`generateContractMd`, `generateJobMd`, `generateProposalMd`, `generateOfferMd`, `slugify`) with 0 callers across the estate.
2. `wom7func/src/services/unifiedAts.ts`: 180 lines of uncalled ATS connector logic (`UnifiedAtsService`, `submitCandidate`, `fetchVacancies`, `MergeConnector`).
3. `wom7func/src/lib/crawler.ts` (and `wom7api/src/lib/crawler.ts`): unreferenced batch crawler helpers (`domainResultToMarkdown`, `scanDomains`) with 0 callers outside `@webomage/crawler`.
4. `wom7web/packages/lib/src/interviews/hume.ts`: 99 lines of unused Hume AI SDK calls (`initializeHumeEVI`, `generateQuestion`, `synthesizeResponse`, `transcribeAudio`) superseded by `packages/lib/src/interviews/hume-evi-browser.ts` (T197). Deleting this allows removing `"hume": "^0.15.15"` from `wom7web/package.json`.
5. `wom7web/packages/lib/src/interviews/videoRecorder.ts`: Unused methods (`pauseRecording`, `resumeRecording`, `getState`, `getAudioStream`, `destroy`, `RecordingState`) never called by `InterviewSession.svelte`.
6. `wom7api/supabase/functions/_shared/image-utils.ts`: Dead stub `generateImageWithGemini` that unconditionally throws an error with 0 callers.

Removing these dead modules reduces bundle sizes, eliminates supply-chain dependencies, and prevents developer confusion.

Verify worker compiles cleanly via `pnpm --dir wom7func exec tsc --noEmit` and `scripts/wasm_worker_check.py --check`.

- [x] AC3 — **Prune Dead Subroutines in `videoRecorder.ts`**: Clean up unused methods (`getAudioStream`, `pauseRecording`, `resumeRecording`, `getState`, `destroy`, and `RecordingState`) in `packages/lib/src/interviews/videoRecorder.ts` that have no callers in `InterviewSession.svelte`.
- [x] AC4 — **Prune Dead Image Stub in `wom7api`**: Remove `generateImageWithGemini` from `supabase/functions/_shared/image-utils.ts` and verify `deno check` passes cleanly across `image-utils.ts` and all calling edge functions (`generate-asset`, `generate-blueprint-image`, `generate-post-image`).
- [x] AC5 — **Re-verify Zero Callers & Dead Code Elimination**: Re-verified across all 7 estate repositories via `LC_ALL=C git grep` and TypeScript/Deno compilers that all targeted dead modules, subroutines, and dependencies are eliminated with zero broken imports.
