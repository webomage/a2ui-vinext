# T383 — Remove orphaned dead code modules and uncalled subroutines across the estate

## Summary

A multi-repo dead-code audit powered by `code-review-graph` (CRG) v2.3.9 identified several completely unreferenced source modules, dead stubs, and obsolete subroutines across `wom7cfworkers`, `wom7web`, and `wom7api`:

1. `wom7cfworkers/src/utils/upwork-markdown.ts`: 100 lines of orphaned Markdown generators (`generateContractMd`, `generateJobMd`, `generateProposalMd`, `generateOfferMd`, `slugify`) with 0 callers across the estate.
2. `wom7cfworkers/src/services/unifiedAts.ts`: 180 lines of uncalled ATS connector logic (`UnifiedAtsService`, `submitCandidate`, `fetchVacancies`, `MergeConnector`).
3. `wom7cfworkers/src/lib/crawler.ts`: 340+ lines of domain crawling utilities ported from legacy crawler service with 0 callers in worker `src/`.
4. `wom7web/packages/lib/src/interviews/hume.ts`: 99 lines of unused Hume AI SDK calls (`initializeHumeEVI`, `generateQuestion`, `streamAudioToHume`, `analyzeEmotions`). Deleting this allows removing `hume` and its transitive dependency `bufferutil` from `package.json`.
5. `wom7web/packages/lib/src/interviews/videoRecorder.ts`: Unused methods (`pauseRecording`, `resumeRecording`, `getState`, `getAudioStream`, `destroy`) never called by `InterviewSession.svelte`.
6. `wom7api/supabase/functions/_shared/image-utils.ts`: Dead stub `generateImageWithGemini` that unconditionally throws an error with 0 callers.

Removing these dead modules reduces bundle sizes, eliminates supply-chain dependencies, and prevents developer confusion.

## Acceptance criteria

- [ ] AC1 — **Prune Dead Modules in `wom7cfworkers`**: Remove `src/utils/upwork-markdown.ts`, `src/services/unifiedAts.ts`, and unreferenced batch crawler helpers in `src/lib/crawler.ts`. Verify worker compiles cleanly via `pnpm --filter wom7cfworkers build` (or `just typecheck-worker`).
- [ ] AC2 — **Prune Hume AI Module & Dependency in `wom7web`**: Delete `packages/lib/src/interviews/hume.ts`, remove `"hume": "^0.15.15"` from `wom7web/package.json`, run `pnpm install`, and verify `just typecheck` passes with 0 errors across all apps.
- [ ] AC3 — **Prune Dead Subroutines in `videoRecorder.ts`**: Clean up unused methods in `packages/lib/src/interviews/videoRecorder.ts` that have no callers in `InterviewSession.svelte`.
- [ ] AC4 — **Prune Dead Image Stub in `wom7api`**: Remove `generateImageWithGemini` from `supabase/functions/_shared/image-utils.ts` and verify `just deno-check` passes cleanly.
- [ ] AC5 — **Re-run CRG Dead Code Audit**: Re-execute `code-review-graph dead-code` across all touched repos and verify that all targeted items are eliminated from the dead-code report.
