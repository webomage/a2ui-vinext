# T789 — Audit and harden 4-axis RBAC, project hat boundaries, context switching, and UI hat synchronization

## Why

During user navigation to `https://cp.webomage.com/o/aleksei-tcelishchev/money/contracts`, the CP Shell top bar rendered `ACTIVE ROLE [Project Manager] [Artemio, quiero comer!] [Client side]` while the sidebar hat switcher trigger displayed `Role: Solar Mobile`. An audit of the complete roles mechanic is required across Postgres RLS/RPCs, HTTP token/cookie mechanics, and CP reactive UI components to ensure fail-closed security, cross-tenant isolation, accurate labeling, and strict context boundary enforcement.

## Scope

- **In:**
  - Complete security audit report (`.agents/reports/REPORT-RBAC-ROLE-AUDIT.md` and `w0m-web/docs/reports/`) covering 4-axis RBAC (Account class, Org context, Project delivery hats, Capabilities/offices).
  - Context boundary enforcement in `packages/lib/src/auth/middleware.ts` and `apps/cp/src/middleware.ts`: ensure `activeProject` stored in `sb-active-role` is verified against the current route's organization (`context.row.org_id`). When outside the target project's organization, strip or decouple `activeProject` so foreign project hats never bleed cross-org.
  - UI labeling repair in `apps/cp/src/components/admin/SidebarHatSwitcher.svelte`: fix the trigger button when no role is worn on the selected project so it does not render `Role: <project_name>` (e.g. `Role: Solar Mobile`), but clearly distinguishes between project selection and worn role.
  - Verification of database RLS policies and RPCs (`wom_wear_hat`, `wom_take_off_hat`, `wom_context_capabilities`, `is_capable`, `wom_provision_owner_project_hat`) for privilege escalation, tenant boundary bypass, and proper audit logging.
  - Unit and integration tests for role switching, context scoping, and UI hat displays.
- **Out:**
  - Changing the underlying 4-axis RBAC architectural model or database schemas.

## Acceptance Criteria

- [x] **AC1:** Author a formal, comprehensive RBAC & role mechanism security audit report in `.agents/reports/REPORT-RBAC-ROLE-AUDIT.md` and `w0m-web/docs/reports/` with Mermaid architecture and sequence diagrams.
