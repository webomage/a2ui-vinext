# T338 — Add a GitHub-repo link field to the client registry and fix Artemio's wrong vcs.repo

## Summary

Owner 2026-09-11: *"artemio project should be registered properly in w0m system with links to gh
repos"*. Grounding found Artemio is already registered (`project/clients-policy.json`, `id:
"artemio"`, done under [[T182]]) and already carries its own `vcs` block in its own
`.w0m/sdlc.json` — but two things are actually wrong:

1. **`clients-policy.schema.json`/`clients-policy.json` have no field for a GitHub link at all**
   (`additionalProperties: false`, only `id/role/root/enabled/note/repos/canonical_repo/tier_reason/
   runtime`) — so the estate-level registry cannot show which repo a client maps to without opening
   that client's own config.
2. **Artemio's own `.w0m/sdlc.json → vcs.repo` is wrong**: it reads `"proto/artemioquierocomer.mx"`;
   the actual `git remote -v` / `gh repo view` resolve to `casualuser/artemioquierocomer.mx`.

## Acceptance criteria

- [x] AC1 — `clients-policy.schema.json` gains an optional `vcs` property on a registry entry,
      reusing the exact vocabulary `.w0m/sdlc.json` already defines (`provider`, `repo`,
      `default_branch` — see `.w0m/README.md`), not a new/competing shape.
- [x] AC2 — Artemio's entry in `clients-policy.json` populates `vcs` with the verified remote
      (`provider: "github", repo: "casualuser/artemioquierocomer.mx", default_branch: "main"`).
- [x] AC3 — Artemio's own `.w0m/sdlc.json → vcs.repo` (in `_self/delivery/artemioquierocomer.mx`,
      a separate repo) is corrected from `proto/artemioquierocomer.mx` to
      `casualuser/artemioquierocomer.mx`, committed there.
- [x] AC4 — `project/scripts/client_inventory.py` (or whichever script validates
      `clients-policy.json` against its schema) still passes with the new optional field present
      on one entry and absent on the rest.

## Definition of Done

Per [`../../openspec/SPEC-AUTHORING-STANDARD.md`](../../openspec/SPEC-AUTHORING-STANDARD.md):
the client registry can express a GitHub repo link using the same vocabulary as `.w0m/sdlc.json`
(no new lexicon), Artemio's entry carries its verified remote, and the mismatched `vcs.repo` value
inside Artemio's own config is fixed at the source — both committed in their respective repos.
