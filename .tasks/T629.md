# T629 — Open universal shared todos, checklists, and full-featured shared wishlists to all users with tiered Cloudflare R2 media storage and Member-only Workers AI Whisper transcribe & translate

## Summary

Personal to-dos (`public.admin_todos`, `T361`) already used `profile_id` ownership in Postgres, yet `T536` gated `/me/todos` and `admin-todos-api` to `w0m` guild members (`platform.unit`), blocking regular users, clients (`Carol`), and candidates (`Ravi`), while `TodoManager.svelte` supported only flat text strings and carried raw `<button>` tags, `#hex` colors, `28px` mobile hitboxes, and desktop-only hover/double-click actions. Following owner direction (`2026-11-03`) and `AgDR-0055`, we opened universal Lists, repeatable Checklists, and Full-Featured Shared Wishlists (`/u/<slug>/wishlist`, `/wishlist/<token>`, item Claim/Reserve, collaborator `@slug` invites, audited visibility logs) to **everyone**, with a strict **3-tier Cloudflare R2 & Workers AI entitlement hierarchy**:
- **Tier 1 (Everyone — all authenticated users)**: Basic text todos, nested checklist sub-steps, repeatable checklists, and full-featured shared wishlists.
- **Tier 2 (Webomage Members + Clients with Active Subscription — `orgs.subscription_status IN ('active', 'trialing')`)**: Cloudflare R2 (`VAULT_R2`) picture & cross-browser voice-note media storage (`403 MEDIA_ENTITLEMENT_REQUIRED` for unsubscribed users).
- **Tier 3 (Webomage Members ONLY — `platform` org hat / `team_members` / `admin`)**: Cloudflare Workers AI (`@cf/openai/whisper-large-v3-turbo`) voice **Transcribe** (`task: "transcribe"`) and **Translate to English** (`task: "translate"`, `403 MEMBER_AI_ENTITLEMENT_REQUIRED` for non-members).
