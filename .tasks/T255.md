# T255 — an AC may not cite proof that does not exist

## Summary

[[T254]]'s execution plan names, for every phase, the `just` recipe that proves it — and **two of
those recipes do not exist yet**. The ticket says so in prose. Prose is not a gate, and the failure
mode it warns about is specific:

> *a phase whose gate does not exist is a phase that will be declared done on a code read.*

So the rule was made mechanical. Measuring the corpus to build it produced a sharper instance than
the one that motivated it:

| measurement (2026-08-22) | |
|---|---|
| distinct `just` recipes cited across ticket ACs | **163** |
| live recipes in the justfile | **373** |
| cited but non-existent | **8** |
| …of those, in a **TICKED** AC | **2** |

🔴 **One of the two was mine, written the day before.** [[T250]] AC4 is ticked and cited
*"just suites"* as the thing that gates `tasks-bounds`. That command does not exist — the runner is
**`just test`** (offline) / **`just test-all`** (offline + live). The *substance* held:
`run_suites.py:80` really does default `blocking` to True, so the suite really is gated. But the
command named as proof was not there, and nothing noticed.

## Why the rule is narrow, and why that is the design

A gate over **all** citations fires on 8 of 163, and at least three are legitimate:

- `just oc` ([[T153]]) is a rename's **old** name — its absence is that ticket's success condition;
- `just serve` ([[T152]]) appears in a sentence about a recipe that does *not* exist;
- `just standards-check` ([[T214]]) is a gate the ticket proposes **building**.

**A gate that cries wolf on 3 of 8 gets switched off** — [[T250]] AC2 learned that on the column
reader, and [[T135]] AC8 states it as policy. So:

| citation | verdict | why |
|---|---|---|
| **unticked** AC, missing recipe | **PLAN** — reported, not a finding | an AC that intends to build a gate may name it first |
| **ticked** AC, missing recipe | 🔴 **FAILURE** | it asserts a gate proved something, and the gate is not there |
| historical / negation | **ACKNOWLEDGED** with a reason, printed every run | an acknowledgement that vanishes is a gate that stopped looking ([[T246]] AC5) |

⚠️ **The prose escape is documented rather than left to be guessed.** To *mention* a dead recipe —
a rename's old name, a correction recording what an AC used to say — write it in *italics*, not
backticks. The gate's contract is that a citation is a **backticked** `just <name>`. The very first
fix this gate produced needed that escape: T250's correction note quoted the name it was correcting,
and the gate fired on the sentence describing the fix.
