# T730 — Add Infisical Dead-Env Prune Helper (`just env-prune-dead`), Skip Dead Keys in `rotate_leaked_secrets.py`, and Retire Disabled `GEMINI_API_KEY` Fallback

## Summary

Follows through on [[T729]] and [[T504]] by turning the `DEAD_UNUSED` Infisical `beta` audit ledger into a fail-closed, dry-run-by-default prune tool (`scripts/env_prune_dead.py` / `just env-prune-dead`), updating `w0m-api/scripts/rotate_leaked_secrets.py` so `--rotate-tier` never re-creates or rotates dead keys (`code_usage == "delete_from_infisical"`), and retiring the disabled (`HTTP 403` leaked) `GEMINI_API_KEY` / `GOOGLE_API_KEY` runtime env reads from `w0m-api/supabase/functions/_shared/ai-router.ts`, `w0m-api/scripts/sync_supabase_secrets.py`, `w0m-api/scripts/edge_local.py`, `w0m-api/scripts/healthcheck.py`, `w0m-web/turbo.json`, and `w0m-ext/.env.example` without mutating `w0m-api/deno.lock`.
