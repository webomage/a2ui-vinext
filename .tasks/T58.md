# T58 — Implement Inner-Loop Agent Security Verification

## Summary

Integrate automated inner-loop validation gates (using Biome for AST/lint checks, Semgrep for custom SAST patterns, and OSV-Scanner for SCA lockfile scans) directly inside the agent execution workflows. Guard against "agentic slop" and prevent insecure code from being proposed.

## Acceptance criteria

- [ ] AC1 — Configure `biome check --write` execution inside the agent's code generation pipelines.
- [ ] AC2 — Integrate local AST-grep inspections to identify anti-patterns (such as parsing JWTs without signature verification).
- [ ] AC3 — Set up Semgrep SAST scans using custom w0m/Trail of Bits rulesets.
- [ ] AC4 — Hook OSV-Scanner checks to scan locks pre-commit.
