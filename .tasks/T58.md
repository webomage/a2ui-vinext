# T58 — Implement Inner-Loop Agent Security Verification

## Summary

Integrate automated inner-loop validation gates (using Biome for AST/lint checks, Semgrep for custom SAST patterns, and OSV-Scanner for SCA lockfile scans) directly inside the agent execution workflows. Guard against "agentic slop" and prevent insecure code from being proposed.

## Acceptance criteria

- [x] AC1 — Configure `biome check --write` (superseded by Oxc `oxlint` + `oxfmt --write` under T106/T120) execution inside the agent's code generation pipelines (`.pre-commit-config.yaml` in `wom7web` and `wom7api`).
- [x] AC2 — Integrate local AST-grep inspections to identify anti-patterns (such as parsing JWTs without signature verification via `wom7web/project/ast-grep/rules/jwt-decode-without-verification.yml` and `just sg-test`).
- [x] AC3 — Set up Semgrep SAST scans using custom w0m/Trail of Bits rulesets (`wom7web/project/semgrep/w0m-security.yml` + pre-commit `semgrep` hooks).
- [x] AC4 — Hook OSV-Scanner checks to scan locks pre-commit (`osv-scanner` v2.4.0 in `wom7web/.pre-commit-config.yaml` and `wom7api/.pre-commit-config.yaml`).
