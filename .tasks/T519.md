# T519 — Group D: retire eight scripts

## Summary

Split from [[T509]]. Of the 37 "no caller" scripts, eight remain after the weighted re-check that nothing useful would be lost
by retiring. This is deliberately a short list: the first-pass recommendation was to delete about 18, and re-reading showed
most of those were worth keeping or converting ([[T516]], [[T517]], [[T518]]). Retire means `git mv` to
`_arch/<descriptive-name>/` (the estate's soft-delete bin, gitignored, not a permanent archive), never `rm`.

## The eight

| Script | Why retire | Evidence |
|---|---|---|
| `wom7api/scripts/update_system_status.py` | **Fakes a health check.** Its own comment says "in a real scenario, this would check APIs, Terraform state, etc. For now, we simulate a check", so it reports a status nothing measured. That is false assurance, the estate's recurring failure shape | 60 lines, last touched 2025-12-23, no caller |
| `wom7web/project/scripts/env_rename_migrate.py` | The `--env=dev` to `--env=beta` rename it performed is finished | Owner decision 2026-08-19; last touched 2026-09-18 |
| `wom7api/scripts/fix_diagrams.mjs` | One-shot data fix on `blueprints.diagram_mmd` | 30 lines; the fix is applied |
| `wom7api/scripts/fix_missing_prompts.py` | One-shot placeholder fill for posts | Last touched 2026-01-17 |
| `wom7api/scripts/check-upwork-proposal.js` | Debug probe hardcoded to one contract's storage folder | 29 lines |
| `wom7api/scripts/gen_codemap_mmd.py` | Its input `design/codemap.yml` no longer exists | Verified missing 2026-09-30 |
| `wom7api/scripts/gen_tracks_artifacts.py` | Its output directory `wom7web/src/data` no longer exists | Verified missing 2026-09-30 |
| `wom7api/scripts/validate_rust_vs_python.py` | Compares the Rust MLX port to a Python baseline; belongs to `wom7mlx`, from December 2025 | 187 lines; only an archived report mentions it |

## Acceptance criteria

- [ ] AC1 — **Dependents are re-checked immediately before each move,** with `git -C <repo> grep` across all seven repos and
  the tickets, because references change daily on a shared tree. A script that has gained a caller since 2026-09-30 is
  removed from this list, not moved.
- [ ] AC2 — **Each script is moved with `git mv` to `_arch/<name>/`** with a one-line note of why and which commit
  retired it. Nothing is deleted outright.
- [ ] AC3 — **`validate_rust_vs_python` is offered to `wom7mlx` first.** If the Rust port is still being compared, it moves
  there instead of being archived.
- [ ] AC4 — **`update_system_status` is checked for consumers of its output.** If anything reads the status it writes, that
  reader is told it was never measured, and the status source is replaced by a real check or removed.
- [ ] AC5 — **`just test` offline tier is green and the check count is not lower** than before the moves, and
  `suites-drift` stays at 0 undeclared.
