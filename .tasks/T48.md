# T48 — Migrate workflows to Hatchet SDK V1

## Summary

Migrate all legacy workflows in `wom7workers` (such as `webnames-batch.ts` and `upwork-poller.ts`) to use the new Hatchet V1 SDK syntax (`hatchet.task({ name, fn })` closure syntax) instead of the deprecated v0 `Workflow` object structure. This eliminates active deprecation warnings in the Railway dashboard logs.

- [x] AC1 — `webnames-batch.ts` updated off legacy Hatchet v0 `Workflow` syntax (`wom7api/src/workflows/webnames-batch.ts` migrated to native Cloudflare `WorkflowEntrypoint`).
