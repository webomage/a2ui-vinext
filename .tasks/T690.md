# T690 — Fix 'Invalid captcha' on `/audit` & `/blueprints/order`, Step Auto-Scroll, Paid-Tier Registration+Checkout, and AI Agent Helper Handoff

## Summary

Fix the `"Invalid captcha"` error on `webomage.com/audit/` and `/blueprints/order` caused by single-use Cloudflare Turnstile token double-consumption and missing fallback sitekey, add an actionable recovery banner with 1-click Turnstile refresh + AI Agent Helper fallback, smooth-scroll every step transition, process Client Portal Registration + Free Baseline Audit before Stripe Checkout on paid audit tiers, and route all `/contact` CTAs through the AI Agent Helper to collect scope details and hand off to Free Audit + Registration.

## Acceptance criteria

- [x] AC1 — **Single-Use Turnstile Token Hygiene & Actionable Error Recovery Banner (`security-audit.ts`, `SecurityAuditWidget.svelte`, `BlueprintOrderFlow.svelte`, `audit.astro`, `order.astro`):** Defaulted `turnstileSiteKey` to `"0x4AAAAAAE9GS8gtYiRYPdzL"`, avoided passing a consumed siteverify token a second time to GoTrue when siteverify already succeeded, mapped upstream `"Invalid captcha"` errors to clear user guidance, and added `data-testid="audit-order-error-banner"` / `data-testid="blueprint-order-error-banner"` with `Refresh Security Check & Retry`, `Complete via AI Agent Helper →`, and `Already have an account? Sign In →`.
- [x] AC2 — **Progressive Step Auto-Scroll Across Funnel Forms (`SecurityAuditWidget.svelte`, `BlueprintOrderFlow.svelte`, `AuditPricing.svelte`, `ComplianceAuditCatalogExplorer.svelte`):** Wired `scrollIntoView({ behavior: "smooth" })` on step transitions and package selection so clicking any step/tier link scrolls smoothly to the active form step ending on registration.
- [x] AC3 — **Paid Audit Tier Registration + Free Baseline Audit In-Between Before Stripe Checkout (`AuditPricing.svelte`):** Updated `AuditPricing.svelte` (`submitCheckout`) so commissioning Tier 2/3/4 registers the Client Portal account and reserves the Free Tier 1 Baseline Audit (`POST /api/security-audit`) in-between before redirecting to `/api/stripe/audit-checkout`.
- [x] AC4 — **AI Agent Helper Intake Replacing Direct Contact Form Links (`ChatWidget.astro`, `ChatApp.svelte`, `SolutionsGrid.astro`, `SolutionsPage.astro`, `ContactFormSection.astro`):** Intercepted `[href^="/contact"]` links via `wom:open-chat` to open the AI Agent Helper, collect request scope + target website URL + work email, and trigger `data-testid="chat-handoff-free-audit-btn"` (`Start Free Audit & Register →`) into `#audit-order-widget`.
