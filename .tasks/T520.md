# T520 — Admin CP infrastructure tariff and usage warnings dashboard

## Summary

Following the owner's confirmed decision to operate within the Supabase Free tier ([[AgDR-0003]], [[T229]]),
infrastructure headroom is a strict budget rather than spare room. These limits fail abruptly rather than gradually.
Currently, infrastructure limits are checked offline by CLI (`just supabase-limits`), but CP operators and admins have
no live visibility into resource consumption, quota headroom, or approaching thresholds.

This ticket delivers an infrastructure tariff and usage monitoring surface in the Admin Control Panel (`apps/cp`):
1. **Live Quota Metrics**: Supabase Postgres database size vs 500 MB, Storage bytes vs 1 GB, and project allocation vs 2/2 cap.
2. **Early Warning Indicators**: Visual meters and warning callouts at 70% (amber/warn) and 90% (red/alert).
3. **Inactivity / Keep-Alive Sentinel**: Tracks the Supabase 7-day auto-pause inactivity window.
4. **Cloudflare & Provider Posture**: Cloudflare cron triggers (5/5 cap), R2 storage, Infisical secret counts.
5. **Fail-Closed & Unmeasured Transparency**: Unmeasured metrics (specifically Supabase 5 GB/mo egress) are explicitly reported as UNMEASURED with direct dashboard links, adhering to [[AgDR-0025]] (no false green checks).

## Acceptance criteria

- [x] **AC1 — Backend Infrastructure Usage Endpoint**: Implement an authenticated Admin API route (`/api/admin/infra-usage.ts`) that returns measured database size, storage usage, project allocations, and provider metadata.
- [x] **AC2 — Admin CP Infrastructure View**: Create or integrate an Admin CP view (`apps/cp/src/pages/admin/infra.astro`) rendering quota cards, progress bars, and percentage consumption.
- [x] **AC3 — Early Warning & Actionable Guidance**: When any resource exceeds 70% (warn) or 90% (alert), display actionable banners with copyable remediation commands (e.g., vacuum, prune logs, offload to R2).
- [x] **AC4 — Honest Reporting of Unmeasured Quotas**: Egress and unreachable projects are rendered in an explicit "Unmeasured Surfaces" block, never folded into a passing state.
- [x] **AC5 — Verification & Automated Tests**: Vitest unit/integration tests proving endpoint authorization, threshold warning triggers, and correct handling of unreachable services.
