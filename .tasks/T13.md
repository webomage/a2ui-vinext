# T13 — SDLC skill pack

## Summary


🟢 **LIKELY ALREADY DELIVERED — verify and archive rather than schedule (measured 2026-08-13).**
This asks for *"`openspec-*`, TDD, code-review, security-review and verify composed into one
pipeline"*. That pipeline **exists**: **10 `w0m-sdlc-*` skills** are installed
(`new · start · research · spec · build · review · security · verify · deploy · archive`) plus
`w0m-tdd`, and **`.w0m/sdlc.json` declares the lifecycle literally** as
`new → start → spec → build → review → security → verify → deploy → archive`.
⇒ **AC1 reads as satisfied.** Marked **P3** only so the board can rank it; the real next step is
`w0m-sdlc-archive`, not implementation. ⚠️ **Verify before archiving** — this estate has repeatedly
found "spec-only" changes that were actually built **and** built things that were never archived,
which is [[T16]]'s entire subject.
Compose `openspec-*`/TDD/code-review/security-review/verify into a pipeline.

## Acceptance criteria

- [x] AC1 — ✅ **VERIFIED SATISFIED 2026-08-13.** Not "the skills exist" — **composed**, checked
      component by component:
      | AC1 names | delivered by | evidence |
      |---|---|---|
      | one **pipeline** | `.w0m/sdlc.json → lifecycle` | `new → start → spec → build → review → security → verify → deploy → archive`, and **every gate names its successor in its own SKILL.md** — the routing chain is complete end to end |
      | `openspec-*` | `w0m-sdlc-spec` · `w0m-sdlc-archive` | spec invokes **`openspec-new-change`** + **`openspec-verify-change`**; archive invokes **`openspec-archive-change`** |
      | **TDD** | `w0m-sdlc-build` | test-first / TDD, plus a standalone `w0m-tdd` skill |
      | **code-review** | `w0m-sdlc-review` | correctness · reuse · simplification |
      | **security-review** | `w0m-sdlc-security` | authz · RLS · secrets · injection |
      | **verify** | `w0m-sdlc-verify` | present and routed into by `security`, out to `deploy` |
      🔑 **The distinction that mattered: coexistence is not composition.** Ten skills sitting in a
      directory would not satisfy this AC; a chain where each gate routes to the next does. That is
      what was checked.
