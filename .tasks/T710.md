# T710 — Orca Embedded Browser: Load and Persist w0m-ext MV3 Extension in Electron Browser Session

## Summary

Enable installing, loading, and persisting the `w0m-ext` Manifest V3 browser extension inside Orca Desktop's embedded Electron browser (`w0m-pr/orca` + `w0m-ext`). Investigate Electron's `session.extensions.loadExtension()` / `session.loadExtension()` lifecycle on the Orca browser partition, wire a CLI/settings/auto-load hook (`orca browser extension load <path>` or `just orca-ext-install`), and expose extension popup/side-panel or content-script injection across Orca embedded browser tabs.

## Acceptance criteria

- [x] AC1 — **Electron Partition Extension Loader in `w0m-pr/orca`:** Inspect how Orca Desktop creates `WebContentsView` / `BrowserView` sessions for embedded browser tabs (`w0m-pr/orca/src/main/browser/extensions/browser-extension-session-loader.ts` & `w0m-pr/orca/src/main/browser/extensions/browser-extension-load-directory.ts`), fix unpacked extension staging to skip `node_modules` alongside `.git`, and expose `experimentalBrowserExtensions` in `SettingsUpdate` RPC.
- [x] AC2 — **`w0m-ext` Build & Auto-Provision Recipe (`just orca-ext-install`):** Build `w0m-ext` (`dist/` unpacked MV3 bundle) and provide `scripts/orca_ext_install.py` + `just orca-ext-install` / `just orca-ext-status` recipes (in root `justfile` and `w0m-ext/justfile`) that register `w0m-ext` (`id: bgbjhhmkdadhapfmgfcmafikobaglpgg`) into Orca's embedded browser session.
- [x] AC3 — **Content Script, Service Worker & Action Popup Support in Embedded Tabs:** Stage `w0m-ext` into Orca's `browser-extensions` unpacked store (`e7f0404ede7e81878bc94a7f129f042a`), register the extension record in `installed.json`, enable `experimentalBrowserExtensions: true` in `profile-state.db`, and enable + pin across all 6 Orca browser profiles in `browser-session-meta.json`.
- [x] AC4 — **Automated Verification & Upstream/Fork PR Readiness:** Add automated test coverage in `w0m-pr/orca/src/main/browser/extensions/browser-extension-load-directory.test.ts` (`9 passed`) and `scripts/tests/test_orca_ext_install.py` (`2 passed`) and document the workflow in `.agents/reports/t710-orca-browser-w0m-ext-install.md` (`w0m-web/docs/reports/t710-orca-browser-w0m-ext-install.md`).
