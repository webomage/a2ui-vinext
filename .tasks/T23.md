# T23 — SDLC skill pipeline + tech-debt tracing in hooks

## Summary

Compose the existing skills+tools into a standing lifecycle
(explore→openspec→TDD→code-review→security-review→verify→deploy→archive) AND wire hooks so
each run **emits tech-debt findings into a traced store** (semgrep/osv/deno/tsc/gitleaks +
TODO/FIXME census → `tech_debt` table surfaced in CP). Uses skills+tools together by
default. **Known debt to burn down (found 2026-07-12):** ~29 `deno check` type errors
across live edge fns — linkedin-ingest(6), parse-resume(5), github-repos(5),
platform-webhook-gateway(4), generate-ui-mockup(2), + weekly-digest/upwork-poller/
chat-internal/analyze-interview/generate-{asset,blueprint-image}(1 each). Not
commit-blocking (hook checks staged only) nor deploy-blocking (security gate excludes
deno-check); blocks a future full-stack gate.
