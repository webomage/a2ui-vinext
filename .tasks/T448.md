# T448 — Type the estate's Python against a real contract: Backstage catalog entities first, then an untyped-code ratchet

## Summary

Owner, 2026-09-25: "we potentially should start do typing for python and some kind of classes", measured only
against the SDLC-platform integration. [AgDR-0026] gives that integration a concrete outside contract: the w0m catalog
uses Backstage's entity standard, validated by typed Python models against the `@backstage/catalog-model` JSON
Schemas. This ticket builds those models first, then ratchets typing across the rest of the estate's Python.

Measured 2026-09-25: 155 top-level scripts in `wom7web/project/scripts` (the justfile comment still says 44) and 58 in
root `scripts/`; 129 of them parse JSON into untyped dicts; 7 use dataclasses/TypedDict/Protocol; `wom7web/mypy.ini`
sets none of `disallow_untyped_defs`, `check_untyped_defs`, `strict`, and excludes tests.

## Acceptance criteria

- [ ] AC1 — **Entity models.** Typed Python models for the Backstage envelope and each kind [[T64]] AC2 uses, checked
  against the pinned `@backstage/catalog-model` JSON Schemas; red probes for a bad `apiVersion`, a missing
  `metadata.name`, an unresolved reference and an unknown annotation prefix.
- [ ] AC2 — **Library choice, measured.** Pydantic vs dataclasses + jsonschema, decided on install weight, validation
  error quality and mypy support, recorded in the ticket.
- [ ] AC3 — **Measure the baseline.** A script counts untyped defs and untyped JSON loads per file across both script
  trees; the numbers are recorded here, including how many of the 155 mypy actually checks today.
- [ ] AC4 — **Ratchet.** `just py-typing-check` fails when either count rises; downward only; `-test` red probes;
  declared in `project/test-suites.json`.
- [ ] AC5 — **Typed loaders for the policy files.** `stacks-policy.json`, `.w0m/sdlc.json`, `project/test-suites.json`
  and the other policy schemas load through typed models, so a schema no code reads becomes visible ([[T301]]).
- [ ] AC6 — mypy scope comment in the justfile matches reality.
