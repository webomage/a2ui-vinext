## Summary

**Design System — Claude-Design sync pipeline + adherence enforcement** (the "plan & tools to sync"). Build the repeatable **export → diff → apply**: (1) Claude Design export refreshes `design-system/` (tokens + `_ds_manifest.json` + JSX specs + dc.html); (2) token-drift diff with the manifest as source-of-truth vs `packages/ui` CSS vars + app `global.css`, regenerating the audit dashboards; (3) apply = emit one consumable token CSS bundle for all apps + the JSX→Svelte porting workflow + the hex codemod; (4) **port `design-system/_adherence.oxlintrc.json` (React-selector) to a Svelte-aware linter** and wire it into the pre-commit hook stack ([[wom-precommit-hooks-standard]]) so drift can't re-enter.

## Acceptance criteria

- [x] AC1 — Token drift detection tool (`ds-diff`): A command/script compares tokens in `design-system/_ds_manifest.json` against `packages/ui` CSS variables and `apps/*/src/styles/global.css`, reporting missing tokens, mismatched values, and undocumented overrides.
- [x] AC2 — Consumable token bundle generator: A build recipe compiles canonical design system tokens into a unified CSS package exported by `@webomage/ui` consumable across all four apps.
- [x] AC3 — JSX-to-Svelte spec porting workflow: Document and automate the repeatable workflow for ingesting Claude Design JSX component exports and porting them into idiomatic Svelte 5 components with verified prop contracts.
- [x] AC4 — Svelte & Astro design adherence linter rules: Port the React-specific rules from `design-system/_adherence.oxlintrc.json` into ast-grep rules (`project/ast-grep/rules/`) or linter checks that catch raw hex colors, raw pixel values, and invalid props on `.svelte` and `.astro` files.
- [x] AC5 — Pre-commit enforcement gate: Wire design adherence checks into the pre-commit gate (via `just` recipe), preventing commits that introduce new hardcoded color hexes or unstyled native form controls.
- [x] AC6 — Full pipeline end-to-end verification: Validate the sync pipeline end-to-end: simulate token update in `design-system/`, run diff check, generate bundle, and prove the pre-commit linter blocks unapproved hex styles organically.

## Definition of Done

T93 is done when: a `ds-diff` command reports token mismatches between
`_ds_manifest.json` and both `packages/ui` CSS vars and app `global.css` files, a build
recipe emits one consumable token CSS bundle from `@webomage/ui`, the JSX→Svelte porting
workflow is documented and repeatable (not tribal knowledge), the React-specific
`_adherence.oxlintrc.json` rules exist as ast-grep rules that fire on raw hex/pixel values
in `.svelte`/`.astro`, and a pre-commit gate actually blocks a staged commit introducing a
new hardcoded hex — demonstrated end-to-end, not asserted.
