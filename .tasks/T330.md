      location, distinct from the governed pair `.agent/skills` (dotted singular, retired, confirmed

      files). By name it is a strict subset of `.agents/skills` (`comm -23` between sorted dir
      listings returns empty) but has **not** been content-diffed file-by-file. Diff every one of
      the 46 shared-name dirs against its `.agents/skills` counterpart. If all are byte-identical,

      here with an explicit disposition — not silently dropped either way. It is currently invisible
      to `.w0m/skills.json` / `just skill check`; confirm the gate sees the outcome (absence or a
      declared+excluded entry).

      migrations. For each file, confirm read-only against the live schema whether its DDL/seed is
      already fully represented by committed migrations. Fully superseded → delete the file. Any
      statement that never reached a migration → write that migration first (per the CLAUDE.md

        delete both.

        look like a CV-rendering demo/test fixture set. Grep `apps/`, `packages/`, `specs/` for any

        uses it. If not, delete.

      `.home/Library/Preferences/astro/config.json`, and `.sitepins/config.json` (263 B, purpose
