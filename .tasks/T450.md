# T450 — The admin-client ratchet cannot see `staffAdminClient`

## Summary

`project/scripts/authz_admin_client_triage.py` (T327) counts every importer of the RLS-bypassing Supabase client.
Its `IMPORT_RE` only matches an import whose braces contain the word `supabase`. `apps/cp/src/lib/supabase.ts`
exports the same service-role client as **`staffAdminClient`** (and `supabase = staffAdminClient`), so importing it
by that name escapes the gate.

Measured 2026-09-25 (found by the T439 Plan C1 review): 6 files import `staffAdminClient` — `pages/content/pages.astro`,
`content/posts.astro`, `content/edit/[slug].astro`, `content/edit/new.astro`, `admin/debug.astro`,
`api/admin/impersonate.ts`. The baseline's "no longer imports the shared client" notes for `system/debug.astro`
and `content/posts.astro` are this evasion, not a paydown. `createAdminClient` (`lib/adminClient.ts`) is misnamed
but is the anon key plus the user's token, so it is not in scope.

## Acceptance criteria

- [x] AC1 — `IMPORT_RE` matches every exported name of the service-role client (`supabase`, `staffAdminClient`),
  derived from `lib/supabase.ts`'s exports rather than a second hand list; a red probe imports it as
  `staffAdminClient` and must be counted.
- [x] AC2 — The 6 files are registered in `project/authz-admin-client-baseline.json` with a reason each, or moved
  off the service-role client; the stale `system/debug.astro` entry is removed. The re-baseline is an owner-approved
  measurement correction, recorded here with before/after counts.
- [x] AC3 — `just authz-admin-client --enforce` green; `authz-admin-client-test` covers the alias case.

## Open questions (weighted)

- **Count the `adminClient()` factory too?** Recommend **yes, as its own named set in the same ratchet**
  (new ticket). Cost: small, same script. Risk if not: the factory bypasses RLS just like the
  singleton and 6 non-component callers use it uncounted today (`join/interview/[id].astro`,
  `web/blueprints/compare.astro`, `api/admin/broadcast-extension.ts` in cp and web,
  `corporate-verify.ts`, `kyc-verify.ts`). Unblocks: one number for "who can bypass RLS". Counter-view
  (T202): an explicitly named factory is the sanctioned spelling, so counting it may read as noise.
- **Browser `.svelte` importers of the singleton** (6 in the baseline). In a browser bundle the service
  key is absent, so what that client runs as is an open measurement. Recommend a read-only check
  before any change; low cost, not urgent.
