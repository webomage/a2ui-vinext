# T599 — Private cross-host workload state persistence, Linux session archive/closeout, and `w0m-prs` new PR/branch discovery with Orca task/automation registration

## Summary

Provide deterministic private persistence of multi-host project and agent workload state across `local` (macOS) and `linux-host` (`~/.w0m/state/workload/`), collect and archive the completed `w0m` sessions and brain artifacts from `linux-host` (`40410adb-a034-4a71-8a83-98907b5e3a7f` and `514770da-2de8-4c42-b74c-763a3bf102dd`) while closing their idle Orca terminals, and extend `scripts/w0m_prs.py` (`just prs`) to discover both open upstream PRs and unsubmitted PR-ready feature branches in `w0m-pr/*` and register an Orca Task & zero-token-precheck Orca Automation (`orca-sync` / `check-delta`) so PR monitoring runs natively in Orca without keeping a permanent token-burning agent session alive.
