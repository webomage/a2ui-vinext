# T45 — Research: AI-Native Security Auditing & Code Verification

## Summary

Analyze and establish inner-loop security checks (AST syntax validation, SAST rules for JWT/signature bypasses, SCA for dependency integrity) that autonomous AI coding agents must run prior to proposing commits, minimizing "agentic slop" and technical debt.

## Acceptance criteria

- [x] AC1 — Analyze common security failures and vulnerabilities associated with autonomous agent commits.
- [x] AC2 — Design an inner-loop pre-commit verification architecture using AST parsers, Semgrep rules, and SCA scanners.
- [x] AC3 — Propose human-in-the-loop validation triggers based on task complexity and code impact metrics.
- [x] AC4 — Document the tooling integration roadmap inside agent environments.
