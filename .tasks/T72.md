# T72 — Consolidate spec systems

## Summary

Three parallel spec systems coexist: OpenSpec (the ecosystem standard), `.agent/specs/system_v1.md` (a DSL citing nonexistent `src/lib/models`), and `wom7ext/.windsurf/` speckit (9 dangling workflows; `.specify/` scaffold = 0 hits). Pick one, retire/migrate the others so agents stop treating parallel/legacy specs as truth.

## 🔬 Re-measured 2026-08-13 — two of three still stand, and there is a FOURTH the ticket never named

| system | state today |
|---|---|
| **OpenSpec** — `openspec/changes/` | ✅ **19 active changes.** The ecosystem standard, and the one the SDLC gates read. |
| `wom7web/.agent/specs/system_v1.md` | 🔴 **still present** (4 KB) — the DSL citing a nonexistent `src/lib/models`. |
| `wom7ext/.windsurf/` speckit | 🔴 **still present** (88 KB, **9 workflows**). |
| `wom7ext/.specify/` scaffold | 🟢 **GONE** — so the 9 `.windsurf` workflows that reference it are now **dangling by definition**, which is [[T192]]'s **D43**. |

⚠️ **The fourth system is Gauge, and it is NOT a competitor — do not "consolidate" it away.**
`wom7web/specs/` holds **189 `.spec` files** (**364** estate-wide) and **0 Gherkin**. By standing
decision **Gauge specifies TESTS and OpenSpec specifies CHANGES** — different jobs, different
lifecycles. A consolidation that counted `.spec` files as a rival system would delete the estate's
entire executable-test corpus. **This ticket is OpenSpec vs the two legacy DSLs, and nothing else.**

## Acceptance criteria

- [x] **AC1 — record the decision BEFORE deleting anything.** OpenSpec is the change-spec standard,
      Gauge is the test-spec standard, and `.agent/specs/system_v1.md` + `wom7ext/.windsurf/` are
      retired. ⚠️ The reason this ticket exists is that **agents treat whatever they find as truth**,
      so a deletion with no recorded decision just moves the ambiguity somewhere else.
- [x] **AC2 — retire `.agent/specs/system_v1.md`, triaging its content rather than dropping it.**
      It cites a nonexistent `src/lib/models`, so most is stale by construction — confirm nothing in
      it is the only record of a decision first. 🔴 **`.agent/` is Antigravity's LIVE surface and must
      NOT be deleted — only this file.** An agent has already deleted a client's entire `.agent/` on
      a narrower warning than this one.
- [x] **AC3 — remove or repoint the 9 `wom7ext/.windsurf/` workflows.** They reference a `.specify/`
      scaffold that **no longer exists**, so every one is dangling. Same finding as [[T192]] **D43** —
      close them together or say why not.
- [x] **AC4 — a check proves the retired systems stay retired.** Fails if `system_v1.md` or a
      `.windsurf/` workflow reappears, or a new spec dialect lands undeclared. ⚠️ **Red-probe it
      against today's tree**: a gate written only after the cleanup has never been seen to fail,
      which is the vacuous-green shape this estate keeps re-learning.
- [x] **AC5 — Gauge is explicitly a KEEPER, not a casualty.** The 189 `.spec` files are the
      executable test corpus and this ticket's own title invites deleting them. State the
      OpenSpec/Gauge split in `openspec/SPEC-AUTHORING-STANDARD.md`.
- [x] **AC6 — the agent-facing rule surfaces name the authority.** `CLAUDE.md` / `AGENTS.md` already
      point at `openspec/`; add the negative half — *these two are retired* — because the failure
      mode is an agent finding a legacy spec and believing it.

## Definition of Done

- One change-spec system (OpenSpec) and one test-spec system (Gauge), both stated in writing.
- The two legacy DSLs are gone and a red-probed check keeps them gone.
- No agent-facing rule surface points at a retired system.
