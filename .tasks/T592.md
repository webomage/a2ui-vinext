# T592 — Feature Voting Board: One-Click Supabase GitHub OAuth Voting & Cloudflare Edge SVG Badge Cache

## Summary

Upgrade the GitHub-Issues-as-SSOT Feature Voting Board (`apps/cp/src/lib/githubFeatureBoard.ts`, `/api/board/[owner]/[repo]`, `/api/board/[owner]/[repo]/badge.svg`, and `FeatureVotingBoard.svelte`) with:
1. **One-Click Supabase GitHub OAuth Session Voting (`resolveUserGithubToken`)**: Automatically extract the user's GitHub OAuth `provider_token` from an active Supabase Auth session (`locals.session?.provider_token`, `supabase.auth.getSession()`, or `sb-github-provider-token` cookie) in addition to explicit `X-GitHub-Token` / `Authorization: Bearer` headers, while strictly preserving the `github_account_required` rule (401 with `Sign in with GitHub OAuth` CTA when unauthenticated).
2. **Cloudflare Edge Cache (`caches.default`) + Deterministic Weak `ETag` (`304 Not Modified`)**: Compute deterministic weak ETags (`W/"fb-<hex>"`) for `/api/board/[owner]/[repo]` and `/api/board/[owner]/[repo]/badge.svg`, short-circuit matching `If-None-Match` requests with `304 Not Modified`, and cache rendered SVG badges in Cloudflare's `caches.default` with `s-maxage=600, stale-while-revalidate=3600`.

## Acceptance Criteria

- [x] **AC1**: Implement `resolveUserGithubToken` in `w0m-web/apps/cp/src/lib/githubFeatureBoard.ts` supporting `X-GitHub-Token` header, `Authorization: Bearer` header, JSON body `github_token`, `sb-github-provider-token` cookie, and Supabase OAuth `session.provider_token`, while strictly enforcing `github_account_required` (`401`) when no GitHub account token is present.
- [x] **AC2**: Implement `computeFeatureBoardEtag` and `isEtagMatch` in `w0m-web/apps/cp/src/lib/githubFeatureBoard.ts` and wire `ETag`, `If-None-Match` (`304 Not Modified`), and Cloudflare Edge `caches.default` (`X-Edge-Cache: HIT|MISS|REVALIDATED`) into `/api/board/[owner]/[repo]/badge.svg.ts` and `/api/board/[owner]/[repo].ts`.
- [x] **AC3**: Update `FeatureVotingBoard.svelte` (`@webomage/ui` primitives) to surface a 1-click `Sign in with GitHub OAuth` CTA (`/api/auth/oauth?provider=github&next=...`) in both the auth alert banner and auth panel.
- [x] **AC4**: Verify with unit tests in `w0m-web/apps/cp/src/tests/api/board/feature-board.test.ts` and `w0m-web/apps/cp/src/components/oss/__tests__/FeatureVotingBoard.test.ts` (all passing).
