# T7 — Durable/summarized conversation memory

## Summary

Replace the 10-row `chats` replay with a rolling summary + recent turns; pairs with the
CF Agents SDK / Durable Objects.

## Acceptance criteria

- [x] AC1 — Rolling summary + recent turns replaces the fixed 10-row `chats` replay
- [x] AC2 — Memory backed by a Cloudflare Durable Object (native `DurableObject`, one per session)
      reachable from the edge function's existing authenticated call path into the `wom7api`
      Worker — not the `agents` npm SDK, which this change does not adopt (see spec `design.md`
      Decision 2)

## Definition of Done

A replayed session's model context is built from a Durable-Object-backed rolling summary + recent
turns, never from a raw `chats`-table read; a session past the recent-turns threshold carries a
non-empty summary; a poisoned (non-replayable) turn never reaches Durable Object state; the
`/api/chat-memory/:sessionId` route 401s without the shared bearer token and degrades the chat to
empty history (never a thrown error) on a Durable Object fetch failure.
