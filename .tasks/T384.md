# T384 — Audit and eliminate inline code suppressions across estate; remove programmatic @ts-ignore scripts and audit test security bypasses

## Summary

Audit of the 7 estate repos on 2026-09-18 revealed **622 inline suppressions** (`wom7web` 311, `wom7mlx` 261, `wom7api` 27, `wom7ext` 18, `wom7cfworkers` 5) that bypass linter and typecheck quality gates without individual tracking or architectural review.

Critical hotspots include:
1. `wom7web/fix_ts.py` and `fix_static_imports.py` programmatically injecting `// @ts-ignore` into Cloudflare Workers source code rather than supplying proper ambient type definitions.
2. 44 unreviewed `nosemgrep` bypasses in test suites (`tests/bot_security_steps.ts`, `tests/steps/ats.steps.ts`) suppressing dynamic regex and child process spawning checks.
3. 138 Python `# noqa` in `wom7web` and 152 in `wom7mlx`.

This ticket audits and eliminates gratuitous suppressions, provides proper ambient typing for Cloudflare worker imports, establishes threat models or narrow semantic rules for test security checks, and introduces an inline suppression ratchet gate so unchecked suppressions cannot silently grow.

## Acceptance criteria

- [ ] AC1 — **Eliminate Programmatic @ts-ignore Scripts**: Retire `fix_ts.py` and `fix_static_imports.py`'s `@ts-ignore` injection; provide proper ambient TypeScript declarations for `cloudflare:workers` and static imports so worker files typecheck cleanly without comments.
- [ ] AC2 — **Audit Test Security nosemgrep Bypasses**: Audit all 44 `nosemgrep` comments in `tests/bot_security_steps.ts` and `tests/steps/ats.steps.ts`; remove unneeded bypasses and document threat model rationale for any legitimately required test mock.
- [ ] AC3 — **Audit & Reduce Web/API/Ext Suppressions**: Audit `// @ts-ignore`, `@ts-expect-error`, and `# noqa` across `wom7web`, `wom7api`, and `wom7ext`, resolving root type/lint defects and reducing baseline count.
- [ ] AC4 — **Suppression Ratchet Gate**: Implement an inline suppression count ratchet check in `project/scripts/` (registered in `project/test-suites.json`) to prevent suppressions from expanding unnoticed.
- [ ] AC5 — **Tech Debt Update**: On archive, delete or update row D65 in `TECH-DEBT.md`.
