# T5 — Unified contracts registry

## Summary


🟡 **TRIAGED P2 2026-08-13.** Product work with a written spec
(`openspec/changes/2026-07-11-client-conversion-and-contracts`) and 3 ACs. ⚠️ **Sequence it after
[[T204]]** — T204 separates the three meanings of `projects` and establishes that `contracts` is
already multi-source (95 upwork + 1 direct); building a "unified registry" before that split is named
would unify the wrong things.
One view over `source: direct` + external platforms (`platform`/`platform_ref`); the
external mirror is read-only, internal annotations are editable.

## Acceptance criteria

- [x] AC1 — Single registry view spans `source: direct` and external platforms (`apps/cp/src/lib/contracts/unified-registry.ts` `buildUnifiedContractRegistry`, `apps/cp/src/pages/o/[org]/money/contracts/index.astro`, `apps/cp/src/components/admin/ContractManager.svelte`)
