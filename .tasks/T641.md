# T641 — Orca Mobile: move arrow-keys settings button to bottom-right and add zoom-stable Gamepad control layer

## Summary

1. **Top-Right Control Overflow (`ScreenEdgeNavigationOverlay.tsx`)**: The arrow-keys settings / mode-switcher chip (`edge-arrow-flavour-chip`) was anchored at `{ top: PANE_EDGE_INSET, right: PANE_EDGE_INSET + 2 }`, colliding with top-right session/pane controls (`•••`, close/split/review buttons). Moving it (`edge-arrow-settings-dock`: `edge-arrow-flavour-chip` + 1-tap `⚙` `edge-arrow-settings-button`) to **bottom-right** keeps top-right chrome unobstructed while placing the settings control directly under the right thumb (with `bottomRightOffset` lifting cleanly when the native-chat jump-to-tail FAB is visible).
2. **Zoom-Stable Gamepad Control Layer (`mode === 'gamepad'`)**: While keeping all existing modes (`pills`, `strips`, `orbs`, `off`) 100% intact, added **`gamepad`** mode (`EdgeGamepadPad.tsx` + `useZoomStableViewport`):
   - **Bottom-Left D-Pad**: Compact cross pad (`Up`, `Down`, `Left`, `Right` around a center grip) with tactile haptics and press-and-hold auto-repeat.
   - **Bottom-Right Diamond Action Cluster + Settings Dock**: Console diamond (`Tab`, `Alt+M` (`\x1bm`), `Esc` (`\x1b`), `Enter` (`\r`) on terminal panes; `Prev Tab`, `Top`, `Next Tab`, `Bottom` on non-terminal scroll/chat panes) stacked cleanly above the bottom-right arrow-keys settings dock.
   - **Pinch-Zoom Stability (`useZoomStableViewport`)**: Counter-scales `edge-arrows-zoom-hud` against `window.visualViewport` (`1 / scale` from `transformOrigin: 'top left'`) across both Orca Mobile's WebView session shell and mobile browsers so pinch-zooming never enlarges or clips the HUD.
