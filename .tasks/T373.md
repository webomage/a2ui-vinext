# T373 — Unified Stripe commercial billing: one-time audit purchases on main, client subscription management in CP, and custom service invoicing

## Summary

Owner directive, 2026-09-18:
> *"we have to have one time purchases for audit on main*
> *and also subscription management for client and custom invoicing for services for development and other continuous money relationships"*

This ticket unifies the three core commercial payment rails for the w0m platform under Stripe:
1. **One-Time Audit Purchases on Main (`apps/web` / `webomage.com`)**: Self-serve purchasing of Level 2/3 security, code, and infrastructure audit packages with metadata capture (repo URL, company name, contact) and automated client intake provisioning upon checkout completion.
2. **Subscription Management for Clients (`apps/cp` / `cp.webomage.com`)**: Recurring retainer and access subscriptions (Starter, Growth, Enterprise) with Stripe Billing Checkout, active subscription telemetry in the Client Portal, and 1-click self-serve management via Stripe Customer Portal (`billingPortal.sessions.create`).
3. **Custom Service Invoicing for Engineering Delivery (`apps/cp`)**: Milestone, sprint, and ad-hoc development invoices issued by w0m managers/PMs, payable by clients via Stripe Checkout, with automated webhook fulfillment updating `invoices.status = 'paid'` and crediting project treasuries.
4. **Reconciliation & Non-Vacuous Accounting**: Interlocking with [[T290]]'s reconciler to guarantee that every paid invoice, one-time audit purchase, and active subscription reconciles against real Stripe API records.

## Acceptance criteria

- [x] AC1 — **One-Time Audit Checkout on Main**: `apps/web` provides a direct Stripe Checkout integration for purchasing one-time audit packages (e.g. Code & Infrastructure Audit), capturing target repository URL, client email, and requirements in Checkout metadata.
- [x] AC2 — **One-Time Purchase Webhook Fulfillment**: Server-side webhook handler verifies Stripe signatures and processes `checkout.session.completed` for one-time audits, automatically creating or linking the client record (`public.clients`), marking the invoice paid, and registering the audit order.
- [x] AC3 — **Client Subscription Tier Management**: `apps/cp` Client Portal provides a dedicated Billing & Subscriptions interface displaying active tier (`trial`, `starter`, `growth`, `enterprise`), renewal date, and billing period, with a checkout action for activating or upgrading subscriptions.
- [x] AC4 — **Self-Serve Stripe Customer Portal**: Implement backend endpoint (`/api/client/billing-portal`) generating an authenticated Stripe Customer Portal session, allowing clients to securely manage payment methods, download PDF invoices, and cancel/upgrade subscriptions without agent or admin intervention.
- [x] AC5 — **Custom Invoicing for Development Services**: Custom milestone and ad-hoc engineering invoices in `public.invoices` can be paid by clients via Stripe Checkout (`stripe-checkout` / `apps/cp/src/components/client/InvoiceList.svelte`), updating `status = 'paid'`, recording `external_invoice_id`, and crediting the project treasury upon payment confirmation.
- [x] AC6 — **Anti-Vacuous Stripe Reconciliation**: Verified with automated reconciliation tool (`just reconcile-stripe`) ensuring invoices, one-time charges, and subscriptions in Supabase reconcile against live Stripe API records, failing on mismatched records or empty comparisons (AC4 of T290).

## Definition of Done

T373 is done when:
1. A visitor on `webomage.com` can purchase an audit package via Stripe Checkout and receive immediate confirmation with client intake created.
2. A client on `cp.webomage.com` can view their active subscription, subscribe to recurring plans, and launch the Stripe Customer Portal to manage cards and billing self-serve.
3. Custom milestone invoices generated in the portal are payable via Stripe and automatically reconciled to `status = 'paid'`.
4. All webhook endpoints verify signatures with `STRIPE_WEBHOOK_SECRET` and fail closed.
5. Automated quality checks (`just reconcile-stripe`, `just typecheck`, `pnpm test`) pass cleanly.
