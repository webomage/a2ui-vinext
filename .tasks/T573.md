# T573: Pre-push typecheck host-RAM auto-scaling, V8 heap sizing & global flock serialization (Load 70 swap-thrash fix)

## Context

On `<= 8 GiB` hosts (such as the `5.0 GiB` usable RAM AMD A10-5745M Linux notebook with a `4.0 GiB` SATA SSD `/swapfile`), `prepush_runner.py run-typecheck --concurrency 3` spawned 3 concurrent `astro check` Node/TypeScript language-server processes with `NODE_OPTIONS="--max-old-space-size=8192"`. Because an 8 GiB V8 heap ceiling suppresses garbage collection on a 5 GiB host, the 3 parallel processes grew to ~3.5 GiB RSS combined on top of the ~3.2 GiB OS/Chrome/agent baseline, causing severe SATA SSD swap thrashing (`20.2 min` typecheck duration, Linux load average `~70` from 60+ threads in uninterruptible disk-wait `D` state, and `systemd-journald` 3-minute watchdog timeouts).

## Acceptance Criteria

- [x] **AC1 (Host-RAM-aware `run-typecheck` concurrency):** `scripts/prepush_runner.py` (`host_total_ram_gib()`, `default_typecheck_concurrency()`) and `justfile` (`just typecheck`) auto-scale `astro check` concurrency when `--concurrency` / `W0M_TYPECHECK_CONCURRENCY` is not explicitly set (`1` on `<= 8 GiB` RAM hosts, `2` on `<= 14 GiB` RAM hosts, `3` on `>= 16 GiB` RAM hosts).
  <!-- verify: python3 -m pytest -q scripts/tests/test_prepush_runner.py -->
- [x] **AC2 (Proportional V8 heap ceiling):** `scripts/prepush_runner.py` (`default_node_max_old_space_mb()`) scales default `NODE_OPTIONS=--max-old-space-size` to `2048` MB on `<= 8 GiB` hosts, `4096` MB on `<= 14 GiB` hosts, and `8192` MB on `>= 16 GiB` hosts so V8 runs garbage collection before pushing pages into swap.
  <!-- verify: python3 -m pytest -q scripts/tests/test_prepush_runner.py -->
- [x] **AC3 (Cross-worktree global `typecheck.lock`):** `cmd_run_typecheck()` acquires an exclusive `fcntl.flock` on `~/.cache/w0m/prepush/typecheck.lock` (`typecheck_global_lock()`) so concurrent agent trees or `just typecheck` runs never stack multiple `astro check` pools on the same machine.
  <!-- verify: python3 -m pytest -q scripts/tests/test_prepush_runner.py -->
