# T460 — Research: group training in one engagement

## Summary

Owner, 2026-09-26 (T458 Q30): training runs through engagements, like delivery. An engagement joins exactly two orgs
(contractor and client), so a trainer teaching several people from several personal orgs needs one engagement per
trainee today. The owner can imagine one engagement where a trainer teaches several persons from several personal orgs,
and asked for it as a P2 research item, not part of the base model.

## Acceptance criteria

- [ ] AC1 — Compare: one engagement per trainee (today's model) vs an engagement with several client-side orgs vs a
  cohort grouping several two-party engagements; for each, what access each trainee has to the others' work.
- [ ] AC2 — Check the Backstage shape of each (an engagement `Group` has one parent; the client is an annotation).
- [ ] AC3 — Recommend, with a weighted decision; if built, it is its own ticket.

## Definition of Done

T460 is done when the owner has a written recommendation and either a build ticket exists or the option is closed with
its reason.
