# T452 — One fixed site background (Warp), deprecate other scenes, remove DB queries on SSR, and simplify Slide Management UI

## Summary

Owner direction 2026-09-25:
> "so in general we stick with current background animation as the one and only and can set it as default and only available to use since now"
> "so let's not delete completely but disable usage with deprecation of all other slides/demos/backgrounds and tweak real UI connection to this part simple and straightforward"

Prior to this ticket, both `web` and `cp` layouts queried `site_settings` and `slide_config` on every SSR page load (or loaded dynamic snapshots and auth tokens), causing page flash, unnecessary database queries, and fragile client-side synchronization for a background configuration that is effectively static. Furthermore, `AppShell.svelte` had an unscrollable content column issue when host apps locked root document overflow.

This ticket fixes the active background to `Warp` in code across all apps, deprecates other scenes/playlists without deleting them, eliminates database/settings reads from the layout render path, fixes AppShell scrolling, and simplifies the Slide Management UI in CP.

## Acceptance criteria

- [x] AC1 — **Shared Fixed Background Definition.** `@webomage/lib/background` defines `ACTIVE_BACKGROUND` (`demos: warp`, sky-400 `#38bdf8`, speed `0.07`, duration `25000`) and exports `DEPRECATED_SCENES` and `DEPRECATED_BACKGROUND_TYPES`.
- [x] AC2 — **Zero Database / Settings Queries on Background Render.** `apps/cp/src/layouts/Layout.astro`, `apps/web/src/layouts/Layout.astro`, and both `BackgroundManager.svelte` components render `ACTIVE_BACKGROUND` without querying `slide_config`, `site_settings`, or `getPublicSettings()`. Verified by `packages/lib/src/background.spec.ts` (all 6 tests passing).
- [x] AC3 — **AppShell Scroll Lock Resolution.** `packages/ui/src/lib/components/layout/AppShell.svelte` uses `height: 100dvh` and `.col { min-height: 0; overflow-y: auto }` so content scrolls properly even when document root has `overflow: hidden`.
- [x] AC4 — **Simplified Slide Management UI in CP.** `apps/cp/src/pages/content/slides.astro` and `apps/cp/src/components/admin/SlideManager.svelte` present the active Warp background cleanly, disable obsolete playlists/types with deprecation notices, and provide simple, straightforward controls without fragile dynamic sync.
