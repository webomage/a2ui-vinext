# T400 — wom7func Reliability: Retry policies, DLQ handling, and structured health logging for Cloudflare Workflows

## Summary

Enhance reliability and observability for background workflows running in `wom7func`. Establishes standardized retry semantics, dead-letter queue (DLQ) storage for failed workflow steps, and structured health logging for monitoring.

## Acceptance Criteria

- [ ] AC1 — Configure explicit exponential backoff retry policies for all scheduled workflow steps.
- [ ] AC2 — Implement DLQ capture mechanism storing failed execution payloads for replay and analysis.
- [ ] AC3 — Standardize structured JSON logging across all handlers in `wom7func`.
- [ ] AC4 — Author automated unit tests verifying retry boundaries and error propagation.
- [ ] AC5 — Verify `pnpm test` and `pnpm exec tsc --noEmit` pass cleanly in `wom7func`.
