# T753 — Remove hardcoded personal GitHub handle from members projects API

## Summary

- Removed hardcoded `"casualuser"` personal GitHub identifier from `w0m-web/apps/cp/src/pages/api/members/projects.ts` (flagged by `no-personal-data-in-components.test.ts` during `just deploy-all`).
- Added `resolveMemberGithubLogin` to resolve the signed-in member's GitHub login dynamically from GitHub OAuth `user.identities` / `user_metadata`, `profile_contact.github_url`, or `https://api.github.com/user` (with user-scoped cache key `cachedForLogin`).
- Updated `mergeDiscoveredPrsIntoProjects` and `fetchGithubMemberPrs` to filter self-forks and attribute personal upstream PRs dynamically to the resolved member login.

## Why

`just deploy-all` blocked on `vitest` (`just test-js`) because `w0m-web/apps/cp/src/pages/api/members/projects.ts` contained a hardcoded personal GitHub username from T751, tripping `no-personal-data-in-components.test.ts` and risking cross-member PR leakage.

## Scope

- **In:** `w0m-web/apps/cp/src/pages/api/members/projects.ts` and `w0m-web/apps/cp/src/tests/api/members/__tests__/projects.test.ts`.
- **Out:** `w0m-web/apps/cp/src/config/participating-projects.json` static catalog and `scripts/w0m_prs.py`.
