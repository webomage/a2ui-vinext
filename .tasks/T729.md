# T729 — Audit Estate Infisical & Worker Environment Variable Code Usage, Prune Dead Env Residue, and Publish Repo-First Rotation/Deletion Ledger

## Summary

Audits every Infisical-injected environment variable (`114` keys, including all historical-digest secrets flagged by `just secret-history-check`) against word-boundary executable readers across all estate repositories (`w0m-web`, `w0m-api`, `w0m-cf`, `w0m-ext`, `w0m-sec`, `w0m-skills`, `w0m-mlx`, and `@wom` scripts/recipes) without ever logging secret values. Separates **dead/unused keys** (which can be deleted outright from Infisical instead of rotated) from **active runtime / CLI / E2E keys**, prunes dead env residue from `w0m-web/turbo.json` and `w0m-cf/worker-configuration.d.ts`, updates `w0m-api/scripts/rotate_leaked_secrets.py`, and publishes a repo-first audit report.
