# T695 — Fix `/me/todos` Infinite `$effect` Loop, SSR Preload + Parallel Query Wave, and Restore Open `admin_todos` State

## Summary

Fix the `"Loading collections..."` hang on `me.webomage.com/me/todos` caused by a self-mutating Svelte 5 `$effect` (`entitlements = { ...entitlements, ...initialEntitlements }` while `loading === true` throwing `effect_update_depth_exceeded` during hydration whenever `initialEntitlements` was passed), parallelize `GET /api/todos` (`handleTodosApi`) + SSR-preload `initialLists` and `initialItems` in `w0m-web/apps/me/src/pages/me/todos.astro` and `w0m-web/apps/cp/src/pages/o/[org]/p/[project]/todos.astro`, and add migration `w0m-api/supabase/migrations/20261109210000_restore_admin_todos_open_state.sql` restoring the 7 originally open `admin_todos` items verified from the R2 backup (`backup_20261001_081509.sql`).

## Acceptance criteria

- [x] AC1 — **Eliminate Svelte 5 `$effect` Infinite Loop & Add SSR Preload Support (`TodoWorkspace.svelte`, `todos.astro`, `TodoWorkspace.test.ts`):** Removed the self-referential `$effect` on `entitlements` in `w0m-web/apps/cp/src/components/todos/TodoWorkspace.svelte`, initialized `$state` cleanly with `untrack(...)`, added `initialLists`/`initialItems` SSR preload props + a 12-second `AbortController` timeout, and added regression test coverage in `w0m-web/apps/cp/src/components/todos/__tests__/TodoWorkspace.test.ts` (`4/4` tests passing).
- [x] AC2 — **Parallelize `GET /api/todos` & Preload on SSR (`todos-server.ts`, `w0m-web/apps/me/src/pages/me/todos.astro`, `w0m-web/apps/cp/src/pages/o/[org]/p/[project]/todos.astro`):** Refactored `handleTodosApi` (`GET`) in `w0m-web/apps/cp/src/lib/todos-server.ts` to run `todo_lists`, `profile_public_settings`, `todo_visibility_audit_log`, and `resolveTodoEntitlements` in a single parallel `Promise.all` wave (only calling `ensurePersonalInboxList` when `lists.length === 0`), and wired SSR preload into `w0m-web/apps/me/src/pages/me/todos.astro` and `w0m-web/apps/cp/src/pages/o/[org]/p/[project]/todos.astro`.
- [x] AC3 — **Restore Pre-E2E Open State of Migrated `admin_todos` Items (`20261109210000_restore_admin_todos_open_state.sql`):** Authored idempotent migration `w0m-api/supabase/migrations/20261109210000_restore_admin_todos_open_state.sql` restoring `is_completed = false, completed_at = NULL` on the 7 originally open items (`website daily builds`, `telcel contract`, `Seat for bike`, `frigie write board`, `upwork and github accounts for both on that e-mails`, `resume servicio777.mx development`, `Test Todo`) verified from `backup_20261001_081509.sql`.
