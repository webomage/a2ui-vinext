# T376 — Modern Python test suite: uv-managed dependencies, pytest runner with xdist parallelization, and unified just recipes

## Summary

Owner directive, 2026-09-18:
> *"let's have for python more modern test suit from uv stack"*

Currently, the estate's Python code (`wom7web/project/scripts/` and `wom7api/scripts/`) implements all critical gates, ratchet checks, and SDLC tooling for the 7 estate repositories. However, its 80+ test suites (`project/scripts/tests/test_*.py`) are managed and run through ad-hoc, fragmented mechanisms:
1. Individual standalone executions (`python3 project/scripts/tests/test_foo.py`) relying on standard library `unittest.main()`.
2. Ad-hoc `python3 -m pytest` or `pytest` calls without a unified manifest or pinned test dependencies.
3. No declarative `pyproject.toml` or `uv.lock` governing test dependencies (`pytest`, `pytest-xdist`, `pytest-cov`, `pytest-mock`), pytest flags, or discovery rules.
4. Slow sequential execution with no automated parallelization across CPU cores.

This ticket modernizes the Python test infrastructure across the estate by adopting Astral's **`uv` stack**:
1. **Declarative `pyproject.toml`**: Governs dependencies (`pytest>=8.0`, `pytest-xdist>=3.5`, `pytest-cov>=5.0`, `pytest-mock>=3.14`) and standardizes pytest configuration (`[tool.pytest.ini_options]`).
2. **Fast, Isolated Execution via `uv run`**: Tests run reproducibly without manual virtualenv management or global environment pollution.
3. **Multi-Core Parallel Acceleration**: Harnesses `pytest-xdist` (`-n auto`) for high-speed concurrent execution across CPU cores.
4. **Full Unittest Compatibility**: Seamlessly executes existing `unittest.TestCase` suites without breaking changes.
5. **Unified Estate Recipes**: Exposes clean `just` recipes (`just py-test`, `just py-test-fast`, `just py-test-cov`, `just py-test-file <path>`), integrated into `project/test-suites.json` and stacks policy.

## Acceptance criteria

- [x] AC1 — **Modern `uv` Manifest & Pytest Configuration**: Create `wom7web/pyproject.toml` configuring the `uv` toolchain, declaring modern test dependencies (`pytest`, `pytest-xdist`, `pytest-cov`, `pytest-mock`), and configuring `[tool.pytest.ini_options]` with test discovery root (`project/scripts/tests/`), import modes, durations, and output formats.
- [x] AC2 — **Fast Isolated Execution via `uv run`**: Ensure `uv run pytest` seamlessly provisions the virtual environment and runs tests without polluting the global python environment or requiring manual venv activation.
- [x] AC3 — **Parallel Multi-Core Test Acceleration**: Implement `just py-test-fast` leveraging `pytest-xdist` (`-n auto`), achieving parallel execution and sub-second batch test speeds across multi-core CPU architectures.
- [x] AC4 — **100% Backward Compatibility with Unittest Suites**: Existing `unittest.TestCase` classes in `project/scripts/tests/` collect and run cleanly under the uv/pytest runner without requiring rewrites of existing assertions or test helpers.
- [x] AC5 — **Estate Justfile & Suite Registry Integration**: Add `py-test`, `py-test-fast`, `py-test-cov`, and `py-test-file` to `wom7api/justfile` (and symlinked `wom7web/justfile`), register suites in `project/test-suites.json`, and confirm `just suites-drift` and `just discovery` pass cleanly.
