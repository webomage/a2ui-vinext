# T55 — Audit shared components for silently-purged Tailwind utilities

## Summary

[[T38]] fixed the **mechanism** by which Tailwind v4 purged `@webomage/ui` classes — an off-by-one
`@source` path — and proved it with a single class count (`ring-brand` 0 → 2). It never surveyed the
**blast radius**. T38's own row demanded that second step and no record shows it was run; the
restoration of `T38.md` on 2026-08-21 recorded it as an unowned residual. This ticket owns it.

🔑 **Why this is not merely tidying.** The defect class is *silent*: a purged utility produces no
build error, no console warning and no failing test — only a component that renders slightly wrong
somewhere nobody looked. T38 was found because one instance was visible enough to break the header
layout (`flex-row-reverse` was absent, so the language switcher grew the wrong way and shoved search
and auth aside). Every utility used *only* inside a shared component was exposed to the same purge
for the same period. One was noticed. The rest were never counted.

⚠️ **Scope guard.** This is an audit of what the purge window damaged, not a general design-system
conformance pass — that is [[T42]], which covers the same components with a different question.
Findings that are DS divergences rather than purge casualties belong there.

## Acceptance criteria

- [x] **AC1** — the purge window is established as a date range from git history (broken `@source`
      introduced → `7307645e` on 2026-07-14), so "which classes were at risk" is a measured set
      rather than a guess. *(Recorded in `wom7web/docs/reports/2026-10-21-t55-tailwind-purge-audit.md` and `tailwind_source_audit_t55.py`: broken `@source "../../../packages/ui"` introduced in `7307645e` on `2026-07-14`, fixed on `web`/`cp` in `1ca7b89c` on `2026-07-17`, and extended to all 5 apps on `2026-10-21`.)*
- [x] **AC2** — every app's compiled CSS is diffed against the utilities actually referenced in
      `packages/ui/src`, producing a **list of classes referenced by a shared component but absent
      from at least one app's output**. 🔴 The check must run per app: `@source` was verified present
      in `apps/web` and `apps/cp` only — **`apps/job` and the fourth app were never confirmed**, and
      an app still missing the directive would reproduce the whole bug. *(Added `src/styles/global.css` with `@source "../../../../packages/ui/src";` in `apps/job`, `apps/join`, and `apps/demo`; verified across all 5 apps `web`, `cp`, `job`, `join`, `demo` by `tailwind_source_audit_t55.py`.)*
- [x] **AC3** — AC2's finding is either **empty and proven empty**, or each entry is triaged as
      still-broken, already-fixed-incidentally, or intentionally-unused. A count of zero must be
      accompanied by evidence the comparison could have found something. *(Unscanned shared utility count is `0` across all 5 apps; non-vacuous proof demonstrates `>= 50` shared-only utilities per app — including `flex-row-reverse` and `ring-brand` — that would be purged if `@source` were missing or broken.)*
- [x] **AC4** — the interim rule T38 imposed is explicitly **retired or retained**: *shared
      components must use inline or scoped styles for critical layout, not purgeable utilities*. It
      was a workaround for the broken `@source`; with the path fixed it should be unnecessary, but
      nothing records lifting it, so components may still be carrying it. Whichever way it goes,
      record the decision — an unretired workaround becomes folklore. *(Explicitly **RETIRED** in `wom7web/docs/reports/2026-10-21-t55-tailwind-purge-audit.md` §3.)*
- [x] **AC5** — a **standing gate** so this cannot silently regress: assert that every app CSS entry
      carries an `@source` resolving to `packages/ui/src`, and that the path **exists on disk**.
      🔴 An `@source` pointing at a non-existent directory is exactly the original bug and Tailwind
      reports nothing — so a gate checking only that the directive is *present* would have passed
      throughout the defect's entire lifetime. Register it in `project/test-suites.json`
      ([[T240]] — an unregistered gate is an invisible one). *(Implemented in `wom7web/project/scripts/tailwind_source_audit_t55.py` + `wom7web/project/scripts/tests/test_t55_tailwind_source_audit.py`, proven failing-first on `@source "../../../packages/ui";`.)*
