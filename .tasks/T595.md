# T595 — Standardize cross-platform toolchain on Homebrew with LTS floors, latest comparison, and Node 26 alignment (AgDR-0052)

## Summary

Establish the estate-wide toolchain and package currency rule (`AgDR-0052`):
1. **Minimum LTS Floor + Latest Comparison:** Every tool in `project/policies/tools-policy.json` and runtime/package in `project/policies/deps-policy.json` must declare a `min` version at or above active LTS (e.g. Node `>=22.23.3`) while tracking and comparing against `latest` stable (`known_good: "26.13.0"`), lifting artificial `<23` upper bounds that block current Homebrew stable releases.
2. **Homebrew as Canonical Cross-Platform Package Manager:** Standardize on `brew` (`/opt/homebrew` on macOS `darwin-arm64` and `/home/linuxbrew/.linuxbrew` on Linux `x86_64`) as the preferred package manager across all developer and agent hosts instead of fragmented language-specific version managers (`nvs`, `fnm`, `pyenv`, `tfenv`).
3. **Cross-Host Version Comparison:** Enable side-by-side comparison of installed versions against policy `min` (LTS), `known_good` (latest verified), and cross-platform hosts (`darwin-arm64` Mac vs `linux-x86_64` HP).
4. **Complete Host CLI & Workspace `.bin` Toolchain Governance:** Govern all 9 previously unmanaged host CLIs invoked across `justfile` and `scripts/` (`pnpm`, `pre-commit`, `git`, `colima`, `podman`, `warp-cli`, `cloudflared`, `caddy`, `mkcert`) in `project/policies/tools-policy.json` + `scripts/tool_usage_probe.py`, and verify/auto-provision workspace `node_modules/.bin` CLI binaries (`tsx`, `wrangler`, `vitest`, `tsc`, `oxlint`, `oxfmt`, `astro`, `drizzle-kit`) across all 5 TypeScript repos (`w0m-web`, `w0m-api`, `w0m-cf`, `w0m-ext/extension`, `w0m-skills`) so `just deploy-all` never fails with `Command "tsx" not found`.
