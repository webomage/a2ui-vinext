# T129 — SDLC structural enforcement

## Summary

Imported 2026-07-24 from a client-delivery note (`_self/delivery/SDLC_ENFORCEMENT.md`, written for
`artemioquierocomer.mx`, since deleted). It documents *why* agents skip SDLC gates in long sessions
— rules are behavioral text, not mechanical blockers; context-window pressure buries early
instructions; a short user message pattern-matches to a fast code response — and proposes
**structural** fixes. Only the generalizable, w0m-applicable mechanisms are imported here (the
Antigravity-specific `/learn` fix is not).

The load-bearing gap: **w0m does not structurally enforce ticket-first discipline at commit time.**
Verified this session — several `chore(...)`/`build(...)` commits landed with **no `T##` reference**
and passed the Conventional Commits hook. So the "create a ticket before code" rule is honored by
convention, not mechanically. This ticket makes it structural.

Distinct from **[[T119]]** (SDLC v2.1 = deterministic gate *execution* — commands via `just`,
secrets via `infisical`, hermetic env, `gate-advance`) and **[[T23]]** (the gate lifecycle itself,
done). T129 is the *enforcement-at-commit* axis on top of those.

## What is already known (do not re-derive)

- **Current commit hooks:** wom7web/wom7api run a `Conventional Commits` commit-msg hook (validates
  `type(scope): desc`) but it does **not** require a `T##`. `chore|docs|build`-typed commits with no
  ticket ref pass today (confirmed this session).
- **The source doc's Fix 3 hook** (adapt, don't copy verbatim): require a `T##` unless the message
  is an exempt conventional type (`chore|docs|trivial|merge|revert|wip|style|ci|build|test`). Note
  the exemption list is broad — `build`/`chore`/`docs` cover a lot, so calibrate it so real feature
  work can't dodge the gate by mistyping the prefix.
- **Trivial vs non-trivial** already lives informally (CLAUDE.md "if the work maps to a ticket");
  the source doc gives a crisp split — full gate for `src/`/data/UX/deploy; compressed
  (new→build→verify→archive) for typo/`*.md`/dev-tooling. `.w0m/sdlc.json` is the place to codify it.
- **No-bash rule:** any new hook logic is Python/TS, not a bash script (the source doc's example is
  `sh` — port it), consistent with the existing hook stack + [[wom-precommit-hooks-standard]].
- **CLAUDE.md → AGENTS.md chain** already carries the "SDLC is MANDATORY" block; the doc's point is
  to keep it at the TOP so it's read every turn. Verify placement, reinforce if buried.

## Acceptance criteria

- [x] **AC1 — commit-msg `T##` gate.** A commit-msg hook (Python/TS, not bash) requires a `\bT[0-9]+\b`
      reference; exemptions by an explicit, calibrated conventional-type allowlist. Rejects a
      feature/fix commit with no ticket; the message + example are clear. Proven red on a no-ticket
      `feat:` and green on `feat(x): … T129`. (`scripts/conventional_commit.py`, `just commit-msg-check`, `just t129-t386-hooks-test`)
- [x] **AC2 — no bypass regression.** The gate composes with the existing Conventional Commits hook
      (both must pass); `--no-verify` remains prohibited by policy; exemption list documented so it
      can't silently widen, with staged-file anti-dodge calibration (`classify_substantive_staged_files`) refusing unticketed `chore:`/`docs:`/`style:`/`ci:` commits that stage substantive code or migrations.
- [x] **AC3 — trivial/non-trivial codified in `.w0m/sdlc.json`.** A machine-readable policy (paths/
      change-classes → full vs compressed gate) that the gates + this ticket's docs reference, so
      "non-trivial" is unambiguous rather than per-agent judgment (`.w0m/sdlc.json → change_classification` & `conventions.ticket_before_code`, `.w0m/sdlc.schema.json`).
- [x] **AC4 — anti-retroactive-ticket rule stated + placed.** The rule "a ticket created *after* code
      shipped is a violation, not compliance" is recorded where agents see it (`AGENTS.md`, `.agents/rules/sdlc.md`, `wom7web/CLAUDE.md`, `wom7web/AGENTS.md`
      top block), and the SDLC-mandatory block is confirmed at the TOP of the CLAUDE.md→AGENTS.md
      chain.
- [x] **AC5 — rollout across w0m repos.** The commit-msg gate is installed in the standard
      pre-commit/commit-msg stack for the active w0m repos (`@wom`, `wom7web`, `wom7api`, `wom7func`, `wom7ext`, `wom7sec`, `wom7skills`, `wom7mlx/wom7mlx`), verified by `just t129-t386-hooks-test`.
