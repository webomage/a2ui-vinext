# T515 — Tinybird token literal in a tracked script

## Summary

Found by the root-migration research ([[T509]]) and re-checked: `wom7api/scripts/init_tinybird_schemas.py` is tracked in git
and contains **one 220-character token-shaped string literal**. The value was **not read or copied** while checking (only
its count and length were measured), and it must not be copied into this ticket, a commit message or any report. Whether
the token is still live is not known: that is AC1.

This matches a pattern the estate has been bitten by: a credential seen in a file is treated as compromised, and the
secret reaches a command only by process injection (`infisical run --env=<env> --silent -- <cmd>`, never a literal, never a
`.env`).

## Acceptance criteria

- [ ] AC1 — **Is it live?** The owner, or an agent through secret injection with the value never printed, checks whether
  the token still authenticates to Tinybird. Record only the outcome (live or revoked) and the date.
- [ ] AC2 — **Rotate.** If live, the owner rotates it in Tinybird and updates the stored secret in Infisical. Owner-only:
  rotating a credential is an account action.
- [ ] AC3 — **The script reads it by injection.** `init_tinybird_schemas.py` takes the token from the environment and fails
  closed with a clear message when it is absent. No literal remains in the working tree.
- [ ] AC4 — **History is assessed.** `git log -S` over the repo establishes since when the literal has been committed and
  whether the remote is public or private. Rewriting history is outward-facing and owner-only; this ticket records the
  decision, it does not do it.
- [ ] AC5 — **The scanner would have caught it.** Find out why the gitleaks hook did not flag a 220-character literal in a
  tracked file (rule gap, allowlist or a `p.`-prefixed token shape), and close the gap with a red fixture.
- [ ] AC6 — **Related live use is unaffected.** Tinybird analytics dual-writes (3 datasources) keep working after the
  rotation; verified by one write and one read through the existing path, not by this script.

## Definition Done

- Every AC ticked with the measuring command in the status note; no secret value anywhere in the repo, the ticket or the
  transcript. `just secrets-check` and the gitleaks hook green.

## Open questions (recommended answer first, with weight)

1. **Rotate even if it looks revoked?** *Recommend yes, unless AC1 proves it revoked.* Weight: rotation is cheap, a live
   token in git history is not.
2. **Delete the script or keep it?** *Recommend deciding in [[T509]] U0* (it is one of 37 scripts with no caller). If the
   schemas are already created, the script has no remaining job. Weight: low.
