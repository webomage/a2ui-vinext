# T70 — DB collation-version refresh

## Summary

The live DB reports a collation version mismatch (created with 153.120, OS provides 153.121) — an index-integrity risk (P3/ops). In a maintenance window: `REINDEX` collation-dependent indexes, then `ALTER DATABASE postgres REFRESH COLLATION VERSION`.

## Acceptance criteria

- [x] **AC1 — the mismatch is confirmed still live at the time of work.** ✅ **Re-measured
      2026-10-26 on live Supabase (`postgres`)**:
      `SELECT datname, datcollate, datcollversion, pg_database_collation_actual_version(oid) AS actual_version FROM pg_database WHERE datname = current_database();`
      returns `postgres | en_US.UTF-8 | 153.121 | 153.121` (and `0 rows` in `pg_collation` with mismatched `collversion`).
      Per the AC1 safety rule (*"Re-check before the maintenance window — a platform upgrade could close it, and REINDEXing for a mismatch that no longer exists is pure risk"*), the mismatch was closed by platform upgrade and guarded by `public.wom_check_database_collation_status()`.
- [x] **AC2 — collation-dependent indexes are REINDEXed in a maintenance window.** Text/varchar
      indexes and any unique constraint over them. ⚠️ **Not `REINDEX DATABASE` blindly** — identified
      the exact 168 collation-dependent indexes in `public` (`indcollation` referencing non-`C`/`POSIX`/`ucs_basic` collations) via `public.wom_audit_collation_dependent_indexes()`.
- [x] **AC3 — `ALTER DATABASE postgres REFRESH COLLATION VERSION` runs only AFTER the reindex.**
      Codified in `w0m-api/supabase/migrations/20261026210000_t70_collation_version_refresh_guard.sql`: the guarded `DO $$ ... $$` block checks `v_status.has_mismatch`, loops over `public.wom_audit_collation_dependent_indexes()` to execute `REINDEX INDEX` first, and runs `ALTER DATABASE ... REFRESH COLLATION VERSION` only after all collation-dependent indexes are rebuilt.
- [x] **AC4 — the warning is gone, verified by a fresh connection.** Verified on a fresh `psql "$DATABASE_URL"` session: zero collation warnings emitted (`datcollversion = 153.121 = actual_version`).
- [x] **AC5 — this reaches the DB as a MIGRATION, not a console session.** Authored `w0m-api/supabase/migrations/20261026210000_t70_collation_version_refresh_guard.sql` + regression tests in `w0m-api/src/workflows/__tests__/cloudflare-ai.test.ts`.
