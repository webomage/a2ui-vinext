# T713 — Client Project Multi-Dialect Spec Bootstrap & Registry (`clients-policy.json`, `GENERIC-SDLC-SET.md`, client-spec-init for Spec Kit, OpenGSD & OpenSpec)

## Summary

Support **GitHub Spec Kit (`github/spec-kit`, `.specify/`)** and **OpenGSD (`open-gsd/gsd-core`, `.planning/`)** alongside **Vanilla OpenSpec (`openspec/`)** and **`w0m-openspec` (`.w0m/sdlc.json`)** for client projects (`role: "managed"` and `role: "self-managed"` in `project/policies/clients-policy.json`), with a one-command bootstrapper (`just client-spec-init`) that injects Webomage's `Testing seams` and security/quality overlays without leaking `.w0m/` internal tracking surfaces into external client repositories.

Split from: [[T712]]

## Acceptance criteria

- [x] AC1 — **`spec_dialect` Policy Schema (`project/policies/clients-policy.schema.json`, `clients-policy.json`):** Added `spec_dialect` enum (`w0m-openspec`, `openspec`, `github-speckit`, `open-gsd`, `bmad`, `conductor`, `cc-sdd`) to `clients-policy.schema.json`, populated `clients-policy.json` (plus reconciled `development_modes` and `elephant_goldfish_model` tier contract surfaces), and wired automatic `client_spec_bridge.detect_spec_dialect` fallback in `scripts/client_inventory.py`.
- [x] AC2 — **One-Command Client Spec Bootstrapper (`client-spec-init`):** Implemented `scripts/client_spec_init.py` + `just client-spec-init` + `just client-spec-init-test` (`w0m-web/project/test-suites.json`) supporting `github-speckit` (`<client>/.specify/templates/overrides/testing-seams.md`), `open-gsd` (`<client>/.planning/TESTING-SEAMS.md`), and `openspec` (`<client>/openspec/`), with optional `--skills` delegation to `w0m-skills/scripts/install_generic.ts` and zero `.w0m/` leakage.
- [x] AC3 — **Update `w0m-skills/GENERIC-SDLC-SET.md` Lifecycle Matrix:** Extended the portable `Lifecycle -> skill map` table across all 7 phases (`research`, `spec`, `build`, `review`, `security`, `verify`, `archive`) with concrete `OpenSpec`, `GitHub Spec Kit` (`/speckit.*`), and `OpenGSD` (`/gsd-*` + `egm-*`) commands plus `just client-spec-init` bootstrap docs.
- [x] AC4 — **Automated Unit Tests (`test_client_spec_init.py`):** Added `scripts/tests/test_client_spec_init.py` (`7 passed`) proving dialect auto-detection, non-destructive overlay generation across `github-speckit`, `open-gsd`, and `openspec`, `client_inventory` schema validation, and zero `.w0m/` leakage on `self-managed` client targets.
