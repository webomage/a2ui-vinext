# T713 — Client Project Multi-Dialect Spec Bootstrap & Registry (`clients-policy.json`, `GENERIC-SDLC-SET.md`, `just client-spec-init` for Spec Kit, OpenGSD & OpenSpec)

## Summary

Support **GitHub Spec Kit (`github/spec-kit`, `.specify/`)** and **OpenGSD (`open-gsd/gsd-core`, `.planning/`)** alongside **Vanilla OpenSpec (`openspec/`)** and **`w0m-openspec` (`.w0m/sdlc.json`)** for client projects (`role: "managed"` and `role: "self-managed"` in `project/policies/clients-policy.json`), with a one-command bootstrapper (`just client-spec-init <target> --dialect <speckit|gsd|openspec>`) that injects Webomage's `Testing seams` and security/quality overlays without leaking `.w0m/` internal tracking surfaces into external client repositories.

Split from: [[T712]]

## Acceptance criteria

- [ ] AC1 — **`spec_dialect` Policy Schema (`project/policies/clients-policy.schema.json`, `clients-policy.json`):** Add optional `spec_dialect` (`"w0m-openspec"` | `"openspec"` | `"github-speckit"` | `"open-gsd"`) to client project declarations with automatic filesystem detection fallback (`.w0m/sdlc.json` -> `w0m-openspec`, `.specify/` -> `github-speckit`, `.planning/` -> `open-gsd`, `openspec/` -> `openspec`).
- [ ] AC2 — **One-Command Client Spec Bootstrapper (`just client-spec-init <target> --dialect <speckit|gsd|openspec>`):** Implement `scripts/client_spec_init.py` + `just client-spec-init` to initialize `.specify/` (with Webomage `Testing seams` preset override in `.specify/templates/overrides/`), `.planning/` (with `Testing seams` verification overrides in `.planning/`), or `openspec/`, plus install the portable `w0m-skills` set (`just skills-install-generic`).
- [ ] AC3 — **Update `w0m-skills/GENERIC-SDLC-SET.md` Lifecycle Matrix:** Extend the portable `Lifecycle -> skill map` table so every phase (`research`, `spec`, `build`, `review`, `security`, `verify`, `archive`) documents the exact workflow for `OpenSpec`, `GitHub Spec Kit` (`/speckit.*`), and `OpenGSD` (`/gsd-*` + `egm-*`).
- [ ] AC4 — **Automated Unit Tests (`scripts/tests/test_client_spec_init.py`):** Verify dialect auto-detection, non-destructive template overlay generation for `speckit`, `gsd`, and `openspec`, and zero `.w0m/` leakage on `self-managed` targets.

## Definition of Done

Per [`w0m-web/openspec/SPEC-AUTHORING-STANDARD.md`](../w0m-web/openspec/SPEC-AUTHORING-STANDARD.md):
- Acceptance criteria AC1–AC4 verified by unit tests and `just client-inventory`.
