# T624 — Multi-platform social & GitHub signal tracing (Telegram, Threads, LinkedIn, X, Reddit, GitHub) lacks unified automated/on-demand connectivity, ToS-aware CF Edge Reader extraction, and 1-click insight promotion to todos, tasks, and projects

## Summary

Today w0m's social and developer signal surfaces are fragmented, narrow, or unwired:
1. **Narrow or missing social connectors**: Telegram (`telegram-job-source.ts`) and Threads (`threads-job-source.ts`) only parse USD hiring posts rather than general channel/post search and member engagement insights; Reddit (`services-policy.json`) was `implemented: false`; X had no zero-cost public search/oEmbed or budget-guarded API v2 adapter; `githubAdapter.sync` ignored stars (`/user/starred`, inbound repo stargazers) and forks (`/users/:login/events`, inbound repo forks); `linkedin-ingest` fetched org share stats without extracting normalized post/reaction/share signals or accepting ToS-safe LinkedIn Data Export (`Saved_Items.csv`, `Shares.csv`, `Reactions.csv`) and explicit `w0m-ext` user clips.
2. **Platform constraint gaps in outreach & clipper**: `outreach_clips`, `outreach_threads`, `source_links`, `outreach-clip-ingest`, and `w0m-ext`'s `ClipPlatform` omitted `'github'`, `'reddit'`, and `'x'`.
3. **No first-party ToS-aware Cloudflare Edge Reader ("CF Jina-Reader analogue")**: `w0m-cf` already binds `BROWSER` and `AI` with V8 crawling (`crawler.ts`), yet lacked an authenticated, `robots.txt`- and ToS-enforcing `/api/reader/extract` + MCP `edge_read` surface that turns public URLs, RSS/JSON feeds, and oEmbed endpoints into clean Markdown + structured metadata without violating `T98` (zero LinkedIn headless/`li_at` scraping) or `T550` (zero Telegram MTProto user-account automation).
4. **No Signals → Insights → Todos / Tasks / Projects pipeline**: Captured likes, stars, forks, shares, bookmarks, and search hits had no normalized `social_signals` store, no AI/deterministic `social_insights` synthesis, and no 1-click approval inbox (in CP `/me/insights` and via Telegram Bot inline callbacks) to materialize `public.todo_lists` + `public.todo_items`, `.tasks/T##.md` / GitHub Issues, or `public.projects` + `public.source_links` with append-only `social_signal_audit_log` provenance (`T614`).

## Definition of Done

A signed-in member (and the scheduled 6-hour worker for targets marked `automated` or `both`) can search, trace, and ingest signals across Telegram, Threads, LinkedIn, X, Reddit, and GitHub — optionally routed through `w0m-cf`'s `robots.txt`- and ToS-enforcing Edge Reader without violating `T98` or `T550` — see deduplicated signals synthesized into pending Todo, Task, or Project insights in `/me/insights` and Telegram, and promote any insight in one click into a real `todo_items` row, GitHub Issue/task draft, or `projects` + `source_links` record with an append-only `social_signal_audit_log` trail and zero code-to-schema or route-policy drift.
