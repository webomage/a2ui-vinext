# T727 — Accelerate Edge TTFB, Anonymous Edge Caching, SSR Query Parallelism, and Below-the-Fold Island Hydration Across `web`, `me`, and `cp`

## Summary

Eliminates uncached per-request Supabase round-trips on anonymous public routes (`webomage.com/` `1,093ms` TTFB and `me.webomage.com/` `1,505ms` TTFB per `AgDR-0055`), adds safe anonymous-only `Cache-Control` headers (`s-maxage=60, stale-while-revalidate=300`) that strictly bypass any request carrying session/impersonation cookies or `Authorization` headers, parallelizes sequential SSR Supabase queries on `/me/profile`, and defers below-the-fold Svelte island hydration from `client:load` to `client:visible` on `/me/profile` and `/cp/profile`.

## Acceptance criteria

- [x] AC1 — **Cache Public `site_pages`, `getPosts`, and `jobs-list` Lookups + Safe Anonymous `Cache-Control` (`w0m-web/packages/lib/src/security/edge-cache-policy.ts`, `w0m-web/apps/web/src/middleware.ts`, `w0m-web/apps/web/src/lib/supabase.ts`, `w0m-web/apps/me/src/pages/index.astro`, `w0m-web/apps/me/src/middleware.ts`):** Added 60s `BoundedTtlCache` + Cloudflare Edge Cache helper (`fetchPublicJsonCached`) and anonymous-only `applyAnonymousHtmlEdgeCache`, verified by `w0m-web/packages/lib/src/security/__tests__/edge-cache-policy.test.ts` (`5/5` passed).
- [x] AC2 — **Parallelize Sequential SSR Queries & Defer Below-the-Fold Islands to `client:visible` (`w0m-web/apps/me/src/pages/me/profile.astro`, `w0m-web/apps/cp/src/pages/profile.astro`):** Replaced sequential `await supabase.from(...)` queries with `Promise.all([...])` and moved below-the-fold islands to `client:visible` on both profile pages.
