# T37 — Consolidate wom7ext LLM path onto the CF Workers AI proxy

## Summary

The extension currently calls **Mistral-direct (primary) → Gemini-direct → local** from
the client (`extension/src/services/llmService.ts::callLLM`); OpenRouter was already gone
from code (this session scrubbed the last stale docs/specs/manifests/tests naming it).
Target: route inference through `wom7cfworkers` **`/ai/chat`** (exists; CF Workers AI,
tools + SSE streaming) so the extension aligns with the T36 provider policy (CF-primary,
no client-side third-party keys). ⚠️ **Privacy-model change** — today content goes
direct-to-provider (or on-device for local) with **no server of ours in the path**;
routing via our proxy means our worker sees page content. The extension
`constitution.md`/`project.md` Privacy-first principle must be re-decided & rewritten
before this ships. Needs an OpenSpec change (proposal + spec delta over `extension`
capability + tasks) per the authoring standard; keep the local-LLM option for
privacy-sensitive users.
