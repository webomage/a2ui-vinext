# T701 — Publication-Grade Multi-Page Printable Audit Report PDF Dossier & PKCE Auth Callback Hardening

## Summary

1. Fix manual printing (`Ctrl+P` / `window.print()`) and the `Export PDF / Print` action on `/o/[org]/projects/security-audit` so that instead of clipping at 1 page (`100vh`) with dark-mode `text-white` / `text-gray-400` text on white paper and CP shell chrome (`ACTIVE HAT`, Obsidian sync bar, `PageHeader` instructions, tab buttons, and `🐛 Report Bug`), printing produces a clean, high-contrast, multi-page **Executive & Technical Security, Lighthouse CWV, Code/Skill & Compliance Audit Report Dossier** (`data-testid="cp-printable-audit-report-dossier"`).
2. Fix the `PKCE code verifier not found in storage` error on `/login` when authenticating as admin or via OAuth / magic link (`packages/lib/src/auth/middleware.ts`, `packages/lib/src/auth/server-client.ts`, `packages/lib/src/auth/handlers.ts`, `apps/{cp,web}/src/pages/api/auth/reset-request.ts`, and `packages/ui/src/lib/components/ui/AuthForm.astro`).

## Acceptance criteria

- [x] AC1 — **Unclip Multi-Page Print Pagination & Hide CP Shell Chrome in `@media print` (`apps/cp/src/styles/global.css`, `apps/cp/src/components/shell/CpShell.svelte`, `apps/cp/src/pages/o/[org]/projects/security-audit.astro`):** Override `html, body, .page-content, .content-scroll-area` with `height: auto !important; min-height: 0 !important; max-height: none !important; overflow: visible !important; background: rgb(255 255 255) !important; color: rgb(15 23 42) !important;` in `@media print`, and hide the CP hat availability bar, Obsidian connection toolbar, floating `BugReportWidget`, and interactive workbench controls when printing.
- [x] AC2 — **Structured Multi-Page Printable Audit Report Dossier (`SecurityAuditReportViewer.svelte`):** Render a dedicated, high-contrast (`rgb(15 23 42)` ink on `rgb(255 255 255)` paper with `print-color-adjust: exact` and `break-inside: avoid` cards) printable audit report (`data-testid="cp-printable-audit-report-dossier"`) containing:
  1. **Executive Cover & 4-Pillar Scorecard Header** (Organization, Target Domain, Verification Method, Report Timestamp & SHA-256 Hash, Surface Security Score + Grade, Lighthouse Mobile & Desktop Scores, Level 2 Repo & Skill/UI-UX Score, Level 3 Compliance Readiness % & `@k7c` FinOps Savings);
  2. **Section 1 — Surface & Perimeter Security Findings & Remediation Playbook** (complete table/cards of all findings with Severity, Status, CWE/OWASP, Observed vs Expected values, and copy-paste remediation snippets);
  3. **Section 2 — Mobile & Desktop Lighthouse Core Web Vitals (`LCP`, `INP`, `CLS`, `FCP`, `TTFB`) & Performance Remediations**;
  4. **Section 3 — Repository SAST/SCA/IaC & Read-Only Skill / 12-Dimension UI/UX Craftsmanship Summary**;
  5. **Section 4 — Cloud Infrastructure (`@k7`), FinOps Cost Optimization & Modular Compliance Readiness Matrix (`SOC 2`, `HIPAA`, `GDPR`, `PII`, `PCI-DSS`) + Synthesized Mistral Fixes**.
- [x] AC3 — **On-Screen Print Preview Toggle & Direct Export PDF Action (`SecurityAuditReportViewer.svelte`):** Add a `"Preview Printable Report"` toggle button (`data-testid="audit-toggle-print-preview"`) alongside `"Export PDF / Print"` (`data-testid="audit-export-pdf-top"` / `data-testid="audit-export-pdf"`) so users can inspect the exact formatted report dossier on-screen or print/save to PDF (`window.print()`) from any tab at any time.
- [x] AC4 — **PKCE Auth Callback Ceremony Hardening (`middleware.ts`, `server-client.ts`, `handlers.ts`, `reset-request.ts`, `AuthForm.astro`):** Skip pre-reading `supabase.auth.getUser()` inside `createAuthMiddleware` on `/api/auth/*` ceremony routes (`isAuthCeremonyApi`) so `GoTrueClient._removeSession()` never deletes `sb-<ref>-auth-token-code-verifier` when an expired session cookie is present; configure `cookieOptions` + non-empty duplicate-cookie protection in `server-client.ts`; recover cleanly in `handleCallback` when a session is already established or purge stale code-verifier cookies on failure; use `getSupabaseServerClient` in `reset-request.ts`; and strip one-time `error`/`message` params from `/login` URL history in `AuthForm.astro`.
- [x] AC5 — **Automated Unit & Print Layout Regression Tests:** Add unit tests in `packages/lib/src/auth/middleware.spec.ts`, `packages/lib/src/auth/handlers.spec.ts`, and `apps/web/src/tests/audit-blueprint-order-ui.test.ts` verifying PKCE ceremony preservation, `@media print` multi-page unclipping, and the structured `cp-printable-audit-report-dossier` sections.
