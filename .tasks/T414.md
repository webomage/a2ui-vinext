# T414 — Elevate Central Registers (LESSONS, STATE, TECH-DEBT, ROADMAP, docs) and Estate Tooling to Workspace Root

## Summary

Phase 1 of the workspace elevation ([[T411]], [[T412]]) established `@wom/.tasks/` as the single canonical task queue, elevated `.w0m/sdlc.json` and policies to `@wom/project/`, and relocated core queue scripts (`tasks_query.py`, `tasks_render.py`, `ticket_audit.py`, `dod_check.py`, `state_doctor.py`, `sync_github.py`) to `@wom/scripts/`.

However, the estate remains split across several central knowledge and operational boundaries:
1. **Central Registers Trapped in `wom7web`**: `LESSONS.md`, `STATE.md`, `TECH-DEBT.md`, `ROADMAP.md`, and `docs/` (which hold architecture, ecosystem maps, and decisions across all 7 repositories) remain nested in `wom7web/`.
2. **SDLC Machinery Trapped in `wom7api`**: Three core SDLC utilities — `gate_advance.py` (which mutates tickets and TASKS.md), `sdlc_doctor.py`, and `check_ticket_paths.py` — still live in `wom7api/scripts/`.
3. **Estate Tools Trapped in `wom7web`**: Core multi-repo governance tools (`w0m_audit.py`, `w0m_prs.py`, `host_posture.py`, `npx_audit.py`, `ticket_duplicate_check.py`, `ticket_recycle.py`, `sync_manifest_versions.py`) still execute through `wom7web/justfile`, triggering unnecessary Astro/web pre-commit overhead.

This ticket delivers **Phase 2 Elevation** governed by three non-negotiable architectural principles:
- **Rule 1: Fail Fast, Never Fall Back Silently**: Tools must check exactly one canonical location and fail loudly if missing, rejecting multi-tier fallback ladders.
- **Rule 2: Clean Cutover Over Backward-Compat Shims**: Update 100% of callers atomically to point directly to the workspace root rather than accumulating fragile permanent shims.
- **Rule 3: Zero Shadow Symlinks (Pure Single Source of Truth)**: Do NOT leave symlinks in old locations. A file exists in exactly one place in the repository tree. Leaving symlinks in legacy locations acts as an unobservable silent fallback, creates duplicate search results, and fools tools into thinking the legacy directory is still authoritative.

## Acceptance criteria

- [ ] AC1 — Elevate `LESSONS.md` to `@wom/LESSONS.md` as the canonical estate rules register. Remove `wom7web/LESSONS.md` completely (no shadow symlink). Update all callers (`lessons_query.py`, `w0m_audit.py`, justfiles) to resolve strictly from the workspace root.
- [ ] AC2 — Elevate `STATE.md` to `@wom/STATE.md` as the canonical session handoff surface. Remove `wom7web/STATE.md` completely. Update `state_doctor.py` and root `justfile` recipes (`state-check`, `state-save`) to operate directly at root.
- [ ] AC3 — Elevate `TECH-DEBT.md` and `ROADMAP.md` to `@wom/` root, removing the files from `wom7web/`. Update `debt_register_check.py` and `.w0m/sdlc.json` path references.
- [ ] AC4 — Relocate misplaced SDLC utilities from `wom7api/scripts/` (`gate_advance.py`, `sdlc_doctor.py`, `check_ticket_paths.py`) to `@wom/scripts/`, updating all callers to invoke `@wom/scripts/` directly with zero shadow files.
- [ ] AC5 — Relocate Tier 1 estate operations tools from `wom7web/project/scripts/` to `@wom/scripts/`, removing them from `wom7web` and exposing them directly in root `justfile`.
- [ ] AC6 — Record [[AgDR-0025]] in `docs/decisions/` ("Reject Silent Fallbacks, Backward-Compatibility Shims, and Shadow Symlinks") citing industry evidence, and index it in `docs/DECISIONS.md`.
- [ ] AC7 — Verify all quality gates pass from both `@wom` and `wom7web` (`just preflight --fast`, `just state-check`, `just search-test`, `just ticket-audit T414`).

## Definition of Done

T414 is complete when:
1. `LESSONS.md`, `STATE.md`, `TECH-DEBT.md`, `ROADMAP.md` reside canonically at `@wom/` root.
2. `gate_advance.py`, `sdlc_doctor.py`, and the Tier 1 estate tools reside in `@wom/scripts/` and execute natively from root `@wom/justfile`.
3. Code paths enforce Rule 1 (fail closed on missing canonical target, no silent fallback searching) and Rule 2 (clean cutover of callers).
4. `AgDR-0025` is documented and indexed.
5. All test suites pass cleanly across root and subrepos with zero `--no-verify`.
