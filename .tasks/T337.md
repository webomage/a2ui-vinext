# T337 — Advanced Code & Infrastructure Audit Runner with Ephemeral Air-Gapped Sandboxes

## Summary

Builds the Level 2 (Advanced Code) and Level 3 (Deep Cloud Infrastructure & Runtime) audit execution engines for `wom7sec`, positioning Webomage directly against visual IaC competitors like Brainboard while offering superior application-to-runtime depth and senior remediation.

For Level 2 (Code & Blueprint Audit), ordering the audit immediately provisions a **trial client account with no subscription activated** (no credit card or Stripe checkout required upfront), operating in **limited demo mode** (1 repo scan up to 50k LOC, sandbox execution quota, preview of executive summary + top-3 critical vulnerability remediation diffs, with continuous monitoring and automated fix PRs gated behind plan activation). The runner ingests third-party git repositories into strictly isolated, ephemeral sandboxes (leveraging Tart VM / Cloudflare Sandbox substrates). To defend against malicious repositories and prompt-injection attacks, the sandbox clones the repository, strictly severs all outbound network interfaces, and executes polyglot static analysis offline (Semgrep SAST, Trivy/OSV SCA, Gitleaks secret scanning, and Checkov IaC linting).

For Level 3 (Deep Infrastructure & Runtime Posture), the runner integrates read-only cloud provider credentials (AWS IAM cross-account roles, GCP Service Accounts, Cloudflare, Supabase) and leverages the sibling `@k7` curated stack (`terraformer` / `terracognita` for live cloud reverse-engineering, `k7tg` Rust engine for visual topology graphing, and `terracost` for FinOps waste estimation). Furthermore, it provides modular **Compliance Packet Extensions** (SOC 2, HIPAA, GDPR, PII, and PCI-DSS) that evaluate cloud IAM, encryption, audit trails, and multi-tenant RLS isolation to produce audit-ready readiness binders. All results are wrapped in a uniform structured-result contract and rendered in the Client Portal (`apps/cp`).

## Acceptance criteria

- [ ] AC1 — **Ephemeral Sandbox Provisioning & Lifecycle**: Implement the sandboxed audit runner interface capable of spawning clean, isolated execution environments (Tart microVM or Cloudflare Sandbox) with strict CPU/memory quotas, execution timeouts, and guaranteed post-run teardown.
- [ ] AC2 — **Air-Gapped Repository Ingest & Quarantine**: Implement the git ingest pipeline: clones target repo into a quarantined volume, revokes all outbound network access (`--network none`), and verifies no outbound packets can escape during analysis.
- [ ] AC3 — **Polyglot Offline Code Analyzers (Level 2)**: Wrap Semgrep (SAST), Trivy (dependency CVEs), Gitleaks (secrets), and Checkov (Terraform/IaC) into a uniform execution harness that emits normalized findings matching the `wom7sec` schema.
- [ ] AC4 — **Live Cloud Provider Connectors & @k7 Ingestion (Level 3)**: Implement read-only cloud ingestion connectors (AWS IAM role, GCP, Cloudflare, Supabase) and wrap `@k7c` (`terraformer`, `terracost`) to extract live cloud resources and calculate FinOps waste without modifying client infrastructure.
- [ ] AC5 — **Automated Topology Graphing Engine (Brainboard Competitor)**: Integrate `k7tg` / `inframap` to automatically generate interactive visual cloud topology diagrams and resource dependency graphs from extracted Terraform/cloud state.
- [ ] AC6 — **Compliance Packet Extensions (PII, SOC 2, HIPAA, GDPR, PCI-DSS)**: Implement modular compliance pack evaluation rulesets for Level 3 audits: checks least-privilege IAM, KMS encryption at rest, in-transit mTLS, immutable audit trail retention, and RLS database tenant isolation. Generates an exportable Compliance Gap Matrix and Executive Readiness Binder in the Client Portal.
- [ ] AC7 — **Adversarial Containment Probe & Client Portal Presentation**: Prove through an automated red test that a weaponized test repository (containing reverse shells, network probe scripts, and prompt injection traps) cannot compromise the host. Render advanced code findings, interactive topology map, FinOps waste report, and compliance gap matrices inside the authenticated Client Portal (`apps/cp`).
- [ ] AC8 — **Trial Client Provisioning & Limited Demo Mode (Level 2 Order Flow)**: When ordering a Level 2 audit, provision a trial client account (`status: 'trial'`, subscription inactive, no payment method required upfront). Enforce limited demo mode: quota of 1 repository scan, 50k LOC limit, 10-minute sandbox execution cap, rendering an executive summary with top-3 critical findings and remediation diffs in the Client Portal (`apps/cp`), while gating continuous monitoring and automated fix PRs behind full subscription activation.
