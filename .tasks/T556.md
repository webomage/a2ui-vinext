# T556 — Extend Orca (`casualuser/orca`) and w0m agent stack with Google Research Harness²

## Summary

Google Research's **Harness²** (`google-research/harness2`, `arXiv:2610.14224`, forked to `casualuser/harness2` in `wom7pr/harness2`) formalizes recursive agent harnessing across an 8-component `SurfaceSpec` (`c1` system prompt, `c2` context policy, `c3` long-term memory, `c4` tool guidance, `c5` subagents, `c6` skills, `c7` scripts, `c8` hooks/plugins) using a **Propose–Probe–Compose** loop and a structured **Experience Library** (`library/EXPERIENCE.md` + `INDEX.md`).

Because **Orca** (`casualuser/orca` in `wom7pr/orca`) is our desktop + mobile multi-agent IDE orchestrator managing isolated git worktrees, Claude/Codex/OpenCode agent sessions, skills, and hooks, extending Orca with Harness² turns Orca worktrees into interactive Propose–Probe–Compose environments while bringing Harness²'s `SurfaceSpec` hygiene, cue-indexed experience library, `ContextTree` evidence bundles, and `runmark` fingerprinting to the `w0m` stack. Full architectural report: [`.agents/reports/2026-10-18-harness2-w0m-analysis.md`](../.agents/reports/2026-10-18-harness2-w0m-analysis.md).
