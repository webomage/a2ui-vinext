# T41 — Demo accounts + demo-data empty states

## Summary

Seeded LIVE demo personas (`demo-client`, `demo-candidate`; `demo_account` marker; non-admin;
magic-link login) showcasing the client & candidate funnels; the demo data doubles as the badged
**empty-state** for new users (yields to real data on first create). **Three provisioning modes**
over one idempotent seeder (`supabase/functions/seed-demo/index.ts`): (1) `just seed-demo` CLI,
(2) an admin CP "Provision demo" button, (3) a scheduled reset. Sandboxed (no real
emails/payments/sync/invite); excluded from admin audit + real analytics. Reused as the non-admin
actors in the Gauge suite. Spec: OpenSpec `2026-07-14-demo-accounts`. Full history: the T41 board row.
