# T568 — `just eli5 T*` — plain-English one-paragraph ELI5 ticket explainer CLI & recipe

## Summary

When triaging a batch of tickets across areas or prefixes (`T57`, `T5*`, `T*`, or `--area ai`), reading raw `.tasks/T##.md` files requires wading through frontmatter, markdown tables, code blocks, and internal acronyms (`RLS`, `AAL2`, `SSOT`, `DORA`, `MV3`, `DCR`).

Owner direction (2026-10-23): provide `just eli5 T*` so any single ticket, comma/space list of tickets, wildcard pattern (`T5*`, `T*`), or area/priority/status filter outputs a crisp, grounded **one-paragraph plain-English ELI5 explanation** per ticket.
