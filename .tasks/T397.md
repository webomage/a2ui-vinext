# T397 — Automated ticket recycling: repurpose closed duplicate ticket IDs with new content and GitHub sync

## Summary

Owner directive, 2026-09-18: *"can we automate option a?? ... Repurpose T397"*.

When tickets are marked as duplicates or superseded, their issue IDs remain occupied in the monotonic sequence. Rather than leaving dead gaps or wiping remote project boards, Option A automates recycling these closed duplicate ticket IDs into brand-new tasks while strictly preserving the `T<n> == gh_issue == #<n>` 1:1 invariant across local files and GitHub.

This ticket designs and implements an automated ticket recycling utility (`project/scripts/ticket_recycle.py`), provides discovery of recyclable duplicate tickets (`--list`), fail-closed safety guards (refusing to overwrite active or genuine delivered tickets), pre-flight candidate draft uniqueness checking, atomic rewriting of ticket markdown and `TASKS.md` rows, and automated GitHub reopening and body/label synchronization via `sync_github.py`.

## Acceptance Criteria

- [x] AC1 — **Recyclable Pool Discovery**: Implement discovery mode (`--list`) in `project/scripts/ticket_recycle.py` that scans all ticket frontmatter and reports available recyclable duplicate tickets (`closed_as: duplicate`), showing ticket ID, previous title, and canonical target.
- [x] AC2 — **Fail-Closed Safety & Draft Uniqueness Check**: Implement `--recycle T<n> --draft <file>`. Fails closed with exit code 1 if the target ticket is not marked `closed_as: duplicate` (protecting active and completed work). Invokes `ticket_duplicate_check.py --check-draft` to ensure the incoming draft itself is not a duplicate of existing active tickets.
- [x] AC3 — **Atomic Local File & Board Rewriting**: Atomically rewrites `project/tickets/T<n>.md` while strictly preserving `id: T<n>` and `gh_issue: <n>`. Resets `status: queued`, clears `closed_as`, resets AC counters, updates title, summary, ACs, tags, and epic. Rewrites the corresponding 6-column row in `TASKS.md` in place.
- [x] AC4 — **GitHub Reopen & Re-projection**: Support `--sync` (default enabled) which drives `sync_github.py` to reopen GitHub issue `#<n>`, update its title and markdown body, reconcile labels, and re-populate the card on GitHub Project #2.
- [x] AC5 — **Automated Test Suite & Tooling**: Author `project/scripts/tests/test_ticket_recycle.py` with offline synthetic test fixtures covering: (a) pool discovery, (b) fail-closed protection of active/done tickets, (c) draft duplicate rejection, (d) atomic markdown and `TASKS.md` row rewriting. Expose recipes `ticket-recycle` and `ticket-recycle-test` in justfiles and register in `project/test-suites.json`.
