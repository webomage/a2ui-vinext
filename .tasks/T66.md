# T66 — Indeed Profile Form-Fill Helpers (wom7ext)

## Summary

Add Indeed.com as a supported platform in `wom7ext` for semi-automatic profile fulfillment. No public API exists — the approach is DOM-based form fill using the existing `formFillerService.ts` and `specEngine.ts` infrastructure (same pattern as Upwork/Fiverr, zero new architecture needed).

Source of truth: `public.profile_cv_facts` and `public.profile_experience` (with fallback to cached canonical profile state in `chrome.storage.local`).

## Approach

**Approach B (Field-by-Field Extension Fill)** — implement first. Takes ~1.5 hrs.

1. User navigates to `my.indeed.com/resume/edit/*`
2. Extension popup shows Form Filler Helpers section
3. User focuses a text field, clicks an action button
4. LLM generates text → overlay → "Insert into Field" dispatches React-compatible events

**Approach A (PDF Resume Upload)** — optional follow-up via T37 (wom7api integration).

## Acceptance Criteria

- [x] **AC1** — `manifest.json` content script injected on `https://my.indeed.com/*` and `https://www.indeed.com/*` (`wom7ext/extension/manifest.json`, `wom7ext/extension/manifest.firefox.json`, `wom7ext/extension/scripts/build-manifest.mjs`).
- [x] **AC2** — `extension/specs/indeed.profile.json` and `extension/src/specs/indeedProfileSpecs.ts` created with 4 actions:
  - `indeed.profile.fill_summary` (`indeed_fill_summary`) — Professional Summary from canonical `profile_cv_facts` + headline/about
  - `indeed.profile.fill_experience_bullet` (`indeed_fill_experience_bullet`) — bullet points for focused experience field from `profile_experience`
  - `indeed.profile.fill_skills` (`indeed_fill_skills`) — clean comma-separated skills list
  - `indeed.profile.fill_education` (`indeed_fill_education`) — formatted education entry
- [x] **AC3** — `background.ts` routes `indeed.profile.*` and `indeed_fill_*` action IDs to `formFillerService.ts`.
- [x] **AC4** — `popup.ts` detects `my.indeed.com` (`isIndeedResumeUrl`) and shows the Indeed Profile Form Filler Helpers section.
- [x] **AC5** — `popup.html` shows buttons for all 4 actions when on Indeed (`btn-indeed-summary`, `btn-indeed-experience`, `btn-indeed-skills`, `btn-indeed-education`).
- [x] **AC6** — All 4 actions generate contextually correct text using canonical `profile_cv_facts` / `profile_experience` (and cached profile state) via `mapCanonicalProfileToIndeedFields` (`wom7ext/extension/src/services/__tests__/indeedProfileSpecs.test.ts`).
- [x] **AC7** — "Insert into Field" (`setReactCompatibleInputValue` / `fillIndeedProfileField` in `indeedProfileSpecs.ts` and `specEngine.ts`) populates Indeed text areas using the native `HTMLInputElement`/`HTMLTextAreaElement` prototype value setter and dispatches bubbling `input` and `change` events.

## DOM Strategy

Use `aria-label`, `data-testid`, and `label[for=X]+input#X` selectors — **avoid dynamic class names** like `css-1q2m4rd` which break on Indeed deploys. Our `focusedText` virtual field sidesteps this entirely.

## Definition of Done

- Extension content script active on Indeed.
- All 4 buttons visible in popup on `my.indeed.com/resume/*`.
- Each action generates relevant, profile-sourced text in overlay.
- Text successfully inserts into Indeed form fields.
- Build passes. Pre-commit hooks pass. Committed to `beta`.
