# T66 — Indeed Profile Form-Fill Helpers (wom7ext)

## Summary

Add Indeed.com as a supported platform in `wom7ext` for semi-automatic profile fulfillment. No public API exists — the approach is DOM-based form fill using the existing `formFillerService.ts` and `specEngine.ts` infrastructure (same pattern as Upwork/Fiverr, zero new architecture needed).

Source of truth: `linkedin_canonical_personal` already stored in `chrome.storage.local`.

## Approach

**Approach B (Field-by-Field Extension Fill)** — implement first. Takes ~1.5 hrs.

1. User navigates to `my.indeed.com/resume/edit/*`
2. Extension popup shows Form Filler Helpers section
3. User focuses a text field, clicks an action button
4. LLM generates text → overlay → "Insert into Field" dispatches React-compatible events

**Approach A (PDF Resume Upload)** — optional follow-up via T37 (wom7api integration).

## Acceptance Criteria

- [ ] **AC1** — `manifest.json` content script injected on `https://my.indeed.com/*` and `https://www.indeed.com/*`
- [ ] **AC2** — `extension/specs/indeed.profile.json` created with 4 actions:
  - `indeed.profile.fill_summary` — Professional Summary from LinkedIn `about` + `headline`
  - `indeed.profile.fill_experience_bullet` — bullet points for focused experience field
  - `indeed.profile.fill_skills` — clean comma-separated skills list
  - `indeed.profile.fill_education` — formatted education entry
- [ ] **AC3** — `background.ts` routes `indeed.profile.*` action IDs to `formFillerService.ts`
- [ ] **AC4** — `popup.ts` detects `my.indeed.com` hostname and shows Form Filler Helpers section
- [ ] **AC5** — `popup.html` shows buttons for all 4 actions when on Indeed
- [ ] **AC6** — All 4 actions generate contextually correct text using stored LinkedIn profile
- [ ] **AC7** — "Insert into Field" successfully populates Indeed text areas (React `input`/`change` events fire)

## Key Indeed URLs

| Page | URL Pattern |
|---|---|
| Profile overview | `my.indeed.com/resume` |
| Work experience | `my.indeed.com/resume/edit/experience` |
| Education | `my.indeed.com/resume/edit/education` |
| Skills | `my.indeed.com/resume/edit/skills` |
| Summary | `my.indeed.com/resume/edit/summary` |

## DOM Strategy

Use `aria-label`, `data-testid`, and `label[for=X]+input#X` selectors — **avoid dynamic class names** like `css-1q2m4rd` which break on Indeed deploys. Our `focusedText` virtual field sidesteps this entirely.

## Definition of Done

- Extension content script active on Indeed.
- All 4 buttons visible in popup on `my.indeed.com/resume/*`.
- Each action generates relevant, profile-sourced text in overlay.
- Text successfully inserts into Indeed form fields.
- Build passes. Pre-commit hooks pass. Committed to `beta`.
