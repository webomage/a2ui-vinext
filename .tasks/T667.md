# T667 — Purge internal ticket and AgDR numbers from user-facing UI copy and enforce a no-ticket-spam UI gate

## Summary

Internal SDLC tracking identifiers — ticket numbers (`T53`, `T21`, `T476`, `T442`, `T537`, `T99`, `T272`, `T229`, `T60`, `T359`, `T452`, `T111`, etc.), architectural decision IDs (`AgDR-0003`, `AgDR-0014`, `AgDR-0019`, `AgDR-0025`, `AgDR-0028`), and acceptance-criteria markers (`AC4`, `AC6`, `AC9`) — have leaked into user-facing UI headings, card titles, badges, labels, status chips, table headers, and client/member portal descriptions across `w0m-web` (`apps/cp`, `apps/web`, and UI-rendered catalogs in `packages/lib`).

Internal ticket and decision IDs belong in commit messages, `.tasks/T##.md`, `openspec/`, `docs/decisions/`, and code comments — never in product UI copy shown to clients, members, visitors, or operators (outside dedicated engineering quest-tracker data models whose domain entity is literally a ticket ID).

## Acceptance criteria
