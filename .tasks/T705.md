# T705 — Adopt Google Elephant-Goldfish Model (EGM), 3-Tier Project Dev Modes (ultra/balance/wise) & Fast Session-Complete, and Remove @k7 UI Mentions + Seed Webomage Live Audit Results

## Summary

1. **Remove all user-facing `k7` / `@k7` mentions from Audit UI & Website (`w0m-web`) and run/seed our own live Webomage audit results:** Replace internal `@k7*` / `@k7c` / `@k7tg` / `@k7s` branding across `ClientDashboard.svelte`, `SecurityAuditReportViewer.svelte`, `SubscriptionManager.svelte`, `ChatApp.svelte`, `AuditPricing.svelte`, `order-form-state.ts`, `passive-audit.ts`, `advanced-audit.ts`, `entitlements/index.ts`, and `knowledge-snapshot.json` with clean industry-standard Cloud Infra / FinOps / Terraform / OpenTofu / Inframap terminology, execute our live L1/L2/L3 + Lighthouse audit suite against `webomage.com`, `cp.webomage.com`, and `me.webomage.com`, and seed the live results into `orgs.service_usage` (`webomage` and `aleksei-tcelishchev`).
2. **P0 — Adopt Google's Elephant-Goldfish Model (`https://github.com/google/elephant-goldfish-model`):** Fork `google/elephant-goldfish-model` to `github.com/webomage/elephant-goldfish-model`, vendor and register its 7 skills (`egm-brainstorm`, `egm-draft`, `egm-resolve`, `egm-bootstrap`, `egm-review`, `egm-review-loop`, `egm-drift-report`) into `w0m-skills` and `.w0m/skills.json` (`just skills-sync`), and wire the Elephant (persistent context builder) + Goldfish (stateless zero-memory adversarial reviewer) loop into `.w0m/sdlc.json`.
3. **3-Tier Project Development Mode (`ultra`, `balance`, `wise`) & Fast Worktree Landing (`scripts/dev_mode.py`, `scripts/session_complete.py`, `justfile`):** Diagnose why `session-complete` / `agent-tree-land` took ~15–31 minutes (`refresh_canonical_graph_union` running full `kb_vector` + `graph_global` rebuilds on every worktree land plus 3x duplicate `certify_estate_tree` / `.husky/pre-push` executions), introduce `just mode [status|ultra|balance|wise]` (`W0M_DEV_MODE`), deduplicate pre-land/land certification, and move shared estate-wide rebuilds (`kb_vector` + `graph_global` + full-estate `mmd-validate` / `py-typecheck`) to `just deploy` (`_deploy-preflight`) and `wise` mode.
