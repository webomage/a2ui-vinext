# T256 — no emoji where a matcher reads, Markdown and Mermaid by default

## Summary

Owner instruction, 2026-08-22:

> *"since emoji cause a lot of issues with parsing so let's prohibit using emojies in logs, reports,
> etc and use everywhere .md/.mmd format as default / add gates"*

**The instruction was earned the same day it was given.** Hours earlier, a grep of `ROADMAP.md` for
section 33 reported **no match** — so the conclusion drawn was that [[T254]]'s epic did not exist.
It does. The heading reads `## <pictograph> 33. Client Closed Beta`, with a pictograph between the
hashes and the number. Seven tickets cite that section and every one of them was correct. The
matcher was wrong, and a pictograph is why.

## Measuring first changed the design completely

A literal reading — *delete the emoji* — would have broken the estate. Two measurements:

| measurement (2026-08-22) | |
|---|---|
| emoji in markdown headings, authored files, whole estate | **3,451** |
| emoji-bearing output lines in `project/scripts` | **805** |
| …of those, lines whose ONLY emoji is a **protocol glyph** | **582** |
| parsers that read emoji **as data** | **6** hand-found → **9 declared**, from **45** swept matcher sites |

🔴 **Six parsers read emoji as values.** The decisive one is `run_suites.py:44`:

```python
CHECK = re.compile(r"^\s*[<pass><fail>]\s", re.M)
```

**The suite runner counts every probe's pass/fail by matching emoji.** Stripping emoji from script
output while leaving that regex alone would make all 124 suites report **zero checks and pass
vacuously** — a false green across the entire test aggregate, produced by obeying a cleanup
instruction literally. `tasks_bounds.py` is the same shape: `STATUS_GLYPH` means a TASKS.md row's
status *is* the glyph.

⇒ So emoji here are **protocol**, not decoration, and the gate **asserts the coupling** instead of
banning the glyph. And a gate firing 3,451 times gets switched off ([[T135]] AC8), so the rest
ratchets.

## The three tiers

| tier | rule | why |
|---|---|---|
| **HARD** | markdown headings in the 9 governance docs → **zero** | a heading is what other files cite by number; this is the position that actually broke |
| **PROTOCOL** | a glyph a parser reads → **asserted**, printed every run | removing it silently breaks the parser in the direction nobody watches |
| **RATCHET** | everything else → count may fall, never rise | 3,451 occurrences cannot be fixed in one commit, and pretending otherwise produces a gate nobody runs |

⚠️ **The boundary is declared, not guessed.** The arrow, em-dash, middot, section sign and
box-drawing rule are **not** emoji: single-width, no variation selector, and no matcher in this
estate has ever broken on one. Six probes pin that, because over-application is the real risk of
this instruction — a gate that flagged `session → device → user` would fire on thousands of lines
that were never the problem.

## Two defects the gate found in its own author

🔬 **① The first baselines were measured from the wrong corpus.** I wrote 4,266 and 918 — counted
*before* the exclusion list existed, so generated `graphify-out/` reports (31 emoji headings apiece)
counted as authored text. The gate then **congratulated itself on a 754-heading improvement it had
not earned.** Baselines are now the gate's own measurement, so gate and baseline cannot disagree by
construction. That is the **third wrong-corpus error of the day** after the `wom7mlx` path and the
ROADMAP heading itself: *a survey that starts at the wrong root describes a different system
accurately.*

🔬 **② The ratchet counted the protocol it was built to protect.** Writing the probe file for this
gate raised `script_output` from 801 to 805 — because a probe prints its results with the very
glyphs `run_suites` parses. **A ratchet that counts protocol glyphs is a ratchet whose only way to
go green is to break the parser.** The zone now counts decorative emoji only: **223, not 805**. The
number got smaller because it started measuring the thing the instruction was actually about.

🔬 **③ And the format gate caught a waiver of mine.** An acknowledgement reading only *"Same
deliverable, private variant"* — 33 characters, a waiver wearing a reason's clothes. Fixed by
writing the reason, not by lowering the bar.

## Definition of Done

Per [`../../openspec/SPEC-AUTHORING-STANDARD.md`](../../openspec/SPEC-AUTHORING-STANDARD.md): both
gates shown red on real data then green, probes proving each discriminates in both directions,
registered as blocking suites, the estate's meta-gates re-run after the recipes landed, the rules in
`CLAUDE.md`, and TASKS.md plus this ticket in sync.

🔴 **Explicitly NOT done, and not claimed:** the **3,012** heading occurrences and **115** decorative
output lines outside the hard zone are **held by ratchet, not fixed**. ⚠️ Those two numbers are
*lower* than the 3,451/223 first written here, and the reason matters: **no emoji were removed to
achieve it.** The count fell because the sweep proved four more glyphs are protocol, so the
classification got more accurate. A baseline that falls from work done and one that falls from
measurement improved are different events, and the policy records each with its cause. Retiring the six protocol couplings —
which is what "no emoji in logs" fully means — is a producer-and-parser migration across 141
scripts, tracked as [[T257]]. Saying otherwise would be the false-green this ticket exists to stop.
