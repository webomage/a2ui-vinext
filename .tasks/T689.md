# T689 — Domain ownership verification: CF/AWS/DO/GoDaddy guidance, automation, AI agent tabs, webomage.com record & db-drift-check timeout/redaction fix

## Summary

1. During release `2026.11.09-1794256975` (`just deploy-all`), `db_drift_check.py`'s `dry_run_pending_migrations()` timed out after 120 seconds without `PGCONNECT_TIMEOUT`, `lock_timeout`, or transient connection retry, and formatted `SubprocessError.__str__()` containing the raw `DATABASE_URL` password on `argv` (triggering `deploy_logged.py`'s `REDACTED 1 secret-shaped value(s): {'pg-url': 1}` alarm).
2. In Client Portal (`/o/[org]/projects/security-audit`), confirming website ownership for `webomage.com` and client domains required provider-specific DNS guidance + CLI/IaC/API automation for Cloudflare (`CF`), AWS Route 53 (`AWS`), DigitalOcean (`DO`), and GoDaddy, dedicated AI Agent instruction tabs (`Universal Agent Prompt`, `DNS & Cloud Ops Agent`, `Web Repo & Deploy Agent`), and live provisioning of `_w0m-verify.webomage.com` (`w0m-site-verification=w0m-verify-dcea66578113a6ea7e3745cc2952c8de`).

## Acceptance criteria

- [x] AC1 — **Fix `db_drift_check.py` credential leak and dry-run timeout resilience:** Redact any `postgres(ql)://` URL from subprocess error messages (`_redact_db_url`), set `PGCONNECT_TIMEOUT=15` + `SET LOCAL lock_timeout = '15s';` + `SET LOCAL statement_timeout = '60s';`, and retry transient connection/timeout failures (`max_attempts=3`) before failing.
- [x] AC2 — **Add provider-specific DNS guidance & CLI/IaC/API automation (`Cloudflare`, `AWS Route 53`, `DigitalOcean`, `GoDaddy`):** Add `buildDnsProviderGuides` and `provisionDomainOwnershipDnsTxt` (`action === "auto_provision_dns"`) across `domain-ownership.ts`, `/api/client/security-audit.ts`, and `SecurityAuditReportViewer.svelte`.
- [x] AC3 — **Add dedicated AI Agent instruction tabs (`Universal Agent Prompt`, `DNS & Cloud Ops Agent`, `Web Repo & Deploy Agent`):** Render copyable agent prompts + verification commands in `SecurityAuditReportViewer.svelte` (`buildAgentOwnershipGuides`) and auto-verify across both `dns_txt` and `http_well_known` (`verifyDomainOwnershipAnyMethod`).
- [x] AC4 — **Provision canonical `_w0m-verify.webomage.com` DNS TXT record on Cloudflare & repo:** Create live `_w0m-verify.webomage.com` TXT record on Cloudflare (`id: e594ac64531a576364f3f1cc1608e1f7`), codify `cloudflare_record.webomage_w0m_verify_txt` in `w0m-api/cloudflare/records.tf` and `w0m-web/apps/web/public/.well-known/w0m-verify.txt`, and verify `webomage.com` in `public.domain_ownership_verifications` (`86669d0d-fec3-4f57-92b0-f64f7265b433`).
- [x] AC5 — **Unit and regression verification:** Pass `test_migration_versions_unique.py` (`23/23`), `domain-ownership.spec.ts` (`10/10`), `security-audit-order.test.ts` (`5/5`), `test_t336_security_audit.py` (`6/6`), `svelte-typecheck-ratchet` (`4/4` apps, `0` errors), `ds-conformance`, `supabase-surface-drift`, and `ui-ticket-leak-check`.
