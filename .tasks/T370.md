# T370 — Tooling: add default command with general info overview across estate justfiles

## Summary

Owner ask, 2026-09-17: *"let's have default command with general info for our justs having there docs for command is too much and commands changes a lot"*.

Previously, running bare `just` at the workspace root executed `@just --justfile wom7web/justfile --list`, which dumped 400+ recipes and hundreds of lines of detailed command docstrings to the terminal. In `wom7web/justfile` (and symlinked `wom7api/justfile` and `wom7cfworkers/justfile`), there was no `default` recipe, which caused `just` to fall back to the first recipe in the file (`deploy-contact`). While gated by `_confirm`, running a deployment target by default on bare `just` is unexpected and suboptimal.

This ticket introduces an explicit, clean `default` recipe printing a concise general info overview of core workflows (queue triage, PR tracking, knowledge graph, tests, dev server) and pointers for command discovery, avoiding overwhelming doc dumps and accidental deploy triggers.

## Acceptance criteria

- [x] AC1 — Explicit `default` recipe defined in `wom7web/justfile` (shared by `wom7api` and `wom7cfworkers`) preceding `deploy-contact`, outputting a concise general info banner.
- [x] AC2 — Root `justfile` `default` recipe updated to forward to the general info recipe rather than raw `--list`.
- [x] AC3 — The general info screen highlights key daily commands (`tasks`, `prs-open`, `ask`, `test`, `dev`, `status-dashboard`) and documents discovery flags (`just --list`, *just <recipe>*).

- [x] AC4 — Automated test verifies that bare `just` in root and `wom7web` renders the general info banner and does not invoke `deploy-contact` or raw `--list`.
- [x] AC5 — All SDLC gates (`just dod-check --ticket T370`, `just emoji-check`, `just state-check`) pass.

## Definition of Done

Bare `just` execution from both the workspace root and `wom7web` (and symlinked `wom7api`, `wom7cfworkers`) reliably prints a concise general info summary of primary commands without invoking `deploy-contact` or dumping the full `--list` catalogue. Verified by automated tests and passing estate quality gates.
