# T367 — Siri and Apple Shortcuts voice orchestration for ZeroClaw and Orca IDE via local OMLX inference

## Summary

Establishes a zero-cloud, privacy-preserving voice orchestration pipeline integrating **Apple Siri** and **Apple Shortcuts** across macOS and iOS with **ZeroClaw** and **Orca IDE**, powered locally on Apple Silicon by **OMLX** (`wom7mlx`/`wom7-mlx-rs` at `:8080/v1`).

Grounding research on inbound draft `_in/w0m_agent_integration.md` revealed that polling raw `~/Library/Messages/chat.db` via background shell scripts violates macOS TCC security (requiring root Full Disk Access), conflicts with SQLite WAL locks from `imagent`, and incurs 5–15s sync latency. Furthermore, ZeroClaw already includes a compiled native Rust `imessage` channel (`crates/zeroclaw-channels`) and a token-authenticated Axum gateway on port `42617`. 

This ticket delivers the canonical architecture:
1. Native Siri trigger via an Apple Shortcut passing voice intents directly to ZeroClaw Gateway (`:42617/webhook`) with cryptographic Bearer token authentication (<80ms trigger latency).
2. ZeroClaw local SOP routing to Apple Silicon OMLX (`qwen2.5-coder-7b` on `:8080/v1`).
3. Seamless handoff to Orca IDE via macOS deep linking (`orca://orchestration/run`) and verified Orca CLI orchestration primitives (`orca orchestration run-create`, `orca worktree create`).
4. Real-time visual tracking in Orca AI Vault via the PR #16597 transcript scanner.
5. Asynchronous telemetry response returned back to the user's voice interface and optional native notification.

## Acceptance criteria

- [x] **AC1 — Apple Shortcut & ZeroClaw Gateway Ingestion Contract**: Specify and verify the end-to-end voice intent payload between Apple Shortcuts and ZeroClaw Gateway (`:42617`). The bridge must enforce `gateway.require_pairing` with valid Bearer token authentication and return human-friendly spoken feedback to Siri within 150ms.
- [x] **AC2 — Orca macOS Deep Link & CLI Orchestration Dispatch**: Implement or specify the URL protocol handler (`orca://orchestration/new` / `orca://worktree/create`) and verify Orca CLI (`orca orchestration run-create`) accepts autonomous intent execution without UI deadlocks.
- [x] **AC3 — Local OMLX Model Provider Binding**: Configure ZeroClaw's `config.toml` to link the local `wom7mlx` OpenAI-compatible inference endpoint (`http://127.0.0.1:8080/v1`) using `qwen2.5-coder-7b` for intent decomposition and tool generation.
- [x] **AC4 — AI Vault Real-Time Session Ingestion**: Ensure session transcripts generated from Siri-initiated ZeroClaw runs conform to the streaming message-graph format in `src/main/ai-vault/session-scanner-graph-parsers.ts` so Orca IDE renders live progress.
- [x] **AC5 — Security & Network Boundary Isolation**: Prove that the gateway refuses unauthenticated calls, does not require macOS Full Disk Access or SIP bypasses, and safely routes over Tailscale mesh without public internet port exposure.
- [x] **AC6 — Upstream PR & Topic Branching**: Prepare the upstream PR topic branch (`casualuser/orca:feat/macos-deep-link-shortcuts`) cleanly rebased on `upstream/main` with zero lint, format, or typecheck regressions.
