# T699 — Crypto Smart-Contract Security Auditing & Coin / Tokenomics Intelligence Service

## Summary

Expand the Webomage Security & Craftsmanship Audit platform (`w0m-web`) with a dedicated **Crypto Smart-Contract Audit & Coin / Tokenomics Intelligence** product line. This service enables Web3 protocols, DeFi teams, L1/L2 ecosystems, and institutional diligence desks to order read-only static + formal-invariant smart-contract audits across **Solidity / EVM**, **Rust / Solana (Anchor)**, and **Move (Sui / Aptos)** alongside structured **Coin & Tokenomics Risk Intelligence** (mint/freeze authority inspection, upgrade-proxy admin key centralization, liquidity lock & holder concentration, vesting cliff unlocks, oracle manipulation vectors, and regulatory/sanctions exposure).

## Acceptance criteria

- [x] AC1 — **Read-Only Multi-Chain Smart-Contract Static & AST Audit Engine (`packages/lib/src/security/crypto-contract-audit.ts`):** Implement zero-execution static analysis and AST pattern detectors for Solidity/EVM (reentrancy, unchecked external calls, delegatecall/UUPS storage collisions, flash-loan price oracle manipulation, ERC-20/ERC-4626 inflation vectors), Rust/Solana Anchor (missing signer/owner checks, arbitrary CPI, PDA bump seed canonicalization, arithmetic overflow), and Move (capability leak, resource drop/copy safety).
- [x] AC2 — **Coin, Tokenomics & On-Chain Governance Intelligence Module (`packages/lib/src/security/coin-intelligence.ts`):** Build a structured coin/token profile and risk-scoring engine covering supply schedule & mint/burn/freeze authorities, proxy upgradeability & multisig timelock posture, top-holder & LP lock concentration, oracle dependency topology, and tokenomics sustainability metrics.
- [x] AC3 — **Public Ordering & Selector Integration (`/audit`, `/services`, `/solutions`):** Add Crypto Smart-Contract & Coin Intelligence package and by-request ordering selectors (target chain: Ethereum/EVM, Arbitrum/Base/Optimism, Solana, Sui/Aptos; target input: verified contract address, GitHub repo, or token symbol/address) with fast OAuth / magic-link registration.
- [x] AC4 — **Client Portal Crypto Audit & Coin Intelligence Report Tab (`SecurityAuditReportViewer.svelte`):** Render interactive smart-contract vulnerability findings (SWC / DeFi threat taxonomy, severity, line-level remediation diff) and Coin / Tokenomics Intelligence scorecards inside the Client Portal Security Audit Workbench.
- [x] AC5 — **Unit & Schema Conformance Tests:** Add comprehensive unit tests covering Solidity/Solana/Move vulnerability detection, coin intelligence scoring, and UI/API contract conformance with zero external paid RPC dependencies on the free tier (`AgDR-0055`).
