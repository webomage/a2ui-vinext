# T682 — `k7kb` Knowledge Base, SEO/GEO/Security Scanner, Enterprise Observability, Same-Host ACP Management & TabLinux Integration

## Summary

Onboard the `@k7` Knowledge Base, Data Mining, SEO/GEO/Security, Enterprise Observability, and Same-Host Agent Client Protocol (ACP) TUI/CLI project (**`k7kb`**, registered as Module #10 `[0] kb` in **`k7hub`**) alongside `@wom` crew tools and **`TabLinux`** (`LinuxOnTab`) integration across `w0m-web/apps/cp` (`/me/work`), `Orca`, and `@k7`:

1. **`k7kb` 6-Tab Rust TUI & CLI (`k7kb` + `k7 --module kb`)**:
   - **Tab `[1]` / `k7kb search`**: Hybrid RRF (`hybrid`, `bm25`, `vector`) search across the `1,938`-doc / `18,489`-chunk `@wom` Knowledge Base (`scripts/w0m_kb_vector.py`).
   - **Tab `[2]` / `k7kb vaults`**: Per-project Obsidian vault inspector (`10` projects), `.md` note counts, `<project>@webomage.com` Mistral scopes (`MISTRAL_API_KEY_<PROJECT_UPPER>`), `r2://<slug>/` prefixes, and `cross_project_access = false`.
   - **Tab `[3]` / `k7kb datamine`**: Corpus category distribution and HDBSCAN semantic topic clusters.
   - **Tab `[4]` / `k7kb analytics [--probe]`**: 10-channel Product, Marketing & Enterprise Observability connectors (**Microsoft Clarity**, **Google Analytics 4**, **Meta Business / Pixel**, **LinkedIn**, **PostHog**, **Tinybird + Cloudflare Edge**, **Sentry Enterprise**, **Datadog Enterprise**, **Grafana Cloud / LGTM**, and **OpenTelemetry + PagerDuty**) with automatic `infisical export` fallback and redacted `sha256:` fingerprints.
   - **Tab `[5]` / `k7kb seo-geo <url>`**: Crew **SEO, GEO (Generative Engine Optimization), and Perimeter Security Scanner** evaluating HTML metadata, `/robots.txt`, `/sitemap.xml`, `/llms.txt`, Schema.org JSON-LD entity graphs, AI crawler directives (`GPTBot`, `ClaudeBot`, `PerplexityBot`, `Mistral`), and HTTP security headers + RFC 9116 `/.well-known/security.txt`.
   - **Tab `[6]` / `k7kb acp`**: **Same-Host Agent Session Discovery & Agent Client Protocol (`2025-03-26`) JSON-RPC 2.0 Manager** (`initialize`, `session/new`, `session/load`, `session/prompt`, `session/cancel`, `host/discover`).
2. **Same-Host ACP Discovery & Crew Scanner (`scripts/acp_host_discovery.py` + `scripts/tests/test_acp_host_discovery.py`)**:
   - Discovers active `@wom` agent worktrees, `Antigravity` sessions, `Claude Code` projects, `Orca` host session bus, and `Mistral Vibe` (`vibe-acp`) endpoints (`just acp-discover`, `just acp-msg`, `just seo-geo-scan`).
3. **`w0m-cp` & `TabLinux` Crew Integration (`w0m-web/packages/lib/src/security/seo-geo-scanner.ts` + `w0m-web/apps/cp/src/components/admin/CrewToolkitAndTabLinuxConsole.svelte`)**:
   - Mounted in `w0m-web/apps/cp/src/pages/me/work.astro` using 100% `@webomage/ui` primitives (`Card`, `Badge`, `Button`, `InputComponent`, `Select`) and wired to `TabLinux` (`/shell/?module=<slug>&project=<project>&env=beta`).
