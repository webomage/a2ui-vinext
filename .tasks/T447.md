# T447 — Process the _in tray: each item shows whether it became a spec, a ticket or code, or is still new

## Summary

`_in/README.md` says the tray is not an archive: pick an item up, act on it, move it out. In practice nothing moves
out, and there is no way to see which items were already turned into specs, tickets or code.

Measured 2026-09-25: **25 items** (plus `README.md` and `active-work.json`), dated 2026-09-02 to 2026-09-25.
**18 are not cited by filename** in any ticket, OpenSpec change, `docs/` file or `STATE.md`. 7 are cited 1-4 times.
Filename citation undercounts: a ticket may carry an item's content without naming the file. So the processing
has to read each item, not just grep for it.

## Acceptance criteria

- [x] AC1 — **Disposition ledger.** Each `_in` item has one state: `new`, `adopted` (with where: ticket id, OpenSpec
  change, report path or commit), `declined` (with a reason) or `living` (e.g. `active-work.json`). It lives in one
  file (`_in/INDEX.md`, generated from front-matter or a sidecar), so the owner sees at a glance what is new.
- [x] AC2 — **Triage recipe.** `just in-triage` lists items by state and age. For each `new` item it shows which
  tickets or specs *look* related (graph and search hits), so the reader decides with the evidence in front of them.
  It never auto-adopts.
- [x] AC3 — **Process the backlog.** All 25 current items get a state. Adopted items move out of `_in` (to
  `docs/reports/` or into the ticket) with a pointer left in the ledger. `Lahore_*` (client prospect material) goes
  to the client-projects tier, never the public KB (KB content policy).
- [x] AC4 — **Gate.** `just in-check` fails when an item has no state or has sat `new` longer than the declared
  limit. Red probes in `just in-check-test`. It runs at session start (`just preflight`) so an agent sees new drops.
- [x] AC5 — **Drop protocol.** `_in/README.md` says how a dropping agent records the item (state `new`, author,
  date) and how a picking-up agent closes it. The AGENTS.md session-start section points at `just in-triage`.
