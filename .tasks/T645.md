# T645 — Add in-session `just session-complete` SDLC wrap-up CLI (`scripts/session_complete.py`) and normalize post-deploy Orca session surfaces

## Summary

`.w0m/sdlc.json` (`session_wrapup`, `T613`) and `AGENTS.md` mandate a 6-step wrap-up and 9 verification gates before ending any agent session or handing off human-gated deploys, yet `justfile` previously lacked a single callable `just session-complete` recipe. Agents had to manually run ~12 separate commands across member repos, causing repeated wrap-up drift (`T635`/`T638`/`T639` left with `queue != done`, `.agents/reports/*.md` unmirrored to `w0m-web/docs/reports/`, concurrent `T##` collisions at `agent-tree-land`, or removed worktree `getcwd` errors when invoked from inside a live session).

This ticket delivers `scripts/session_complete.py` + `just session-complete` (`just session-complete-test` registered in `w0m-web/project/test-suites.json`), designed specifically to be called **from inside the active agent session** without killing the caller's live terminal, and dogfoods `just session-complete` inside this session to normalize `T627`, `T635`, `T638`, `T639`, and `T645`.
