# T647 — Orca Mobile: default 4-side arrow keys to Floating Orbs and hide quick-switcher chips by default

## Summary

1. **Default 4-Side Edge Arrows to Floating Orbs (`'orbs'`)**: Changed `DEFAULT_EDGE_NAVIGATION_MODE` in `mobile/src/navigation/edge-arrows/edge-navigation-preference.ts` from `'pills'` to `'orbs'` (and resolved `cycleEdgeNavigationMode('off')` to `DEFAULT_EDGE_NAVIGATION_MODE`) so compact circular half-transparent `Floating Orbs` are the out-of-the-box arrow-key experience across terminal, agent-session, and content panes while keeping `'pills'`, `'strips'`, `'gamepad'`, and `'off'` selectable.
2. **Hide Quick-Switcher Chips by Default (`DEFAULT_EDGE_SWITCHER_CHIP_HIDDEN = true`)**: Added `DEFAULT_EDGE_SWITCHER_CHIP_HIDDEN = true` in `edge-navigation-preference.ts` (`isEdgeSwitcherChipHidden` returns `true` when unset and respects explicit boolean `false` or `true`), and updated `optionalEdgeFields` in `mobile/src/terminal/terminal-accessory-layout.ts` plus `setTerminalEdgeNavigationMode` / `setTerminalEdgeSwitcherChipHidden` (destructuring `{ version: _version, ...nextLayout }` from `createTerminalAccessoryLayoutPreference` so stacked overlay gesture fields survive intact) to serialize explicit boolean `edgeSwitcherChipHidden` (`true` and `false`) without adding extra keys to `getDefaultTerminalAccessoryLayout()`.
