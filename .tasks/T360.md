# T360 — Personal profile experience, member Upwork sync, and per-profile resume vault

## Summary

Currently in the w0m ecosystem, member career history and Upwork data are fragmented and disconnected from the personal profile entity (`public.profiles`):
1. **Flat Profile Career Fields**: `public.profiles` only stores scalar `years_experience: integer` and `seniority: varchar`, with no structured relational model for past jobs, projects, contracts, companies, or timeline accomplishments.
2. **Estate-Centric Upwork Sync**: Upwork credentials and sync routines (`upwork-poller`, `upwork_auth_tokens`) are tied to the estate/agency level, with contracts inserted into a global `public.contracts` pool lacking member attribution. Individual guild members cannot connect their personal Upwork accounts or sync their personal contracts into their w0m profile.
3. **Resume Storage Detached from Profile Relational Schema**: Resumes are uploaded to unstructured paths with parsing (`parse-resume`) only extracting skill tags (`profile_skills`), discarding work history and not versioning or backing resume documents per profile.

This ticket moves experience handling and Upwork syncing to the **personal profile level**, delivering:
- A dedicated, RLS-governed `public.profile_experience` table for rich work history.
- Per-profile Upwork OAuth connection integration via `public.connections` (`owner_kind = 'member'`), enabling members to sync their Upwork contracts directly into their profile experience.
- A per-profile resume vault (`public.profile_resumes` and storage under `resumes/${profile_id}/`) with structured parsing that populates work experience into `profile_experience`.
- UI surfaces in Admin CP and Member Portal for managing experience, resumes, and Upwork sync.

## Acceptance criteria

- [x] AC1 — Database Migration for Profile Experience: Create `public.profile_experience` (`id uuid primary key`, `profile_id uuid references public.profiles(id) on delete cascade`, `company text not null`, `title text not null`, `location text`, `employment_type text`, `start_date date not null`, `end_date date`, `is_current boolean default false`, `description text`, `skills text[] default '{}'`, `source text not null check (source in ('manual', 'resume', 'upwork', 'linkedin'))`, `source_id text`, `created_at timestamptz default now()`, `updated_at timestamptz default now()`). RLS enabled: authenticated read, member profile owner manage (`auth.uid() = profiles.auth_user_id` or admin).
- [x] AC2 — Database Migration for Per-Profile Resumes: Create `public.profile_resumes` (`id uuid primary key`, `profile_id uuid references public.profiles(id) on delete cascade`, `storage_path text not null`, `file_name text not null`, `file_size integer`, `mime_type text default 'application/pdf'`, `parsed_data jsonb`, `is_primary boolean default true`, `created_at timestamptz default now()`). Configure storage policies on `cv`/`resumes` bucket ensuring member-isolated paths under `resumes/${profile_id}/*`.
- [x] AC3 — Member Upwork Sync Integration: Build per-profile Upwork synchronization endpoint/service. When triggered with a member's personal Upwork connection (`public.connections` where `owner_kind = 'member'` and `profile_id = profile.id`), fetches personal contracts/feedback and maps completed contracts into `public.profile_experience` rows tagged with `source = 'upwork'`.
- [x] AC4 — Resume Parser Experience Extraction: Upgrade resume ingestion to parse structured work history (roles, companies, dates, bullet points) alongside skills, writing structured entries to `public.profile_experience` (with `source = 'resume'`) and registering the document in `public.profile_resumes`.
- [x] AC5 — Member & Admin Profile Experience UI: Build and integrate profile experience timeline and resume vault components in `apps/cp` (`/profile`) and `apps/join` (`/dashboard`). Include manual CRUD for experience items, resume upload/viewing, and a 1-click "Sync from Upwork" action.
- [x] AC6 — Automated Tests & Verification: Vitest unit tests in `apps/cp` and `wom7api` testing experience CRUD, Upwork contract transformation, and resume extraction. Zero errors, zero warnings, zero hints across `just typecheck`.
