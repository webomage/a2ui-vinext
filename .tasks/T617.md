# T617 — Fix release worktree node_modules drift, enforce symlink-safe gitignore rules, and verify full deploy app builds

## Summary

Running `just deploy-all` (`2026.11.03-1793712665`) failed immediately at `release.verify()` before Touch ID / `db-migrate` with:

- `w0m-api: changed since checkout: ?? node_modules`
- `w0m-cf: changed since checkout: ?? node_modules`
- `w0m-ext: changed since checkout: ?? extension/node_modules`

Root cause had two coupled defects plus a hidden host-CPU binary crash uncovered by full isolated deploy-build verification:

1. **Git trailing-slash `.gitignore` rules do not ignore symlinks**: `w0m-api/.gitignore`, `w0m-cf/.gitignore`, `w0m-ext/.gitignore`, `w0m-web/.gitignore`, and `w0m-sec/.gitignore` only declared `node_modules/` (or `**/node_modules/`). In Git, a trailing `/` matches directories only — never symlinks — so symlinks created by `provision_worktree_fixtures()` appeared as untracked (`??`) in `git status --porcelain` across both release worktrees and `agent-tree` worktrees (whereas `w0m-skills/.gitignore` carried `node_modules` without `/` and stayed clean). Meanwhile `project/policies/ignore-policy.json` used `"match": "node_modules"`, allowing trailing-slash-only `node_modules/` rules to pass `just ignore-audit --enforce`.
2. **Release worktrees symlinked live `node_modules` before `pnpm install --frozen-lockfile`**: `scripts/release.py -> worktree(v, install=True)` (and `_stable_sync_unlocked` / `_stable_promote_unlocked`) called `provision_worktree_fixtures()` unconditionally before checking `if (d / "pnpm-lock.yaml").exists() and not (d / "node_modules").exists():`, causing `(d / "node_modules").exists()` to see the symlink to the live checkout and skip hermetic `pnpm install --frozen-lockfile` in `w0m-api` and `w0m-cf` (and never installing nested `w0m-ext/extension/pnpm-lock.yaml`).
3. **Unpinned `pnpm dlx pagefind` crashed with `SIGILL` (`exit 132`) on `aleksei@HP` (`AMD A10-5745M`)**: Running every `deploy-all` build step inside the isolated worktree proved all 5 Astro apps (`web`, `cp`, `join`, `job`, `demo`), provisioning gates, and 6 Wrangler dry-runs pass, and caught unpinned `pnpm dlx pagefind` pulling `pagefind@1.6.0`, whose static Linux `pagefind_extended` binary executes x86-64-v3/AVX2 instructions unsupported on x86-64-v2 hardware, whereas `pagefind@1.5.2` indexes all 43 pages (`ru`, `en`, `es`) in `0.31s`.

## Acceptance criteria

- [x] **AC1 — Enforce symlink-safe `node_modules` `.gitignore` rules across all governed JS repos & `ignore-policy.json`**: Added unslashed `node_modules` (and `**/node_modules` in `w0m-ext/.gitignore`) across `w0m-api/.gitignore`, `w0m-cf/.gitignore`, `w0m-ext/.gitignore`, `w0m-web/.gitignore`, and `w0m-sec/.gitignore`, tightened `project/policies/ignore-policy.json` required rule `"node_modules"` regex to `"^(\\*\\*/)?node_modules$"`, refreshed `w0m-web/project/scripts/layout_check.py --inventory`, and verified `python3 scripts/ignore_audit.py --enforce` + `just layout-check` pass with `0` untracked `node_modules` across all repos.
- [x] **AC2 — Separate hermetic frozen-lockfile installation (`install=True`) from agent-tree `node_modules` symlinking (`link_node_modules=True`) in `scripts/release.py`**: Parameterized `provision_worktree_fixtures(..., link_node_modules: bool = True)` and added `NESTED_PNPM_DIRS` / `pnpm_lock_targets()` in `scripts/release.py` so `agent-tree` (`w0m-web/project/scripts/agent_tree.py`) keeps fast read-only symlinks with `0` untracked files, while `worktree(v, install=True)`, `stable_sync(install=True)`, and `stable_promote(install=True)` pass `link_node_modules=not install` and install hermetically from `pnpm-lock.yaml` across both repo roots and `w0m-ext/extension`.
