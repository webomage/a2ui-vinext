  correctly. Re-pointing a skill onto canonical is worthless if nothing *keeps* it there.
  `skills.ts` synced only `w0m*` names and compared only `SKILL.md`; the hook was scoped
  `^\.(agents|claude)/skills/w0m` = **11 of 79**. Both widened:

    `supabase-postgres-best-practices` files unguarded (same blind spot as D4). An **active-only file
    is drift** too.
  - excluded from a skill's unit: a top-level **`<skill>-*`** subdirectory — a sibling skill misfiled
    inside another skill. Canonical `skills/w0m/` holds **13** of them plus `w0m-e2e-workspace`, none
    ever deployed; this rule keeps `w0m`'s synced unit byte-identical to what it already was. → [[T128]].
